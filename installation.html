Installation

Download. Copy. Run.

WysiQ is distributed as a single self-contained Windows executable.

The executable already contains:

  • documentation
  • multilingual help files
  • default configuration files
  • default AI profiles
  • application resources
  • workspace templates

Simply copy WysiQ.exe into any folder and run it.

There is no installation, no setup program and no administrator privileges required.

First launch and Microsoft Defender

At the first launch, Microsoft Defender may analyze the executable for approximately 20–30 seconds.

During this initial security scan, Windows may temporarily report that the application is not responding.

This is normal for a large self-contained executable.

When WysiQ starts for the first time, it automatically creates a complete workspace next to the executable by extracting all embedded resources, documentation, help files, AI profiles and default configuration files.

Fully portable environment

The executable and its workspace are fully portable.

The entire WysiQ environment can simply be copied to another folder, another disk, a USB flash drive or an external SSD, then executed on another Windows laptop, workstation or server without reinstallation.

Multiple independent workspaces can coexist on the same computer or on removable media, making it easy to organize projects, customers or demonstrations.
