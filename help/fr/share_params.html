CENTRE DE PARTAGE & PUBLICATION

TERMINOLOGIE
WysiQuery   L'ensemble live : table source + analyse (séries,
            métriques, filtres) + fenêtre graphe.
Query       Instantané WysiQuery sauvegardé (query.json dans queries/).
Queries     Pluriel — plusieurs fichiers Query.
WysiQ prépare des paquets de partage depuis un WysiQuery ouvert
(instantané graphe HTML) ou depuis une Query exportée (bundle ZIP) —
HTML interactif (PNG matplotlib avec zoom/pan dans le navigateur ;
Plotly en preview WiFi local), brief vocal optionnel, texte
d'analyse court — puis publie automatiquement là où c'est
possible et prépare des brouillons pour les réseaux sociaux.
Les exports Query ZIP suivent le même pipeline
(galerie, feeds, brouillon LinkedIn, canal Telegram).
Bouton 📦 Prep dans la palette distante du graphe :
  Clic gauche   = popup Prep (enregistreur + outbox)
  Clic droit    = basculer les contacts On/Off rapidement
Fenêtre principale → Share → Share Center, onglet Send :
  lister les fichiers préparés, choisir les destinataires, Envoyer.
  Les canaux automatiques (onglet Publish) s'exécutent à l'envoi, pas au Prep.

ONGLET SEND (OUTBOX)

Fichiers préparés dans :
  workspace/share/outbox/graphs/    HTML, PNG, PDF, WAV vocal
  workspace/share/outbox/queries/   bundles Query ZIP
Sources : Remote 📦 Prep, export Print, Query → Partager…
WhatsApp manuel : joindre les fichiers depuis share/outbox/graphs/ ou …/queries/

ONGLET PUBLISH (PUBLICATION)

CANAUX AUTOMATIQUES

  Telegram      diffusion vers canal + envoi direct aux contacts
  Discord       post via webhook — fichier + lien + légende si activé
  Site gallery  copie HTML/ZIP vers le dossier galerie local/public
  RSS           mise à jour de wysiq_feed.xml
  JSON feed     mise à jour de wysiq_feed.json pour site / API
  Cochez les canaux souhaités puis cliquez
  "Save publish options".
  TG channel ID   identifiant du canal ou groupe de diffusion
  TG bot id       optionnel — remplace le bot de bots.json
  Discord webhook   URL du webhook (paramètres du serveur Discord)
                    envoie pièce jointe HTML/ZIP + légende + lien

RÉSEAUX SOCIAUX SEMI-AUTOMATIQUES

  LinkedIn      copie le texte du post + ouvre LinkedIn dans le navigateur
  Reddit        prépare le titre / corps ; l'utilisateur soumet manuellement
  X / Twitter   ouvre l'intent tweet avec texte et lien
  Ces canaux ouvrent un onglet navigateur avec le brouillon
  pré-rempli. Vous complétez et publiez vous-même.

IDENTITÉ DU MESSAGE PAR DÉFAUT

  Site base URL    adresse de base liée dans tous les posts
                   ex. https://wysiq.org
  Default tags     hashtags ajoutés aux brouillons sociaux
                   ex. #WysiQ #DataVisualization #Analytics
  Signature        pied de page dans les posts générés
                   ex. Généré avec WysiQ

ONGLET GALLERY / FEEDS

GALERIE DU SITE

  Local folder     dossier de destination pour les fichiers HTML / ZIP
                   vide → workspace/share/outbox/graphs
                   Query → sous-dossier gallery/queries/
  Public base URL  adresse publique où les fichiers sont accessibles
                   ex. https://wysiq.org/visualizations

FLUX RSS / JSON

  RSS title        titre du canal dans le XML du flux
  RSS description  courte description du canal
  JSON filename    nom du fichier JSON de sortie
                   défaut : wysiq_feed.json

FICHIERS GÉNÉRÉS

  Zone de texte listant tous les fichiers présents
  dans le dossier publish. Cliquez "Refresh list" pour actualiser.
Boutons :
  Save gallery/feed options   enregistre les paramètres
  Refresh list                relit le dossier publish
  Open publish folder         ouvre le dossier dans l'explorateur

Testez les modèles de brouillons avant de publier.
  Title     titre du graphe ou de l'analyse
  URL       lien public vers le fichier HTML du graphe
  Insight   observation courte optionnelle sur les données

APERÇU / OUVERTURE

  Preview LinkedIn / Preview Reddit / Preview X
               choisir une entrée — le brouillon s'affiche
  Open LinkedIn / Open Reddit / Open X
               choisir une entrée — ouvre le réseau avec le texte d'aperçu
  Copy text          copie l'aperçu dans le presse-papiers
  Create draft files enregistre un fichier .txt par réseau
                     dans workspace/share/drafts/

DISCORD — CONFIGURER ET TESTER

Discord est entièrement automatique (comme le broadcast canal Telegram) :
chaque Send (Share Center) ou 📤 Share… publie directement dans votre canal Discord via un
webhook. Pas d'onglet navigateur à compléter — le message apparaît tout de suite.
Contrairement à LinkedIn, Discord reçoit le fichier .html ou .zip en
pièce jointe. Vous n'avez PAS besoin de site web public ni d'hébergement
pour que les membres ouvrent le graphe — ils le téléchargent depuis Discord.
CE QUE WysiQ ENVOIE SUR DISCORD
  • Texte légende    message court depuis le modèle publish générique
                     (titre, URL, tags par défaut)
  • Pièce jointe     graphe .html ou Query .zip
  • Memo vocal       WysiQ_{title}_voice.wav si enregistré au 📦 Prep
  • Embed            carte avec titre du graphe + lien cliquable (si URL définie)
Configuration stockée dans :  workspace/share/publish.json

ÉTAPE 1 — CRÉER UN WEBHOOK DANS DISCORD

  1. Ouvrir Discord (app ou navigateur) → votre serveur
     (créer un serveur gratuit si besoin : "+" → Créer le mien).
  2. Créer ou choisir un salon texte, ex.  #wysiq-graphs
  3. Paramètres du salon (⚙ à côté du nom du salon)
     → Intégrations → Webhooks → Nouveau webhook
  4. Nommer "WysiQ" (ou autre), confirmer le salon cible.
  5. Cliquer "Copier l'URL du webhook"
     Format : https://discord.com/api/webhooks/123456789/AbCdEf…
  Gardez cette URL secrète — quiconque la possède peut poster sur votre salon.
ÉTAPE 2 — CONFIGURER WysiQ
  1. Ouvrir Share Center… (menu Share).
  2. Onglet Publish → Canaux automatiques → cocher Discord.
  3. Coller l'URL dans "Discord webhook".
  4. Cliquer "Save publish options".
  Discord est désactivé par défaut (contrairement à LinkedIn). Il faut le cocher une fois.
ÉTAPE 3 — TESTER AVEC UN GRAPHE (même chemin que Telegram)
  1. Ouvrir un graphe avec des données.
  2. Graph Remote ▸ 📦 Prep, puis Share Center ▸ onglet Send.
  3. Enregistrer éventuellement un commentaire vocal → Send.
  Après l'envoi Email/Telegram aux contacts, le pipeline publish poste
  aussi sur Discord si activé. Vérifier votre salon Discord :
  vous devez voir la légende, le fichier .html joint, WysiQ_{title}_voice.wav
  (si enregistré) et un embed.
  Pour une Query : Query > Export query → 📤 Share… → Send.
  Discord reçoit le bundle .zip de la même façon.
CANAL TELEGRAM vs WEBHOOK DISCORD
  Canal Telegram      bot BotFather + TG channel ID + token bot
  Webhook Discord     seulement l'URL webhook — pas de bot par destinataire
  Les deux joignent le fichier directement. Les deux envoient le memo vocal au Send.
  Les deux fonctionnent sans hébergement wysiq.org.

SANS HÉBERGEMENT ACTIF (DOMAINE SEUL)

  Discord fonctionne immédiatement : le .html interactif est uploadé sur
  Discord en fichier. Les membres cliquent la pièce jointe → s'ouvre dans le navigateur.
  Le lien dans l'embed peut pointer vers une URL locale ou WiFi si aucune
  URL publique n'est configurée — la pièce jointe reste utilisable ; seul le
  lien embed est moins pratique jusqu'à config Gallery ou HTTP Server.

DÉPANNAGE

  Rien dans Discord      → Discord décoché, URL webhook vide, ou
                           "Save publish options" non cliqué.
  Webhook invalide       → recréer le webhook dans Discord et coller
                           la nouvelle URL (doit commencer par https://).
  Webhook supprimé       → Discord renvoie une erreur ; WysiQ ignore silencieusement —
                           vérifier le salon et mettre à jour publish.json.
  Fichier trop gros      → limite Discord ~25 Mo ; HTML graphe WysiQ ~150 Ko.
  Pas de vocal Discord   → enregistrer avant Send dans la fenêtre 📦 Prep ; comme Telegram.

LINKEDIN — COMMENT TESTER (AVEC OU SANS SITE ACTIF)

LinkedIn est semi-automatique : WysiQ prépare le texte du post et ouvre
LinkedIn dans votre navigateur. Vous collez le texte et publiez vous-même.
PRÉREQUIS (2 minutes)
  1. Ouvrir Share Center… (menu Share).
  2. Onglet Publish → cocher LinkedIn (Réseaux sociaux semi-automatiques).
  3. Cliquer "Save publish options".
  LinkedIn est activé par défaut. Telegram et LinkedIn peuvent rester tous deux cochés.
TEST 1 — SANS ENVOYER DE GRAPHE (le plus rapide)
  Onglet Social drafts du Share Center :
    1. Modifier Title et URL si besoin (mettre une vraie URL https://…
       quand vous en avez une).
    2. Combo Preview LinkedIn → le texte du brouillon s'affiche en bas.
    3. Copy text → coller ailleurs (Ctrl+V) pour vérifier le presse-papiers.
    4. Combo Open LinkedIn → le navigateur ouvre le dialogue de partage LinkedIn.
  Cela valide modèle + presse-papiers + ouverture navigateur — sans envoi de graphe.
TEST 2 — COMME TELEGRAM (via 📦 Prep sur un graphe)
  1. Ouvrir un graphe avec des données.
  2. Graph Remote ▸ 📦 Prep, puis Share Center ▸ onglet Send.
  3. Enregistrer éventuellement un commentaire vocal → Send.
  Ce qui se passe automatiquement :
    • Le texte du post LinkedIn est copié dans le presse-papiers.
    • LinkedIn s'ouvre dans le navigateur (share-offsite avec l'URL).
    • Un fichier brouillon .txt est aussi enregistré dans
      workspace/share/drafts/  (…_linkedin_….txt).
  Dans LinkedIn : coller le texte (Ctrl+V), vérifier le lien, puis publier vous-même.

IMPORTANT — L'URL DANS LE POST

  LinkedIn ne peut prévisualiser que des liens accessibles depuis
  Internet public (les serveurs LinkedIn récupèrent la page).
    Source de l'URL                      Aperçu lien LinkedIn
    http://192.168.x.x:47430 (WiFi)      ✗  local seulement — pas d'aperçu
    Chemin local (C:\… ou workspace/…)   ✗  pas un lien web
    Public base URL (onglet Gallery)     ✓  si les fichiers sont sur un serveur web
    Upload HTTP Server (onglet Setup)    ✓  si l'upload réussit
    Site base URL (onglet Publish)         ✓  seulement si cette adresse sert vraiment les fichiers

PAS D'HÉBERGEMENT ACTIF (DOMAINE SEUL)

  Vous pouvez posséder wysiq.org, wysiq.fr, wysiq.eu, etc. sans site
  web en ligne pour l'instant. C'est normal pendant la mise en place.
  Ce qui fonctionne sans hébergement :
    • Telegram (fichier .html direct aux contacts ou canal) — comme votre test
    • Email avec pièce jointe .html
    • WhatsApp manuel via workspace/share/outbox/graphs/ ou …/queries/
    • Texte LinkedIn copié + navigateur ouvert (Social drafts ou Send)
    • Fichiers brouillon .txt dans workspace/share/drafts/
  Ce qui ne fonctionne pas tant que les fichiers ne sont pas servis sur le web :
    • Lien public cliquable dans un post LinkedIn (carte d'aperçu)
    • Flux RSS/JSON pointant vers de vraies pages publiques
    • Public base URL galerie (ex. https://wysiq.org/visualizations)
  Quand vous ajouterez un hébergement plus tard :
    • Gallery / Feeds → Local folder + Public base URL sur votre serveur
    • ou Setup → HTTP Server → Public URL + Upload path
    • hébergement cloud wysiq.org — prochainement
  En attendant : utilisez Telegram ou Email pour le .html interactif ;
  utilisez LinkedIn pour le texte préparé — collez-le manuellement, ou
  mentionnez le fichier partagé par un autre canal.

DÉPANNAGE

  Rien ne s'ouvre       → LinkedIn décoché ou "Save publish options" non cliqué.
  Presse-papiers vide   → réessayer ; Windows peut bloquer le clipboard depuis un thread.
  LinkedIn s'ouvre mais → configurer une URL publique (Gallery ou HTTP Server) quand
  le lien est inutile     l'hébergement sera disponible ; l'URL WiFi locale ne suffit pas.

ONGLET SETUP — CONTACTS

Stocké dans :  workspace/share/contacts.json
Ajoutez des contacts manuellement (cadre Add / Edit : Add ajoute, Update
modifie le contact sélectionné, Delete le supprime) ou
importez-les depuis un tableur (📂 Import xlsx/csv). « Click On/✉/✈ to
toggle » rappelle que les colonnes se basculent au clic. Chaque contact
possède :
  Nom       — nom d'affichage
  Email     — pour l'envoi Email/SMTP
  Téléphone — référence pour Telegram

COLONNES DE LA LISTE

  On    = contact actif globalement
          Cliquez pour activer/désactiver.
  ✉ on  = canal email actif
          Cliquez pour activer/désactiver.
  ✈ on  = canal Telegram actif
          Cliquez pour activer/désactiver.
  📱 on  = référence téléphone (partage WhatsApp manuel)
          WysiQ copie les fichiers dans workspace/exchange/
          — pas d'envoi automatique WhatsApp (API payante).
  TG    = ✓ si le Chat ID Telegram est enregistré
          (voir section Telegram — Étape 3)

IMPORT DEPUIS UN TABLEUR

  Cliquez "📂 Import xlsx/csv" pour charger un fichier
  Excel ou CSV. Une fenêtre (« Map columns to contact fields: ») permet de
  mapper vos colonnes, puis Import :
    Colonne Nom    → nom d'affichage du contact (requis)
    Colonne Email  → utilisé pour l'envoi SMTP
    Colonne Tél    → référence téléphone
  Les contacts existants ne sont pas écrasés.
  Les nouveaux noms sont ajoutés à contacts.json.

ONGLET SETUP — EMAIL / SMTP

Stocké dans :  workspace/share/sender.json
WysiQ envoie le graphe en pièce jointe .html par SMTP.
Si un commentaire vocal a été enregistré, il est joint
en tant que WysiQ_{titre graphe}_voice.wav dans le même email.

CHAMPS

  Nom expéditeur  affiché dans le champ De de l'email
  Serveur SMTP    ex. smtp.gmail.com
  Port            587 pour STARTTLS  /  465 pour SSL
  Identifiant     votre adresse email
  Mot de passe    voir note Gmail ci-dessous
  STARTTLS (port 587)  recommandé pour le port 587
  Test & Save     enregistre les réglages puis teste la connexion et
                  l'authentification SMTP (« Connection successful! »).
  Rappel affiché : « Gmail: enable App password in your Google account ».
GMAIL
  Gmail exige un Mot de passe d'application —
  pas votre mot de passe Google habituel.
  Aller sur :  myaccount.google.com
               → Sécurité
               → Validation en 2 étapes
               → Mots de passe des applications
               → Créer "WysiQ"
  Utilisez le code à 16 caractères (sans espaces).
MODE HTML (« HTML mode: »)
  Standalone (~3.5MB, offline)
                ~3,5 Mo   fonctionne hors ligne
                          Plotly.js intégré (WiFi / anciens chemins)
  Lightweight (~500KB, needs internet)
                ~500 Ko   nécessite une connexion internet
                          Plotly.js chargé depuis CDN
  Note : l'envoi graphe par Email et Telegram utilise
  actuellement un HTML matplotlib PNG autonome (~150 Ko)
  avec zoom/pan tactile — indépendant du mode Plotly ci-dessus.

ONGLET SETUP — TELEGRAM

WysiQ envoie le fichier .html du graphe directement
via un Bot Telegram gratuit. Zéro coût. Aucun service
tiers.
Si un commentaire vocal a été enregistré, il est envoyé
en message audio séparé après le graphe.

ÉTAPE 1 — CRÉER VOTRE BOT

  Ouvrez Telegram → cherchez @BotFather → envoyez /newbot
  Donnez-lui un nom, ex. :  WysiQ Analytics
  Donnez-lui un identifiant se terminant par 'bot',
    ex. :  wysiq_monentreprise_bot
  👍 Aidez WysiQ à grandir — incluez 'wysiq' dans le nom.
  BotFather vous donne un token :  123456:ABCdef...

ÉTAPE 2 — COLLER LE TOKEN ET VÉRIFIER

  Collez le token → cliquez Verify & Save.
  WysiQ appelle getMe pour confirmer la validité.
  Le token est sauvegardé dans workspace/share/sender.json.

ÉTAPE 3 — ENREGISTRER LES DESTINATAIRES

  Chaque destinataire doit ouvrir votre bot dans Telegram
  et envoyer /start (une seule fois).
  Cliquez ensuite "Scan new contacts" dans WysiQ.
  WysiQ lit les messages entrants et enregistre chaque
  Chat ID automatiquement dans contacts.json.

ÉTAPE 4 — MESSAGE DE TEST

  Envoie un message de confirmation à tous les contacts
  Telegram enregistrés pour vérifier le bon fonctionnement.
À L'ENVOI (Send)
  WysiQ appelle sendDocument pour livrer le fichier .html
  directement dans le chat Telegram du destinataire.
  Le destinataire appuie sur le fichier → s'ouvre dans
  son navigateur mobile → zoom et déplacement disponibles.

ONGLET SETUP — SERVEUR HTTP

Pour les équipes disposant d'un serveur web interne
ou d'un NAS.
WysiQ téléverse le HTML du graphe sur votre serveur
et génère un lien cliquable court envoyé aux destinataires.

CHAMPS

  URL publique   URL visible par les destinataires
                 ex. https://wysiq.monentreprise.fr
  Chemin upload  dossier de destination côté serveur
                 ex. /var/www/wysiq/graphs
                 ou le chemin SFTP distant
  Identifiant    login serveur (si requis)
  Mot de passe   mot de passe serveur (si requis)
MÉTHODES (« Method: »)
  SFTP          transfert SSH — plus sécurisé
  FTP           FTP classique
  HTTP PUT      endpoint REST d'upload
  Dossier local lecteur réseau partagé
Boutons : Save enregistre la « Server configuration » ; Test URL vérifie
que l'URL publique répond.
Hébergement cloud wysiq.org — prochainement (« wysiq.org cloud sharing
(coming soon) »).
Si Public URL et Upload path sont configurés ici, chaque Send (Share
Center) ou 📤 Share… envoie aussi le HTML graphe ou le ZIP Query sur votre serveur
(dossier local, HTTP PUT, FTP, ou SFTP si paramiko est installé).
Le lien public est utilisé dans les feeds, Discord, canal Telegram
et brouillons sociaux lorsque l'upload réussit.
 ENVOI D'UN GRAPHE (📦 Prep puis Send)
Il n'y a plus de bouton 📱 dans la palette distante : le partage d'un graphe
se fait en deux temps.
  1. Graph Remote ▸ 📦 (clic gauche) : enregistreur vocal optionnel
     (● Rec, ■ Stop, ▶ Play, Erase), puis 📦 Prep dépose le HTML (+ WAV)
     dans share/outbox/graphs/. Cancel ferme sans rien écrire.
  2. Share Center ▸ onglet Send : choisir le fichier, le canal (Email, TG,
     Both), les destinataires, puis Send :
       Contacts email    → graphe .html + vocal .wav en pièces jointes
       Contacts Telegram → graphe .html via bot, vocal .wav en message audio
  Clic droit sur 📦 : fenêtre « 📱 Contacts On/Off » (colonnes On, Name,
  ✉on, 📱on, ✈on) pour activer / désactiver rapidement contacts et canaux.

PARTAGE WHATSAPP (MANUEL)

  Les graphes (.html) sont copiés dans  workspace/share/outbox/graphs/
  Les Queries (.zip) sont copiées dans  workspace/exchange/queries/
  Partagez ces fichiers vous-même depuis WhatsApp sur votre téléphone
  ou ordinateur — aucun envoi automatique WhatsApp.
À chaque Send du Share Center ou 📤 Share…, WysiQ exécute aussi le pipeline Publish
si activé : copie exchange, upload serveur HTTP (si configuré),
galerie, feeds JSON/RSS, broadcast canal Telegram, webhook Discord,
brouillon LinkedIn (texte copié + navigateur ouvert).
 PARTAGE QUERY (📤 après Export query)
Après Query > Export query, la popup de résultat propose 📤 Share…
  Channel     Email / Telegram / Both (défaut depuis Setup)
  Bot         sélecteur de bot Telegram optionnel (bots.json)
  Recipients  liste à cases — seuls les contacts cochés reçoivent
              le bundle ZIP Query
À l'envoi, les mêmes effets publish que pour les graphes :
  exchange/queries/   partage WhatsApp / fichiers manuel
  gallery/queries/    si Site gallery est activé
  feeds JSON / RSS    si activés dans l'onglet Publish
  Webhook Discord     si Discord activé + URL webhook renseignée
  LinkedIn            texte du brouillon copié + dialogue de partage
  Canal Telegram      si TG channel ID est configuré
Import côté destinataire : Query > Import query.
Note : un ZIP Query contient la définition WysiQuery sauvegardée
(table, analyse, réglages graphe, PNG/PPTX optionnels, memo vocal) —
pas seulement un instantané HTML du graphe.
Le ZIP est envoyé tel quel (Email, Telegram, webhook Discord, galerie)
pour que des profils techniques puissent l'importer via Query > Import query,
modifier les WHERE, filtres et métriques, et reconstruire ou adapter le graphe.
Memo vocal optionnel dans le bundle :
  WysiQ_{nom query}_voice.wav
  (les anciens bundles peuvent encore contenir voice_note.wav)

ONGLET SETUP — JOURNAL D'ENVOI (LOG)

Stocké dans :  workspace/share/send_log.json
Chaque envoi Email ou Telegram (graphe ou Query) est journalisé.
  Refresh     relire le journal depuis le disque
  Purge       supprimer toutes les entrées (confirmation demandée)
  Export CSV  enregistrer le journal en fichier tableur
Colonnes : date/heure, titre graphe ou Query, canal, contact,
adresse, statut (OK / ERR), message d'erreur le cas échéant.

RÉSULTAT DE L'ENVOI

Après Send, une petite fenêtre de résultat affiche une icône (succès ou
erreur) et le message (nombre d'envois réussis, erreurs par contact et
canal, ex. « pas de chat_id », « erreur SMTP ») ; OK la ferme. Le détail de
chaque envoi est conservé dans l'onglet 📋 Log.
ONGLET SETUP — HELP
  L'onglet Help de Setup affiche cette page (choix de la langue, zoom).
