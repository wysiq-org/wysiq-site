QUERY - AXES ET DISPOSITION DES TABLES

Settings > Query présente sur UNE page les paramètres du graphe actif
et la disposition de ses tables. Sans graphe actif, les champs d'axes
utilisent les valeurs par défaut prévues par WysiQ.
AXES / Y AXIS
  Unit text      Libellé de l'unité verticale (MW, EUR, etc.).
  Scale (x)      Coefficient de conversion verticale ; 1 = inchangé.
  Decimal        Nombre de décimales d'affichage.
  Period factor  Facteur utilisé pour les calculs tenant compte de la période.
  X min / X max    Bornes de l'axe X affiché (vue globale), pas une coupe
                 dans une table particulière. Vide = automatique.
  Y min / Y max    Bornes de l'axe Y. Vide = automatique.
  X/Y ticks      Graduations principales ; auto = calcul automatique.
  x/y minor      Subdivisions mineures (0 = aucune).
Les libellés X min et X max donnent accès au choix de date.
Valider les champs d'axes par Entrée ou en quittant le champ.
X AXIS - BOUNDS BY TABLE
  X min / X max  Période de chaque INSTANCE de table dans cette query.
  Rows           Nombre de lignes de la période, avant adaptation.
  Start / End    Première / dernière position sur l'axe composite.
  Une même table peut être ajoutée deux fois (ex. spot2225_2).
  Modifier les bornes d'une instance ne modifie pas la table source.
MULTI-TABLE - TABLE OFFSETS
  X offset       Décalage en LIGNES ; 0 = superposition ;
                 Auto (calendar) = proposition basée sur les dates.
  Y offset       Constante ajoutée à Y.
  Coeff          Multiplicateur de Y.
  Mode           As is, Shrink, Shrink AVG/SUM/MIN/MAX ou Expand.
  Target rows    Nombre final de lignes souhaité.
  Every N        Une ligne sur N, prioritaire sur Mode.
  Exec           Applique et retrace la query.
  Reset          Sequential, Overlay ou restauration sélective.
Pour chaque bouton ?, WysiQ ouvre une aide détaillée ; le ? du
bloc Multi-table ouvre table_layout.txt avec les presets, les modes,
les exemples RTE/SPOT et les limites des offsets en lignes.
Les réglages propres à la query sont conservés via SaveQuery.
Every accepte 2 (lignes) ou 30mn (cadence). Mode permet un Shrink et un Expand par un clic.
LAST PCA SUMMARY
  Bloc du dernier calcul PCA (onglets Summary / loadings, Scores / datasets,
  PCA guide, Multi-table PCA ; bouton Refresh PCA). Le bouton ? de ce bloc
  ouvre l'aide détaillée « query_window ».
