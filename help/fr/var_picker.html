Sélecteur de variables — Aide

Liste compacte ouverte depuis les champs numériques des métriques (clic droit
sur k, +/-, Min, Max, Δ, Fill, Lag, valeur WHERE…), ou par
Rules & params ▸ Rules & Vars… dans la fenêtre graphique.
Boutons : Stay open, Vars series, PLOT, New…, Catalog (ouvre le Variables
Catalog), ?, Save, Close. Double-clic ou Entrée sur une ligne = insérer la
référence.

OUVERTURE / INSERTION

Clic droit sur un champ lié → ouvre ce sélecteur.
Clic sur une ligne → insère &ref dans le champ actif.
« Stay open » laisse la fenêtre ouverte pendant l'édition du champ métrique.
Filtres Theme / Variable réduisent la liste (mémorisés pour la session).

CRÉER UNE VARIABLE

New… crée une variable sans passer par le Variables Catalog : thème, nom,
valeur, unité, description. Un nom de thème inexistant crée le thème.
Si un champ est ciblé (métrique, valeur WHERE…), la ref de la nouvelle
variable y est insérée. Ouvert depuis Rules & params ▸ Rules & Vars… (sans champ
ciblé), la variable est seulement créée et sélectionnée.
Clic droit sur une ligne : Insert ref / Create… / Duplicate… / Rename / edit… / Delete.

IN QUERY / SHOW / VARS SERIES

IN
  ✓ = variable utilisée par au moins une métrique de la requête ouverte
      (combo k/+/−/Min/Max/Δ/Fill, WHERE, WHERE tableau…).
Show  (variables IN uniquement)
  Active/désactive la variable dans l'aperçu.
  Clic sur l'en-tête Show → tout ON / tout OFF.
  Les cases G/T/A de la palette Series restent ; l'aperçu filtre seulement.
Vars series
  • Liste limitée aux variables IN.
  • La colonne Description est remplacée par des sliders (bornes entre la
    valeur JSON et la valeur simulée courante).
  • Les autres métriques sont masquées dans l'aperçu tant que Vars series
    est coché.
  • Survol / clic droit sur le nom Variable : liste des métriques inchangée.
  • La fenêtre se réduit à ses sliders ; elle reprend sa taille en
    décochant Vars series.
PLOT
  Rafraîchit le graphe (comme PLOT de la palette Series) après un changement
  de valeur.

MÉTRIQUES QUI UTILISENT CETTE VARIABLE

Survol colonne Variable (mode normal) ou nom Variable (Vars series) :
  infobulle « Uses: … » (refs directes) et « Depends: … » (chaîne combo/alias).
Clic droit sur le nom Variable :
  liste des métriques (lecture seule), puis Insert ref / Duplicate / Rename / Delete.
VALEUR — SIMULER vs ENREGISTRER
Clic sur la cellule Value (ou le libellé en mode Vars series) → édition directe.
Valeur simulée
  Appliquée immédiatement aux métriques et à l'aperçu (Min/Max suivent la simu).
  Affichée avec un * final (non enregistrée).
Save
  Écrit toutes les valeurs simulées dans le JSON du thème sur disque.
  Actif seulement s'il existe au moins une valeur *.
  Dialogue de confirmation avant écriture.
Close sans Save
  Annule toutes les valeurs simulées (*) et revient aux valeurs JSON.
  Efface l'aperçu variables sur le graphe.

FENÊTRE

Taille par défaut élargie pour garder PLOT et ? visibles.
Position et taille mémorisées par requête (comme les palettes Series / Table).
Redimensionnez ou déplacez la fenêtre — la géométrie est restaurée à la
réouverture de cette query.
CHAMPS DES MÉTRIQUES (&x.y)
Dans la Composition, une variable est affichée sous sa forme compacte &x.y
(x = n° de thème, y = n° de variable), ex. &1.4.
Survol du champ → infobulle : thème, nom, valeur, unité et description,
ex. « &1.4 = energie.min_nucl = 35000 MW ».
Clic droit sur le champ → ouvre ce sélecteur.
Les numéros &x.y sont propres au workspace : la query enregistre la forme
par nom (&theme.variable), portable d'un workspace à l'autre.
TRI
Clic sur un en-tête (IN, Ref, Theme, Variable, Value, Description) : tri
croissant ; nouveau clic : tri décroissant. Aucun marqueur dans l'en-tête.
?
  Cette aide (langue définie dans Params de l'application).

DISPLAY SUR LE GRAPHE / STYLE

Show garde son comportement (sélection dans l'aperçu de la query).
Display est distinct : coché, la variable est tracée directement sur le graphe
comme un repère graphique, SANS texte (ni nom, ni valeur, ni unité). Une valeur
numérique produit une ligne de référence horizontale ; une formule utilisant
des séries produit une courbe si ses séries de dépendance sont disponibles.
Display est OFF par défaut et ne modifie ni les séries, ni les métriques, ni le
WHERE. En mode Vars series, chaque ligne a trois pastilles cliquables :
Legend (texte de la légende), Display (repère graphique) et Style.
Style ouvre le popup de style SANS Position : couleur (More...), profondeur
(↓ ↑), Type, Marker, Size, Alpha et Blink. États Normal / Below / Above :
Below et Above reprennent les valeurs de Normal tant qu'ils ne sont pas
modifiés. Close ferme le popup. Les styles et Display sont enregistrés dans le
JSON du thème. Voir aussi l'aide « variables_catalog » (types Line, Fill, Bar,
Point, Both).
