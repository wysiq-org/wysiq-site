NAV HTML WYSIQ — Aide

Accès : Main ▸ AI ▸ Answers… ; AI Command Center ▸ 🌐 HTML Viewer ;
Open Nav dans AI Connections.
Rôle
Le Nav HTML sert à parcourir rapidement les réponses HTML générées par l'IA
(AI Cases et anciennes AI Sessions), ainsi que les exports HTML de WysiQ.
Le détail par profil, question et exécution reste dans l'AI Case Center.
Historique (onglet ⏱ History)
La table affiche une ligne par AI Case / session :
  Date | AI Session | WysiQuery
Double-clic (ou Entrée) sur une ligne : ouvre ou réutilise l'onglet de ce
Case. L'onglet porte le nom du Case.
Navigation dans un Case
  ←  /  →   Réponse HTML précédente / suivante du Case affiché, tous profils
            confondus.
  ↑         Liste des documents du niveau supérieur : ↑ Up remonte encore,
            Open (ou double-clic, Entrée) ouvre le document choisi, Cancel
            ferme la liste.
Barre HTML
La ligne HTML affiche le détail du document visible : Case, numéro de
réponse et position dans la série. Elle est informative (pas une barre
d'adresse). Une image ou un graphe WysiQ intégré s'ouvre dans le navigateur
par un clic.
Boutons
Open file…  Ouvre un fichier HTML de votre choix dans un nouvel onglet.
New tab     Crée un onglet pour le profil courant.
Close       Ferme le Nav.
?           Cette aide.
A- / A+     Réduit / agrandit la police du rendu texte.
Print       Imprime via le navigateur système.
Copy        Copie le texte visible.
Reload      Recharge le document courant.
Browser     Ouvre le document courant dans le navigateur système.
Clic droit sur un onglet
  Rename…                    renomme l'onglet ;
  New tab for this profile   ouvre un onglet pour le même profil ;
  Close tab / Close all tabs ferme l'onglet / tous les onglets.
Bon usage
Choisir un Case dans History, puis balayer ses réponses avec ← / →.
Ouvrir l'AI Case Center pour connaître le profil, la question ou le contenu
exact d'un échange.
