ATELIER PCA — Analyse en composantes principales

Accès : bouton PCA de la fenêtre graphique, rond PC de la Graph Remote, ou
PCA→Series dans la palette Area.
Processus type :
  cocher A sur au moins deux séries → ouvrir l'atelier → choisir Mode,
  Standardization, Weighting, Missing values, Components → lire Explained
  variance, Loadings, Scores → vues complémentaires → export ou → AI.
Rôle
L'atelier PCA réduit plusieurs séries corrélées à quelques axes synthétiques appelés composantes principales (PC1, PC2, PC3...), classés par variance décroissante. Chaque axe est une combinaison pondérée des séries d'origine. WysiQ s'en sert comme d'une loupe : les axes résument la structure dominante du graphe, puis font ressortir les groupes, les oppositions, les dérives et les anomalies.
Le graphe comme source de données
Contrairement à une PCA classique qui relit un fichier, WysiQ ne relit jamais les tables. Le moteur travaille directement sur les séries affichées dans le graphe, après application du coefficient, des masques et des filtres. Le coefficient, le shrink, les offsets et les NaN déjà présents à l'écran sont repris tels quels. Le moteur reste indépendant de l'interface : il ne renvoie que des objets Python et des tableaux numériques, réutilisables par l'IA, les exports et les rapports.
Choisir les séries
Dans la palette Series, cochez la colonne A pour chaque série à inclure. Il en faut au moins deux. Ouvrez ensuite l'atelier PCA depuis la barre de boutons du graphe. Le calcul se relance automatiquement dès que vous changez un réglage de configuration, et le bouton Refresh PCA force une relecture complète de l'état courant du graphe : cocher ou décocher une série, changer un coefficient, un shrink ou un offset, ajouter ou retirer une table.
Modes de projection
Le mode décide comment plusieurs tables sont combinées, et il fixe la colonne X offset du tableau Multi-table.
Sequence (concaténé) : les tables sont vues comme des périodes successives des mêmes variables et empilées l'une après l'autre. Le X offset est l'offset calendaire réel du graphe (par exemple 0, 17520, 35040). Utile pour suivre une dérive ou repérer une rupture entre deux périodes.
Overlay (superposition) : les tables décrivent les mêmes variables et sont superposées dans le même espace pour comparer les populations. Les tables partageant le même espace, tous les X offset valent 0. Utile pour comparer des années et voir si une table ne suit plus les autres.
Reference (référence) : la première table calcule les axes ; les autres sont seulement projetées dessus, sans recalcul des composantes. Les X offset valent 0. Utile pour mesurer l'écart d'une période récente par rapport à une référence, ou pour de la détection d'anomalies.
Fusion (espace commun) : toutes les tables participent simultanément au calcul, fusionnées en une seule population. Le X offset reprend l'offset réel du graphe. Utile pour construire un référentiel commun robuste.
Le nombre de lignes réellement utilisées par table (colonne Rows used) est toujours le vrai décompte de chaque table, quel que soit le mode ; il n'est jamais multiplié par le nombre de tables.
Projection configuration (colonne de gauche)
Mode : Reference projection, Overlay (superposition), Sequence (concatenated),
Fusion (common space) — voir Modes de projection.
Weighting : poids de chaque table dans le calcul — Equal (1.0), By table rows
(au prorata des lignes), By visible variance (au prorata de la variance
visible).
Components : nombre de composantes calculées (2 à 20).
Chaque changement recalcule immédiatement la PCA.
Tableau Multi-table : la case Use de chaque table (clic) l'inclut ou
l'exclut du calcul.
Components view (à droite)
X axis (PC) / Y axis (PC) : composantes affichées dans la projection
(PC1 à PC10).
Content : Auto, Datasets (points des tables), Variables (flèches des séries)
ou Biplot (les deux).
Show labels : affiche les noms ; Show trails : relie les points successifs
d'une même table.
Standardisation
Z-score (mean=0, std=1) met toutes les séries à la même échelle et évite qu'une série de grande amplitude écrase les autres. C'est le choix par défaut, recommandé quand les unités diffèrent.
Center only retire seulement la moyenne et conserve les variances d'origine.
None utilise les données brutes, sans recentrage ni mise à l'échelle.
Valeurs manquantes
Interpolate linear comble les trous par interpolation linéaire le long des lignes.
Mean imputation remplace chaque manquant par la moyenne de sa colonne.
Drop complete rows retire toute ligne comportant au moins un manquant.
Lire les résultats
Explained variance donne la variance portée par chaque composante et le cumul. Un PC1 très fort (au-delà de 70 %) signale des séries qui bougent surtout ensemble ; un PC1 moyen avec un PC2 fort révèle deux logiques distinctes ; des PC1/PC2/PC3 proches indiquent une structure plus complexe, souvent multi-régimes.
PCA loadings montre le poids de chaque série sur chaque axe, la norme du vecteur de charges et la composante dominante. Une charge élevée en valeur absolue signale une série centrale de l'axe ; deux séries de même signe vont dans le même sens, deux signes opposés structurent une opposition.
PCA scores place chaque table dans le plan PC1 vs PC2, avec sa distance à l'origine et à la référence ; la projection à droite reprend ces points. Des points proches traduisent des comportements proches, un point éloigné une population atypique ou une anomalie.
Quality indicators résume les critères de sélection : Kaiser retient les composantes de valeur propre supérieure à 1 ; broken-stick compare la variance de chaque PC à un modèle de référence ; le conditionnement signale une quasi-colinéarité ; le résidu moyen et la qualité de reconstruction mesurent la perte d'information des axes retenus.
Tableaux interactifs
Tous les tableaux se font défiler verticalement et horizontalement. Tirez le bord d'un titre de colonne pour la redimensionner. Cliquez sur un titre pour trier les lignes ; un second clic inverse l'ordre. La flèche indique le sens du tri, croissant ou décroissant.
Détail d'une composante
Dans le tableau Explained variance, un double-clic ou un clic droit sur une ligne PC ouvre une petite fenêtre listant, pour cette composante, chaque série avec son loading et sa contribution. Le loading est le coefficient signé de la série dans la combinaison linéaire de l'axe ; la contribution est son poids relatif absolu, en pourcentage. La fenêtre affiche cinq lignes à la fois et se fait défiler pour les suivantes ; ses colonnes sont redimensionnables et la fenêtre elle-même est redimensionnable. Un signe opposé entre deux séries traduit une opposition de comportement sur cet axe.
Vues et exports
Scree plot affiche les valeurs propres composante par composante. Cumulative variance trace le pourcentage cumulé expliqué. Loadings heatmap montre les charges par série et par composante : plus une case est foncée, plus la valeur absolue du loading est forte. Ces trois vues restent au-dessus de l'atelier PCA. Une seule fenêtre de chaque type peut être ouverte ; cliquer de nouveau sur son bouton ramène au premier plan la fenêtre existante.
Refresh PCA relit l'état courant du graphe et recalcule ; ? ouvre cette aide.
Copy (loadings + scores) place les deux tableaux dans le presse-papiers ; Export CSV (loadings + scores) les enregistre dans un seul fichier, section loadings puis section scores ; Export plot (PNG) enregistre la projection. PCA HTML produit un rapport autonome. Le bouton → AI envoie l'analyse courante dans le panier de ressources de l'IA.
Repères d'interprétation
Une PCA montre une structure, pas une causalité. Le signe des axes peut s'inverser sans changer le sens de l'analyse. Une série de très grande échelle domine si l'on ne standardise pas. Trop de variables redondantes peuvent écraser les signaux rares, et une PCA sur des périodes mélangées peut masquer une dérive temporelle : dans ce cas, préférez le mode Sequence pour la rendre visible.
Grille de décision rapide
Comparer plusieurs années : Overlay ou Fusion.
Suivre une dérive dans le temps : Sequence.
Contrôler un nouveau jeu face à un historique : Reference.
Construire un modèle global : Fusion.
Trouver une population atypique : Scores et distance PCA.
Comprendre quelles séries dominent : Loadings et contribution.
