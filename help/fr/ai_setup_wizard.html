AI Setup / Bench — Aide

L'assistant trouve les modèles d'IA utilisables — sur ce PC, sur les autres
ordinateurs du réseau et dans le cloud —, les teste avec une vraie question
et crée les profils. Choisissez un modèle, ou plusieurs pour les comparer
côte à côte (bench).
Il s'ouvre avec l'AI Command Center (décochez « Open this assistant when
the AI Command Center opens » pour l'éviter), depuis la barre latérale
(🧭 AI Setup / Bench), depuis Parameters ▸ AI (🧭 Assistant…) et depuis
⚡ Analyze graph quand aucun profil n'est encore utilisable.
1 · OÙ SONT VOS IA ?
  This PC
    Discover Ollama / LM Studio on this computer
                 Cherche Ollama (port 11434) et LM Studio (port 1234) sur cet
                 ordinateur. Le dossier des modèles Ollama (« Ollama data »)
                 est rappelé dessous.
    Start Ollama automatically if it is installed but not running
                 Si rien ne répond sur le port 11434, l'assistant lance un
                 script de démarrage *ollama*.bat trouvé (workspace, dossier
                 WysiQ, dossier personnel, Bureau, Documents) ou
                 « ollama serve », puis attend jusqu'à 30 s.
  Local network
    Other computers (e.g. a Mac running Ollama or LM Studio)
                 Les autres ordinateurs ; saisir leurs IP ou noms dans
                 Hosts / IPs (ex. MacBook-Pro.local), séparés par des
                 virgules. Ils sont mémorisés.
    Scan the whole subnet (≈ 10 s)
                 Interroge toutes les adresses du sous-réseau.
  Cloud APIs
    Providers with an API key
                 Les fournisseurs dont la clé est déjà enregistrée (ou dans
                 une variable d'environnement), listés dessous.
    Add a key:   choisir le fournisseur (ou le laisser reconnaître par le
                 préfixe : sk-ant- → Anthropic, sk-or- → OpenRouter, AIza →
                 Gemini, xai- → Grok), coller la clé, puis Add.
  Open this assistant when the AI Command Center opens
                 Ouvre l'assistant à chaque ouverture du Command Center tant
                 qu'aucun modèle n'est connecté.
  ?              Cette aide.   Close   Ferme l'assistant.
  Search →       Lance la recherche et passe à l'écran 2.
  ↻ Last selection (n) — test →
                 Saute la recherche et reteste les modèles du dernier bench.
2 · CHOIX DES MODÈLES
  Les modèles sont groupés par lieu (This PC, LAN <hôte>, Cloud —
  fournisseur). Un clic sur une ligne (ou Espace) la coche. Plusieurs
  modèles cochés = un bench. Colonnes Model, Size, Profile (le profil
  existant réutilisé, ou « new profile »). La dernière sélection est
  recochée automatiquement. None décoche tout ; « n selected » compte la
  sélection ; ← Back revient à l'écran 1 ; Test selected → lance les tests.
3 · TEST & CONNEXION
  Chaque modèle reçoit une petite vraie question, en parallèle. ✔ = il a
  répondu (temps affiché), ✖ = échec, avec une piste. Double-clic sur une
  ligne pour l'erreur complète.
  Corrigé automatiquement (🔧) : /v1 manquant (Anthropic, OpenAI,
  Ollama…), /api/v1 d'OpenRouter, /v1beta/openai de Gemini, une URL qui
  finit par /chat/completions, « Bearer » ou guillemets collés avec la clé.
  Connect       Enregistre et active les profils qui ont répondu, les
                connecte (un onglet chacun) et fait du premier le profil
                par défaut.
  ⚡ Connect & analyze graph
                Idem, puis envoie la question Analyze graph à chaque
                modèle connecté : chaque réponse arrive dans son onglet.
                Les Send suivants partent vers l'onglet actif seulement.
  Retry failed  Reteste les modèles en échec (un modèle local qui se
                charge pour la première fois peut être lent).
ÉCHECS FRÉQUENTS
  Rien ne répond sur ce PC     Ollama / LM Studio n'est pas démarré.
  Ordinateur du LAN injoignable
                               Sur cet ordinateur, Ollama doit écouter le
                               réseau : OLLAMA_HOST=0.0.0.0 (Mac :
                               launchctl setenv OLLAMA_HOST 0.0.0.0, puis
                               relancer Ollama), et le pare-feu doit
                               accepter les connexions entrantes.
  Clé API refusée (401/403)    Recopiez la clé en entier ; vérifiez le
                               fournisseur.
  Quota / crédit (429)         Vérifiez la facturation chez le fournisseur.
  Modèle introuvable (404)     Ce nom de modèle n'existe plus pour votre
                               compte — choisissez-en un autre.
