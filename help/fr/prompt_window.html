Prompt — WysiQ

Note (version actuelle) : la fenêtre Prompt n'était ouverte que depuis Expert
Studio, qui n'est plus accessible. Le prompt se saisit désormais directement
dans l'AI Command Center (zone de prompt, ▶ Send, Ctrl+Entrée).
La fenêtre Prompt est l'interface indépendante où vous éditez la question
envoyée à l'IA. Elle est alimentée par l'Expert Studio (Send to AI…,
Generate Expert Report), et le bouton Send délègue le transport à la
plomberie existante (session, feed grounding, routage des réponses vers
le HTML Viewer et la fenêtre Scenario).

UTILISATION

1. Ouvrir : depuis l'Expert Studio (bouton "Prompt…") ou automatiquement
   à l'ouverture d'Expert Studio.
2. Éditer : tapez ou modifiez le texte du prompt. L'Expert Studio peut
   pré-remplir la zone via Send to AI… (scénario) ou Generate Expert
   Report (rapport complet).
3. Envoyer : bouton "▶ Send". La fenêtre AI Profile est ouverte / rappelée
   automatiquement pour héberger la connexion, la question est envoyée
   avec le feed courant (JSON AI Feed, Data AI Feed, ou Area feed selon
   ce qui a été poussé), et la réponse revient dans le HTML Viewer.

BOUTONS

Clear     Vide la zone du prompt.
AI Request…  Ouvre le catalogue AI Request (requêtes IA enregistrées).
AI Feed…  Ouvre l'AI Feed Stack.
Attach…   Joint des fichiers au prompt ; 📌 les joint pour toute la session.
          Liste des pièces jointes : clic gauche active / désactive, clic
          droit retire.
🎤 Mic    Ouvre l'enregistreur vocal.
▶ Play    Envoie le groupe suivant du plan préparé dans l'AI Feed Stack (un
          groupe Send # par clic) ; grisé sans plan.
Refresh   Met à jour le résumé « AI Feed: N feeds ».
▶ Send    Envoie le prompt à l'IA via la plomberie AI Profile / Session.
          Toutes les vérifications (profil sélectionné, session active,
          feed grounding) s'appliquent comme dans l'ancien AI Analyst.
?         Affiche cette aide.

RETOUR DES RÉPONSES

Les réponses ne s'affichent PAS dans cette fenêtre :
  - HTML Viewer : contient les réponses formatées (chapitres si le
    toggle "Chapter HTML answers" est actif dans Expert Studio).
  - Fenêtre Scenario : si la réponse est un scénario structuré
    (kind=wysiq_scenario_response), les points sont injectés.

CONNEXION IA

Cette fenêtre ne gère pas les profils IA — utilisez le bouton
"AI Profiles" de l'Expert Studio pour créer, connecter ou changer de
profil. Elle ne gère pas non plus les sessions — utilisez le bouton
"AI Session".

COMPORTEMENT DE FENÊTRE

Traitée comme les autres palettes flottantes WysiQ (Expert Studio,
Series, Table) : reste au-dessus du graphique en permanence
(attribut -topmost persistant sur Windows) et se remet au premier plan
sur activation ou reprise de focus.
