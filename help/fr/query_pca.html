QUERY — Last PCA / Axes

Rôle
Cette zone documente le dernier calcul PCA/ACP réalisé depuis Area.
Elle ne remplace pas Area : Area calcule, Query documente.
La Query comme recette ACP
Le fichier query.json garde le processus qui a permis d'obtenir la dernière ACP :
- table de travail,
- colonnes source,
- Metrics définis dans la Query,
- séries cochées A dans la palette Series,
- bornes X/Y utilisées,
- nombre de PC,
- variance expliquée,
- coefficients et contributions.
La Query est donc une recette analytique ACP, pas seulement une requête SQL.
Ce qui est mémorisé
WysiQ garde seulement un résumé compact du dernier calcul PCA :
- nombre de lignes utilisées,
- nombre de séries d'entrée,
- bornes Area utilisées,
- PC calculées,
- pourcentage expliqué par chaque PC,
- pourcentage cumulé,
- principales séries contributrices,
- coefficients et contributions.
Ce qui n'est pas mémorisé
Les valeurs des séries AXIS_* ne sont pas écrites dans query.json :
- AXIS_PC1, AXIS_PC2, ...
- AXIS_RECONSTRUCTION_ERROR
- AXIS_DIST_PCA
Pour les utiliser dans Metrics, Signals ou Table, créez-les depuis Area avec le bouton PCA→Series.
Pour les conserver définitivement, exportez/materialisez une table de travail.
Affichage
La table de variance montre PC1, PC2, etc. et le cumul.
La table des coefficients affiche les principales séries contributrices de chaque PC pour éviter de noyer l'utilisateur avec toutes les séries.
P1%, P2%, ... indiquent la contribution relative de la série dans la PC correspondante.
Dom.PC indique la PC dominante pour cette série.
Σ|coef| donne une indication d'importance globale.
Règle WysiQ
Area produit le calcul.
Query garde le dernier résumé.
Post-it/PPTX gardent plusieurs états.
Une table matérialisée garde les valeurs PC dans le temps.
