DISPOSITION DES TABLES - SETTINGS > QUERY

Les réglages des axes et des tables partagent maintenant une seule page Query.
Les changements s'appliquent à la query en cours, sans modifier les tables
physiques du catalogue. Chaque instance d'une table a ses propres réglages.
1. X AXIS - BOUNDS BY TABLE
Table    Instance dans la query. Ajouter une même source deux fois produit,
         par exemple, spot2225 et spot2225_2, réglables séparément.
X min    Début de la période utilisée pour cette instance.
X max    Fin de la période utilisée pour cette instance.
         Format JJ/MM/AAAA [HH:MM], ou date ISO. Une date de fin sans
         heure inclut la journée entière. Vide = pas de limite.
Rows     Nombre de lignes source retenues, AVANT Shrink / Expand ; si la
         période est limitée, le total est affiché sous forme retenues/total.
Start    Première position sur l'axe X composite après transformation.
End      Dernière position sur ce même axe.
Valider une borne avec Entrée, ou quitter les deux champs X min/X max.
Les dates modifient la sélection de la QUERY, jamais la table DuckDB.
Le changement d'une borne peut recalculer l'offset automatique ; un offset
marqué manuel reste intact.
2. MULTI-TABLE - TABLE OFFSETS
Une ligne par instance, dans l'ordre des onglets Series. La table principale
sert de référence pour l'axe X. Changer l'ordre des onglets ne déplace
pas volontairement les offsets personnalisés.
X offset (rows)  Position de départ sur l'axe composite, en LIGNES,
                 et non en heures, jours ou dates.
                 0 = superposition au début de la table principale.
                 Auto (calendar) = suggestion d'après les horodatages
                 des tables de référence (si disponibles).
                 Flèche + nom de table = départ après cette table ;
                 cumul = après les tables précédentes.
                 Il est possible de saisir directement un entier puis Entrée.
Y offset         Constante ajoutée aux valeurs Y de l'instance.
Coeff            Multiplicateur appliqué aux valeurs Y (1.0 = inchangé).
Mode             Rééchantillonnage des lignes sélectionnées.
Target rows      Nombre de lignes visé APRÈS la transformation.
                 Vide avec Mode actif = valeur par défaut (table principale).
Every N          Garde une ligne sur N ; VIDE = inactif. Si renseigné,
                 il prend la priorité sur Mode et Target rows.
Exec             Applique les changements de la ligne et retrace le graphe.
3. MODES DE RÉÉCHANTILLONNAGE
As is (all rows)    Toutes les lignes de la période, sans adaptation.
Shrink              Sous-échantillonnage par sélection de lignes.
Shrink AVG          Moyenne des valeurs de chaque tranche cible.
Shrink SUM          Somme des valeurs (pour les quantités additionnables).
Shrink MIN / Shrink MAX    Minimum / maximum des valeurs par tranche.
Expand - Interpolate  Interpolation linéaire entre mesures.
Expand - Step (last) Dernier prix ou état connu maintenu jusqu'au suivant.
Expand - Next        Utilise la valeur suivante.
Expand - Smooth      Interpolation puis lissage.
Expand - Spline      Interpolation par spline si assez de points.
Expand - Zero-fill   Complète avec des zéros.
Expand - NaN-fill    Laisse les points non mesurés manquants.
AVG/SUM/MIN/MAX utilisent toutes les mesures sélectionnées dans les
intervalles cible quand les dates sont exploitables. Une tranche vide reste
manquante (NaN), et non zéro. Sans dates exploitables, les regroupements
suivent l'ordre des lignes. Pour les prix en EUR/MWh, utiliser AVG, pas SUM.
4. RESET ET DISPOSITIONS
Reset ▾ (menu)
  X offsets → ↔↔↔ Sequential (restore)   retour à la disposition séquentielle
                                         mémorisée.
  X offsets → ↔ Overlay (restore)        retour à la disposition superposée
                                         mémorisée.
  Y offsets = 0, Coeffs = 1              Y offset = 0 et Coeff = 1.
  Mode = As is (all rows), Every N cleared
                                         supprime Shrink/Expand et Every N.
  X min/max = full physical table        revient aux bornes de la source
                                         physique.
  Reset all (Sequential + Y/Coeff + Mode)
                                         rétablit la disposition séquentielle
                                         et les autres réglages de table, y
                                         compris les bornes.
Layout: Custom      Certains offsets ont été choisis manuellement.
Le passage Sequential -> Overlay -> Sequential restaure les offsets
personnalisés (par exemple SPOT à 0), les modes Shrink/Expand, Every,
Target rows et les périodes propres à chaque instance. Chaque disposition
garde ses propres réglages. Seul Reset > Mode ou Reset all efface ces modes.
SaveQuery sauvegarde aussi les deux dispositions et leurs réglages.
5. EXEMPLE RTE + SPOT, 2022-2025
RTE2022/23/24/25 : quatre tables consécutives à 30 minutes.
spot2225 (instance 1) : du 01/01/2022 au 30/09/2025, tarifs horaires ;
  offset 0, Expand - Step (last), vers les lignes RTE correspondantes.
spot2225_2 (instance 2) : du 01/10/2025 au 31/12/2025, prix à 15 min ;
  offset Auto (calendar), Shrink AVG, vers les lignes RTE de cette période.
Les deux instances lisent une seule table source, sans la dupliquer.
ATTENTION : un offset reste une position par ligne. Expand et Shrink ne sont
pas, à eux seuls, une jointure temporelle universelle. Vérifier les pas
réels, les trous et les changements d'heure pour les calculs monétaires.
Sauvegarder avec SaveQuery ; les périodes, offsets et modes sont persistés.
FIX24 — EVERY EN DUREE, SHRINK + EXPAND SIMULTANES
  Le champ Every garde son ancien sens pour un nombre sans unite :
  2 = conserver une ligne sur deux. Vide = traitement par Target rows.
  Une duree explicite (30s, 30mn, 30min, 1h, 1j) active Adjust temporel.
  Le champ Target rows n'est alors pas utilise : les dates determinent les tranches.
  Cliquer sur le champ Mode puis sur une methode Shrink et une methode Expand.
  Les deux choix actifs apparaissent en GRAS. Un clic = selection/desactivation ;
  choisir une autre methode de la meme famille remplace la precedente. La fenetre est deplacable, sans bloquer Settings. OK applique.
  Shrink AVG = moyenne ponderee par la duree des observations ;
  SUM = somme ; MIN/MAX = valeurs extremes. Expand Step (last) maintient la valeur.
  Exemple SPOT : Evenement 1h -> 2 valeurs a 30mn ; puis deux valeurs
  a 15mn -> 1 valeur a 30mn, automatiquement dans la meme instance.
  Un trou dans les mesures laisse NaN, pas zero. Aucune table source n'est modifiee.
  Les X offsets restent independants et ne sont jamais recalcules par Adjust.
  Le pas repose sur les veritables X DateTime ; un X numerique n'est pas admis.
  Utiliser de preference des X UTC coherents pour les transitions d'heure.
