WysiQ — WWW Connection | Aide

Accès : Main ▸ Database ▸ WWW Connection.
PRINCIPE
WWW Connection découvre des jeux de données publiés sur Internet (RTE, ENTSO-E,
INSEE, Eurostat, BCE, OCDE, ONU, Open-Meteo, SDMX worldwide…), sélectionne des
séries, les teste, puis construit une table datée WysiQ : WS (WWW Static,
instantané) ou WL (WWW Live, actualisée périodiquement). Les tables s'utilisent
ensuite dans Query, Graph, Table, Metrics, Rules & Vars, Area et Scenario.
Les droits d'utilisation restent ceux du fournisseur.
Processus type :
  choisir le site → choisir le dataset (Discover datasets) → sélectionner les
  dimensions / codes (Discover series, Select values…, Choose series…)
  → Test connection (statut ✓ ready) → Download selection (aperçu de la liste,
  dates From / To, nom de table) → Load → la table WS/WL apparaît dans Main.
Ne confondez pas : site (fournisseur), dataset / dataflow (structure publiée),
clé de série (sélection de codes), connexion (réglages enregistrés) et table
WysiQ (données téléchargées). Découvrir un dataflow indique sa structure, pas la
présence garantie d'observations.
Les dates affichées et saisies suivent le format de Parameters ▸ Globals ▸ Core
(« Date format (tables) »), comme dans les autres fenêtres.

FENÊTRE PRINCIPALE — BARRE DU HAUT

  New                Crée un connecteur (« New WWW connector ») : Site existant
                     ou New site, Data existante ou New data (URL, Query).
                     Create l'enregistre ; Test montre ensuite ce que le site
                     renvoie.
  Add URL…           Analyse une URL de fournisseur ou de dataset (Analyze URL),
                     affiche le fournisseur, les datasets et limites trouvés ;
                     « Create a connection when a usable dataset was
                     identified » crée aussi la connexion ; Add to catalog
                     enregistre, Cancel abandonne.
  SDMX worldwide…    Annuaire officiel SDMX (Global Discovery Service) :
                     Refresh agencies, Explore dataflows, Filter flows, Add
                     selected dataset (ajoute le dataflow au catalogue), Copy
                     service URL, Close.
  Test All…          Teste une à une les connexions : « Selected site » ou « All
                     sites ». Start tests lance, Cancel arrête, Close ferme. Un
                     test n'est réussi qu'avec de vraies observations numériques.
  ?                  Cette aide.
  Folder             Ouvre le dossier workspace/WWW (connecteurs, profils).
  Updates…           « Site updates » : Check lit le catalogue signé WysiQ,
                     Install selected installe les définitions vérifiées,
                     Restore previous revient à la version précédente.
RECHERCHE (« Search worldwide catalogue »)
  Search        Recherche locale dans tous les sites, datasets et ressources
                connus (aucune requête Internet à la frappe).
  Where         AND : tous les mots doivent correspondre ; OR : au moins un.
  All sites     Retire le filtre de site.
  Include sites without datasets   Affiche aussi les sites de référence sans
                dataset chargeable.
Listes Themes [A-Z] et Sites : cliquer pour filtrer.
CONNEXIONS DU SITE (« Connections of selected site »)
Colonnes : Connector, Site, Theme, Table, Rows, Last load, Account.
Clic sur un en-tête : tri. Double-clic : ouvre l'éditeur de la connexion.
Statuts de la colonne Account :
  ✓ ready          dernier test réussi avec données numériques datées ;
  ● key saved      clé enregistrée, test à faire ;
  ○ no key         site public sans clé ;
  ○ sign up        inscription nécessaire ;
  · catalogue      entrée de catalogue sans définition chargeable ;
  ○ test required  pas encore testé (Not tested) ;
  ○ no data        test terminé mais sans observation ;
  ✗ test failed    dernier test en échec ;
  ◌ testing… / ◌ cancelling…   test en cours / annulation demandée ;
  ○ cancelled      dernier test annulé (ce n'est pas un échec).
Un statut Ready n'est accordé qu'après réception de données numériques datées
pour cette sélection exacte ; un changement de paramètres le remet en cause.
Boutons sous la liste :
  Account          Ouvre la fenêtre du compte du site (voir plus bas).
  Test connection  Teste exactement la connexion sélectionnée et ses paramètres.
  Cancel test      Arrête le test en cours (y compris sur un autre site) ; se
                   désactive dès que l'arrêt est demandé.
Clic droit sur une connexion : New, ▶ Load, ⟳ Update to today (si un historique
existe), Rename…, Delete (supprime le connecteur ; la table reste dans le
workspace), Site account….
Test des fréquences : pour les données annuelles, trimestrielles, mensuelles ou
hebdomadaires, WysiQ tient compte de la fréquence déclarée dans le connecteur.
Sans dates enregistrées, il examine respectivement 3 années, 8 trimestres,
12 mois ou 12 semaines civils complets. Pour les fichiers historiques complets
(comme DWD annuel), une seule lecture vérifie toute la période From / To.
Un retour HTTP 200 sans observation numérique datée ne donne jamais Ready.
Between requests ne change que le délai réseau, pas la période de test.

DATA / RESOURCES

  Show                All items, Datasets, Parameters, Series, Fields.
  Discover datasets   Récupère la liste officielle des datasets / dataflows du
                      fournisseur (métadonnées uniquement, aucune table créée).
  Discover series     Lit les dimensions, codes ou séries du dataset
                      sélectionné. Pour INSEE BDM, la DSD (structure) est lue
                      d'abord ; une erreur de DSD n'est pas une erreur de clé.
  Download selection  Ouvre l'onglet Download / Live de l'éditeur avec la
                      sélection courante (aucune requête à l'ouverture).
Arbre : colonnes Name, Code, Type ; cochez directement les codes (☑ / ☐) ou
double-cliquez un paramètre pour ouvrir le sélecteur. Le cadre « Selected item »
détaille l'élément (Description / Source).
  Select values…  Sélecteur commun de valeurs pour tout paramètre ; plusieurs
                  valeurs possibles.
  Fit names       Élargit la colonne Name au libellé le plus long (760 px max).
Sélections multiples : si l'API n'accepte qu'un code par appel, WysiQ fait
plusieurs requêtes puis fusionne les séries sur Date. Une combinaison trop
volumineuse est refusée avant téléchargement. Une connexion existante peut être
téléchargée dès qu'un dataset ou l'un de ses codes est affiché ; pour réunir
plusieurs datasets, cochez explicitement leurs lignes Dataset.
Zone « Messages / trace » (bas du catalogue et de l'éditeur) : messages et
erreurs, conservés après fermeture d'une trace. Clic droit : Copy all, Clear
messages.
SÉLECTEUR DE VALEURS (codes publiés)
Search filtre la liste, All / None cochent ou décochent tout, le compteur
indique la sélection ; OK valide, Cancel abandonne. La fenêtre est redimension-
nable (2 colonnes, 1 colonne si étroite) ; le texte complet et le code sont dans
l'infobulle.
SÉLECTEUR DE SÉRIES SDMX (Dimensions / Choose series…)
Une ligne par dimension (commencer par Frequency). Pour chaque dimension :
Choose values… (codes publiés), saisie libre dans Codes puis Set, ou Clear.
Cochez plusieurs valeurs pour obtenir plusieurs séries.
  One series     construit la clé SDMX d'UNE série précise (recommandé).
  Apply filter   applique le filtre (peut donner plusieurs séries).
  Cancel         abandonne.
« All series » / « All series (large) » télécharge tout le dataflow : demande
une confirmation explicite, peut être refusé par le fournisseur (HTTP 413) ;
préférez Choose series…. WysiQ n'invente jamais un filtre et refuse un
chargement massif non confirmé. UNData accepte une requête sans clé (segment
omis) ; INSEE BDM utilise sa syntaxe /all. Une série INSEE peut aussi être
choisie directement par son IDBANK.
ÉDITEUR D'UNE CONNEXION — ONGLETS ET BOUTONS COMMUNS
Onglets : Download / Live, Connection / Test, History, Columns. Changer d'onglet
garde la taille de la fenêtre. En bas : Messages / trace, Close (ferme
l'éditeur) et ? (cette aide, dans une fenêtre séparée).
1. DOWNLOAD / LIVE (SINGLE DATA / LIVE)
« Build and download ONE WysiQ table ».
Cadre « Selected datasets / series (uncheck to exclude) » (après Download
selection) : colonnes Use / Series, Provider / Dataset, Codes / Filter ;
décocher une ligne l'exclut. Choose series… ouvre le sélecteur SDMX ; All series
(large) prend tout le dataset après confirmation. Les dataflows sans filtre sont
signalés ALL.
Cadre « Data to download » :
  From / To        Période demandée.
  Time             Local (fuseau du fournisseur ; l'heure du changement d'heure
                   d'automne apparaît deux fois) ou UTC.
  Update to today  Load ajoute depuis la dernière date chargée jusqu'à
                   aujourd'hui (From / To inutilisés).
  Paramètres       Valeurs du connecteur (pays, variables, clés) ; ☰ ouvre le
                   sélecteur de valeurs.
Cadre « Table / Live options » :
  Table            Nom de la table WysiQ à créer ou mettre à jour.
  Replace / Append Replace remplace le contenu ; Append ajoute les dates et
                   séries (les valeurs historiques absentes du nouveau lot sont
                   conservées).
  Data mode        WS = instantané statique ; WL = acquisition WWW
                   incrémentale.
  Live             Coché = table WL en UTC, nouvelles dates ajoutées à chaque
                   période tant que WysiQ tourne ; décoché = WS.
  Polling every    Période en minutes (WL seulement) ; 0 = arrêt.
  Between requests Délai en SECONDES ENTIÈRES entre deux appels HTTP ; le
                   minimum du fournisseur reste imposé (Background et Test
                   compris). Default rétablit la valeur recommandée.
  Provider quotas  Quotas connus ; Docs ouvre la page de quotas du fournisseur
                   (absent si non publiée).
  Load             Télécharge la période dans la table (créée si besoin).
  Clear            Vide la table (définition conservée) après « Confirm clear ».
  Drop             Supprime la table (DuckDB, .parquet, définition) après
                   « Confirm drop » ; le connecteur est conservé. Les graphes
                   qui l'utilisent sont signalés.
  Stop             Arrête le téléchargement en cours.
  Background       Charge la période par morceaux en arrière-plan : chaque
                   morceau est écrit aussitôt (table utilisable pendant le
                   remplissage), la fenêtre peut être fermée, la reprise se fait
                   après redémarrage. Utile pour les sites qui refusent les gros
                   téléchargements (HTTP 429).
Règles de Load :
  • Une table doit être nommée (« Enter a table name »).
  • Un dataflow SDMX découvert doit avoir réussi Test pour cette sélection
    exacte avant création ou mise à jour (« Test required »).
  • WL exige Time = UTC et un Load initial.
  • Remplacer une table qui ne vient pas de cette source WWW demande une
    confirmation (protection des tables étrangères).
  • Plusieurs sources : jointure externe sur Date ; les dates absentes restent
    vides (ni inventées, ni remplacées par zéro). Si une source échoue, aucune
    table partielle n'est créée. Une sélection multi-datasets est toujours WS
    (pas de Live, pas de Background repris).
  • Les périodes statistiques (année, trimestre, mois) sont gardées comme dates
    de début de période, sans décalage UTC (2024-Q1 = 2024-01-01).
2. CONNECTION / TEST
Cadre « Connection settings » :
  New       Crée une nouvelle connexion à partir de TOUTES les valeurs affichées
            (paramètres, dimensions, périodes, séries), avec un nouveau nom de
            table ; aucune donnée, aucun historique, aucun statut Ready copié.
  Name      Nom de la connexion.
  Site      Fournisseur (statut du compte affiché à droite).
  Data      Ressource / dataset du site.
  Series…   Lit un jour de données puis choisit les séries à garder (vide =
            toutes).
  Liens     Boutons vers la documentation et les pages du site.
  Account…  Clé API, identifiant et proxy de ce site.
Les dataflows SDMX exigent souvent une sélection dans Dimensions ; la clé de
série est construite à partir de la DSD. Utilisez Test connection sous la liste
pour vérifier les vraies observations avant tout chargement.
3. HISTORY
« History of this connector » : When, Period, Rows, Mode des chargements de la
connexion active. Double-clic sur une ligne : réutilise sa période dans
Download / Live. L'historique concerne le connecteur, pas la sélection
temporaire.
4. COLUMNS
Liste des séries / colonnes de la connexion. Read series lit un court
échantillon chez le fournisseur pour lister les séries d'un dataset sans série
choisie (aucune table modifiée).
5. HELP (bouton ?)
Le bouton ? (barre du haut, ou à côté de Close dans l'éditeur) ouvre cette aide
dans la fenêtre d'aide standard : choix de la langue, A− / A+, ↺. Il n'y a pas
d'onglet Help dans l'éditeur. Un seul fichier www_connection.txt par langue
décrit toute la fenêtre WWW.
COMPTE DU SITE (« WWW — Site account »)
  Site                    Choix du fournisseur et statut.
  Liens                   Inscription, documentation, compte.
  How to get the key…     Procédure d'obtention de la clé (et modèle d'e-mail :
                          Write e-mail, Copy text).
  Check links             Teste les liens de documentation et de compte.
  Test                    Teste le fournisseur ; le détail s'affiche dessous
                          (Show log ▾ / Hide log ▴).
  API credentials         Clé(s) API demandées par le site.
  Account details ▸       Login / e-mail, Password, Registered, Note
                          (facultatif).
  Save secrets            Mots de passe et clés enregistrés sous forme
                          brouillée dans WWW/profiles (comme pour les
                          connexions DB) ; sinon gardés pour la session.
  Show                    Affiche les secrets saisis.
  Proxy                   Vide = proxy système (ex. http://proxy.societe:8080).
  Verify SSL              Vérification des certificats (laisser coché).
Les réglages sont enregistrés automatiquement, et à la fermeture.
TEST ET ANNULATION
Pendant un test, la colonne Account affiche « testing » puis « cancelling » si
Cancel test est demandé. La fenêtre de trace d'un test propose Copy, Cancel test
et Close. Les pauses dues aux quotas s'interrompent immédiatement ; une requête
HTTPS déjà partie peut attendre son délai (20 s maximum en Test). Un test annulé
ne modifie aucune table et libère le moteur pour un autre test.
ERREURS ET LIMITES
  HTTP 404   mauvaise ressource ou clé : vérifier le dataset et les codes.
  HTTP 413   périmètre trop large : réduire les dimensions ou la période.
  HTTP 429   trop de requêtes : augmenter Between requests, utiliser
             Background, réessayer plus tard.
  HTTP 400   requête refusée : le message du fournisseur est affiché en texte
             lisible.
  no data    la requête a abouti sans observation : changer la période ou les
             codes.
Un échec ou un timeout ne prouve pas que le dataset est vide. Les sources
peuvent avoir des fréquences et unités différentes : vérifiez leur cohérence
avant de comparer les colonnes.
SÉCURITÉ ET PROVENANCE
Ne partagez pas les clés API. Respectez les licences de réutilisation. La
provenance de chaque table (connecteur, ressource) est conservée dans
tables/<table>.json et visible dans le Table Catalog (Import source). Les
connecteurs sont dans workspace/WWW/connectors/.
PÉRIODE ET QUOTAS
From / To déterminent exactement la période du prochain Load/Download (sauf Update to today activé). Les messages « Last background load » décrivent un ancien transfert, sans modifier les dates actuelles. Test lit un échantillon dans la période sélectionnée ; les fichiers historiques complets sont vérifiés sur toute cette période. Le délai Between requests est modifiable ; les quotas de l'API sont respectés automatiquement, même pour 0 seconde.
SITES WEB ET DATES HISTORIQUES
Clic droit sur un site dans la liste Sites : Open website in browser ouvre l'adresse homepage declaree dans son JSON ; Open API documentation ouvre sa documentation si disponible. Show site information affiche les renseignements deja connus (description, sujets, couverture, licence, jeux de donnees) dans Messages / trace en bas a droite.
Fetch additional website information recupere, sur demande et en arriere-plan, le titre et la description publics de la page Web (eventuellement mots-cles, editeur et langue). Cette description est ajoutee au JSON local WWW/www_type/<site>.json et conservee lors des mises a jour officielles. Elle ne constitue PAS un inventaire certifie des donnees de l'API ni une autorisation de reutilisation. Aucun appel Internet n'est fait au simple changement de site.
Pour les series historiques, une date anterieure a 1678 reste une date de calendrier sans conversion en UTC. Elle est stockee en precision microseconde plutot que supprimee par la limite de TIMESTAMP_NS, sans regle specifique a un fournisseur.
