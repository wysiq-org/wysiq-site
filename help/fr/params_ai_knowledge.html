PARAMÈTRES AI — Requests · Knowledge · Sessions · Profile

Accès : Parameters ▸ AI ▸ Help (cette aide s'ouvre au choix de l'onglet),
Main ▸ AI ▸ Help.
ORGANISATION DE L'ONGLET AI (Parameters)
  Profile       profils IA (voir l'aide « params_ai »).
  Observatory   sélectionner cet onglet ouvre directement la fenêtre de
                réglage de l'AI Observatory (aide « activity_tracking »).
  AI Folder     sélectionner cet onglet ouvre le dossier AI du workspace dans
                l'explorateur.
  Help          ouvre cette aide.
REQUESTS (QUESTIONS PRÉDÉFINIES)
Bibliothèque de questions réutilisables à insérer dans le prompt IA. Elle
s'ouvre depuis l'AI Command Center (📋 Request ou PANELS ▸ 📋 Requests
Catalog) : fenêtre « AI Requests ».
Les fichiers sont stockés dans : WysiQ/AI/Feed/<langue>/<nom_question>/question.txt
Insérer une question dans le prompt
    Double-clic, Entrée ou Ctrl+D sur une question → insère le texte complet
    dans le prompt du Command Center.
    Ctrl+C sur le texte à droite → insère le texte sélectionné (ou tout le
    corps si rien n'est sélectionné).
Créer une question
    Ajouter un dossier WysiQ/AI/Feed/<langue>/<id_question>/ contenant un
    fichier question.txt (l'identifiant du dossier sert de libellé, espaces =
    underscores), ou dupliquer une question existante (clic droit ▸
    Duplicate) puis l'éditer.
Language
    Sélectionne la langue du répertoire de questions à afficher.
    Les questions d'un second répertoire (anglais) s'ajoutent en complément
    si la langue choisie ne couvre pas tous les dossiers.
Recherche dans Questions
    Le champ Search filtre la liste des questions à gauche ET surligne les
    occurrences dans le texte à droite.
    Les boutons << et >> naviguent entre les occurrences dans le texte.
    L'occurrence courante est surlignée en orange, les autres en jaune.
Clic droit sur une question
    Edit — ouvre l'éditeur complet (renommage d'id + édition du texte).
    Duplicate — copie la question dans un nouveau dossier.
    Rename — renomme le dossier sans ouvrir l'éditeur de texte.
    Delete — supprime définitivement le dossier de la question.
KNOWLEDGE
Les Knowledge sont des fichiers JSON envoyés à l'IA lors de chaque connexion
(bouton Connect d'AI Connections). Fenêtre : Main ▸ AI ▸ Knowledge… ou
Command Center ▸ 📖 Knowledge Setup. Ils apportent à l'IA le contexte permanent
de votre domaine : définitions métier, règles d'interprétation, nomenclatures,
conventions, ontologies sectorielles.
Un seul répertoire : WysiQ/AI/protocol/
    Les schémas techniques WysiQ (Protocol v0.2) et vos fichiers Knowledge
    coexistent dans le même répertoire. Tous les fichiers JSON du répertoire
    sont listés dans l'écran Knowledge avec leur état Send individuel.
    Les fichiers WysiQ par défaut (000_protocol_handshake…, 001_ai_response…
    etc.) sont présents dès l'installation. Vous pouvez y ajouter librement
    vos propres JSON de contexte métier.
Colonne Send  ☑ / ☐
    Cliquer sur la case bascule l'état du fichier : ☑ = envoyé à la connexion,
    ☐ = ignoré. L'état de chaque fichier est mémorisé entre les sessions dans
    WysiQ/AI/protocol_send_selection.json.
    Seuls les fichiers cochés sont inclus dans le handshake Protocol WysiQ v0.2
    transmis au début de chaque session AI.
Ce que l'IA fait avec les Knowledge
    Au Connect, WysiQ envoie l'ensemble des fichiers ☑ comme contexte système.
    L'IA reconnaît ainsi vos codes produits, unités, seuils métier, noms de
    séries ou toute règle d'interprétation propre à votre domaine, sans que
    vous ayez à le rappeler à chaque question.
Langue des Knowledge
    Les Knowledge n'ont pas de langue prédéfinie : rédigez-les dans la langue
    de travail de votre domaine. Les schémas WysiQ par défaut sont en anglais.
Créer un fichier Knowledge
    Ajouter un fichier JSON dans WysiQ/AI/protocol/ (bouton Open protocol
    folder de la fenêtre AI Knowledge), ou dupliquer un fichier existant
    (clic droit ▸ Duplicate) puis l'éditer. Le JSON est vérifié à la
    sauvegarde — un JSON invalide est rejeté.
Aperçu
    La case JSON de la fenêtre AI Knowledge affiche l'aperçu du fichier
    sélectionné.
Clic droit sur un fichier
    Edit — ouvre l'éditeur JSON intégré avec vérification à la sauvegarde.
    Duplicate — copie le fichier sous un nouveau nom.
    Rename — renomme le fichier (l'état Send suit le renommage).
    Delete — supprime définitivement le fichier.
SESSIONS ET AI CASES
Les échanges IA sont archivés par requête WysiQ. Les échanges actuels sont
des AI Cases (qai/cases) : questions posées, réponses reçues, jetons
consommés et rapports HTML. Ils se consultent dans l'AI Case Center
(Main ▸ AI ▸ AI Cases…) et le Nav HTML (Main ▸ AI ▸ Answers…).
Les sessions historiques (versions précédentes) restent stockées dans
WysiQ/AI/sessions/<nom_requête>/ ; l'ancien écran Sessions n'est plus ouvert
par aucun menu (aide « ai_session_window »).
PROFILE
Un Profile est une instance configurée d'un fournisseur AI : modèle, URL,
clé API, température et timeout. Plusieurs profils peuvent coexister ; la
case Default connection marque le profil présélectionné par l'assistant
AI Setup / Bench.
Pour l'aide détaillée des champs du profil, ouvrir l'onglet Profile
puis cliquer le bouton ? de cet onglet.
