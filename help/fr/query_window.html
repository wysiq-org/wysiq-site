ECRAN QUERY — Last PCA summary — AIDE WysiQ

Accès : Settings ▸ Parameters… ▸ onglet Query, bloc « Last PCA summary »,
bouton ?.
Rôle
Cet écran regroupe les paramètres de la Query active et le résumé de la dernière ACP/PCA calculée dans Area.
Le bloc PCA a quatre onglets : Summary / loadings, Scores / datasets,
PCA guide, Multi-table PCA ; Refresh PCA relit le dernier résumé. Les paramètres d'axes et la disposition des
tables sont décrits dans les aides « query_params » et « table_layout ».
Une Query WysiQ n'est plus seulement une requête SQL : c'est une recette analytique. Elle peut décrire la table source, les séries sélectionnées, les Metrics construits, les bornes Area, les résultats PCA, les signaux, les tests et le Feed AI.
Paramètres de query
Y axis : unité, échelle, décimales et facteur de période.
Axes / ticks : bornes X/Y et graduations pour l'affichage et l'extraction des données.
Ces deux blocs peuvent être masqués pour laisser plus de place au résumé PCA.
Résumé ACP
La section Last PCA summary montre le dernier calcul PCA effectué depuis Area.
Ce qui est sauvegardé dans query.json :
- le contexte de la Query,
- la table source,
- les colonnes utilisées,
- les définitions de Metrics présentes dans la Query,
- les bornes X/Y utilisées pour le dernier calcul PCA,
- les séries A qui ont servi d'entrée à l'ACP,
- les PC calculées,
- les pourcentages de variance expliquée et cumulée,
- les coefficients et contributions principales.
Ce qui n'est pas sauvegardé :
- les valeurs lourdes des séries AXIS_PC1, AXIS_PC2, etc.,
- AXIS_RECONSTRUCTION_ERROR,
- AXIS_DIST_PCA.
Ces séries doivent être recréées dans Area avec le bouton PCA→Series, ou matérialisées dans une table de travail si vous voulez les conserver durablement.
Table variance
Variance % : part d'information expliquée par chaque composante.
Cumulative % : information conservée en cumulant PC1, PC2, PC3, etc.
Table coefficients / loadings
Pour rester lisible, l'écran affiche les principales séries contributrices de chaque PC, généralement les 3 plus importantes par composante.
PC1, PC2, ... : coefficient de la série dans chaque composante.
P1%, P2%, ... : contribution relative de cette série dans la composante.
Dom.PC : composante où cette série pèse le plus.
Σ|coef| : importance globale de la série dans les PC affichées.
mean / scale : centrage et échelle utilisés pour le calcul.
La couleur reprend la couleur réelle de la série dans la palette Series.
Règle pratique
Si vous voulez plusieurs ACP historiques, utilisez Post-it ou PPTX.
Si vous voulez réutiliser les valeurs PC plus tard, exportez/materialisez une table de travail.
