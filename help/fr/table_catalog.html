WysiQ — Table Catalog (catalogue des tables)

Accès : Main ▸ Database ▸ Catalog…
RÔLE
Le Table Catalog liste et documente les tables du workspace (Host = Local
(DuckDB)) ou les tables d'une connexion SQL (Host = un profil connecté).
Il sert à choisir les tables et colonnes retenues (Sel), gérer les recettes
de réduction (Recipe / shrink), consulter l'origine (Import source), renommer,
supprimer, et préparer une acquisition DB Live.
Il ne convertit PAS une table Static en Live par un simple clic.
Processus type (base distante) :
  Host = profil → Search table / Column LIKE → cocher Sel (crée la définition
  JSON) → cocher les colonnes utiles → Recipe (shrink) → la table apparaît dans
  Main (RS) → l'ouvrir ; ou clic droit ▸ Create DB Live… pour un suivi Live.

BARRE DU HAUT

  Close                 Ferme la fenêtre.
  Refresh               Relit la liste et le détail.
  Reload DuckDB         (Host local) Après confirmation, relit depuis le disque
                        chaque table .parquet du registre (colonnes cochées +
                        shrink) et réduit sur place les autres tables en mémoire
                        qui ont un tables/<nom>.json. Résumé « n table(s)
                        processed » et erreurs éventuelles.
  Rebuild remote JSON   (Host distant) Après confirmation, SUPPRIME toutes les
                        définitions JSON des tables de cette connexion : les
                        sélections de colonnes et recettes sont effacées, puis
                        la liste distante est relue. À utiliser pour repartir
                        d'un catalogue propre.
  Drop                  Supprime la table sélectionnée après confirmation (le
                        message liste exactement ce qui sera supprimé) :
                          Local : DROP dans DuckDB + suppression du .parquet et
                                  du .json ;
                          Distant : DROP TABLE exécuté sur le serveur.
                        Une source Live (L) se supprime dans Live Sources.
  Rename…               Renomme la table (DuckDB, fichiers, registre ; RENAME sur
                        le serveur pour une connexion distante) et met à jour
                        les Queries sauvegardées qui l'utilisent. Un Live L se
                        renomme dans Live Sources.
  → AI                  Envoie la définition de la table (structure, pas les
                        données) dans l'AI Feed Stack.
  ?                     Cette aide.

FILTRES

  Host:            Local (DuckDB) ou un profil de connexion actif.
  Search table:    Filtre sur le nom de table (pendant la frappe).
  Column LIKE:     Liste les tables contenant une colonne correspondant au
                   motif (syntaxe LIKE, % = joker).
  Catalog:         (Oracle) All (ALL_TABLES) ou User (USER_TABLES).

LISTE DES TABLES — COLONNES

  Type :
    LO  table locale indépendante (DuckDB/Parquet) — affichée LS dans Main
    RS  table issue d'une base SQL, copie statique
    RL  table persistante associée à une acquisition SQL Live
    WS  table issue d'un connecteur WWW, chargement Static
    WL  table issue d'un connecteur WWW, actualisation Live configurée
    L   source technique LIVE1/LIVE2… gérée dans Live Sources
    DB  table distante pas encore enregistrée dans le workspace
    V   ancien objet de type vue (lecture seule), seulement s'il existe
  Type indique l'origine et le mode déclaré, PAS l'état Running/Paused.
  Source name  Nom de la table ou de la source.
  Sel          ✓ = définition retenue. Clic :
                 local  — retient / retire la table (une table décochée
                          disparaît de la liste Main, sans être supprimée) ;
                 distant — crée ou supprime le JSON de définition dans
                          workspace/tables/ ;
                 L       — coche / décoche toutes les séries Live.
  Recipe       Indicateur de recette (shrink). Clic : ouvre la boîte Shrink
               (sauf L et V).
Clic sur un en-tête : tri croissant / décroissant.
Rows max. (bas de liste) : nombre maximal de lignes lues pour l'aperçu et
les statistiques (ALL ou vide = sans limite ; défaut 500, partagé avec le
paramètre global).
BOÎTE SHRINK (Recipe)
  Shrink to: N + Auto    réduire à environ N lignes ;
  Every: N + Every       garder une ligne sur N ;
  Apply                  enregistre la recette (appliquée au chargement) ;
  Delete                 supprime la recette ; Cancel ferme sans changer.
DÉTAIL (cadre Definition)
  WysiQ name, Rows, Columns, Owner, Created, Modified : métadonnées.
  Import source : origine RÉELLE de la table — fichier ou répertoire,
    connexion SQL / table, ou connecteur WWW de l'API Internet.
    Pour WS/WL, le nom vient de workspace/WWW/connectors/ et du lien
    source/www_source mémorisé dans tables/<table>.json ; une infobulle montre
    le texte complet. « WWW: connector not linked » signale un connecteur
    absent. Une copie DuckDB/Parquet ne change pas cette origine.
  File path : chemin complet pour une source L issue de fichiers.
  SQL (view) : texte SQL d'un ancien objet V.
  Les champs modifiables se valident par Entrée.
Colonnes (liste de droite) : Sel / Column / Type.
  Clic sur Sel d'une colonne : la retient ou l'exclut (persistant, utilisé par
  les Queries, le SQL Assistant et Reload DuckDB). Clic sur l'en-tête Sel : tout
  cocher / tout décocher. Le X d'un Live L reste coché.
MENU CLIC DROIT (sur une table)
  Edit shrink…                     Ouvre la boîte Shrink.
  View: no shrink / Live table: managed in Live Sources   (grisés, informatifs)
  → AI                             Comme le bouton → AI.
  Create DB Live…                  (tables SQL, pas WS/WL) Prépare une source
                                   DB Live (colonne X, clé, début/fin, polling)
                                   dans Live Sources.

PRÉPARER UNE SOURCE LIVE

- Base SQL : connexion existante, choisir la table, clic droit ▸ Create DB
  Live…, puis régler X, clé, début/fin et polling dans Live Sources.
- WWW/API : Main ▸ Database ▸ WWW Connection, choisir le connecteur, la
  ressource, les dates et l'actualisation (Static ou Live), puis télécharger.
- Fichiers : Live Sources ▸ Add source ▸ fichiers.
Une source Live L et une table persistante RL/WL ne sont pas la même chose.
Enregistrer un mode ne lance pas une acquisition ; ni le Type ni un double-clic
ne convertissent une table.
STOCKAGE
Définitions des tables : workspace/tables/*.json.
Connecteurs WWW : workspace/WWW/connectors/*.json.
Définitions Live L : workspace/live/live_tables.json.
Les fichiers Parquet ne sont ni renommés ni effacés par l'affichage du
catalogue. Les secrets de connexion ne sont jamais affichés dans Import source.
