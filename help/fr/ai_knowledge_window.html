AI Knowledge Setup

Cette fenêtre autonome gère les fichiers JSON protocole/connaissance
envoyés à l'IA à la connexion (AI Connections). Ouvrez-la depuis Main ▸ AI ▸
Knowledge…, AI Command Center ▸ 📖 Knowledge Setup, ou Parameters ▸ AI.
Elle contient la liste « Protocol schemas » ; ? ouvre cette aide, Close
ferme la fenêtre (la sélection Send est enregistrée).

ONGLET PROTOCOL SCHEMAS

Les fichiers de connaissance sont des fichiers JSON envoyés à l'IA à
chaque connexion. Ils donnent à l'IA le contexte permanent de votre
domaine : définitions métier, règles d'interprétation, nomenclatures,
conventions, ontologies sectorielles — en plus des schémas techniques
propres à WysiQ (handshake, format de réponse, schémas de requête
métrique/PCA/signal/stat).
Répertoire unique : WysiQ/AI/protocol/
    Les schémas techniques par défaut de WysiQ (000_protocol_handshake_
    generic…, 001_ai_response_required_format… etc., présents dès
    l'installation) et vos propres fichiers JSON de contexte métier
    coexistent dans le même répertoire. Chaque fichier JSON trouvé y est
    listé avec son propre état Send.
Colonne Send
    Cliquez sur le symbole pour basculer l'état d'un fichier :
    ✓ = envoyé à la connexion, ○ = ignoré. L'état de chaque fichier
    est mémorisé entre les sessions dans
    WysiQ/AI/protocol_send_selection.json.
    Seuls les fichiers ✓ sont inclus dans le handshake du protocole
    WysiQ transmis au début de chaque session IA.
Schémas ★ CORE (000, 001, 002)
    Les trois fichiers marqués ★ sont le vocabulaire protocol minimal.
    Ils sont ✓ par défaut. Pour un chat simple hors protocole WysiQ
    (prompts et data seulement), décochez les trois (○) avant Connect.
    Le bouton « Reset (recommended) » remet les valeurs conseillées.
Autres fichiers protocol (010, 020, 040…)
    Non envoyés à Connect. Ils partent automatiquement avec le JSON AI Feed
    lorsque le type correspondant est dans l'AI Feed Stack (ex. feed Signals
    → schémas signal). La colonne Send ici ne concerne que Connect.
Bouton JSON
    Affiche ou masque l'aperçu du fichier sélectionné (masqué par défaut).
Liste des schémas (gauche) / aperçu JSON (droite)
    Sélectionnez un fichier à gauche pour prévisualiser son contenu à
    droite.
Clic droit sur un fichier : Edit, Duplicate, Rename, Delete
    Double-clic sur une ligne (hors colonne Send) : Edit. L'éditeur JSON
    propose Save et Cancel.
    Pour importer des fichiers partagés par un collègue, copiez-les dans
    WysiQ/AI/protocol/ (Open protocol folder), puis rouvrez la fenêtre.
→ AI Feed Stack
    Dépose le schéma sélectionné dans l'AI Feed Stack courant.
Open protocol folder
    Ouvre WysiQ/AI/protocol/ dans l'explorateur de fichiers système —
    pour ajouter, inspecter ou éditer directement les fichiers JSON de
    connaissance avec n'importe quel éditeur.
Langue des fichiers de connaissance
    Les fichiers de connaissance n'ont pas de langue prédéfinie :
    rédigez-les dans la langue de travail de votre domaine. Les schémas
    par défaut de WysiQ sont en anglais.
ORGANISATION DU WORKSPACE  (dossier AI/)
AI/protocol/
    Fichiers JSON de protocole + connaissance sélectionnables avec la
    colonne Send ci-dessus. Envoyés à la connexion.
AI/protocol_send_selection.json
    Stocke les bascules Send de chaque fichier JSON de protocole/
    connaissance.
AI/Feed/<lang>/
    Dictionnaire de questions (Requests Catalog du Command Center ;
    Parameters ▸ AI).
AI/sessions/ et qai/cases/
    Échanges IA archivés (anciennes sessions et AI Cases ; voir AI Case
    Center).
Les définitions de métriques, métadonnées de séries, résultats PCA,
corrélations, tests et signaux sont envoyés avec le JSON d'analyse de
requête au moment de la question, pas depuis cet écran Knowledge — cet
écran ne contrôle que les fichiers *protocole / contexte métier*
envoyés une seule fois à la connexion.
Les règles d'interprétation PCA, ou toute autre règle propre à votre
domaine, peuvent être ajoutées comme un fichier JSON normal directement
dans AI/protocol/ — donnez-lui un nom de fichier descriptif et cochez-le
dans la colonne Send ci-dessus.
