Sort X — Aide

Sort X définit l'ORDRE des points (les lignes de la query) le long de X, avec
jusqu'à trois clés de priorité. S'ouvre depuis le bouton Sort X de la palette
Séries (ligne Table + X Axis). Le tri est sauvegardé avec la query.
CHAQUE LIGNE (Sort 1, Sort 2, Sort 3)
  Colonne  Ce sur quoi on trie : « <X> — X-axis value » (le X tracé, y compris
           une métrique X composée) ou l'une des entrées de la métrique X
           active. Vide = ligne inutilisée. Sort 1 s'applique d'abord, puis
           Sort 2 pour départager les égalités, puis Sort 3.
  Mode     Comment la valeur est lue :
             Value               la valeur elle-même (date ou nombre)
             Weekday             jour de la semaine ; l'ordre commence au
                                 jour défini dans Réglages ▸ Globals ▸ Core ▸
                                 Week 1st day
             Day of month (1–31) regroupe tous les 1ers du mois, tous les 2, …
             Week-in-month       numéro de la semaine dans son mois (1–5)
             Month               mois de l'année (jan … déc)
             Year                année civile
           Les modes proposés se règlent dans Réglages ▸ Globals ▸ List values
           ▸ Sort X (clés séparées par des virgules raw, dow, dom, wom, month,
           year ; listes distinctes pour X date et X numérique ; les anciens
           pas polaires saisis là sont ignorés).
  ASC/DESC Ordre croissant ou décroissant.
           « <X> — X-axis value » en DESC avec le mode Value retourne l'axe X
           (grandes valeurs à gauche ; les graduations restent linéaires).
AFFICHAGE
  Les modes calendaires (Weekday, Month, …) conservent l'ordre Sort X des
  lignes. Pour les séries rendues en Line ou Both, les points sont alors
  dessinés en marqueurs seuls (sans ligne qui les relie), sinon le graphe se
  remplirait de segments qui font des allers-retours dans le temps. Les séries
  en Point et les graphes polaires ne changent pas.
BOUTONS
  ?        Cette aide.
  Clear    Supprime le tri (retour à l'ordre naturel de X) et replotte.
  Cancel   Ferme sans appliquer.
  Apply    Applique et replotte ; la fenêtre reste ouverte pour comparer.
