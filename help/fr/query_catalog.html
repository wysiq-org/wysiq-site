Catalogue des Queries

Accès : Main ▸ Query ▸ Catalog.
Le Catalogue des Queries liste toutes les Queries sauvegardées dans le
workspace courant. Il permet de parcourir, filtrer, ouvrir, renommer et
supprimer des Queries sans passer par l'arbre de la fenêtre principale.
Zoom texte : Ctrl + molette.

BARRE D'OUTILS

Refresh
  Recharge la liste depuis le disque. À utiliser si des Queries ont été
  sauvegardées ou supprimées pendant que le catalogue était ouvert.
Open
  Ouvre la Query sélectionnée dans une fenêtre Graph. Équivalent au
  double-clic sur la ligne (hors colonne Sel) ou à la touche Entrée.
→ AI
  Envoie la définition de la Query sélectionnée (structure JSON, sans
  données) dans l'AI Feed Stack.
Rename
  Ouvre un dialogue pour renommer la Query (raccourci F2). Le fichier JSON
  est renommé et son champ interne query_name mis à jour.
Delete
  Supprime définitivement la Query sélectionnée (raccourci touche Suppr).
  Un dialogue de confirmation est affiché avant toute action.
JSON
  Ouvre le JSON brut de la Query sélectionnée dans une visionneuse de texte
  en lecture seule. Utile pour inspecter la définition complète sans ouvrir
  une fenêtre Graph. Supporte Ctrl + molette (zoom) et défilement horizontal.
  Search (en bas à gauche) : taper un mot, << / >> (ou Entrée / Maj+Entrée)
  pour l'occurrence précédente / suivante, compteur n/N. Ctrl+F : champ de
  recherche, Échap : effacer.
?
  Ouvre cette fenêtre d'aide.

PANNEAU GAUCHE : FILTRES ET LISTE DES QUERIES

Catalog filters
  Query like
    Filtre la liste sur une sous-chaîne du nom de Query.
  Table like
    Filtre la liste aux queries qui référencent une table dont le nom
    contient le texte saisi.
  Les deux filtres sont cumulables.
Liste Queries
  Colonne Sel
    ✓      = la Query est visible dans l'arbre de la fenêtre principale.
    (vide) = la Query est masquée de la fenêtre principale.
    Clic sur une ligne de la colonne Sel pour basculer la visibilité.
    Clic sur l'en-tête Sel pour tout activer / tout masquer en une fois
    (tout activer si au moins une query est masquée, sinon tout masquer).
    Le réglage est persisté dans params.json immédiatement. L'arbre de
    la fenêtre principale est rafraîchi automatiquement après chaque
    basculement.
  Tri
    Clic sur le label d'en-tête « Queries [A-Z ▲] » pour cycler entre
    quatre modes de tri : A-Z, Z-A, Date croissant, Date décroissant.
Liste Table (à droite de Queries)
  Liste les tables distinctes référencées par les queries chargées.
  Clic sur un nom de table pour filtrer la liste Queries sur cette table.
  Clic sur « (all) » pour retirer le filtre table.
  Clic sur l'en-tête « Table ▲ » pour trier la liste table.
MENU CONTEXTUEL SUR UNE QUERY (clic droit)
Le clic droit sur une ligne de query ouvre un menu contextuel :
  Open
    Ouvre la query dans une fenêtre Graph.
  → AI
    Envoie la définition de la query dans l'AI Feed Stack.
  Rename…
    Renomme la query.
  Save metrics to catalog
    Parcourt le JSON de la query à la recherche de séries virtuelles
    (metrics / combo). Tout metric trouvé qui n'existe pas encore dans
    le catalogue des metrics est créé (workspace/metrics/).
    Les metrics déjà présents sont ignorés pour ne pas écraser l'existant.
    Un dialogue de résumé indique combien de metrics ont été créés ou ignorés.
    À utiliser quand une query contient des metrics qui n'ont jamais été
    explicitement sauvegardés dans le catalogue.
  Delete
    Supprime définitivement la query.

PANNEAU DROIT : DÉTAIL DE LA QUERY

En-tête Query
  Query     Nom de la Query sélectionnée.
  Owner     Propriétaire enregistré dans le JSON (si présent).
  Table     Table de référence de la Query.
  Modified  Horodatage de dernière modification stocké dans le JSON.
Liste Series
  Affiche les séries (colonnes) définies dans la Query sélectionnée.
  Pour une Query multi-tables, les séries sont préfixées par leur table
  (Table.série).
  Colonnes :
    @      Marqueur métrique. Affiché uniquement pour les séries
           virtuelles (expr_type non vide) : @ pour une métrique standard,
           ❄ pour une métrique figée (frozen).
    Serie  Nom de colonne ou de métrique.
    Axe    Axe : X pour l'axe X, Yl ou Yr pour l'axe Y gauche/droite.
           Yl/Yr n'est affiché que pour les séries ayant G (Graph) actif.
    G      ✓ si la série est tracée dans la vue graphe.
    T      ✓ si la série apparaît dans la vue table.
    A      ✓ si la série est active dans la vue area.
    Coeff  Coefficient d'échelle appliqué à la série.
  Seules les séries ayant au moins un flag actif (G, T ou A) sont
  affichées, plus toutes les métriques quel que soit leur état.
  Clic sur l'en-tête « Serie ▲ » pour trier les séries. La ligne X
  reste toujours en tête de liste.
  Le double-clic sur une série metric (marqueur @ ou ❄) ouvre le Combo Editor
  directement pour ce metric, sans avoir à ouvrir la query dans une fenêtre Graph.
  Appuyer sur Entrée sur une ligne metric focalisée a le même effet.
Visionneuse JSON
  Affiche le JSON brut de la Query sélectionnée. Lecture seule ; utiliser
  Open pour modifier la query via la fenêtre Graph.
  Ctrl + molette pour zoomer le texte.
AI Answers — Réponses AI
  Les échanges AI de la query sélectionnée, du plus récent au plus ancien.
  Ils viennent des AI Cases de la query (AI Command Center), plus les
  anciennes réponses HTML s'il en reste.
  Colonnes :
    Date         Date et heure locales.
    AI profile   Profil qui a répondu.
    Answer       Début de la réponse, ⚠ + message pour une erreur, ou
                 📄 pour un rapport HTML.
  Une réponse et son rapport HTML partagent une ligne (📄 = rapport disponible).
  Double-clic (ou Entrée) : les lignes 📄 s'ouvrent dans le navigateur ; les
  autres ouvrent l'AI Case Center sur leur Case.
  Open in browser  Comme le double-clic.
  Open AI Case     Ouvre l'AI Case Center sur le Case de la ligne choisie.
  L'icône 🤖 de la liste des queries signale les queries qui ont un AI Case.
RACCOURCIS CLAVIER (liste des Queries)
  Entrée = Open · F2 = Rename · Suppr = Delete · double-clic = Open.

VISIBILITÉ DANS LA FENÊTRE PRINCIPALE

Le flag Sel du Query Catalog contrôle quelles queries apparaissent dans
l'arbre de la fenêtre principale.
Les queries avec Sel = (vide) sont masquées de la fenêtre principale,
même après un Refresh. Seules les queries avec Sel = ✓ sont listées.
Cela permet de garder la fenêtre principale lisible tout en conservant
toutes les queries dans le catalogue pour un accès occasionnel.
Le réglage est stocké dans params.json sous la clé "hidden_queries".
