METRIC SCOPE — Aide

Accès : Éditeur de métrique ▸ bouton ? de la barre Where Series / NaN Policy.
Le Metric Scope définit les filtres et restrictions appliqués lors du calcul
d'une métrique. Les paramètres sont indépendants et cumulatifs.
☑ Where Series  (barre de scope dans le Metric Editor)
Quand coché (ON par défaut), les clauses WHERE définies sur les séries
sources sont propagées au calcul de la métrique.
Exemple numérique : si une série source est filtrée avec « <= 0 » ou
« < -15000 », la métrique n'est calculée que sur les points conservés par
ce filtre. Les points exclus deviennent des NaN volontaires.
Désactiver pour obtenir la valeur brute de toutes les lignes, sans les filtres
des composants.
NaN Policy  (à côté de Where Series)
Cette option indique comment les NaN produits par les filtres sont traités
dans les calculs de composition.
  NaN+x=x
    Mode souple : les NaN sont ignorés quand d'autres valeurs existent.
    Utile pour des additions classiques de séries partiellement vides.
  NaN+x=NaN
    Mode strict : si une série-condition filtre un point, le résultat reste
    absent. Utile pour les recherches d'événements avec plusieurs conditions,
    par exemple :
      PROD-CONSO < -15000
      AND Solaire <= 0
    Dans ce cas, une série à coefficient 0 peut servir de condition sans créer
    une fausse ligne horizontale à 0.
Metric Scope on X  (bouton en bas du Metric Editor)
Popup WHERE standard avec opérateurs c1 / c2 / c3 appliqué à l'axe X.
Exemples :
  c1 :  >=  2020-01-01
  join: AND
  c2 :  <=  2023-12-31
  → La métrique n'est calculée que sur la plage 2020–2023.
  c1 :  >=  0
  join: AND
  c2 :  <=  120000
  → Restriction numérique sur X.
Bouton 📅 sur chaque champ valeur : ouvre le sélecteur de date
(Day / Month / Year) et insère la date au format ISO YYYY-MM-DD.
L'activation se fait automatiquement dès qu'une valeur est saisie (case
Where ON). Bouton + : affiche / masque la condition c3. Apply valide,
Cancel ferme sans modifier. Le libellé à côté du bouton indique le filtre
actif ou « not set ».
Placement X0  (mode de positionnement, post-calcul)
Contrôle où le premier point non nul de la métrique est placé sur l'axe X,
une fois le calcul terminé. Trois modes :
  none      Comportement par défaut : aucun repositionnement.
  Table X0  Suit le X0 de la table / query dans les dispositions
            multi-tables.
  Free X0   Place le premier point non nul scopé à l'index de ligne graphe
            demandé. La longueur est déjà définie par Metric Scope on X.
Ce placement agit après le calcul ; il ne filtre pas les données.
Filtrage des lignes de table
Le filtre « Metric Where » des anciennes versions a été retiré. Le filtrage
des lignes de la table passe désormais par un seul chemin : le WHERE de la
palette Table. Pour restreindre les lignes AVANT l'agrégation, définissez le
WHERE sur la série / la table concernée ; Where Series le propage ensuite au
calcul de la métrique.
Combinaison et résumé
Where Series + NaN Policy + Metric Scope on X + Placement X0 peuvent être
actifs simultanément. Le résumé « Scope: X + S + X0 » indique quels filtres
sont actifs :
  X   = Metric Scope on X (axe X)
  S   = Where Series (filtres des séries sources propagés)
  X0  = placement Table X0 ou Free X0
Le résumé affiche « Scope: none » quand aucun n'est actif.
