AI Connections — WysiQ

Accès : AI Command Center ▸ PANELS ▸ 👤 AI Connections (Ctrl+N dans le
Command Center).
La fenêtre AI Connections ouvre l'AI Case de la query, choisit un profil IA et
le connecte. Les envois (feeds JSON, données, questions) se font ensuite dans
l'AI Command Center : prompt, ▶ Send, >>AI Next, ⚡ Analyze graph. Chaque
échange est archivé automatiquement dans l'AI Case actif (voir AI Case Center).
Processus type :
  AI Case: (nom proposé = nom de la query) → Create → AI profile: → Connect
  → retour au Command Center (un onglet par profil connecté) → envoyer.

CONTRÔLES

  AI Case:      Nom de l'AI Case (champ modifiable). Un clic sur le nom
                affiché permet de le renommer.
  Create        Crée l'AI Case (commun à tous les profils) ou le rouvre s'il
                existe déjà. Un profil IA doit être sélectionné.
  Close         Ferme le panneau (la connexion et le Case restent actifs ;
                le Command Center peut être fermé ou ouvert sans couper la
                session).
  ?             Cette aide.
  Last req:     Jetons du dernier échange (tous profils).
  Session:      Total cumulé des jetons de l'AI Case actif.
  AI profile:   Profil IA à utiliser (liste des profils de Parameters ▸ AI).
  Connect       (actif seulement quand un AI Case est créé ou ouvert)
                Connecte le profil courant : envoie en handshake les schémas
                de protocole sélectionnés et le contexte query/Case. N'envoie
                pas le payload analytique. Une fois connecté, le bouton
                devient Disconnect (le profil se déconnecte, le Case reste
                ouvert, les autres profils restent actifs).
  AI Params     Ouvre Parameters ▸ AI (profils, clés, modèles).
  Open Nav      Ouvre le visualiseur HTML des réponses.
  Connection log  Journal de la connexion (handshake, erreurs, jetons).

AI CASE UNIQUE MULTI-PROFILS

Un seul AI Case regroupe tous les profils IA actifs : même dossier, même
historique, même nom affiché.
  Profil principal (main)
    Le premier profil connecté devient le profil principal. Ses questions
    (JSON AI Feed, Data AI Feed, Send) sont les événements de référence du
    Case, rejouables sur les autres profils.
  Profils secondaires
    Tout profil ajouté ensuite est secondaire. À sa connexion, il reçoit
    automatiquement en replay les questions déjà posées au profil principal,
    pour produire sa propre réponse sur le même feed analytique. Chaque
    profil a son propre onglet dans le Command Center.
  Changer d'onglet (profil)
    Sélectionner l'onglet d'un profil dans le Command Center bascule vers ce
    profil, sa file de replay et son historique ; le Case ne change pas.

PROTOCOLE

- La sélection des schémas envoyés par Connect se fait dans AI Knowledge
  Setup (colonne Send). Reset (recommended) rétablit les 3 schémas ★ CORE
  (000, 001, 002) si tout a été décoché par erreur.
- Les autres schémas (PCA, signaux, stats…) partent automatiquement avec le
  feed JSON correspondant de l'AI Feed Stack.
PAYLOAD ET ENVOI (dans le Command Center)
- Les feeds de l'AI Feed Stack décident de ce que contient le JSON
  d'analyse (graphe, Area, tests, signaux, corrélations, PCA, scénario).
- Les échantillons de données ne sont envoyés que sur demande ; seule leur
  recette est archivée, jamais les valeurs des lignes — un replay régénère
  un échantillon frais à partir des données actives.
- ▶ Send envoie la question du prompt au profil actif (et aux cibles
  Broadcast).
  INTÉGRITÉ DES DONNÉES
  Les schémas de protocole imposent à l'IA de n'utiliser que les données
  reçues dans les payloads WysiQ. Elle ne doit jamais inventer, extrapoler
  ou imaginer des valeurs, noms, montants ou identifiants absents du payload.
  Si une donnée est absente, l'IA doit le dire explicitement.

REPLAY

- >>AI Next (Command Center) parcourt les étapes en file pour le profil
  actif. La file peut être préparée dans l'AI Case Center.
- Quand un profil secondaire est connecté, le replay des questions du profil
  principal est déclenché automatiquement.
- Seules les questions du profil principal sont dupliquées sur les profils
  secondaires ; celles posées directement à un profil secondaire lui restent
  propres.

COMPTEURS DE JETONS

- « Last req » : jetons du dernier échange, tous profils confondus.
- « Session » : total cumulé de l'AI Case actif ; remis à zéro à chaque Create
  et Close du Case.
- Le compteur sous l'onglet d'un profil (Command Center) affiche les jetons de
  sa dernière requête.
