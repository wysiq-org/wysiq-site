ÉDITEUR DE MÉTRIQUE — Aide

Accès : palette Series ▸ clic sur @ d'une métrique, clic droit ▸
Composition…, en-tête « Create Metric from "In" » ; catalogue des métriques.
Processus type :
  cocher In sur les séries sources → Create Metric from "In" → choisir Agg et
  Post → régler chaque composante (Transform, k, +/-, Where…) → Group by X si
  besoin → Apply → la métrique apparaît dans la palette Series (@).
L'Éditeur de Métrique (fenêtre Composition) construit une métrique calculée
à partir de plusieurs séries avec des transformations par série, une
agrégation, un post-traitement et un fenêtrage sur X.
La métrique est enregistrée avec la query et peut être sauvegardée dans le
catalogue workspace/metrics/<nom>.json. Elle est identifiée par son seul nom
(la table n'entre pas dans l'identité) et réutilisable par d'autres queries
dont les tables ont les mêmes colonnes.
EN-TÊTE
  Name      Nom de la métrique (lecture seule ici ; renommer depuis la palette
            Series, clic droit ▸ Rename…).
  Alias     Libellé court affiché dans la légende.
  Output    Type du résultat : auto, datetime, float, int, str (datetime pour
            une métrique utilisée comme axe X).
  Description  Texte libre enregistré avec la métrique.

BARRE DU HAUT

Agg  [SUM | AVG | MIN | MAX | RANGE | MEDIAN | * | / | PROD | NORM-L1 |
      NORM-L2 | RMS | STDDEV | VARIANCE | SUM-SQ | SUM-SQRT | ENTROPY]
  Comment les composantes actives sont combinées en une seule valeur, ligne
  par ligne (étape 4 de l'ordre d'application). Le Group Agg (étape 6)
  s'applique ENSUITE au résultat combiné et post-transformé. Les deux réglages
  sont indépendants.
  Standard : SUM  AVG  MIN  MAX  RANGE  MEDIAN  *  /
  Norme : NORM-L1 (S|xi|)  NORM-L2 (sqrt(S xi^2))  RMS (sqrt(moy(xi^2)))
  Statistiques : STDDEV  VARIANCE
    Note : STDDEV et VARIANCE n'ont de sens qu'avec au moins 3 à 5 composantes.
    Avec 1 ou 2 composantes, le résultat est trivial (0 ou sqrt(diff/2)).
  Non-linéaires : PROD  SUM-SQ  SUM-SQRT
  Information : ENTROPY (entropie de Shannon : -S(pi * log2 pi))
Post  [none | √ | ² | ³ | ABS | LOG | LN | 100× | %]
  Transformation sur le résultat final de l'agrégation (après Agg).
  none   Aucune (défaut).
  √ / ² / ³ / ABS / LOG / LN   Fonctions mathématiques classiques.
  100×   Multiplie par 100 (ex. 0.42 → 42%).
  %      Normalise pour que la somme totale vaille 100%.
Add [liste déroulante]
  Double-clic pour insérer la série sélectionnée comme composante.
Export   Exporte la définition complète de la métrique (fichier JSON).
JSON     Fenêtre JSON de la métrique : Copy, Paste, Apply (applique le JSON
         édité), Export, Import (charge un fichier dans l'éditeur), Close.
SQL      Affiche l'équivalent SQL du calcul (Copy, Close) — informatif.
?        Cette aide.

GRILLE DES COMPOSANTES

  Column     Nom de la série source.
  Where      Indicateur du filtre (vert = actif). Clic pour ouvrir.
  Sc         Mode de jointure (AND / OR) pour les filtres globaux.
  Transform  Transformation appliquée AVANT le multiplicateur k.
    √ SQRT, ² square, ³ cube, |·| ABS, LOG₁₀, LN, EXP eˣ, 1/x inv, — none,
    % of sum, Z-score, RANK
  k          Multiplicateur APRÈS la transformation (défaut 1.0).
             Constante ou référence &1.4 — clic droit sur le champ.
  +/-        Décalage constant APRÈS k (défaut 0.0). Clic droit → variables.
  Min / Max  Bornes de valeur après transformation, k et offset.
  Delta      Décalage en points sur X.
  Fill       Valeur de remplissage. Clic droit → variables (&1.4).
Group by X — Lag, Size, Step : clic droit pour insérer une variable.
X0 Free : clic droit pour une variable.
Clic gauche sur le nom → Popup WHERE (voir ci-dessous).
Clic droit → Menu contextuel : Where / Duplicate / Delete.

POPUP WHERE PAR COMPOSANTE

Clic gauche sur le nom d'une composante pour ouvrir sa popup WHERE.
Le filtre s'applique AVANT la transformation et le multiplicateur k.
  Where ON   Interrupteur. ON = actif. OFF = suspendu.
  With other cols [NONE | AND | OR]
    NONE   Mode local. Les valeurs qui échouent au filtre deviennent 0
           (ou la valeur de l'offset). Les autres lignes ne sont pas
           affectées. La métrique s'exécute sur toutes les lignes.
    AND    Masque global. Les lignes qui échouent au masque combiné
           AND/OR sont mises à NaN sur TOUTES les composantes avant
           l'agrégation. Utilisez AND pour exclure des lignes entières
           (ex. export négatif sur n'importe quelle composante).
    OR     Comme AND mais en logique OR. Une ligne survit si elle passe
           au moins un filtre OR.
  c1   Première condition (toujours visible) : opérateur + valeur.
  join [AND | OR]   Logique entre c1 et c2.
  c2   Deuxième condition.
  Bouton +   Affiche ou masque c3 (troisième condition).
             Quand c3 est visible, il participe à la logique join.
             Cliquez à nouveau pour masquer c3 et effacer sa valeur.
  c3   Troisième condition (visible après avoir cliqué +).
  Opérateurs : =  !=  <  <=  >  >=  ~ (contient)  ^ (commence par)  $ (finit par)  in
Exemples courants :
  c1 : > 0                Seules les valeurs positives entrent dans l'agrégation.
  c1 : >= 10, join: AND, c2 : <= 100   Valeur bornée entre 10 et 100.
  c1 : != 0               Exclure les zéros exacts (données manquantes).
  With other cols : AND, c1 : <= 0    Exclure du metric les lignes où
                                       cette série est <= 0.
Le filtre WHERE s'applique AVANT la transformation et le multiplicateur k.
Pour filtrer sur le résultat final calculé, voir la section Ordre d'application.
GROUP BY X (fenêtrage)
Fenêtre le résultat combiné (après Agg, étape 4, et Post, étape 5) dans une
fenêtre sur X (étape 6).
Group by X   Off (aucun fenêtrage), Moving ou Fixed.
Moving       Fenêtre glissante de Size points.
Fixed        Blocs non chevauchants de Size points.
Lag          Points initiaux forcés à zéro.
Size         Taille de la fenêtre en points.
Step         Écart entre blocs (mode Fixed uniquement).
Group Agg  [AVG | SUM | CUM | MIN | MAX | Δ | ABS(Δ) | RANGE | MEDIAN | STDVAR]
  Réduction dans la fenêtre sur X, appliquée à la série combinée.
  Indépendant du Agg de la barre du haut (combinaison inter-séries).

ORDRE D'APPLICATION

  1. Metric Scope on X     Restriction à une plage de l'axe X.
  2. Filtre WHERE          Filtrage des valeurs par composante.
  3. Transform, k, offset, Min/Max, Delta   Par composante.
  4. Agg (barre du haut)   Combinaison de toutes les composantes (cross-séries).
  5. Post-transformation   Appliquée juste après Agg, AVANT le fenêtrage.
                           Exemple : Agg=SUM-SQ + Post=sqrt → norme euclidienne.
  6. Group Agg             Agrégation du résultat post-transformé dans les fenêtres X.
  7. WHERE palette Table   Filtre global sur le résultat final.
Les trois étapes d'agrégation/transformation en détail :
  Agg (étape 4)
    Opération CROSS-SÉRIES. Combine les N séries transformées ligne par ligne.
    Exemples : SUM de trois séries d'énergie, NORM-L2 des composantes.
  Post-transformation (étape 5)
    Appliquée à la série combinée produite par Agg.
    S'exécute AVANT Group Agg pour que le fenêtrage opère sur l'unité finale.
    Exemple : Agg=SUM-SQ + Post=√ → norme euclidienne (L2).
    Exemple : Agg=SUM + Post=100x → conversion en pourcentage.
  Group Agg (étape 6)
    Opération TEMPORELLE. Applique une fenêtre glissante ou fixe sur la série
    déjà agrégée et post-transformée.
    Exemple : moyenne mobile sur 48 points de la norme euclidienne.
    Group Agg est optionnel (désactivé quand Size = 0).
Appliquer un WHERE APRÈS la métrique (post-filtrage) :
  Les filtres WHERE par composante agissent AVANT l'agrégation. Pour filtrer
  sur le résultat final calculé, créez une seconde métrique qui inclut cette
  métrique comme seule composante, et ajoutez un WHERE sur cette composante.
  Exemple : la métrique A calcule une norme glissante ; la métrique B inclut
  A avec WHERE > 100 pour ne garder que les instants où la norme dépasse 100.

SERIE WHERE

Interrupteur maître pour tous les filtres WHERE par composante.
ON (défaut)   Tous les filtres actifs.
OFF           Tous suspendus sans suppression (utile pour comparaison rapide).

PERSISTANCE

Tous les paramètres sont sauvegardés dans le JSON et restaurés au rechargement :
  Agg, Post, Transform, k, +/-, Min, Max, Delta, Fill, filtres Where,
  paramètres Group by X, Alias, type Output.
  Les champs k, +/- et Fill peuvent contenir une référence &theme_id.var_id
  (ex. &1.4) dans l'éditeur ; à l'Apply/Save, le JSON metric enregistre la forme
  portable &theme.var (ex. &energie.seuil_kwh). La valeur est lue au tracé.
  Dans le picker, double-clic Value simule en session (*); Save écrit le JSON workspace.
  Fenêtre Variables (clic droit sur k, Min, Max, Δ, Fill…) : gardez-la ouverte (Stay open)
  pour simuler tout le graphe de la query (sliders, mode Vars series, Min/Max/Δ).
  Bouton Vars dans la palette Scénario pour tester des extrêmes pendant DRAW/MOVE.
  L'état Freeze est uniquement en session (non persisté).
BAS DE FENÊTRE
  Metric Scope on X   Restreint le calcul à une plage de X (voir l'aide
                      « metric_scope », bouton ? de la barre Where Series).
  X0  Table / Free    Origine des positions X de la métrique : Table (début
                      de la table) ou Free (valeur saisie, variable possible
                      par clic droit) ; les deux cases sont exclusives.
  Freeze              « Freeze » : gèle le résultat (cache ❄ Frozen) ;
                      « ⚠ Refreeze » si une source a changé ; décocher pour
                      dégeler.
  Apply               Calcule et applique la métrique au graphe (la fenêtre
                      reste ouverte).
  Close               Ferme l'éditeur.
Where Series et NaN Policy
Where Series active les conditions Where portées par les séries de la composition. Ces conditions servent souvent à détecter un événement métier : par exemple PROD-CONSO < -15000 ET Solaire <= 0.
NaN Policy contrôle ce qui arrive lorsqu'une série de condition filtre un point et produit un NaN dans le calcul final.
NaN+x=x : mode permissif. Les NaN sont ignorés dans la somme ; une série de condition avec k=0 peut donc créer des points à 0. Utile pour des additions classiques de séries partiellement vides.
NaN+x=NaN : mode strict. Si une série de condition est filtrée ou vaut NaN, le point final reste absent. Recommandé pour les filtres AND, les séries helper à k=0 et les recherches d'événements.
Valeur spéciale NaN dans les WHERE
  = NaN    Sélectionne les positions avec une valeur manquante (NaN / NULL / NaT).
  != NaN   Sélectionne les positions avec une valeur présente, y compris zero.
  = 0      Sélectionne les vrais zéros ; 0 et NaN sont différents.
  Les majuscules/minuscules sont ignorées (NaN, nan, NAN).
  Seuls = et != sont acceptés avec NaN ; < NaN ou > NaN ne correspondent a rien.
  Le Nb de chaque composante affiche combien de positions passent son WHERE.
  Avec With other cols = AND/OR, on peut utiliser un WHERE = NaN sur une
  composante pour limiter le calcul d'une autre composante à ces positions.
  Aucun NaN n'est remplacé par un zéro et aucune ligne absente n'est créée.
DÉTAIL DES AGRÉGATS (Agg)
  SUM       Somme des composantes actives.
  AVG       Moyenne arithmétique.
  MIN / MAX Minimum / maximum entre composantes.
  RANGE     Max moins Min (amplitude).
  MEDIAN    Médiane entre composantes (voir plus bas).
  *         Produit S1 × S2 — utilise les 2 premières composantes.
  /         Quotient S1 / S2 — utilise les 2 premières composantes ; une
            division par 0 donne NaN. À la sélection de /, un petit +/-
            de 0.001 est pré-rempli sur le dénominateur s'il est vide.
  PROD      Produit des N composantes : x1 × x2 × … × xn.
  SUM-SQ    Somme des carrés : S xi².
  SUM-SQRT  Somme des racines : S sqrt(|xi|).
  STDDEV / VARIANCE   Écart-type / variance entre composantes (population,
            ddof=0).
  ENTROPY   -S(pi × log2 pi) avec pi = |xi| / S|xi|.
La liste Add contient toutes les séries de la query (colonnes et autres
métriques) ; une même série peut être ajoutée plusieurs fois avec des
paramètres différents.
LIGNE DE RÉSULTAT (⟹ Metric)
Sous la grille, « ⟹ Metric nb=… [0]: … [N]: … » affiche le nombre de
valeurs et le résultat sur la première et la dernière ligne ; elle se met
à jour quand un paramètre change. « (no data …) » : lancer un PLOT ou
ouvrir la Table pour disposer des données.
FREEZE (détail)
  Freeze (décoché)  calcul en direct à chaque tracé.
  ❄ Frozen          résultat gardé en cache, réutilisé tel quel.
  ⚠ Refreeze        une source a changé : le cache est périmé ; Apply le
                    recalcule.
L'état Freeze n'est pas enregistré : après rechargement, la métrique est
recalculée en direct.
NaN POLICY PAR AGRÉGAT
NaN+x=x (permissif) : les composantes NaN sont ignorées, seules les
valeurs présentes comptent ; un point n'est absent que si TOUTES les
composantes sont NaN sur la ligne.
  SUM x+y · AVG (x+y)/2 · MIN/MAX/MEDIAN/RANGE/STDDEV/VARIANCE/ENTROPY sur
  les valeurs présentes · NORM-L1 |x|+|y| · NORM-L2 sqrt(x²+y²) ·
  RMS sqrt((x²+y²)/2).
NaN+x=NaN (strict) : si au moins une composante est NaN sur une ligne, le
résultat est NaN quel que soit l'agrégat.
Valeur proposée : NaN+x=x pour une nouvelle métrique ; NaN+x=NaN pour une
métrique existante enregistrée sans NaN Policy (c'est ainsi qu'elle est
calculée), afin qu'un simple Apply ne change pas ses valeurs.
CALCUL DE MEDIAN
MEDIAN trie les valeurs présentes de chaque ligne et renvoie la valeur
centrale ; avec un nombre pair de valeurs, la moyenne des deux valeurs
centrales.
  [10, 20, NaN, 40] : NaN+x=x → médiane de [10, 20, 40] = 20 ;
                      NaN+x=NaN → NaN.
  [10, 20, 30, 40]  : (20 + 30) / 2 = 25 dans les deux modes.
MEDIAN est peu sensible aux valeurs aberrantes (contrairement à AVG).
