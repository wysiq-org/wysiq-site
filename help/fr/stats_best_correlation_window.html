Find Best Correlation — Aide

Cette fenêtre recherche, pour deux séries, le décalage (lag) qui
maximise la corrélation de Pearson en valeur absolue. Elle calcule
aussi la régression linéaire associée et permet d'en faire une
Metric résiduelle éditable dans WysiQ.

1) INTERFACE

Accès : bouton Best corr de la fenêtre Statistical Tests, après avoir
coché une série A et une série B (sinon : « Select Serie A and Serie B »).
  Target        (lecture seule) Cible y = série A ; la série B est la source x.
  Scope         (lecture seule) Sélection de la fenêtre Statistical Tests :
                Area limite le calcul à la zone ; All prend tous les points.
  Lag           Décalage maximal (champ numérique). Le scan va de -Lag à +Lag.
  Run           Lance la recherche.
  See residual  Charge le résidu dans __COMBO__ et ouvre le Metric Editor.
  Create Serie  Crée une Metric nommée dans la palette Series et ouvre
                le Metric Editor pour la vérifier ou la modifier.
  Clear         Vide les résultats.
  Export        Enregistre la grille en .xlsx ou .txt (« No result to
                export » si la grille est vide). Ctrl+C copie les lignes
                sélectionnées dans le presse-papiers.
  → AI          Envoie les lignes sélectionnées, ou toute la grille si
                aucune ligne n'est sélectionnée, vers AI Feed.
Résumé (au-dessus de la grille) : Best lag, Pearson, Counter, Slope,
Intercept, Relation du meilleur résultat. Clic sur un en-tête de la grille :
tri.
La ligne choisie dans la grille détermine le lag, la pente et
l'intercept utilisés par See residual et Create Serie. Sans sélection,
WysiQ utilise le meilleur résultat.

2) LECTURE DES RÉSULTATS

  lag           Décalage en nombre de points.
  corr          Corrélation de Pearson r à ce lag.
  counter_corr  Corrélation obtenue au lag opposé.
  p             p-value de Pearson (vide si SciPy est indisponible).
  spearman      Corrélation de rang de Spearman.
  kendall       Tau de Kendall.
  slope         Pente de la régression cible ~ source décalée.
  intercept     Constante de cette régression.
  n             Nombre de couples valides après alignement.
  relation      direct si r > 0, inverse si r < 0.
  lag = 0 : séries alignées sans décalage.
  lag > 0 : la source est décalée de lag points et précède la cible.
  lag < 0 : décalage dans le sens opposé.
Un lag n'est calculé que si au moins trois couples finis subsistent.

3) METRIC RÉSIDUELLE CRÉÉE

Le modèle ajusté est :
  cible estimée = slope × source décalée + intercept
La Metric créée représente ce qui n'est pas expliqué par ce modèle :
  résidu = cible - (slope × source décalée + intercept)
Dans le Metric Editor, WysiQ construit exactement deux composants :
  cible : coeff = 1,        dx = 0,   offset = 0
  source : coeff = -slope,  dx = lag, offset = -intercept
Le nom proposé est de la forme :
  residual_cible_vs_source_lag+N
Il est rendu unique automatiquement si ce nom existe déjà.

4) SEE RESIDUAL OU CREATE SERIE ?

See residual ouvre la Metric spéciale __COMBO__ dans le Metric Editor.
Elle sert à prévisualiser et ajuster le calcul avant de le conserver.
Elle peut remplacer le contenu précédent de __COMBO__.
Create Serie ajoute immédiatement une nouvelle Metric à la palette
Series du graphique courant, puis ouvre le Metric Editor. La Metric
reste entièrement éditable : nom, coefficients, dx, offsets, activation
des composants, style et autres paramètres disponibles dans l'éditeur.
Elle fait partie de la configuration de la query et peut être réutilisée
comme toute autre Metric lorsque la query est sauvegardée et rechargée.
Attention : le bouton porte encore le libellé historique « Create Serie »,
mais l'objet créé est bien une Metric (série combinée virtuelle).

5) INTERPRÉTATION ET LIMITES

La Metric résiduelle sert à étudier la part propre à la cible : anomalie,
tendance restante, rupture, saisonnalité ou événement non expliqué par
la source. Elle peut ensuite être analysée dans le graphe, Area, Signals,
les tests statistiques, PCA ou envoyée à l'IA.
• Corrélation ne signifie pas causalité.
• Le lag est exprimé en points, pas automatiquement en secondes ou jours.
• Un lag élevé réduit n et peut produire un résultat fragile.
• Vérifier le signe du lag, la pente, le graphe et le contexte métier.
• Scope=Area permet d'étudier un régime ou une période particulière.
• Les coefficients sont calculés sur la zone choisie ; les modifier dans
  le Metric Editor change la Metric, sans relancer la recherche.
