AI MODEL CATALOG (Parameters ▸ AI ▸ Profile ▸ Catalog… / Discover…)

Parcourez les modèles IA connus et créez des Profils à partir d'eux.
S'ouvre en deux modes : Catalog (liste hors ligne) et Discover (requête
en direct de vos fournisseurs).

MODÈLES — TRIÉS PAR ORDRE ALPHABÉTIQUE

Les modèles sont listés par ordre alphabétique — sans favoritisme. Tous
les fournisseurs (anthropic, cursor, deepseek, google, groq, mistral,
ollama, openai, openrouter, qwen, xai…) apparaissent dans la même liste
triée. Dans chaque groupe, les modèles sont également triés par nom.

ICÔNES DANS LA COLONNE MODÈLE

💾  Local — modèle sur votre PC ou LAN (Ollama, LM Studio, Scan LLM…).
    WysiQ renvoie l'historique complet à chaque prompt ; le modèle reste
    chargé en GPU/RAM entre les appels (warm start Ollama).
🔗  Mémoire serveur — le fournisseur cloud conserve cache de prompt ou
    fichiers uploadés entre les appels (OpenAI, Anthropic, Gemini, Kimi…).
    WysiQ peut envoyer un gros contexte une fois et le réutiliser.
    Toggle « Utiliser la mémoire serveur si disponible » dans le profil.
Sans icône : API cloud sans cache/fichiers (OpenRouter, Mistral, Groq…).
  🔗 OpenAI · 🔗 Anthropic · 🔗 Google · 🔗 Moonshot Kimi
  💾 Ollama / LM Studio — pas de clé API, pas de mémoire cloud.
CATALOG vs DISCOVER
Catalog   Liste hors ligne intégrée à WysiQ, toujours disponible.
Discover  Requête en direct des fournisseurs pour lesquels vous avez une
          clé API. Affiche uniquement les modèles accessibles maintenant.
          Bascule automatiquement sur le catalogue hors ligne si un
          fournisseur ne répond pas.
Scan LLM…  (Settings › AI) Détection live d'Ollama, LM Studio et
          serveurs OpenAI-compatibles sur ce PC ou le LAN. Crée un profil
          par modèle trouvé — idéal pour un Ollama distant (192.168.x.x).
          Aide : ? dans cette fenêtre.
ENTRÉE DE CATALOGUE vs PROFIL
Entrée catalogue  Description d'un modèle — fournisseur, nom, taille du
                  contexte, tags. Lecture seule, identique pour tous.
Profil            Votre instance configurée : modèle + clé API + paramètres
                  (température, max tokens, timeout…). Cocher des modèles
                  et cliquer "Appliquer la sélection" crée un Profil par
                  modèle coché, pré-rempli avec des valeurs par défaut.
Un même modèle peut donner plusieurs profils (clés différentes,
températures différentes, variantes nommées).

COLONNES

☑ / ☐      Cliquez n'importe où sur une ligne pour basculer. Espace fonctionne aussi.
Fournisseur Le fournisseur API (anthropic, openai, google…).
Modèle      Nom du modèle. ★ = recommandé WysiQ. 💾 = local. 🔗 = mémoire serveur.
Ctx         Fenêtre de contexte en K tokens.
Tags        Capacités : chat, reasoning, data, code, memory…
Statut      exists = un profil existe déjà dans ce workspace.
            live   = modèle confirmé accessible (mode Discover uniquement).

★ MODÈLES RECOMMANDÉS

L'étoile marque les modèles recommandés par WysiQ pour l'analyse. Utilisez
"★ Rec" dans la barre d'outils pour remettre les cases à cocher sur les
seuls modèles étoilés.

BOUTONS DE LA BARRE D'OUTILS

Filter: [___]      Tapez pour filtrer par fournisseur, nom ou tag.
All                Cocher tous les modèles visibles.
None               Tout décocher.
★ Rec              Cocher uniquement les modèles recommandés.
Apply selection    Crée un Profil par modèle coché (ignore les existants)
                     et supprime les profils gérés par le catalogue qui
                     sont décochés.
Close              Fermer sans modification.
?                  Cette aide.
Colonne Status : état du modèle (profil existant, disponible…).
Clic sur la case ☐ / ☑ d'une ligne : la cocher / décocher.
