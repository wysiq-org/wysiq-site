WysiQ — Ask AI | Aide

À QUOI SERT ASK AI
Ask AI vous fait travailler avec VOTRE assistant IA (ChatGPT, Claude, Gemini, Microsoft Copilot, Le Chat, DeepSeek, Perplexity, Grok, Qwen Chat ou tout autre assistant web). Pas de clé d'API IA ni d'abonnement géré par WysiQ : l'assistant s'ouvre dans votre navigateur habituel, où vous êtes déjà connecté.
WysiQ prépare la demande et les fichiers, vous les envoyez, puis vous recollez la réponse dans WysiQ. WysiQ ne pilote jamais la page de l'assistant : il utilise seulement le presse-papiers et votre navigateur.
Ouverture : Main ▸ AI ▸ Ask AI…, ou bouton Ask AI d'un graphe (tâche Analyze Query présélectionnée). Les profils API restent disponibles dans AI ▸ AI Command Center (Expert).
VOS ASSISTANTS
La première fois, cochez les assistants que vous utilisez. Assistants… modifie la liste ou en ajoute un autre (nom et adresse https:// ; Add another… pour en ajouter plusieurs, OK pour valider). La liste déroulante en haut choisit l'assistant ; la seconde choisit la tâche ; ? ouvre cette aide. Seule l'adresse publique du chat est enregistrée, jamais un identifiant, un cookie ou une clé.
LES CINQ TÂCHES
Ask AI : échange libre ; vous pouvez ajouter des fichiers.
Find Data : sources publiques, jeux de données et séries par thème, pays et période. L'assistant liste ses sources dans un bloc JSON ; Check links interroge chaque adresse de données proposée et n'affiche « data » que si des valeurs numériques datées ont été lues. Create connector from selected enchaîne sur la tâche connecteur WWW.
Create / Complete WWW Connector : donnez un lien (Inspect montre ce que WysiQ reçoit : format, champs, dates) ou choisissez l'un de vos sites à compléter. L'assistant reçoit le schéma des connecteurs WysiQ et un exemple qui fonctionne, peut vous poser des questions, puis renvoie le JSON du connecteur.
Analyze Query : les séries, statistiques et le graphe de la WysiQuery active.
Full AI Feed Report : rapport complet à partir des éléments que vous choisissez (query, statistiques, tests, signaux, corrélations, Areas, éléments de l'AI Feed Stack, sources et licences, image du graphe).
ÉTAPE PAR ÉTAPE
1 Prepare : WysiQ construit le prompt et écrit les fichiers cochés dans le Case IA. Rien n'est envoyé.
2 Copy & open : le prompt est dans le presse-papiers, l'assistant s'ouvre dans le navigateur et le dossier des fichiers s'ouvre. Collez (Ctrl+V), joignez les fichiers, envoyez.
3 Import answer : Paste reprend la réponse depuis le presse-papiers ; Import answer l'enregistre dans le Case IA sous forme de rapport HTML (View report) et lit son bloc JSON.
Continuer : écrivez votre message suivant et refaites Prepare ; la conversation continue dans le même Case IA. New conversation en démarre une nouvelle.
CE QUI EST ENVOYÉ
« Sent to the assistant » liste chaque élément ; cliquez sur ✓ pour l'inclure ou l'exclure. Add file… ajoute un fichier de votre choix ; Refresh from WysiQ reconstruit les éléments depuis l'état actuel. Files ouvre le dossier des fichiers ; Prompt affiche le prompt préparé. Double-clic sur une ligne de l'historique : ouvrir son rapport. Les petits éléments JSON sont aussi recopiés dans le prompt pour les assistants sans envoi de fichiers ; les plus gros doivent être joints. Clés, mots de passe et jetons sont toujours retirés. Les données brutes (data_sample.csv) ne sont jamais cochées par défaut. manifest.json décrit chaque fichier.
CONNECTEUR PROPOSÉ PAR L'ASSISTANT
WysiQ valide le JSON (adresses https, formats connus, paramètres déclarés) et affiche les problèmes. Open WWW Connection ouvre la fenêtre des connecteurs ; JSON affiche le brouillon. Save draft connector l'enregistre comme votre propre site : un site du catalogue n'est jamais remplacé. Test draft fait une requête courte ; Prepare à nouveau envoie à l'assistant les erreurs ou le résultat du test avec le brouillon actuel.
Une proposition n'est jamais Ready : seul un Test réussi dans WWW Connection, avec des observations numériques datées, rend une connexion Ready.
OÙ C'EST CONSERVÉ
Chaque conversation Ask AI est un Case IA (qai/cases) : demandes, fichiers, prompts, réponses et rapports HTML. Retrouvez-les dans AI ▸ AI Cases.
Respectez les conditions d'utilisation de votre assistant et des fournisseurs de données.
