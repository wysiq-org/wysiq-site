SCAN LOCAL LLMs (Parameters ▸ AI ▸ Profile ▸ Scan LLM…)

Détecte Ollama, LM Studio et autres serveurs compatibles OpenAI sur ce PC
ou votre LAN, puis crée un profil AI par modèle trouvé en un clic.

QUAND L'UTILISER

  • Ollama tourne sur un autre PC (ex. 192.168.8.101) avec de gros modèles.
  • Plusieurs modèles locaux installés — profils sans saisir d'URL.
  • LM Studio ou serveur OpenAI local sur un port non standard.
Catalog…        liste hors-ligne de modèles connus. Sert aussi de repli
                automatique quand le réseau est indisponible ou qu'aucune
                clé n'est configurée.
Discover…       fournisseurs cloud (clés API requises).
Scan LLM… détection live sur PC local / LAN.
TYPES DE SERVEUR (port par type)
Ollama          Port 11434 par défaut.
LM Studio       Port 1234 par défaut.
Other (OpenAI-compatible)
                Port 8000 — tout endpoint compatible OpenAI.
Ne cocher que le nécessaire — scan plus rapide.
HÔTES
Liste des machines à sonder (ce PC et LAN — même liste, mêmes ports).
  127.0.0.1 / localhost      Ce PC (loopback)
  192.168.x.x (This PC — LAN) Adresse réseau de ce PC (ajoutée auto.)
  192.168.x.x (LAN)           Autre machine sur le réseau
Add / Rename… / Remove / Purge…
Remove     masque l'IP du scan, profils conservés (ex. à la maison).
Rename…    serveur déplacé (.101 → .100) — migre profils + liste.
Purge…     IP zombie — supprime définitivement tous les profils de cette IP.
Parameters ▸ AI ▸ Profile ▸ Purge IP… fait la même chose sur une adresse saisie.
Les URLs cloud (api.anthropic.com…) sont rejetées automatiquement.
À l'ouverture, les hôtes invalides des anciennes configs sont nettoyés.
SCAN LAN SUBNET (lent) — case « Scan LAN subnet (slow — skips 127.x) »
Balayage optionnel de 192.168.x.1–254 sur chaque port activé.
Laisser décoché si l'IP est connue (beaucoup plus rapide).

BOUTON SCAN & PROGRESSION

Scan désactive le bouton pendant l'opération.
Barre de progression + statut, ex. :
  Ollama @ 192.168.8.101:11434
  Subnet 192.168.8.x:11434 (48/254)
Une IP LAN + Ollama seul : quelques secondes en général.

TABLEAU DES RÉSULTATS

Location    This PC ou LAN (+ IP)
Server      Ollama | LM Studio | Other
Model       Id modèle (ex. qwen3-coder:30b)
Status      joignable / erreur
Cliquer une ligne pour cocher/décocher. Nouveaux modèles cochés par défaut
si aucun profil n'existe encore.

APPLY SELECTION

Crée un profil activé par modèle coché.
  • PC local  → combo [Local Ollama] nom du modèle
  • Hôte LAN  → combo [LAN 192.168.8.101] nom du modèle
                suffixe id __192_168_8_101
  • URL et modèle remplis automatiquement.
Profils créés ici : source "user" — jamais supprimés par Catalog Apply.

CONSEILS

  • Ollama doit tourner sur la machine cible.
  • Windows : autoriser le port 11434 dans le pare-feu pour le LAN.
  • Timeout ~3 s par hôte — échec rapide si injoignable.
  • Après Apply, profils visibles dans Settings › AI et AI Connections.
