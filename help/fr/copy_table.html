Export Table / Copy Table — Aide

La fenêtre « Export Table » crée une table WysiQ (DuckDB + fichier .parquet
dans le workspace) à partir d'une source, et peut aussi pousser les lignes vers
une base distante. Elle est ouverte par :
  • Main ▸ In/Out Data ▸ Export (table sélectionnée) ;
  • Import files ▸ Bulk load (une fenêtre par fichier) ;
  • Check file ▸ >> Table ;
  • la fenêtre Table, le SQL Assistant et les exports de résultats.
Processus type :
  vérifier Input / source → saisir Target table → choisir Target connection
  → (base distante : Remote target table + Remote push) → SQL (contrôle)
  → EXEC.

ÉTAPE 1 — FILE OU TABLE ?

Depuis certaines fenêtres, une première boîte demande la destination :
  File  (export to exchange)            écrire un fichier (voir plus bas) ;
  Table  (DuckDB workspace + remote)    ouvrir la fenêtre Export Table.
Continue valide ; Cancel abandonne. Les imports de fichiers vont directement
à Table.

FENÊTRE EXPORT TABLE — CHAMPS

  Input / source        Origine des données (fichier, table, requête SQL) ;
                        lecture seule.
  Target table          Nom de la table WysiQ à créer (obligatoire).
  Owner                 Propriétaire enregistré avec la table.
  Created               Date de création (lecture seule).
  Target connection     Local (DuckDB) : la table reste dans le workspace.
                        Un profil distant connecté : la table est créée dans le
                        workspace ET les lignes sont poussées vers ce serveur.
                        Seuls les profils actifs sont proposés.
  Remote target table   (connexion distante) Nom de la table sur le serveur ;
                        suit Target table tant qu'il n'est pas modifié à la main.
                        Utiliser schema.table seulement si la base l'exige.
  DuckDB ▸ Add row#     Ajoute une colonne de numéro de ligne.
  Remote push           (connexion distante) Mode d'écriture distante :
    Create / recreate table and load rows   (re)crée la table puis insère
                                            toutes les lignes (droits GRANT
                                            de l'ancienne table perdus) ;
    Append rows to existing table           ajoute les lignes à une table
                                            compatible existante ;
    Delete all rows, then insert            vide la table puis insère
                                            (structure conservée).
WysiQ crée toujours une TABLE (plus de VIEW) : une table peut contenir des
métriques calculées en Python et des données multi-tables qu'une vue DuckDB
ne peut pas représenter.

BOUTONS

  ?       Ouvre cette aide.
  Help    Fiche descriptive de la table qui sera créée (colonnes, types,
          source), dans un visualiseur avec A− / A+, Copy et Close.
  SQL     Affiche le script CREATE TABLE (dialecte de la connexion cible) ;
          Copy le copie dans le presse-papiers (pour un DBA). Ce script n'est
          pas exécuté sur le serveur par ce bouton.
  Cancel  Ferme sans rien créer.
  EXEC    Exécute :
            1. contrôle du nom (« Name is required ») ;
            2. si la table existe déjà : « Table '…' already exists. Overwrite
               it? » — Oui remplace les données, Non abandonne ;
            3. chargement complet de la source (fichier relu en entier, masque
               et shrink appliqués) et CREATE TABLE dans DuckDB ;
            4. écriture du .parquet et de la définition .json dans
               workspace/tables/, mise à jour du registre et de la liste Main ;
            5. si connexion distante : écriture selon Remote push.
          Une fenêtre de fin résume le résultat (OK / Entrée / Échap).
EXPORT VERS FICHIER (« File export »)
  Name                  Nom du fichier (sans extension).
  Folder                Dossier (… pour parcourir) ; par défaut
                        workspace/exchange.
  Parquet / XLSX / CSV  Formats à écrire (plusieurs possibles).
  CSV delimiter         Semicolon ; | Comma , | Tab \t | Pipe |.
  Add Row# column       Ajoute un numéro de ligne.
  Export                Écrit le(s) fichier(s) ; Cancel abandonne.
Un export fichier ne crée aucune table et ne modifie pas le workspace.
IMPORT RAPIDE (« Create »)
Pour un fichier seul, une boîte simplifiée affiche File et Table name :
Create (ou Entrée) charge le fichier dans une nouvelle table ; ? ouvre cette
aide ; Cancel abandonne.
EXPORT DES DONNÉES D'UN GRAPHE (overlay / résultats)
Une petite boîte « Export… » propose Format : Parquet ou XLSX, Max rows
(ALL ou N), Sheet name (XLSX), et affiche le nombre de lignes et de colonnes.

PRÉCAUTIONS

• Overwrite remplace définitivement les données de la table locale.
• Create / recreate et Delete all rows modifient la base distante : vérifier
  la connexion et le nom de la table cible avant EXEC.
