Palette Graph — Télécommande

La télécommande Graph est une palette unique, partagée par toutes les fenêtres
graphiques ouvertes. Elle agit toujours sur le graphe actif (le dernier graphe
cliqué). Elle regroupe l'ouverture des palettes, le mode LINE / POLAR, la
navigation, les captures, l'image de fond, les styles d'axes, le lien entre
graphes et la liste des graphes ouverts.
Cliquer sur la barre de titre de la télécommande remet le graphe actif au
premier plan (utile lorsqu'une autre fenêtre le cache).
Le bouton Graph de l'en-tête d'un graphe rouvre la télécommande.
Pour déplacer la télécommande, faire glisser n'importe quelle zone non
cliquable (titres de section, fond) : utile si la barre de titre est sortie
de l'écran. Valable pour toutes les palettes.
 BARRE D'INFO (haut de palette)
À gauche, un bandeau de texte ; à droite, le logo WysiQ.
Sa couleur indique le niveau du message :
  • Blanc   → information normale
  • Orange  → avertissement
  • Rouge   → erreur ou condition bloquante
En mode LINE :
  Affiche le Xmin et le Xmax visibles de la vue courante.
  Si l'axe X est une date, le format complet de la table est utilisé
  (Params > Core > « Date format (tables) ») : même en zoom serré sur les
  heures, le jour, le mois et l'année restent visibles.
  Le bandeau se met à jour à chaque zoom, pan ou défilement.
En mode POLAR :
  Scope   durée de la fenêtre polaire (ex. 365.0 days)
  Step    pas de rotation actif (Window = une fenêtre entière)
  X000    début de la fenêtre (X0)
  X360    fin de la fenêtre (X360)
  Si X0 et X360 couvrent toute la plage de données, la rotation << X / X >>
  est impossible → fond rouge « ⚠ Adjust X0 & X360 for rotation ».
  Réduisez la fenêtre polaire pour réactiver la rotation.
Les confirmations courtes (Snap, REC, overlay, NewRec, export…) s'affichent
aussi ici pendant environ 4 secondes, puis le contexte habituel revient.

BOUTONS RONDS — PALETTES DU GRAPHE ACTIF

Une rangée de 10 boutons ronds ouvre ou ferme chaque fenêtre du graphe actif.
Vert = ouverte, gris = fermée. Un clic sur un bouton vert ferme la fenêtre,
un clic sur un bouton gris l'ouvre. L'état est rafraîchi à chaque retour
sur la télécommande.
  Gr   En-tête du graphe courant (barre Table / Graph / boutons) : un clic
       le masque — il ne reste que le tracé, par ex. un polar transparent
       posé sur un graphe line — un second clic le réaffiche.
       Vert = en-tête visible.
  Se   Palette Séries (séries, styles, métriques, axes X/Y)
  PC   Atelier PCA (analyse en composantes principales)
  AI   AI Command Center
  Ta   Palette Table (colonnes, tri, filtres WHERE, export)
  Ar   Palette Area (rectangle, statistiques, PCA, Identify/Fit)
  Te   Fenêtre Tests statistiques (également accessible par le bouton
       Tests de l'en-tête du graphe)
  Si   Palette Signal (rugosité, dynamique de variabilité)
  Sc   Palette Scénario (courbes cibles tracées à la main)
  Le   Éditeur de légende

LIGNE DE COMMANDE

LINE / POLAR   Bascule le graphe actif entre le mode cartésien et le mode
               polaire. Le libellé indique le mode courant.
PLOT           Retrace le graphe actif et remet la vue à zéro (bornes de la
               palette Séries, ou échelle automatique).
📦             Prépare le graphe pour le partage (voir PREP plus bas).
               Clic droit : activation rapide des contacts / canaux.
?              Ouvre cette aide.
 MODE D'INTERACTION (mode LINE)
Area   Clic-glisser sur le graphe : trace un rectangle de zoom / sélection
       (défaut). Le rectangle alimente aussi la palette Area.
Pan    Clic-glisser : déplace la vue.
       Souris sur ce bouton : flèche gauche / droite = pan gauche / droite,
       flèche haut / bas = pan haut / bas.
       Le maintien répète au Link delay
       (Settings > Globals > Display, en millisecondes).
Zoom   Molette : zoom centré sur le curseur.
       Souris sur ce bouton : flèche gauche = zoom moins, flèche droite = zoom plus,
       flèche haut = zoom avant vertical, flèche bas = zoom arrière vertical,
       à la même cadence Link delay.
Le bouton enfoncé indique le mode actif.
 MODE POLAR : << X / X >> / Zoom
En mode polaire, les trois boutons deviennent :
<< X    Décale la fenêtre polaire vers l'arrière d'un pas.
X >>    Décale la fenêtre polaire vers l'avant d'un pas.
        Maj+clic ou clic droit sur << X / X >> : choix du pas (Window,
        1 an, 6 mois, 3 mois, 1 mois, 10 jours, 7 jours, 1 jour, heures,
        minutes, secondes pour un axe date ; pas numériques sinon).
        Window = décalage d'une fenêtre entière.
Zoom    Zoom radial à la molette ou au glisser vertical (le rayon mini
        reste fixe).
Le zoom radial est mémorisé : il est réappliqué aux retracés suivants.

HISTORY — NAVIGATION

⌂      Vue d'accueil : vue complète avec échelle automatique
       (en polaire : rotation remise à 0 et zoom radial effacé ; la
       fenêtre X0/X360 est conservée).
Prev   Recule dans l'historique des vues.
Next   Avance dans l'historique des vues.

CAPTURE

Print    Ouvre la boîte d'export PNG/PDF (résolution, marges, mise en page).
Snap     Clic gauche : capture du graphe (+ vue Area si un rectangle Area
         est défini). Clic droit : capture de l'Area seule.
         Fichiers dans snapshots/ du workspace. Si REC est actif, les
         captures sont aussi ajoutées à la présentation PowerPoint.
NewRec   Crée une nouvelle présentation PowerPoint et active REC.
● REC    Clic sur le point : enregistrement ON / OFF.
         Rouge = ON : chaque PLOT et chaque Snap ajoute une diapositive,
         y compris quand on change de graphe dans le combo Graph (le nom du
         graphe apparaît dans l'en-tête de la diapositive).
         Vert = OFF.

BACKGROUND — IMAGE DE FOND

Overlay ...   Affiche / masque le bloc de réglages de l'image de fond :
              W, H (taille d'export), PNG (fichier), Zoom, X, Y (position)
              et α (transparence).
Save          Enregistre les courbes du graphe MAIN seules en PNG dans
              overlays/ (réutilisable comme fond sur une autre query).
Load          Charge un PNG et l'applique en fond du graphe MAIN.
Clear         Retire l'image de fond du graphe MAIN.

AXES — STYLES

X: Top     Affiche aussi l'axe X en haut du graphe.
X: Y=0     Trace une ligne horizontale à Y = 0.
Y: right   Affiche aussi les graduations Y à droite.
 POLAR — RÉGLAGES (visible en mode polaire)
Tx / Ty   Grilles secondaires angulaire (Tx) et radiale (Ty).
X0        Début de la fenêtre polaire (curseur + champ de saisie).
X360      Fin de la fenêtre polaire.
          Clic droit sur l'étiquette X360 : fixe la longueur de la fenêtre
          (1 an, 6 mois, 1 mois, 7 jours, 1 jour, heures…).
Disque    Position horizontale du disque : éditeur Legend ▸ Disk
          (0 = à gauche, 0,5 = centré, 1 = à droite).
Ymin      Rayon minimum (centre du graphe).
Ymax      Rayon maximum (bord du graphe).
Synchronisé avec la palette Series : X0/X360 = X Min/Max et
Ymin/Ymax = Y Min/Max. Tout changement dans la remote (curseur, champ,
X >>, zoom molette) s'affiche aussitôt dans la palette Series ; Entrée /
PLOT dans la palette Series applique ses valeurs à la fenêtre polaire.
Cliquer sur l'étiquette X0 ou X360 ouvre un calendrier si l'axe X est une
date. Ymin / Ymax (rayon) sont numériques : leur étiquette n'ouvre un
calendrier que si le champ contient une date. Le calendrier s'ouvre à côté de
la remote, à la hauteur du champ cliqué. Le survol d'une étiquette indique son
rôle (📅 = calendrier). Entrée ou sortie du champ valide la saisie.

GRAPH LINK — SYNCHRONISATION DES VUES

ON   Active la synchronisation entre les graphes cochés dans la liste.
X    Synchronise l'axe X.
Y    Synchronise l'axe Y.
Le graphe MAIN (rond vert) pilote : les graphes cochés suivent ses zooms,
défilements, Home et retracés.
Le délai de propagation est réglable dans Settings > Globals > Display > Linked & transparent graphs > Link delay (ms). Valeur par défaut : 50 ms ; 0 = synchronisation immédiate.
En mode polaire, maintenez « << X » ou « X >> » pour faire défiler la fenêtre en continu ; la répétition utilise également ce délai.
Le LINK ne fonctionne qu'entre graphes de même type :
  line avec line     X et Y synchronisent les axes (zoom, défilement).
  polar avec polar   X synchronise la fenêtre X0/X360, la rotation et le
                     pan angulaire ; Y synchronise le zoom radial (Ymin/Ymax).
Un graphe line et un graphe polaire ne sont jamais liés entre eux (l'axe X
polaire est un angle et l'axe Y un rayon). En mode polaire, la section
GRAPH LINK s'affiche sous la section POLAR.
Astuce : clic droit sur le combo Graph de l'en-tête d'un graphe ▸ Duplicate graph
= même query dans une 2e fenêtre sur un autre graphe ; avec LINK X, les deux
vues bougent ensemble. ▸ Detach graph = le graphe affiché est calculé en
parallèle dans un autre processus (P2 · …). ▸ Detach area = en LINE, ouvre
l’Area courante dans un autre processus avec ses bornes X/Y.

LISTE DES GRAPHES OUVERTS

Une ligne par fenêtre graphique :
  ☐       case LINK : ce graphe suit le graphe MAIN quand LINK est ON
  nom     nom de la query et graphe affiché, ex. « PPE · Graph 2 »
          (clic : rend ce graphe actif et déroule la liste de ses séries
          tracées ; double-clic : rend actif). Nom long : la fin reste
          visible, la molette fait défiler le nom, le survol affiche le
          nom complet.
  nS      nombre de séries tracées
  ●       rond vert = graphe MAIN (pilote du LINK) ; clic sur un rond gris
          pour désigner ce graphe comme MAIN
Dans la liste déroulée, un clic (gauche ou droit) sur une série ouvre sa
fenêtre de style.

PREP — BOUTON 📦

Le bouton 📦 prépare le graphe actif dans share/outbox/graphs/.
Rien n'est envoyé tant que vous n'utilisez pas
Fenêtre principale → Share → Share Center, onglet Send.
  Clic gauche   Ouvre la fenêtre Prep :
                  • enregistreur vocal optionnel (● Rec / ■ Stop / ▶ Play / Erase)
                  • 📦 Prep → écrit le HTML (+ WAV optionnel) dans share/outbox/graphs/ ;
                    une confirmation « Staged in share/outbox/graphs/ » propose
                    Open Share (ouvre le Share Center) ou OK
                  • Cancel → ferme sans rien écrire
  Clic droit    Activation rapide des contacts / canaux : double-clic sur
                une ligne pour la passer On / Off, Close pour fermer.
Envoi : Share Center ▸ onglet Send (fichiers, destinataires, canal Email / Telegram / Both).
Configuration des contacts et canaux : Share Center ▸ Advanced ▸ Setup.
 ÉCRAN 2
Le bouton Screen2 se trouve dans l'en-tête de chaque graphe (plus dans la
télécommande). Clic gauche : envoie le graphe sur l'écran secondaire ou le
ramène. Clic droit : recentre toutes les fenêtres.
Configuration : Params → Globals → Screen.

CONSEILS

• La télécommande reste visible même si la fenêtre principale est réduite.
• LINK X compare deux graphes sur la même période en gardant des échelles Y
  indépendantes.
• Snap est plus rapide que Print pour une capture sans boîte de dialogue.
• En zoom sur les heures, la barre d'info affiche toujours la date complète.
  Première ligne Display : Link (ms) = Link delay, Zoom (%) = Zoom step, Pan (%) = Pan step, Arrows (ms) = Arrow repeat.
  Display > Linked & transparent graphs : Link delay (ms) règle la latence de synchronisation des graphes LINKED (0 = immédiat, défaut 50 ms) ;
  Zoom step (%) définit le pas de zoom par flèche de Graph Remote (défaut 6 %, plage 1–50 %), indépendant du Link delay ;
  Arrow repeat (ms) (défaut 30 ms, plage 15-250 ms) règle les flèches Pan/Zoom et POLAR << X / X >> dès l’appui, séparément de Link delay ;
  Pan step (%) (défaut 2 %, plage 1–20 %) règle la distance des déplacements Pan par flèche ;
