AI COMMAND CENTER — hub IA unifié

Accès : bouton AI Center de la fenêtre graphique, rond AI de la Graph Remote,
Main ▸ AI ▸ AI Command Center (Expert)… (un graphe doit être ouvert).
Rôle
Le AI Command Center est le point central pour mener une investigation IA sur
la WysiQuery active. Il réunit dans une seule fenêtre le prompt, le fil de
chat, les onglets de connexion, la pile AI Feed Stack, la configuration Expert,
et l'accès direct au panneau AI Connections, au AI Case Center, à Usage et au
viewer HTML. Le graphe analysé reste le héros : le Command Center se pose
dessus et chaque feed envoyé décrit ce graphe, jamais un dump de données brutes.
Déroulement
  1. 👤 AI Connections (barre latérale) — créer ou ouvrir un AI Case / session,
     choisir un profil, puis Connect. La fenêtre de transport s'ouvre en
     panneau ; la fermer ne fait que la masquer. La session reste active que
     le Command Center soit ouvert ou fermé.
  2. AI Feed Stack — activer les blocs analytiques à envoyer (table, area,
     tests, signaux, PCA, corrélations, scénario). L'ordre des clics dans la
     colonne Send # est l'ordre d'envoi.
  3. Expert Config — définir rôle, style et niveau IA pour le feed handshake.
  4. Prompt — saisir la question et ▶ Send, ou utiliser >>AI Next pour
     parcourir la Stack feed par feed, et ▶ Run Remaining pour enchaîner
     les feeds restants.
⚡ Analyze graph — l'analyse en un clic
Le bouton ⚡ Analyze graph (à côté de Send) enchaîne tout le déroulement
ci-dessus à votre place :
  • crée l'AI Case de la query s'il n'existe pas (plus d'étape Create) ;
  • prend le profil déjà utilisé pour cette query (profil principal de son
    Case), sinon le dernier profil utilisé ;
  • active le Feed 0 (contexte du graphe) et, si rien d'autre n'est actif
    dans la Stack, ajoute la synthèse compacte de la Table (jamais la table
    brute) ;
  • connecte le profil et attend qu'il soit prêt (un modèle local peut
    mettre quelques secondes à se charger la première fois) ;
  • envoie une question d'analyse standard dans la langue de l'aide — ou la
    question que vous avez tapée dans le prompt.
Si aucun profil n'est encore utilisable, il ouvre l'assistant AI Setup
(ci-dessous) ; l'analyse part dès que les modèles choisis sont connectés. Le
déroulement complet (Stack, Expert Config, >>AI Next) reste disponible pour
les analyses détaillées.
🧭 AI Setup / Bench — trouver, tester et comparer des modèles
S'ouvre avec le Command Center tant qu'aucun modèle n'est connecté
(désactivable dans l'assistant), ou depuis la barre latérale. En trois
écrans : où sont vos IA (ce PC — il peut lancer votre .bat de démarrage
d'Ollama —, les autres ordinateurs du réseau comme un Mac, les clés cloud)
→ les modèles trouvés, à cocher un ou plusieurs → un vrai test de chacun,
en parallèle, avec corrections automatiques. ⚡ Connect & analyze graph
connecte tous les modèles qui ont répondu (un onglet chacun) et leur envoie
la même analyse : un bench en un clic. Détails : ? dans l'assistant.
Barre latérale (◀ la replie / la rouvre)
  CONNECTIONS   profils connectés : clic = rendre actif ; la ligne
                « WysiQ Support » (si disponible) s'active par sa case On.
  PANELS        🧭 AI Setup / Bench, 👤 AI Connections, 🗄 AI Feed Stack,
                📋 Requests Catalog, 🗂 AI Case Center, 📊 Usage,
                📖 Knowledge Setup, 🎚 Expert Config, 🌐 HTML Viewer.
  SENT PROMPTS  historique des prompts envoyés.
Zone de prompt
  📋 Request   ouvre le catalogue des requêtes ; un clic charge la requête
               dans le prompt.
  🗄 Feed      ouvre l'AI Feed Stack (le résumé de la Stack au-dessus du
               prompt l'ouvre aussi).
  📎 Attach    joint des fichiers (clic sur une pièce jointe : l'activer /
               la désactiver ; ✕ la retire).
  🎤 Mic       dictée vocale.
  Clear        efface le prompt.
  Haut / Bas   (dans le prompt) rappel des prompts précédents.
Barre de recherche 🔎 du fil : Entrée = occurrence suivante, Maj+Entrée =
précédente, Échap = effacer. Un clic sur la barre d'état ouvre Usage.
Onglets de connexion
Chaque profil connecté possède son propre onglet au-dessus du chat. L'onglet
actif reçoit le prochain Send. Les compteurs de jetons sous un onglet
reflètent le dernier échange de ce profil, pour comparer coût et verbosité
entre modèles.
Broadcast
Broadcast (en-tête) ajoute d'autres profils déjà connectés comme cibles
supplémentaires pour le prochain JSON AI Feed, Data AI Feed et Send. Le profil
principal (onglet actif) est toujours inclus. La ligne cible affiche (+N)
quand des profils extra sont armés. Broadcast permet de poser la même question
à plusieurs modèles et de comparer leurs réponses dans un seul Case.
>>AI Next (anciennement Play Next)
>>AI Next parcourt la Stack feed par feed pour l'onglet profil actif. Changer
d'onglet resynchronise le curseur et propose le prochain prompt canonique que
ce profil n'a pas encore reçu (+N = rattrapage benchmark). Un modèle
fraîchement connecté peut ainsi être amené au même point que les autres sans
tout renvoyer à la main.
No Fat AI Feed
Tout ce qui sort de cette fenêtre est du JSON structuré compact : résultats,
métadonnées et empreintes de contenu, jamais la série brute complète. Les
échantillons bruts sont optionnels et configurés explicitement. Le coût en
jetons reste bas et l'IA raisonne sur des faits calculés.
Raccourcis
  Ctrl+Entrée — envoyer
  Ctrl+Haut / Ctrl+Bas — historique des prompts
  Ctrl+N — ouvrir AI Connections (nouvelle session)
  Ctrl+L — effacer le prompt
  F1 — cette aide
Couleurs
Parameters ▸ Globals contrôle la palette du Command Center.
Expert Config (🎚)
  Fenêtre de configuration du feed handshake : Recipe, Role, Context,
  Audience, Style, Language et AI level (listes déroulantes). Save
  enregistre ; → AI dépose la configuration dans l'AI Feed Stack ; Cancel
  ferme sans enregistrer ; Reset rétablit les valeurs par défaut.
Broadcast — choix des profils
  La fenêtre « Broadcast — additional AI profiles » rappelle le profil
  principal (toujours inclus) et liste les autres profils connectés à cocher ;
  Apply arme la sélection, Clear la vide. Sans autre profil connecté, un
  message invite à en connecter un d'abord.
