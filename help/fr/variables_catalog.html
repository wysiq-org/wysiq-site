Catalogue Variables

Le catalogue Variables liste les packs de constantes du workspace, regroupés
par thème (énergie, finance, custom…). Utilisez-les dans les champs numériques
des metrics avec la syntaxe compacte &theme_id.var_id (ex. &1.4).
Même disposition que le catalogue Tables : thèmes à gauche, variables à droite.
Ouverture : menu Metric → Variables…

BARRE D'OUTILS

Create / Duplicate / Delete
  Sous les listes thèmes et variables.
Thresholds
  Ouvre la fenêtre Thresholds (règles d'alerte du workspace, voir l'aide
  « thresholds »).
Set Low / Set High
  (mode seuil, ouvert par Set alert thresholds… dans la palette Series ; la
  barre affiche « Alert: Table.Série — select one variable, then Set Low /
  Set High ») : sélectionner une variable puis Set Low ; le même bouton
  devient Set High pour le seuil haut.
Import / Export
  Importe ou exporte un thème en fichier JSON portable (noms de thème et de
  variables, sans IDs workspace). À l'import, de nouveaux IDs sont assignés ;
  les noms restent stables pour les metrics (&energie.seuil_kwh).
Refresh
  Recharge depuis le disque, assigne les IDs manquants, vide le cache.
JSON
  Affiche le JSON brut du thème workspace (avec IDs).
Search theme / Search variable
  Filtre la liste des thèmes et la grille des variables.
Close / ?
  Fermer ou cette aide.

PANNEAU GAUCHE : THÈMES

Sel
  Active le thème pour la résolution &…
ID
  Identifiant numérique du thème (workspace). Utilisé dans &1.4.
Theme
  Nom technique du pack (nom de fichier, ex. energie).
Description
  Texte libre.

PANNEAU DROIT : DÉFINITION + VARIABLES

Definition
  Theme (nom), ID thème, Ref prefix (&1.), description, date de modification.
Grille Variables :
  Sel, Display, Style, ID, Variable (nom technique), Value, Unit, Description, Ref (&1.4)
  Double-clic sur une ligne pour éditer ; F2 = renommer ; Suppr = supprimer.
Clic droit sur un thème : Create variable, Rename…, Duplicate, Export theme…,
Import theme…, Delete (F2 = renommer le thème).
Clic droit sur une variable : Edit…, Style…, Toggle Display/Show, Duplicate,
Rename…, Delete.
Boîte Edit / Create d'une variable : Theme, nom, Value (formule possible ;
Insert ajoute une référence de série [Table.Série] ou de variable), Unit,
Description ; OK (Entrée) valide, Cancel (Échap) annule.
SÉLECTEUR COMPACT (pendant l'édition metric / WHERE)
Ce catalogue n'affiche PAS « utilisées dans la query » — c'est le rôle du
sélecteur compact Variables, ouvert par clic droit sur un champ numérique lié
(k, +/-, Min, Max, Δ, Fill, Lag, valeur WHERE…).
Le sélecteur affiche :
  ● noir si la variable est utilisée dans la query ouverte (lecture seule)
  Legend pour le texte de la légende (variables ●)
  Vars series avec sliders
  Simulation inline (* jusqu'au Save)
Voir l'aide du sélecteur (?) pour le détail.
IDS NUMÉRIQUES (UI) vs NOMS (PERSISTANCE)
Chaque thème et chaque variable possède un label numérique incrémental
(unique dans tout le workspace). Dans l'UI (catalogue, picker, champs metric) :
  &1.4     thème id=1, variable id=4
  &1.&4    forme acceptée (équivalente)
  &4       variable id=4 seule, si unique dans le workspace
Dans le JSON metric / query enregistré sur disque, les refs sont converties
en noms stables :
  &energie.seuil_kwh
Les deux formes sont résolues à l'exécution. L'import/export de thèmes ne
transporte que les noms (pas les IDs).

USAGE DANS LE METRIC EDITOR

Champs k, +/- (offset), Min, Max, Δ et Fill de chaque composante :
  • Saisir directement &1.4 ou choisir via clic droit → sélecteur compact
  • « Keep open » garde la fenêtre ouverte pendant l'édition
  • Valeurs simulées (*) appliquées tout de suite ; Save écrit le JSON thème
À l'Apply/Save, la metric enregistre &energie.seuil_kwh (nom stable).
L'éditeur réaffiche &1.4 à la réouverture si le thème existe toujours.
Même principe sur Lag, Size, Step (Group by X) et Free (X0).
Référence introuvable (thème ou variable supprimé) → valeur par défaut du champ :
  k / transform_k = 1.0 · offset / fill = 0 · lag / size / step / free = 0.
La ref reste dans le JSON metric (à corriger ou valider plus tard).

USAGE DANS LES CLAUSES WHERE

Les variables s'utilisent aussi dans les champs Value des WHERE (palette
Table/Area, WHERE série, WHERE composition metric).
Champ Value
  • Ref simple (&1.4) ou expression arithmétique :
    &a.x + &b.y · &energie.seuil * 1.1 · (&a.min + &a.max) / 2
  • Clic droit → sélecteur compact pour insérer une ref.
Opérateurs : = != < <= > >= ~ ^ $ in
Plusieurs lignes : AND / OR entre c1, c2, c3.
Persistance en noms stables dans le JSON query ; l'UI réaffiche &1.4 si le
thème existe. Modifier une valeur ici met à jour metrics et WHERE après refresh.

DISPLAY SUR LE GRAPHE / STYLE

Legend = texte des variables utilisées dans la query, dans le panneau Legend.
Display = uniquement un repère graphique. Jamais de nom, valeur ou unité
écrit sur le graphe. La variable ne devient pas une Series ni une Metric.
Display reste possible pour une constante non utilisée dans la query.
Pour une constante numérique, un seul repère couvre toute la largeur :
  Line : ligne horizontale à Y = valeur.
  Fill : bande horizontale fine autour du seuil + ligne de niveau.
  Bar  : bande horizontale sur TOUTE la largeur, de Y = 0 au seuil,
         avec une ligne de contour. Size règle l'épaisseur du contour,
         Alpha la transparence de la bande.
  Point : un seul marqueur au niveau du seuil.
  Both : ligne entière + un seul marqueur.
Une expression variant selon X peut tracer une courbe; en Bar, une seule aire
continue relie la courbe à zéro au lieu d'une barre par échantillon.
En polaire, Line produit un cercle; Bar remplit le disque jusqu'au rayon
seuil sur 360 degrés, sans parts de camembert.
Si le seuil est hors de la plage Y visible, il reste à sa vraie valeur
(et redevient visible après zoom). Aucune étiquette ni ligne de bord
artificielle ne lui est substituée. Les axes et les données sont inchangés.
Les seuils sont reconstruits lors des exports PNG/PDF, sans texte graphique.
Style : mêmes contrôles que Series, sauf Position : couleur, Depth (z),
Type, Marker, Size, Alpha et Blink. Valeurs initiales : Z = 0,
Type = Inherit, Marker = Inherit. Normal / Below / Above sont indépendants.
Legend, Display et styles sont enregistrés dans le JSON du thème.
