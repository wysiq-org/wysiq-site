SEUILS / ALERTES

Accès : Rules & params ▸ Thresholds… (fenêtre graphique) ou Variables Catalog
▸ Thresholds.
BARRE DE LA FENÊTRE
  Refresh          Relit les règles.
  Catalog          Ouvre le catalogue des variables.
  Alerts enabled   Active / désactive globalement les alertes du workspace
                   (enregistré aussitôt).
  ?  / Close       Cette aide / fermer.
  Create, Edit, Duplicate, Delete   Gestion des règles (double-clic sur une
                   règle = Edit). La boîte d'une règle propose Table, Series,
                   Low, High, Mode ; OK (Entrée) / Cancel (Échap).
Les seuils sont des règles globales du workspace qui s'appliquent aux séries des graphes.
CREER UNE REGLE
• Table : choisissez la table de la query.
• Series : choisissez une série de cette table.
• Low : seuil bas, facultatif.
• High : seuil haut, facultatif.
• Mode : outside, above, below ou inside.
Low et High peuvent contenir :
• une valeur numérique ;
• une référence de variable, par exemple &1.4 ;
• une variable calculée à partir d'une formule.
VARIABLES ET SERIES
Une variable peut contenir une formule utilisant une série.
[Consommation] désigne la série Consommation de la table courante.
[RTE2023.Consommation] désigne toujours la série Consommation de la table RTE2023.
Si une valeur de la série de référence manque pour un X, aucun seuil n'est appliqué à ce point.
AFFICHAGE
Le style des points d'alerte est défini dans Style de la série :
• Normal
• Below
• Above
Chaque état peut avoir sa couleur, son type, son marker, sa taille, son alpha, sa profondeur, sa position et Blink.
Le bouton alerte de la palette Series parcourt les modes :
△  alertes désactivées
⚠  alertes affichées
⚠• uniquement les points en alerte ; les autres restent atténués pour le contexte.
En mode ⚠•, Area travaille uniquement sur les instants en alerte : les points en alerte propres de la série, sinon les X en alerte d'une série de la même table.
CATALOG
Le bouton Catalog ouvre le catalogue complet des variables du workspace afin de créer ou modifier les variables utilisées par les seuils.
CLIC DROIT SUR UNE SERIE (palette Series)
Set alert thresholds… ouvre le catalogue en mode seuil : sélectionnez une variable puis Set Low / Set High.
En query multi-tables, activer les alertes (△ ⚠ ⚠•) depuis une table les active pour toutes les tables du graphe : une série sans règle propre utilise la règle de la série homonyme d'une autre table (onglet actif, puis table principale).
Onglet principal ▸ Propagate thresholds recopie toutes les règles et styles Below / Above de la table principale.
Type / Marker « Inherit » dans Below / Above reprend ceux de la série ; la taille est un multiplicateur de celle de la série (défaut : Inherit, taille 1, Blink, orange / rouge).
