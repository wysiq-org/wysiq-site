Fenêtre Check file — Préparer un fichier avant import

Accès : Import files ▸ Fine load ; Live Sources (source fichier CSV, mode Live).
Check file (« Prepare file before import ») nettoie, recadre, type et
sous-échantillonne un fichier (CSV, TXT, XLSX/XLS, Parquet) avant de le
charger comme table DuckDB, de l'exporter vers un fichier ou de l'utiliser
comme source Live.
Processus type :
  File... → régler Separator / Sheet → Top / Bottom / Left / Right / Header
  → Apply → choisir les colonnes, noms, types, politique NaN, formats de date
  → Preview → (Save mask) → >> Table (ou >> File, ou >> Live).

BARRE SUPÉRIEURE

  File...     Choisir ou changer le fichier source.
  First       Nombre de lignes lues pour l'aperçu (10 à 9 999 999 ; défaut :
              paramètre « rows » des Globals). C'est une limite d'affichage
              seulement : l'export relit TOUJOURS le fichier complet.
  Mask        Masque enregistré à appliquer (noms, types, NaN, formats, trimming,
              shrink). La liste contient les masques de ce fichier et du
              workspace.
  Sheet       (Excel uniquement) Feuille à traiter.
  Separator   Séparateur CSV : Auto, ;  ,  Tab, Pipe.
  Reload      Relit le fichier avec First / Sheet / Separator courants.
  ?           Ouvre cette aide.
APERÇU BRUT (Raw preview)
Lignes du fichier tel que lu sur disque. Top, Prev, Next, Bottom déplacent
uniquement cet aperçu (pas de modification des réglages). La largeur des
colonnes est mémorisée.
PARAMÈTRES DE NETTOYAGE (« Cleaning parameters »)
  Top        Lignes supprimées en haut du fichier brut.
  Bottom     Lignes supprimées en bas.
  Left       Colonnes supprimées à gauche.
  Right      Colonnes supprimées à droite.
  Header     Index de la ligne d'en-tête dans la zone restante
             (en mode Live, -1 = pas d'en-tête).
  Shrink     Champ en lecture seule résumant le sous-échantillonnage ; un clic
             ouvre la boîte Shrink.
  Transpose  Permute lignes et colonnes ; nouveau clic = retour.
  Apply      Reconstruit l'aperçu nettoyé avec les réglages courants.

BOÎTE SHRINK

  Enable shrink    Active le sous-échantillonnage.
  Auto to N rows   Calcule le pas pour obtenir environ N lignes.
  Every N row(s)   Garde 1 ligne sur N.
  First rows       Ne garde que les N premières lignes (0 = toutes).
  Apply            Valide ; Delete supprime le shrink ; Cancel ferme sans
                   changer.
Auto et Every sont exclusifs. Le shrink est appliqué à l'export (table ou
fichier) et sauvegardé dans le masque.
APERÇU NETTOYÉ (Cleaned preview)
Résultat après trimming, en-tête, sélection des colonnes, types et
transposition.
COLONNES DE SORTIE (Output columns)
  Sel        Inclure / exclure la colonne. Clic sur l'en-tête Sel : tout
             cocher / tout décocher.
  Name       Clic pour renommer (Entrée valide). Le nom est utilisé partout :
             aperçu, masque, fichier exporté, table.
  Type       Type appliqué au chargement :
               Auto                — détection automatique ;
               Text                — chaîne ;
               Integer (nullable)  — entier nullable ;
               Decimal             — flottant ;
               Time HH:MM → h      — « 10:30 » devient 10,5 (vide → NaN) ;
               Date/time           — date/heure.
  Inferred   Lecture seule : type que WysiQ détecterait (échantillon de
             200 valeurs au plus).
  Empty/NaN  Remplacement des valeurs vides après conversion :
               (keep) — laisser tel quel (défaut) ; "" empty — chaîne vide ;
               NaN — flottant NaN ; 0 — entier 0 ; 0.0 — flottant 0,0.
  Format     Colonnes Date/time : format de lecture. Liste de préréglages
             (DD/MM/YYYY, YYYY-MM-DD…) ou saisie libre au format strptime
             (ex. %d/%m/%Y %H:%M). OK valide, Échap annule.

BOUTONS DU BAS

  Save mask   Enregistre tous les réglages comme masque réutilisable (repris
              par Reload selected dans Import files et par la liste Mask).
  Preview     Applique types et politiques NaN et rafraîchit l'aperçu nettoyé
              (rien n'est exporté).
  >> File     Ouvre la boîte d'export fichier (CSV par défaut, XLSX possible ;
              Parquet non proposé ici).
  >> Table    Ouvre la boîte Copy Table avec le nom proposé ; le fichier complet
              est chargé à l'EXEC, avec trimming, colonnes, types et shrink.
              Le fichier source est ensuite listé dans Import files.
  >> Live     (mode Live seulement) Valide la structure pour une source Live
              CSV. Choisir d'abord la colonne « Date/time X: » ; elle doit être
              cochée et au moins une autre série numérique doit être cochée,
              sinon un avertissement s'affiche.
  Cancel      Ferme sans rien créer (la croix de la fenêtre fait de même).
CHOIX DES COLONNES LIVE (« Use columns »)
Pour une source Live CSV sans en-tête exploitable, une boîte liste les
colonnes : clic pour sélectionner, double-clic ou F2 pour renommer (Entrée
valide, Échap annule), liste de numéros de colonne. Use columns valide,
Cancel abandonne.

À SAVOIR

• Rien n'est écrit tant que >> Table, >> File, >> Live ou Save mask n'est pas
  utilisé.
• Si la table existe déjà, la boîte Copy Table / l'import demande s'il faut
  l'écraser ou la renommer.
