PARAMÈTRES — WysiQ

Accès : Main ▸ Settings ▸ Parameters… (Manual… ouvre directement l'onglet
Help Folder) ; bouton Params de la palette Series ; Settings… du menu AI
(onglet AI). Le dernier onglet utilisé est rouvert.
La fenêtre Paramètres est organisée en deux niveaux :
  • Onglets principaux : Globals | Query | Statistics | Signal | AI | Help | Help Folder | Legal
  • Sous-onglets de Globals : Core | Display | Output | Style | List values | Screens | Help
Les réglages globaux sont conservés par WysiQ ; pour enregistrer
les réglages propres à une query (axes, tables, offsets), utilisez SaveQuery.
Zoom texte (aide) : Ctrl + molette ou boutons A− / A+

ONGLET GLOBALS

Les réglages globaux du workspace (Core, Display, Output, Style, Screens,
List values) sont documentés dans Globals → Help (mêmes langues que cet
onglet). Cet onglet-ci couvre le reste de la fenêtre Paramètres : les
paramètres Query et les références partagées (formats de date, logique du
locator adaptatif).
  Display > Linked & transparent graphs : Link delay (ms) règle la latence de synchronisation des graphes LINKED (0 = immédiat, défaut 50 ms) ;
  Hide when transparent (Grid / Legend / Scale) choisit ce qu'un graphe au fond transparent (▧) masque — valeurs par défaut, modifiables par graphe (clic droit sur ▧, enregistré dans la query).

ONGLET QUERY

Une page unique regroupe les axes du graphe et la disposition des tables.
Axes / Y axis : unité, coefficient Scale, décimales, facteur de période,
bornes visibles X/Y, graduations et subdivisions.
X axis - bounds by table : dates X min/X max de chaque instance de table,
Rows avant rééchantillonnage, positions Start/End sur l'axe composite.
Multi-table - table offsets : offsets X en lignes, Y offset, Coeff,
Mode (Shrink/Expand), Target rows, Every N, Exec et Reset.
IMPORTANT : les bornes X du bloc Axes concernent le GRAPHE ; celles du
bloc X axis - bounds by table concernent UNE INSTANCE de table.
Les offsets de lignes ne sont pas des décalages en temps réel.
Pour les méthodes de recalage (y compris AVG, Step et Auto calendar),
cliquez sur ? dans le bloc Multi-table : aide table_layout.txt.
Enregistrez les modifications de la query avec SaveQuery.

ONGLET STATISTICS

Statistics execution parameters
  p-adjust    correction pour tests multiples (BH, Holm, Bonf, none)
  Max lag     décalage maximum pour les tests d'autocorrélation/corrélation croisée
  Bins        nombre de classes (histogramme) pour les tests de distribution
  Min size    taille d'échantillon minimum requise pour exécuter un test
  Alpha       seuil de signification
Test Notebooks (liste à gauche + éditeur à droite)
  Chaque notebook définit un test statistique personnalisé (source +
  paramètres par test). Sélectionnez un notebook pour voir/modifier ses
  paramètres et son code source.
  Le bouton ? ouvre l'aide des Test Notebooks.

ONGLET SIGNAL

Contrôle les métriques Signal affichées dans la palette Signal.
  Clic sur une ligne        active/désactive cette métrique
  Clic sur l'en-tête Signal active/désactive toutes les métriques
  HF moving average window  taille de fenêtre utilisée par la métrique
                            HF_ENERGY (valeurs impaires centrées, valeurs
                            paires arrondies vers le bas)
Les modifications sont sauvegardées immédiatement — pas de boutons
Save/Cancel séparés.

ONGLET AI

Sous-onglets : Profile | Observatory | AI Folder | Help.
  Profile       Profils IA (fournisseur, modèle, URL, clé), test de
                connexion, 🧭 Assistant… (AI Setup / Bench), catalogue des
                fournisseurs, scan des modèles locaux. Voir l'aide
                « params_ai ».
  Observatory   Sélectionner l'onglet ouvre la fenêtre de réglage de l'AI
                Observatory (serveur d'activité, champs transmis, aperçu
                JSON) ; Observatory Settings… la rouvre. Voir l'aide
                « activity_tracking ».
  AI Folder     Sélectionner l'onglet ouvre le dossier AI du workspace
                (protocole, questions, cases) dans l'explorateur.
  Help          Sélectionner l'onglet ouvre l'aide « params_ai_knowledge ».
Les questions prédéfinies (AI Feed Question Dictionary) se consultent dans
le Requests Catalog de l'AI Command Center (📋 Request) : langue, recherche
<< / >>, liste et texte exact envoyé. Fichiers : dossier ai/Feed/<lang>/ du
programme.

ONGLET HELP

Affiche ce texte d'aide directement dans la fenêtre.
Utilisez le sélecteur de langue pour basculer entre DE, EN, ES, FR et IT.
Cliquez sur ↺ pour recharger après avoir changé la langue.
Zoom : Ctrl + molette ou boutons A− / A+.

ONGLET HELP FOLDER

Parcourez et recherchez tous les fichiers d'aide .txt fournis avec WysiQ
(tous sujets confondus, pas seulement cette fenêtre), dans l'une des 5
langues.
  Sélecteur de langue   DE / EN / ES / FR / IT
  Search + << / >>      recherche plein texte dans les fichiers d'aide de
                        la langue sélectionnée, navigation entre résultats
  Liste (gauche)         tous les sujets d'aide pour la langue sélectionnée
  Texte (droite)         contenu complet du sujet sélectionné
  A− / A+               zoom du texte
RÉGLAGES DE PARTAGE (Share Center ▸ Advanced ▸ Setup)
Les onglets Contacts, Email/SMTP, Telegram, HTTP Server, 📋 Log et Help ne
sont pas dans Parameters : ils se trouvent dans Main ▸ Share ▸ Share Center,
onglet Advanced ▸ Setup. Voir l'aide « share_params ».

RÉFÉRENCE DES FORMATS DE DATE  (codes strftime)
Toutes les chaînes de format utilisent la syntaxe strftime de Python.
Combinez librement les codes, ex. %d/%m/%Y %H:%M:%S
Année
  %Y    année sur 4 chiffres         2025
  %y    année sur 2 chiffres         25
Mois
  %m    mois avec zéro               01 … 12
  %b    nom du mois abrégé           jan. … déc.  (locale)
  %B    nom du mois complet          janvier … décembre  (locale)
Jour
  %d    jour avec zéro               01 … 31
  %j    jour de l'année              001 … 366
Jour de semaine
  %a    jour abrégé                  lun. … dim.  (locale)
  %A    jour complet                 lundi … dimanche  (locale)
  %u    numéro de jour (lun=1)       1 … 7
  %w    numéro de jour (dim=0)       0 … 6
Semaine
  %W    numéro de semaine (lun)      00 … 53
  %V    numéro de semaine ISO        01 … 53
Heure
  %H    heure 24h avec zéro          00 … 23
  %I    heure 12h avec zéro          01 … 12
  %p    AM / PM  (locale)
Minute
  %M    minute avec zéro             00 … 59
Seconde
  %S    seconde avec zéro            00 … 59
Séparateur / littéral
  %%    signe % littéral
Fuseau horaire
  %Z    abréviation du fuseau        UTC, CET …
  %z    décalage UTC                 +0100

EXEMPLES PRATIQUES

  Années seulement (vue longue)        %Y
  Mois + année                         %m/%Y
  Jour + mois                          %d/%m
  Date complète                        %d/%m/%Y
  Date + heure (minutes)               %d/%m %H:%M
  Date + heure (secondes)              %d/%m/%Y %H:%M:%S
  Heure seule (heures:minutes)         %H:%M
  Heure seule (h:m:s)                  %H:%M:%S
  ISO 8601                             %Y-%m-%dT%H:%M:%S
  Numéro de semaine                    S%W %Y
  Mois abrégé + jour                   %b %d

LOGIQUE DU LOCATOR ADAPTATIF

WysiQ choisit automatiquement l'unité des ticks selon l'étendue visible :
  Étendue > 180 j    MonthLocator   — tick majeur tous les N mois
  Étendue 60–180 j   WeekdayLocator — tick majeur toutes les N semaines
  Étendue 14–60 j    MonthLocator   — tick sur jours fixes du mois
  Étendue 2,5–14 j   DayLocator     — tick majeur tous les N jours
  Étendue 0,25–2,5 j HourLocator    — tick majeur toutes les N heures
  Étendue 5min–6h    MinuteLocator  — tick majeur toutes les N minutes
  Étendue < 5 min    SecondLocator  — tick majeur toutes les N secondes
  Les ticks mineurs sont une unité plus fine que le locator majeur.
  Le spinbox « ticks cibles » (Zoom 1–6, voir Globals → Display → Zoom
  date thresholds) contrôle la densité et le format des étiquettes dans
  chaque unité.
  Première ligne Display : Link (ms) = Link delay, Zoom (%) = Zoom step, Pan (%) = Pan step, Arrows (ms) = Arrow repeat.
  Display > Linked & transparent graphs : Link delay (ms) règle la latence de synchronisation des graphes LINKED (0 = immédiat, défaut 50 ms) ;
  Zoom step (%) définit le pas de zoom par flèche de Graph Remote (défaut 6 %, plage 1–50 %), indépendant du Link delay ;
  Arrow repeat (ms) (défaut 30 ms, plage 15-250 ms) règle les flèches Pan/Zoom et POLAR << X / X >> dès l’appui, séparément de Link delay ;
  Pan step (%) (défaut 2 %, plage 1–20 %) règle la distance des déplacements Pan par flèche ;
