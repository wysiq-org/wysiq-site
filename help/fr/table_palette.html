Palette Table — Aide

Accès : bouton Table de la fenêtre graphique ou rond Ta de la Graph Remote.
La palette Table affiche les données de la query sous forme tabulaire : une
zone d'agrégats par série (nb, sum, avg, min, max, Δ) et un tableau de détail
défilant. Elle montre les séries cochées T dans la palette Series ; en
multi-tables, les noms sont préfixés par leur table (Table.série).
Processus type :
  cocher T dans Series → régler rows / Dec / UF → filtrer (WHERE d'une série,
  Search d'une colonne) → trier (Sort) → Export.

1) BARRE D'OUTILS

rows / total
  Nombre de lignes affichées dans le tableau de détail (Entrée pour
  appliquer). Le total, après filtres, s'affiche après « / ».
Dec
  Nombre de décimales affichées (Entrée ou sortie du champ).
UF  (facteur d'unité)
  Multiplie les valeurs avant affichage (ex. 0,001 pour passer de Wh à kWh).
Adj
  Coché : UF est aussi appliqué aux agrégats de la zone du haut.
Sort
  Popup de tri sur 3 niveaux au plus (une ligne par niveau) :
  - case à droite de la colonne : active / désactive le niveau sans perdre la
    colonne choisie (effet immédiat) ;
  - ASC / DESC : texte cliquable, bascule l'ordre ;
  - Apply applique et laisse le popup ouvert ; Clear supprime tous les tris ;
    Cancel ferme.
SQL
  Affiche les requêtes générées (DATA SELECT et AGGREGATES SELECT), avec A− /
  A+ (ou Ctrl+molette), Copy, Close et l'option « Include aggregates rows in
  exported file ».
Export
  Ouvre la fenêtre d'export de la table de travail (fichier CSV / XLSX /
  Parquet, ou nouvelle table WysiQ). Voir l'aide « copy_table ».
WHERE  (case)
  Active / désactive le filtre global combinant les WHERE des séries
  (voir 3).
Row#  (case)
  Affiche / masque la colonne de numéro de ligne.
?
  Cette aide.
Refresh
  Relit uniquement les données de la Table (par ex. nouvelles lignes Live),
  sans PLOT ni changement de zoom du graphe.
2) ZONE D'AGRÉGATS (haut)
Une ligne par série visible : nom | nb | sum | avg | min | max | Δ (max − min),
calculés sur les lignes retenues (zoom, WHERE, alertes ⚠•).
• Clic sur un nom de série : éditeur WHERE de cette série.
• Clic sur un en-tête : tri sur cette colonne.

3) WHERE GLOBAL

Quand la case WHERE est cochée, les conditions WHERE actives des séries sont
combinées et appliquées comme filtre de lignes au tableau de détail.
Le WHERE d'une série reste une restriction sur tout le jeu de cette série
(graphe compris).
4) TABLEAU DE DÉTAIL (bas)
• Colonnes gelées : Seq, Row et la colonne X active restent visibles à gauche
  pendant le défilement horizontal.
• Clic sur un en-tête : tri croissant ; nouveau clic : décroissant.
• Glisser les séparateurs d'en-tête pour redimensionner les colonnes (y
  compris dans la zone gelée).
• Clic droit sur un titre de colonne ou une cellule : popup Search sur cette
  colonne (même éditeur que WHERE, mais il ne sélectionne que les lignes de ce
  tableau). Plusieurs popups Search peuvent être ouverts en même temps, même
  sur la même colonne (titre « Search: colonne #2 »…). Un nouveau clic droit
  rouvre d'abord une recherche existante de la colonne, sinon en crée une.
  Apply n'enregistre que la recherche de son popup et le laisse ouvert ;
  chaque recherche appliquée s'ajoute aux précédentes selon son « With other
  cols » (AND / OR). Clear ne retire que la recherche de son popup.
• Ctrl+C copie les lignes sélectionnées (séparateur tabulation).
• Molette : défilement vertical ; Maj+molette : horizontal.
• Le séparateur entre agrégats et détail est mémorisé avec la query.
5) ÉDITEUR WHERE / SEARCH (popup)
  Where ON / Search ON   active la condition.
  With other cols        NONE, AND ou OR (combinaison avec les autres).
  c1, join, c2           conditions ; + affiche une 3e condition (c3).
  Opérateurs             =  !=  <  <=  >  >=  ~ (contient)  ^ (commence par)
                         $ (finit par)  in
  Valeur                 seuil, motif ou référence de variable (&1.4) ; pour
                         une date, un clic ouvre le sélecteur (OK / Cancel).
  Apply / Clear / Cancel appliquer, effacer, fermer.
Le filtre s'applique aux valeurs brutes de la colonne, avant le facteur UF.
Une métrique se filtre ici comme une série normale ; les WHERE du Metric
Editor portent sur les composantes de la métrique.
Valeurs absentes : saisir NaN avec = (valeurs manquantes NaN / NULL / NaT) ou
!= (valeurs présentes, zéro compris). NaN n'est pas égal à 0 ; aucune ligne
absente n'est inventée.

MODE ALERTES ⚠•

Quand le bouton d'alerte de la palette Series est sur ⚠•, la Table ne garde
que les instants d'alerte : les lignes où une série de la même table est en
alerte (toutes les colonnes restent). Les statistiques d'en-tête et l'Export
portent sur ces lignes. Repasser en △ ou ⚠ restaure toutes les lignes.
CONSEILS
• Dec = 0 pour des données entières.
• UF = 0,001 pour afficher des kWh quand les données sont en Wh.
• Sort + Export exportent rapidement un sous-ensemble trié.
• La Table ne se rafraîchit pas seule sur les paquets Live : utiliser Refresh.
