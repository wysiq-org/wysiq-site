BOT TELEGRAM — Guide de configuration

Accès : Share Center ▸ Advanced ▸ Setup ▸ Telegram (bouton ?).
Boutons : 🔗 Open @BotFather, ✓ Verify & Save, 🗑 Delete, 🔄 Refresh,
🔄 Scan new contacts, 📨 Send test, 🔍 Debug updates ; Ctrl+C copie la ligne
sélectionnée d'une liste.
WysiQ utilise des Bots Telegram pour envoyer
des instantanés graphe d'un WysiQuery ouvert et des
fichiers Query directement à vos contacts.
Vous pouvez configurer plusieurs bots —
un par équipe, projet ou usage.

ÉTAPE 1 — CRÉER UN BOT SUR TELEGRAM

1. Ouvrez Telegram et cherchez @BotFather
2. Envoyez :  /newbot
3. Donnez un nom, ex. :  WysiQ RTE Graphes
4. Donnez un identifiant se terminant par 'bot',
   ex. :  wysiq_rte_graphs_bot
5. BotFather vous donne un token :
   123456789:AABBccDDeeFFggHH...
6. Copiez le token — vous en aurez besoin à l'étape 2.
👍 Aidez WysiQ à grandir — incluez 'wysiq'
   dans le nom d'utilisateur de votre bot.

ÉTAPE 2 — AJOUTER LE BOT DANS WYSIQ

Dans le formulaire sous la liste des bots :
  ID      — clé unique, ex. bot_rte_graphs
            (sans espaces, lettres et _ uniquement)
  Nom     — nom affiché dans WysiQ
  @User   — le @username donné par BotFather
  Token   — collez le token de BotFather
Cliquez "✓ Verify & Save" — WysiQ contacte
Telegram pour vérifier que le token est valide.

ÉTAPE 3 — ENREGISTRER LES ABONNÉS

Chaque destinataire doit :
1. Ouvrir Telegram
2. Chercher le nom d'utilisateur de votre bot
3. Appuyer sur Démarrer ou envoyer /start
Ensuite dans WysiQ, sélectionnez le bot
et cliquez "🔄 Scan new contacts".
WysiQ lit tous les messages /start reçus
et enregistre automatiquement chaque Chat ID.
L'abonné apparaît dans la liste du bas.
ENVOI
Graphes (📦 Prep dans la Graph Remote, puis Share Center ▸ Send) :
  Instantané HTML du WysiQuery courant — envoyé aux contacts
  dont le canal Telegram est actif (✈ on) dans l'onglet Contacts.
  Utilise le bot enregistré pour ce contact.
Query (📤 Share dans Export query) :
  Bundle ZIP Query (WysiQuery sauvegardé : table + analyse +
  réglages graphe) — même mécanisme, envoyé directement dans
  le chat Telegram du contact.

BOTS MULTIPLES

Vous pouvez ajouter autant de bots que nécessaire :
  — un bot par projet
  — un bot pour les graphes, un pour les données
  — un par équipe ou département
Chaque bot a sa propre liste d'abonnés.
Un contact peut être abonné à plusieurs bots —
scannez avec chaque bot séparément.
