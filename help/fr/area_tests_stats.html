TESTS STATISTIQUES — Guide de référence

Ce fichier couvre la documentation détaillée de chaque test
statistique. Les tests sont exécutés dans la fenêtre Statistical
Tests (ouverte depuis la barre d'outils) ; le panneau autrefois
intégré à la palette Area a été retiré. Pour les contrôles de
l'interface (Scope, pAdj, Mode, ReCalc…) consultez l'aide
stats_tests_window.

PORTÉE & ALIGNEMENT

Scope Area / All
  Les tests peuvent porter sur la sélection (Area) ou sur la
  série entière (All).
  • Area : uniquement les points dans le rectangle (Xmin..Xmax).
  • All  : toute la série, indépendamment du rectangle.
  Astuce : comparez Area vs All pour savoir si un effet est local
  ou global.
  Si un résultat vous surprend, basculez Area/All pour comprendre
  l'impact de la sélection.
Tol (alignement sur X)
  Tol définit la tolérance d'alignement des points X lors des
  tests par paires (S1 vs S2).
  formule : bucket(x) = round(x/tol)*tol  (approx.)
  • tol = 0 : alignement strict (souvent par index si X exacts
              rares).
  • tol > 0 : aligne les points X proches — utile si les séries
              ont des timestamps légèrement décalés.
  Vérifiez toujours n (points appariés) dans la table Tests.
  Augmentez Tol si vos séries ont la même forme mais pas
  exactement les mêmes timestamps.

TESTS PAR PAIRES

Pearson  (corrélation linéaire)
  Mesure la relation linéaire entre deux séries appariées.
  r ∈ [-1, +1]
  r proche de +1 → forte corrélation linéaire positive.
  r proche de  0 → pas de relation linéaire.
  r proche de -1 → forte corrélation linéaire négative.
  Pertinent si la relation est approximativement linéaire et les
  outliers sont limités.
Spearman  (corrélation de rang)
  Mesure la relation monotone (pas forcément linéaire) via les
  rangs.
  ρ ∈ [-1, +1]
  Plus robuste aux outliers et aux relations non-linéaires
  monotones.
  À préférer si la relation est monotone mais non linéaire, ou
  en présence d'outliers.
t-test  (apparié)
  Test paramétrique sur la moyenne des différences d = S1 − S2.
  H0 : mean(d) = 0
  p petit → différence moyenne significative entre les deux
  séries appariées.
  Valide si les deltas sont approximativement normaux (ou n grand).
Wilcoxon  (apparié)
  Alternative non-paramétrique au t-test apparié (sur les rangs
  des différences).
  H0 : médiane(d) = 0
  Plus robuste si les différences ne sont pas normales ou en
  présence d'outliers forts.
  À préférer si la distribution des deltas est asymétrique ou
  avec outliers.
MAE / RMSE
  Métriques d'erreur entre S1 et S2 sur les points appariés.
  MAE  = mean(|d|)
  RMSE = sqrt(mean(d²))
  RMSE pénalise davantage les grosses erreurs (sensible aux
  outliers).
  Utiliser pour mesurer la performance prévision vs réel.
Cohen d  (taille d'effet apparié)
  Taille d'effet sur les deltas, exprimée en écarts-types.
  d = mean(deltas) / std(deltas)
  ≈ 0.2 petit  |  0.5 moyen  |  0.8 grand  (règle de pouce)
  Évite le piège : « p très petit mais effet pratiquement nul ».
TESTS DE GROUPE  (≥ 3 séries)
ANOVA  (one-way)
  Test global paramétrique (k séries) sur l'égalité des moyennes.
  H0 : mean(S1) = mean(S2) = … = mean(Sk)
  p petit → au moins une série diffère des autres.
  Compléter avec Tukey HSD pour identifier les paires.
  À utiliser si les résidus sont approximativement normaux et les
  variances comparables entre groupes.
Kruskal-Wallis
  Test global non-paramétrique (k séries) sur l'égalité des
  distributions (basé sur les rangs).
  H0 : distributions identiques
  p petit → au moins une série diffère des autres.
  Compléter avec Dunn pour identifier les paires.
  À utiliser si les distributions sont asymétriques/avec outliers
  ou si la normalité est douteuse.

TESTS POST-HOC

Tukey HSD  (post-hoc après ANOVA)
  Comparaisons par paires après ANOVA ; contrôle l'erreur de type I
  sur l'ensemble des paires (family-wise).
  Basé sur la loi du range studentisé (q).
  Procédure :
    1. Faites d'abord l'ANOVA.
    2. Si ANOVA significative, lisez les lignes Tukey.
    3. p_adj < alpha → différence significative pour cette paire.
  Préférer Kruskal+Dunn si les variances diffèrent fortement ou
  en présence d'outliers importants.
Dunn  (post-hoc après Kruskal)
  Comparaisons par paires sur les rangs, après Kruskal-Wallis.
  Statistique z sur les différences de rangs.
  p_adj < alpha → différence significative (non-paramétrique).
  À utiliser quand Kruskal est significatif et/ou les données
  ne sont pas normales.

CORRECTION POUR TESTS MULTIPLES

p_adj  (correction multi-tests)
  Corrige les p-valeurs quand on effectue plusieurs comparaisons
  pour contrôler le taux de faux positifs.
  • Bonf (Bonferroni) : très conservateur — multiplie chaque p
    par le nombre de tests.  À utiliser si un seul faux positif
    est critique.
  • Holm : step-down, moins sévère que Bonferroni.
  • BH (Benjamini-Hochberg) : contrôle le FDR — recommandé par
    défaut pour l'analyse exploratoire.
  Regardez toujours p_adj (pas seulement p) quand de nombreuses
  paires sont testées.

TAILLES D'EFFET

eta²  (taille d'effet ANOVA)
  Part de la variance totale expliquée par le facteur (quelle
  série).
  eta² = SS_between / SS_total
  Utile pour quantifier l'ampleur, pas seulement la
  significativité (p).
  À utiliser si p est très petit mais l'effet pratique pourrait
  rester faible.

GLOSSAIRE

paired      Test sur les mêmes points X ; compare d = S1 − S2.
one-way     ANOVA à un facteur (k groupes = k séries).
post-hoc    Tests après un test global (ANOVA/Kruskal) pour
            identifier quelles paires diffèrent.
HSD         Honestly Significant Difference (Tukey).  p-valeurs
            déjà ajustées (contrôle family-wise).
FDR         False Discovery Rate — proportion de faux positifs
            parmi les résultats significatifs.
eta²        Taille d'effet ANOVA (part de variance expliquée).
n           Nombre de points appariés utilisés dans le test.
stat        Valeur de la statistique du test (r, t, W, F, H, z
            selon le test).
p           P-valeur brute (non ajustée).
p_adj       P-valeur ajustée après correction multi-tests.
note        Tag complémentaire : "paired", "non-param",
            "post-hoc", etc.
