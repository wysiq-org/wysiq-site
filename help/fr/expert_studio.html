Expert Studio — WysiQ

Note (version actuelle) : Expert Studio n'est plus ouvert par aucun menu ni
bouton. Ses fonctions principales sont reprises par l'AI Command Center
(🎚 Expert Config, 🗄 AI Feed Stack, prompt et ▶ Send). Cette page reste la
référence de l'ancien atelier.
L'Expert Studio est la surface de travail principale qui orchestre les
échanges analytiques avec l'IA. Il ne fait plus le transport lui-même : il
alimente la fenêtre Prompt (indépendante) qui pilote l'envoi vers un profil
IA, et les réponses reviennent dans le HTML Viewer et la fenêtre Scenario.
Architecture générale (WysiQ après démontage) :
  Expert Studio      Configuration, recettes, options JSON/data, scénarios.
  AI Session         Gestion des sessions (créer, archiver, rouvrir).
  AI Profile         Gestion des profils IA (créer, connecter, protocole).
  Prompt             Fenêtre indépendante — édition du prompt, bouton Send.
  HTML Viewer        Réponses en chapitres.
  Scenario           Reçoit les scénarios corrigés par l'IA.

MODE RÉDUIT / PLEIN

Le bouton "Reduced" en haut à droite bascule l'affichage. La hauteur de la
fenêtre s'ajuste automatiquement au contenu (pas d'espace vide qui masque
le graphique).
  Reduced (par défaut)
    Seules les sections d'action restent visibles :
      - Data & session
      - Scenario & exchange
      - Quality bar
      - Footer (?, Settings, Close)
    Utile une fois que le rôle et la recette sont choisis, pour rester
    compact au-dessus du graphique.
  Plein (Reduced décoché)
    Ajoute les sections de configuration :
      - Expert configuration (Recipe, Role, Context, Audience, Style,
        Language)
      - AI analysis options (Graph context, Tests, Signals, Correlations,
        PCA)
      - Run behavior

EXPERT CONFIGURATION

Recipe      Recette d'analyse préconfigurée. Modifier une recette recharge
            automatiquement les autres champs.
Role        Rôle expert que joue le modèle IA.
Context     Contexte d'analyse.
Audience    Public visé par la réponse. Ajuste le vocabulaire.
Style       Format de la réponse.
Language    Langue de la réponse.

AI ANALYSIS OPTIONS

Toggles qui pilotent le payload analytique envoyé à l'IA :
  Graph context   Contexte du graphique courant.
  Tests           Statistiques et tests calculés dans la palette Area.
  Signals         Séries sélectionnées.
  Correlations    Matrice de corrélation.
  PCA             Analyse en composantes principales.

RUN BEHAVIOR

Attach cropped area only    Attache seulement l'image rognée sur l'Area.
Hide AI console             Masque les fenêtres compagnons à l'ouverture.
Open HTML viewer            Ouvre le HTML Viewer quand une réponse arrive.
Chapter HTML answers        Découpe les réponses en chapitres HTML.

DATA & SESSION

AI Session
  Ouvre la fenêtre AI Session Center (gestion des sessions : créer,
  archiver, rouvrir).
AI Profiles
  Ouvre la fenêtre AI Profile — WysiQ (formellement "AI Analyst"), qui
  gère la connexion aux profils IA.
Build JSON
  Reconstruit le JSON payload (Analytics Feed) à partir de l'état
  courant du graphique et des toggles.
Select Data…
  Ouvre la boîte de sélection des données à inclure dans le payload.
Prompt…
  Ouvre la fenêtre Prompt indépendante (l'interface principale d'édition
  et d'envoi vers l'IA). Elle s'ouvre aussi automatiquement à
  l'ouverture d'Expert Studio (sauf si Hide AI console est actif).
Generate Expert Report
  Assemble le prompt complet (rôle, contexte, audience, style, langue)
  et le pousse dans la fenêtre Prompt pour envoi.

SCENARIO & EXCHANGE

Open Scenario…
  Ouvre la palette Scenario du WysiQuery courant.
Send to AI…
  Envoie le scénario actif à la fenêtre Prompt (JSON structuré,
  kind=wysiq_scenario_response). L'utilisateur relit puis clique Send
  dans la fenêtre Prompt pour envoyer effectivement.
Receive from AI…
  Récupère un scénario retourné par l'IA et le réinjecte dans la
  palette Scenario.

QUALITY / ESTIMATED PROMPT

La barre "Quality" et le texte "Estimated prompt" indiquent la qualité du
prompt courant (0-100 %) et une estimation du nombre de caractères et de
tokens.

FOOTER

?         Affiche cette aide.
Settings  Ouvre les préférences globales WysiQ (Params).
Close     Ferme l'Expert Studio. Les fenêtres compagnons (Prompt,
          AI Profile, HTML Viewer) restent ouvertes indépendamment.

COMPORTEMENT DE FENÊTRE

L'Expert Studio est traité comme les autres palettes flottantes WysiQ :
attribut -topmost persistant sur Windows, remise au premier plan sur
activation. Cliquer sur le graphique ne le fait pas disparaître derrière.
