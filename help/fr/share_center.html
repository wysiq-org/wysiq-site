CENTRE DE PARTAGE & PUBLICATION

Accès : Main ▸ Share ▸ Share Center, Main ▸ Query ▸ Share…, bouton Open Share
après un 📦 Prep. En haut : Catalog ouvre le Share Catalog (historique des
partages, Main ▸ Share ▸ History) ; Close ferme la fenêtre.
INTERFACE AUTOMATISÉE
Le centre est organisé en 4 onglets : Send, Channels, Advanced et Help.
Channels détecte et réutilise automatiquement les réglages existants.
  • Auto configure : choisit automatiquement un bot Telegram valide si possible,
    vérifie le bot et tente de détecter un canal/groupe récent.
  • Check channels : vérifie Telegram, le webhook Discord et le dossier Gallery.
  • LinkedIn, Reddit et X sont marqués Assisted : WysiQ prépare le texte
    et ouvre le navigateur ; la validation finale reste manuelle.
Les réglages Publish, Gallery/Feeds, Social drafts et Setup sont dans les
sous-onglets de Advanced. Ils ne sont nécessaires que pour les réglages détaillés.

WORKFLOW COMPLET — DE LA DONNÉE AU PARTAGE

ÉTAPE 1 — CONSTRUIRE LE GRAPHE
  1. Fenêtre principale : sélectionner une table dans l'arbre workspace.
  2. Cliquer sur son nom (ou double-cliquer la ligne).
     Une fenêtre Graph s'ouvre avec les données.
  3. Toolbar Graph → Series : ajouter des séries, choisir l'axe X, styler.
  4. Toolbar Graph → PLOT : exécuter l'analyse et tracer le graphe.
  5. Ajuster le zoom, le pan, le mode polaire, la légende si besoin.
     Les contrôles de navigation sont dans la palette Graph remote
     (Toolbar → bouton Graph, ou la télécommande flottante WysiQ).
ÉTAPE 2 — PRÉPARER LE PARTAGE
  Dans la palette Graph remote, cliquer le bouton 📦 (clic gauche) :
    • Un popup s'ouvre avec le titre du graphe.
    • Optionnel : ● Rec pour enregistrer un commentaire vocal,
                  ■ Stop pour terminer,  ▶ Play pour écouter,  Erase pour annuler.
    • Cliquer 📦 Prep pour déposer le graphe.
  Ce que fait Prep :
    → Génère le graphe en HTML interactif (Plotly pour cartésien,
      PNG + Panzoom pour polaire).
    → Sauvegarde le HTML dans workspace/share/outbox/graphs/
    → Si un commentaire vocal a été enregistré, sauvegarde le WAV à côté.
    → Affiche la confirmation « Staged in share/outbox/graphs/ » :
      Open Share ouvre le Share Center (onglet Send), OK ferme.
  Clic droit 📦 → bascule rapide des contacts et canaux On/Off
  sans ouvrir le popup de préparation.
ÉTAPE 3 — ENVOYER DEPUIS L'OUTBOX
  Dans l'onglet Send (liste de l'Outbox) :
    1. Le fichier déposé apparaît dans la liste (☐ = non sélectionné).
       Cliquer la ligne pour sélectionner (☑).
    2. Choisir le Canal : Email | Telegram | Both.
    3. Destinataires : tous les contacts actifs sont présélectionnés.
       Cliquer un nom pour restreindre à ce contact uniquement.
    4. Cliquer Send.
  À l'envoi :
    → Les contacts Email reçoivent le HTML en pièce jointe
      (+ WAV vocal dans le même email si enregistré).
    → Les contacts Telegram reçoivent le fichier HTML via bot
      (+ WAV vocal en message audio séparé).
    → Les canaux automatiques (Advanced ▸ Publish) s'exécutent également.
ÉTAPE 4 — LE DESTINATAIRE OUVRE LE GRAPHE
  Le destinataire reçoit un fichier .html.
  En l'ouvrant dans n'importe quel navigateur :
    • Graphe cartésien : Plotly — survol, zoom, pan, légende, export PNG.
    • Graphe polaire : PNG haute résolution avec zoom/pan tactile (Panzoom).
  Aucune installation requise. Fonctionne sur mobile et desktop.
ONGLET SEND (OUTBOX)
  Liste tous les fichiers déposés :
    share/outbox/graphs/   → HTML graphes + WAV vocaux
    share/outbox/queries/  → bundles ZIP de Query
  Cliquer une ligne pour sélectionner / désélectionner (☑ / ☐).
  Canal         Email | Telegram | Both
  Destinataires tous les contacts actifs par défaut ;
                cliquer un nom pour restreindre.
  Send          envoie les fichiers sélectionnés.
  Refresh       relit les dossiers outbox.
  📂 Outbox     ouvre le dossier dans l'explorateur.
ADVANCED ▸ PUBLISH — CANAUX AUTOMATIQUES
  Ces canaux s'exécutent automatiquement à chaque Send (pas au Prep).
  Activer chaque canal et cliquer Save.
  Telegram broadcast
    ID canal TG  = @nom_canal ou chat ID numérique
    ID bot TG    = optionnel, remplace le bot par défaut
    → HTML/ZIP posté sur le canal (séparé de l'envoi aux contacts).
  Discord webhook
    URL = https://discord.com/api/webhooks/…
    → HTML/ZIP posté en pièce jointe dans le canal Discord.
  Gallery
    Dossier local   = destination des copies HTML/ZIP
    URL publique    = ex. https://wysiq.org/visualizations
  Flux RSS / JSON   mis à jour automatiquement à chaque Send.
  Réseaux sociaux (semi-automatiques) :
    LinkedIn   → texte copié dans le presse-papiers + ouverture LinkedIn.
    Reddit     → titre/corps préparés ; vous soumettez manuellement.
    X/Twitter  → intent tweet ouvert avec texte et lien.
  Identité du message :
    URL du site    = adresse de base dans tous les posts
    Signature      = pied de message
    Tags par défaut = hashtags
ADVANCED ▸ GALLERY / FEEDS
  Dossier local       destination HTML/ZIP (vide = outbox/graphs)
  URL publique base   ex. https://wysiq.org/visualizations
  Titre / description RSS   métadonnées du canal XML
  Nom fichier JSON    par défaut : wysiq_feed.json
  Fichiers générés    liste outbox, feeds, drafts. Cliquer Refresh.
ADVANCED ▸ SOCIAL DRAFTS
  Tester les modèles avant publication.
  Titre / URL / Insight → sélectionner le canal dans Preview
  → le texte du draft apparaît ; ajuster avant publication.
  Copy          copie le draft dans le presse-papiers.
  Save drafts   écrit des fichiers .txt dans workspace/share/drafts/.
  Combo Open    ouvre le réseau sélectionné avec le texte.
PARTAGE DE QUERIES (bundles ZIP)
  Fenêtre principale → Query → Export query…
    → un bundle ZIP est créé (table + analyse + paramètres graphe
      + PNG/PPTX optionnel + note vocale).
  Dans la fenêtre de résultat de l'export, cliquer 📤 Share… pour envoyer par
  Email/Telegram.
  Ou : le ZIP est copié dans share/outbox/queries/ et apparaît
  dans l'onglet Send pour un envoi ultérieur.
  Les destinataires importent via : Query → Import query….
POUR LES CONTACTS, EMAIL, TELEGRAM, HTTP SERVER
ET LE JOURNAL D'ENVOI — voir Advanced ▸ Setup (aide « share_params »).
ONGLET CHANNELS ET ADVANCED — CONTRÔLES
  Channels : une ligne par canal avec la case Use (activer / désactiver le
  canal) ; Auto configure, Check channels, Advanced… (ouvre l'onglet
  Advanced).
  Advanced ▸ Publish : options de publication automatique, choix du bot
  Telegram (↺ recharge la liste), Save, Open feeds folder.
  Advanced ▸ Gallery/Feeds : dossier de galerie (…), Save, Refresh,
  📂 Feeds, 📂 Outbox.
  Advanced ▸ Social drafts : aperçu et ouverture des brouillons, Copy,
  Save drafts.
  Cadres de ces onglets : Publish = « Automatic channels », « Social networks
  (semi-auto) », « Message identity » ; Gallery/Feeds = « Site gallery »,
  « RSS / JSON feeds », « Generated files » ; Social drafts = « Draft
  generator », « Preview ». Détail des champs : aide « share_params ».
  Advanced ▸ Setup : contacts, email, Telegram, serveur HTTP, journal (aide
  « share_params »).
  Help : cette aide (Language, A− / A+).
