AI FEED STACK — préparer les blocs analytiques du prochain prompt

L'AI Feed Stack est la fenêtre dédiée où vous assemblez les blocs analytiques
qui accompagnent votre prochain prompt IA. Ouvrez-la depuis le AI Command
Center (panneau AI Feed Stack). Chaque feed est une
description JSON compacte d'une partie du graphe actif — jamais un dump de
données brutes.

BARRE D'OUTILS

+ Add feed ▾
    Menu : Table Feed, Area (stats JSON), Area graph (PNG crop), PCA report,
    Signals, Stats / tests, Correlations, Current scenario ; puis Rebuild
    handshake (Feed 0) — recrée le feed de protocole (utile si le niveau
    Expert AI a changé pendant que la Stack était fermée). Select Data… n'apparaît que si Expert Studio est ouvert
    (fenêtre qui n'est plus accessible dans cette version).
    Le handshake (Feed 0) est créé et rafraîchi automatiquement.
Empty
    Retire tous les feeds de la Stack, sauf le handshake Feed 0.
Refresh
    Recharge la liste depuis le panier courant.
Preview
    Affiche ou masque l'aperçu du feed sélectionné (JSON, ou image pour un
    feed Area graph ; clic sur l'image pour l'agrandir). Masqué par défaut pour
    garder la fenêtre compacte. Sert à vérifier exactement ce qui sera envoyé
    avant de dépenser des jetons.
?
    Cette aide.
Close
    Ferme la fenêtre (la Stack est conservée).
LISTE STACK
    Colonnes : Send #, When, Kind, Name, Size. Survol : détail du feed.
    Sélection multiple + touche Suppr : supprimer les feeds sélectionnés.
    Les feeds numérotés sont parcourus par >>AI Next dans le Command Center.

COLONNE SEND #

    Clic gauche sur une cellule : attribue le prochain numéro ; reclic enlève
    le numéro.
    Clic droit sur Send # : « Send with step #n » joint un numéro déjà
    attribué (même groupe = envoi groupé — utile pour les profils sans
    mémoire devant comparer plusieurs Areas dans un seul message) ;
    « New step (send alone) » crée une étape à part ; Disable retire le
    numéro.
    Clic sur l'en-tête Send # : tout cocher / tout décocher.
    Clic droit ailleurs sur la ligne : Delete (ou « Delete n feeds » en
    sélection multiple).
PROTOCOLE vs STACK
    Seuls les trois schémas CORE (000-002) partent à Connect (Knowledge Setup).
    Les autres fichiers protocol (PCA, signals, stats...) sont envoyés
    automatiquement avec le JSON AI Feed lorsque le type correspondant est
    présent ici — par exemple, un feed Signals envoie aussi les schémas signal.
    Vous ne gérez jamais les fichiers protocol à la main ; le Stack le fait
    pour vous.
DONNÉES ORIGINALES vs ACTUELLES
    Un feed rejoué depuis un AI Case peut être envoyé sur les données envoyées
    à l'origine, ou reconstruit sur les données actuelles avec la même recette
    (mêmes bornes et shrink). Clic droit sur la colonne Send # d'un feed issu
    d'un AI Case pour basculer Original data / Current data ; un tooltip indique
    le mode courant. Clic droit sur la colonne Feed pour Delete ou Duplicate.
    Duplicate ajoute une 2e entrée dans le mode OPPOSÉ, pour envoyer côte à
    côte la version originale et la version actuelle (par exemple comparer deux
    années). Les feeds ajoutés via le bouton AI d'une window sont toujours sur
    les données actuelles et n'ont pas ce choix.
BOUTON → AI DES FENÊTRES (Area, Table, Signals…)
    Clic gauche : envoie l'élément dans la Stack selon le mode choisi.
    Clic droit : menu « Left-click sends: » avec les modes Area data (JSON),
    Area graph capture (PNG), Both (data + graph) (✓ = mode actif), puis
    « Send now (current mode) » pour envoyer immédiatement.
