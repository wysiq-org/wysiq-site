PALETTE AREA — Statistiques de sélection, post-its, PCA et Identify

Accès : bouton Area de la fenêtre graphique ou rond Ar de la Graph Remote.
Processus type :
  cocher A dans Series → tracer un rectangle sur le graphe (mode Area) →
  Refresh → (Stats / Pct / PCA / Identify + Fit) → Save (aire nommée) →
  Post-it ou → AI.
Rôle
Calcule les statistiques des séries dont la bascule A = ON, sur un
rectangle de sélection tracé sur le graphique. La palette Area sert aussi
de point d'entrée à l'analyse PCA et à l'exploration de forme Identify /
Fit. Les tests statistiques ne sont plus intégrés ici : ils ont été
déplacés dans la fenêtre Statistical Tests (voir l'aide stats_tests_window).
Les séries d'entrée sont celles sélectionnées par la bascule A dans la
palette Series. Area utilise donc les mêmes séries pour les calculs de
zone, pour la PCA et pour Identify.
BARRE D'OUTILS (première ligne)
Dec       Nombre de décimales affichées dans le tableau (0–12).
Tol       Tolérance X pour l'appariement de deux séries sur des valeurs X
          voisines. Mettre 0 pour correspondance exacte, ou le pas X
          typique (ex. 1.0 pour des données journalières) pour un
          appariement au plus proche voisin.
UF        Facteur d'unité : multiplie la colonne sum quand Adj est ON.
Adj       Active/désactive l'application du Facteur d'unité.
Stats     Affiche les colonnes de statistiques étendues (σ, NA, NA%, IQR,
          MAD, skew, kurt).
Pct       Active les colonnes de percentiles. Cliquer sur le texte « Pct »
          (clic gauche ou droit) ouvre un petit éditeur pour la liste des
          niveaux (ex. 10,25,50,75,90) : OK (Entrée) valide, Close (Échap)
          ferme.
PCA       Calcule les composantes principales sur la portée X de l'Area.
Identify  Affiche les six colonnes Identify (recherche de forme).
Fit       Lance le calcul du meilleur modèle pour chaque série A (Identify).
Edit      Active l'édition visuelle du rectangle Area sur le graphe. Une
          Area doit déjà exister (tracée sur le graphe ou rappelée depuis
          un combo Xmin/Xmax/Ymin/Ymax). Glisser l'intérieur pour déplacer ;
          tirer les bords ou les coins pour redimensionner. Les champs de
          bornes et le tableau se synchronisent pendant le déplacement.
          Après modification, Save enregistre une nouvelle Area nommée ;
          Refresh met à jour les statistiques.
EN-TÊTE DES BORNES (deuxième ligne)
Xmin / Xmax   Plage X éditable. Appuyer sur Entrée ou quitter le champ
              pour appliquer. Pour une date, cliquer le libellé ouvre le
              calendrier (OK / Cancel). Ce sont des combos : sélectionner une aire
              enregistrée (ex. « A2 | valeur ») restaure ses quatre bornes.
ΔX            Largeur de la sélection sur l'axe X.
Ymin / Ymax   Plage Y du rectangle.
ΔY            Hauteur de la sélection sur l'axe Y.
Zoom In / Out et Save
Edit       Active l'édition visuelle du rectangle Area sur le graphe (voir
           aussi la barre d'outils). Glisser l'intérieur pour déplacer ;
           tirer les bords ou les coins pour redimensionner.
Zoom In    Pousse les bornes de l'aire sélectionnée dans les bornes X/Y de
           la palette Series et force un Plot. Tant que Zoom In est actif,
           sélectionner une autre aire enregistrée l'applique au graphe.
Zoom Out   Restaure les bornes plein cadre précédentes.
Save       Enregistre les quatre bornes courantes. Si elles sont nouvelles,
           WysiQ crée une aire nommée (A1, A2, A3…) dans la query JSON.
           Clic droit sur un combo de borne : Delete Area supprime l'aire
           affichée.
BARRE D'ACTIONS (à droite)
Refresh    Réapplique les bornes du rectangle et rafraîchit toutes les
           statistiques. Le calcul n'est pas automatique pour éviter les
           ralentissements sur de gros jeux de données : cliquer Refresh
           après tout changement de bornes, de portée ou de sélection.
PCA→Series Crée les séries lambda temporaires correspondant aux PC (voir
           section PCA).
Actions    Combo regroupant les actions annexes :
             • Post-it     Fige un instantané des stats en post-it flottant.
             • Hide/Show   Masque / restaure tous les post-its ouverts.
             • Add Fit     (Identify, mode Curve) publie la courbe ajustée.
             • → Scenario  (Identify, mode Curve) échantillonne la courbe
                           vers des points de contrôle Scenario.
           Cliquer le texte visible « Post-it » crée directement un
           post-it ; la flèche déroule les autres actions.
?          Ouvre cette aide.
COLONNES DU TABLEAU DE STATS
#      Numéro de ligne.
Serie  Nom de la série (coloré comme sur le graphique).
nb     Nombre de points dans le rectangle.
sum    Somme des valeurs Y (multipliée par UF si Adj est ON).
avg    Moyenne arithmétique.
min    Valeur Y minimale.
max    Valeur Y maximale.
Range  Étendue : max − min.
σ      Écart-type (bascule Stats).
NA     Nombre de valeurs manquantes / NaN (bascule Stats).
NA%    Pourcentage de valeurs NaN (bascule Stats).
IQR    Étendue interquartile Q75 − Q25 (bascule Stats).
MAD    Déviation absolue médiane (bascule Stats).
skew   Asymétrie (bascule Stats).
kurt   Kurtosis excédentaire (bascule Stats).
Pxx    Percentile au niveau xx (bascule Pct ; ex. P10, P75).
Quand exactement deux séries A sont actives, trois lignes supplémentaires
apparaissent :
  S1>S2 : Δ   Deltas positifs (S1 − S2 > 0).
  S1<S2 : Δ   Deltas négatifs (S1 − S2 < 0).
  Δ (S1-S2)   Tous les deltas S1 − S2.
POST-ITS
Un post-it est un instantané flottant sans bordure du tableau courant. Il
ne se met pas à jour quand le rectangle bouge. Faites-le glisser par son
en-tête ; redimensionnez depuis les bords droit/bas ; fermez avec ✕.
« Copy » dans l'en-tête copie toutes les données au format TSV.
« → AI » envoie l'instantané à l'IA.
PCA DANS AREA
La bascule PCA calcule les composantes principales sur la portée X de
l'Area : Xmin / Xmax sélectionnent les lignes utilisées. Les Ymin / Ymax
de l'Area ne filtrent pas les données PCA ; ce sont les Ymin / Ymax plein
graphe qui bornent les valeurs, pour éviter un nombre de points différent
par série avant le calcul.
Le nombre de PC vaut 3 par défaut (données standardisées) ; il n'est plus
réglable dans Parameters (l'ancien onglet Axes a été retiré). L'atelier PCA
(bouton PCA de la fenêtre graphique) offre une analyse plus complète. Area ajoute au
tableau les lignes AXIS_PC1, AXIS_PC2, …, AXIS_RECONSTRUCTION_ERROR et
AXIS_DIST_PCA. AXIS_DIST_PCA = sqrt(somme(PCi²)) agit comme score de
distance global dans l'espace PCA. λ% est la variance expliquée par chaque
composante, cumλ% la variance cumulée.
Le bouton PCA→Series crée les séries lambda temporaires correspondantes
(scores PC, erreur de reconstruction, distance PCA) dans la palette Series.
Elles servent à l'exploration et au tracé rapides mais ne sont pas
enregistrées dans query.json. Pour les conserver, créez une table de
travail contenant les vraies séries et les PC, puis ouvrez-la comme query.
IDENTIFY / FIT (recherche de forme exploratoire)
Explore quelle forme mathématique décrit le mieux chaque série A dans le
rectangle Area courant. C'est une aide Graph First — pas un test
statistique formel. Fit % mesure la qualité du modèle, pas « la
probabilité que les données suivent cette loi ».
Distribution / Curve (combo de mode)
  Distribution — ajuste les valeurs Y dans l'Area seulement (X ignoré).
                 Pour résidus, bruit ou dispersion. Peu adapté aux profils
                 ordonnés (pyramide des âges, série temporelle) : préférez
                 Curve.
  Curve        — ajuste Y = f(X) en utilisant l'axe X de la série (temps,
                 âge, index…).
Fit          Calcule le meilleur modèle pour chaque série A. Les colonnes
             affichent « (click Fit) » tant que Fit n'a pas été pressé.
             Après avoir déplacé le rectangle, rechargé les données ou
             recalculé avec des valeurs changées, cliquez Fit à nouveau.
Colonnes Identify (quand Identify est ON)
  IdType       « dist » ou « curve ».
  Best model   Nom du meilleur candidat classé.
  Fit %        Score de qualité (basé R² pour Curve, basé KS pour
               Distribution).
  Param 1..3   Jusqu'à trois paramètres ajustés (label=valeur).
Actions Add Fit / → Scenario (combo Actions, mode Curve uniquement)
  Add Fit      Publie la meilleure courbe ajustée comme nouvelle série.
               Le modèle est évalué sur TOUT le X de la série — les valeurs
               hors du rectangle Area peuvent être extrapolées.
  → Scenario   Échantillonne la meilleure courbe en points de contrôle
               Scenario et ouvre la palette Scenario.
  Ces deux actions sont masquées quand le mode Distribution est choisi.
RACCOURCIS CLAVIER
Ctrl+C     Copie les lignes sélectionnées (ou toutes) du tableau Stats en
           TSV.
CONSEILS
• Tracez un nouveau rectangle par clic-glisser sur le graphe en mode Area
  (Graph Remote ▸ Area).
• Pour déplacer ou redimensionner un rectangle existant, cliquez Edit puis
  manipulez le rectangle directement sur le graphe.
• Utilisez des Xmin/Xmax cohérents entre post-its pour comparer des
  périodes.
• Réglez Tol au pas de l'axe X pour aligner des séries partageant les
  mêmes dates.
• Pyramides, profils de cohorte, formes saisonnières : utilisez Curve, pas
  Distribution.
• Comptez ~8 points dans l'Area pour Distribution, ~5 pour Curve.
• Les résultats Identify sont inclus dans le JSON AI Feed quand Identify
  est ON et que Fit a été exécuté.
SELECTION HORS CADRE (plusieurs graphes)
Area filtre les points simultanément sur X et Y : une valeur Y située hors
des bornes est exclue du compte « nb », même si sa date est sélectionnée.
En dessinant l'Area, prolonger le geste AU-DESSUS ou AU-DESSOUS du cadre
étend Ymin/Ymax aux extrêmes des séries A et des séries des autres graphes
de la même query. Un geste à GAUCHE ou à DROITE du cadre étend Xmin/Xmax.
L'axe non dépassé conserve la sélection dessinée (par exemple, le pic
temporel sur X). Les graphes et leur zoom ne sont pas modifiés ; seul le
rectangle Area prend ces bornes après relâchement de la souris.
