Fenêtre Import files — Aide

Accès : fenêtre Main ▸ In/Out Data ▸ Import file.
La fenêtre Import files (« Imported files ») liste les fichiers sources déjà
importés dans le workspace et lance les nouveaux imports. Elle reste ouverte
pendant les imports et se met à jour à chaque table créée.
Processus type :
  Fine load (ou Bulk load) → choisir le(s) fichier(s) → nettoyer / typer
  (Check file) ou régler la table (Copy Table) → EXEC / Table → la table
  apparaît dans la liste Main → clic sur son nom pour ouvrir le graphe.

COLONNES DE LA LISTE

  Full path   Chemin complet du fichier source.
  Modified    Date de dernière modification du fichier source.
  Rows        Nombre de lignes lors du dernier import.
  Table(s)    Table(s) DuckDB créée(s) depuis ce fichier. Un classeur Excel à
              plusieurs feuilles produit des tables NOM__FEUILLE.
  Mask        Masque Check file enregistré pour ce fichier (vide si aucun).
Clic sur un en-tête : tri ; nouveau clic : ordre inverse.

BOUTONS DU HAUT

  Bulk load
      Sélecteur multi-fichiers (Excel .xlsx/.xls, CSV, Parquet). Pour chaque
      fichier, la fenêtre Copy Table / Export Table s'ouvre (modale) avec le nom
      du fichier comme nom de table : vérifiez le nom et les options, puis EXEC
      charge la table. Les fichiers sont traités l'un après l'autre ; une erreur
      sur un fichier est signalée et n'arrête pas les suivants.
      Voir l'aide « copy_table ».
  Fine load
      Ouvre la fenêtre Check file pour un seul fichier : aperçu brut, trimming
      (Top / Bottom / Left / Right / Header), transposition, sélection et
      renommage des colonnes, types, format de date, politique NaN, shrink,
      masque réutilisable. La table est créée avec le nom choisi dans Check file.
      Voir l'aide « import_check_window ».
      Si une table du même nom existe déjà (ou des tables NOM__…), WysiQ demande :
        Oui = écraser (les anciennes tables NOM et NOM__… sont supprimées) ;
        Non = renommer automatiquement (NOM_1, NOM_2…) ;
        Annuler = abandonner.
      Une fenêtre de progression « Import file(s) » s'affiche pendant l'import.
  ?   Ouvre cette aide.

BOUTONS DU BAS

  Reload selected
      Relit les fichiers sources des lignes sélectionnées et recharge leurs
      tables (même nom, même masque). Utile après modification du fichier sur
      le disque. Sans sélection : message « Select one or more file rows first ».
      Le double-clic sur une ligne fait la même chose.
  Refresh
      Resynchronise la liste avec le registre des fichiers importés (imports
      faits ailleurs : SQL Assistant, Check file, Copy Table…).
  Close
      Ferme la fenêtre (les imports en cours ne sont pas annulés).
MENU CLIC DROIT (sur une ligne)
  → AI
      Envoie le masque de la ligne (règles de nettoyage, sans les données) dans
      l'AI Feed Stack. Disponible seulement si la ligne a un masque ; sinon
      l'entrée « → AI (no mask) » est grisée.
  Remove entry: <fichier>
      Retire la ligne du registre des fichiers importés. Ne supprime ni la table
      DuckDB, ni le fichier sur le disque.

BULK LOAD OU FINE LOAD ?

  Bulk load   plusieurs fichiers propres et homogènes, réglages de table
              simples (nom, type, destination).
  Fine load   un fichier avec en-têtes multiples, lignes ou colonnes parasites,
              dates non standard, transposition, ou réduction du nombre de
              lignes (shrink).
Le masque sauvegardé (colonne Mask) permet de réimporter le même fichier avec
exactement les mêmes règles via Reload selected, sans repasser par Check file.

TEMPORAIRE / PERSISTANT

Un import crée une table persistante : fichier .parquet + définition .json
dans workspace/tables/ et entrée dans le registre. Écraser une table existante
remplace ses données (pas d'annulation). Remove entry ne touche qu'au registre.
