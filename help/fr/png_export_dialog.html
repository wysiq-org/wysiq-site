Export (PNG/PDF/HTML) — Aide

Accès : Graph Remote ▸ Print.
Génère des rendus haute résolution du graphique courant en PNG, PDF et/ou
HTML interactif, avec contrôle complet sur la résolution, le style de grille,
le format de date, le nombre de ticks et le placement des étiquettes.

BLOC OUTPUT

Format
  PNG      Raster sans perte — fichier léger, universel.
  PDF      Document vectoriel, qualité infinie — idéal impression/rapports.
  PDF+PNG  Exporte PNG et PDF simultanément.
  HTML     Fichier HTML interactif seul (zoom/pan).
  HTML+PNG Fichier HTML interactif + PNG haute résolution.
Type HTML
  Print quality (export res., zoom/pan)
    PNG haute résolution intégré dans une page HTML avec zoom/pan tactile
    (Panzoom). Rendu pixel-perfect identique à l'écran WysiQ. Recommandé
    pour partage mobile et présentation.
  Plotly hover/zoom (~3.5 MB lib., offline)
    Graphe Plotly interactif autonome — hover, zoom, pan, bascule de séries.
    Inclut la bibliothèque Plotly complète (~3.5 Mo). Fonctionne sans internet.
  Plotly hover/zoom (~500 KB, needs internet)
    Graphe Plotly interactif léger — bibliothèque chargée depuis CDN.
    Nécessite une connexion internet à l'ouverture.
Transparent background
  Fond du graphique transparent (PNG et HTML+PNG uniquement).
  Utile pour insérer le graphique sur un fond coloré (diapo, web).
? (ce bouton)  Ouvre cette fenêtre d'aide.
TICKS DE GRILLE — Bouton Style et swatches couleur
Bouton [Style] (ou clic sur une pastille de couleur)
  Ouvre une fenêtre 2×2 pour les quatre combinaisons de grille :
    X axe Majeur  |  X axe Mineur
    Y axe Majeur  |  Y axe Mineur
  Chaque panneau : Couleur (pastilles, More... = palette complète), Taille,
  Alpha ; les changements s'appliquent aussitôt ; Close ferme.
Tick size (pt)  Taille des graduations dans le fichier exporté.
TX  Nombre de ticks majeurs axe X
  "auto" = matplotlib décide. Entier = valeur forcée (ex. 12 = mensuel).
tX  Subdivisions mineures X
  Vide = désactivés. Entier = subdivisions par intervalle majeur.
TY / tY  Mêmes règles pour l'axe Y.
AXE X
Axe X (format date)
  Format date/heure pour les étiquettes dans le fichier exporté (liste de
  préréglages ou saisie, Entrée pour valider).
  Indépendant du format affiché à l'écran.
  JJ/MM → 31/12     JJ/MM HH:MM → 31/12 23:59     AAAA-MM-JJ → 2025-12-31
X labels (étiquettes X)
  Bottom     Étiquettes sous le graphique (standard).
  Zero (Y=0) Étiquettes supplémentaires sur la ligne Y=0.
  Top        Deuxième rang d'étiquettes au-dessus du graphique.
Minor Grid lines (grille mineure)
  X — lignes verticales mineures.   Y — lignes horizontales mineures.
RÉSOLUTION (« Resolution »)
Line (cartésien)  W px / H px — dimensions du graphique cartésien.
Polar             W px / H px — dimensions du graphique polaire.
  Link W & H (square)  Force largeur = hauteur (graphe polaire carré).
DPI               Points par pouce. 150 = usage courant. 300 = impression HQ.
Tight layout (prevents cropped axes)
                  Supprime les espaces blancs autour du graphique et évite
                  les axes coupés.
Ligne de statut (colorée)
  Vert < 500 MP · Orange 500–2 000 MP (lent) · Rouge > 2 000 MP (risque OOM).

BOUTONS

Cancel   (ou Échap) Ferme le dialogue — les valeurs sont sauvegardées pour la
         prochaine fois.
Print    Lance l'export (choix du fichier de destination).
Chaque réglage numérique a un curseur et un champ de saisie (Entrée pour
valider). Après l'export, l'affichage du graphe est rétabli.
