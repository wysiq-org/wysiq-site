AREA — TESTS STATISTIQUES (panneau déplacé)

Important
Le panneau de tests autrefois intégré à la palette Area a été retiré. Les
tests statistiques (Pearson, Spearman, t-test, Wilcoxon, ANOVA, Kruskal,
Tukey, Dunn…) sont désormais réalisés dans la fenêtre dédiée
Statistical Tests, ouverte depuis la barre d'outils. Consultez l'aide
stats_tests_window pour la documentation complète.
Les mêmes statistiques atteignent aussi automatiquement le JSON de l'AI
Analyst : le moteur de tests (stats/tests_engine.py) est réutilisé
directement, sans interface embarquée.
Ce qui reste dans la palette Area
La palette Area conserve le calcul des statistiques de sélection sur le
rectangle (nb, sum, avg, min, max, Range, et les colonnes étendues σ, NA,
IQR, MAD, skew, kurt via la bascule Stats, plus les percentiles via Pct).
Voir l'aide area_palette.
Portée des données
Les tests portent sur les séries dont la bascule A = ON dans la palette
Series. Dans la fenêtre Statistical Tests, la portée (rectangle Area ou
série complète) et l'appariement des valeurs X selon la tolérance sont
gérés depuis cette fenêtre.
Rappel des tests disponibles (fenêtre Statistical Tests)
Par paires :
  Pearson r     Corrélation linéaire + p-valeur bilatérale.
  Spearman r    Corrélation des rangs + p-valeur.
  t-test        Test t apparié sur X alignés (SciPy requis).
  Wilcoxon      Rangs signés de Wilcoxon (apparié, non paramétrique).
  MAE / RMSE    Erreurs d'écart (sans p-valeur).
  Cohen d       Taille d'effet de la différence appariée (sans p-valeur).
De groupe (≥ 3 séries A) :
  Levene / Bartlett   Égalité des variances.
  ANOVA (one-way)     Test paramétrique d'égalité des moyennes.
  Kruskal             Alternative non paramétrique à l'ANOVA.
  Tukey HSD           Post-hoc par paires (statsmodels requis).
  Dunn                Post-hoc non paramétrique (scikit-posthocs requis).
Correction pour tests multiples : BH (Benjamini–Hochberg, FDR, par
défaut), Holm (Holm–Bonferroni), Bonf (Bonferroni, le plus conservateur).
Dépendances
• Tests de base (Pearson, MAE, RMSE, Cohen d) : NumPy uniquement.
• Tests paramétriques (t-test, Wilcoxon, ANOVA…) : SciPy requis.
• Tukey HSD : statsmodels requis.
• Dunn : scikit-posthocs requis.
Un package manquant génère une ligne d'information explicative.
