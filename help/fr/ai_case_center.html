AI CASE CENTER

Accès : AI Command Center ▸ 🗂 AI Case Center, ou Main ▸ AI ▸ AI Cases…
(un graphe doit être ouvert).
Double-clic sur un AI Case de la liste : l'ouvrir (le rendre actif).
Un AI Case est l'enregistrement complet et rejouable d'une investigation IA
bâtie sur une WysiQuery : les questions posées à l'IA (AI Prompts), les
exécutions sur un ou plusieurs Profils IA, les réponses et erreurs, le contexte
envoyé avec chaque question (AI feeds — Area et data feeds), et les rapports
HTML produits. Rien n'est lu depuis des fichiers bruts ici : chaque valeur
provient de la timeline du Case via le CaseStore, un journal en ajout seul avec
corrélation requête / réponse.

DISPOSITION — DEUX LISTES À GAUCHE, DÉTAIL À DROITE

La fenêtre suit la même forme que le catalogue de Métriques.
  AI Case (colonne de gauche) — une ligne par Case, par nom. Le Case actif est
  marqué d'une puce.
  Query (colonne de droite) — la ou les WysiQuery sur lesquelles repose l'AI
  Case sélectionné. Sélectionnez un Case à gauche pour voir la WysiQuery qui le
  porte, comme le catalogue de Métriques montre les « Series used » d'une
  métrique.
La partie droite est un inspecteur du Case sélectionné :
  En-tête AI Case — Nom, Créé, Mis à jour, Query (le nom de la WysiQuery),
  Profils, et Counts (prompts, exécutions, événements, rapports).
  Onglet AI Prompt — les questions posées à l'IA. Un broadcast ayant posé la
  même question à plusieurs Profils se réduit à une ligne de prompt, le nombre
  d'exécutions figurant dans la colonne « x ». Sélectionner un prompt liste ses
  exécutions et réponses (profil, tokens, provenance, erreurs).
  Summary / Prompts & executions / Grouped / Chat — vues du Case complet
  pour une inspection plus fine. Double-clic sur un événement : ouvre le
  rapport HTML associé s'il existe. Les identifiants internes ne sont pas
  affichés dans la timeline ; ils restent dans les fichiers du Case.

VOCABULAIRE

  Query = WysiQuery — la requête WysiQ sur laquelle repose le Case.
  AI Prompt = une question posée à l'IA.
  Exécution = un AI Prompt exécuté sur un Profil IA (un essai).
  AI feed = le contexte envoyé avec une question (Area ou data feed), adressé
  par empreinte de contenu, jamais en données brutes.

BARRE D'OUTILS

  Open folder — ouvrir le dossier du Case sélectionné sur le disque.
  Add to AI Feed Stack — ajoute les feeds des AI Cases numérotés (Sel), ou du
  Case surligné s'il n'y en a aucun, dans l'AI Feed Stack courant, dans l'ordre
  Sel, à la suite des feeds déjà présents. Clic sur Sel pour attribuer /
  enlever le numéro. Tri et Send # ensuite dans l'AI Feed Stack.
  ? — cette aide (bord droit de la fenêtre).
  Close — fermer la fenêtre.

CLIC DROIT SUR UN AI CASE

  Rename... — changer le nom du Case.
  Duplicate... — cloner le Case entier (timeline, feeds, rapports, logs) dans
  un nouveau dossier avec une identité neuve. L'original n'est jamais touché.
  Un duplicata est le point de départ pour rejouer le même Case sur une autre
  WysiQuery ou sur des données mises à jour — par exemple une autre année.
  Delete... — supprimer définitivement le dossier du Case et tous ses fichiers.
  Cette action est irréversible.
La liste se rafraîchit d'elle-même à l'ouverture, la duplication, la
suppression ou le renommage d'un Case : aucun rafraîchissement manuel n'est
nécessaire.
DONNÉES ORIGINALES vs ACTUELLES (dans l'AI Feed Stack)
Un feed rejoué depuis un AI Case peut être envoyé soit sur les données
envoyées à l'origine, soit reconstruit sur les données WysiQ actuelles avec la
même recette (mêmes bornes et shrink). Le choix se fait dans l'AI Feed Stack,
par entrée :
  Clic droit sur la colonne « Send # » d'un feed issu d'un AI Case → Original
  data / Current data. Un tooltip indique le mode courant.
  Clic droit sur la colonne « Feed » → Delete, ou Duplicate. Duplicate ajoute
  une 2e entrée dans le mode OPPOSÉ, pour envoyer côte à côte la version
  originale et la version actuelle (par exemple comparer deux années).
Les feeds ajoutés via le bouton AI d'une window sont toujours sur les données
actuelles et n'ont pas ce choix.
