WysiQ - Catalogue : scripts SQL (technique)

Le catalogue distingue la liste distante, les colonnes et les statistiques.
Les chemins ci-dessous sont relatifs au dossier du programme.
1. Liste des tables distantes :
   connexions/bundled/<connecteur>/list_tables.sql
2. Colonnes et statistiques (created/modified/row_count) :
   connexions/bundled/dialect_lexicon.json
   section catalog_sql (dialectes de chaque SGBD).
3. Exécution et assemblage :
   connexions/catalog_sql_runner.py
   connexions/table_column_rows.py
Les définitions métier et Sel/Recipe appartiennent aux JSON de
workspace/tables/, pas aux scripts SQL. Les connecteurs WWW ne sont pas
une connexion SQL : leurs ressources et paramètres sont dans
workspace/WWW/connectors/ et leur provenance dans source/www_source.
Les sources L sont gérées dans workspace/live/live_tables.json.
Consultez aussi l'aide Catalogue des tables (?) pour les codes LO, RS,
RL, WS, WL et L. Il n'existe pas de bascule Static / Live dans le catalogue
(elle se fait par clic droit sur la table dans la fenêtre Main).
Les objets V historiques restent lisibles lorsqu'ils existent ; ils ne sont
pas une famille d'acquisition de données.
