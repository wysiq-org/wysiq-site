Check file window — Preparing a file before import

Access: Import files ▸ Fine load; Live Sources (CSV file source, Live mode).
Check file ("Prepare file before import") cleans, crops, types and
subsamples a file (CSV, TXT, XLSX/XLS, Parquet) before loading it as a
DuckDB table, exporting it to a file or using it as a Live source.
Typical workflow:
  File... → set Separator / Sheet → Top / Bottom / Left / Right / Header
  → Apply → choose columns, names, types, NaN policy, date formats
  → Preview → (Save mask) → >> Table (or >> File, or >> Live).

TOP BAR

  File...     Choose or change the source file.
  First       Number of rows read for the preview (10 to 9 999 999; default:
              "rows" parameter of Globals). This is a display limit only:
              the export ALWAYS rereads the full file.
  Mask        Saved mask to apply (names, types, NaN, formats, trimming,
              shrink). The list contains the masks of this file and of the
              workspace.
  Sheet       (Excel only) Sheet to process.
  Separator   CSV separator: Auto, ;  ,  Tab, Pipe.
  Reload      Rereads the file with the current First / Sheet / Separator.
  ?           Opens this help.

RAW PREVIEW

Rows of the file as read from disk. Top, Prev, Next, Bottom only move this
preview (no change to the settings). Column widths are remembered.

CLEANING PARAMETERS

  Top        Rows removed at the top of the raw file.
  Bottom     Rows removed at the bottom.
  Left       Columns removed on the left.
  Right      Columns removed on the right.
  Header     Index of the header row in the remaining area
             (in Live mode, -1 = no header).
  Shrink     Read-only field summarising the subsampling; a click opens the
             Shrink box.
  Transpose  Swaps rows and columns; click again = back.
  Apply      Rebuilds the cleaned preview with the current settings.

SHRINK BOX

  Enable shrink    Enables subsampling.
  Auto to N rows   Computes the step to get about N rows.
  Every N row(s)   Keeps 1 row out of N.
  First rows       Keeps only the first N rows (0 = all).
  Apply            Confirms; Delete removes the shrink; Cancel closes
                   without change.
Auto and Every are exclusive. The shrink is applied on export (table or
file) and saved in the mask.

CLEANED PREVIEW

Result after trimming, header, column selection, types and transposition.

OUTPUT COLUMNS

  Sel        Include / exclude the column. Click the Sel heading: tick all
             / untick all.
  Name       Click to rename (Enter confirms). The name is used everywhere:
             preview, mask, exported file, table.
  Type       Type applied on load:
               Auto                — automatic detection;
               Text                — string;
               Integer (nullable)  — nullable integer;
               Decimal             — float;
               Time HH:MM → h      — "10:30" becomes 10.5 (empty → NaN);
               Date/time           — date/time.
  Inferred   Read-only: type WysiQ would detect (sample of at most 200
             values).
  Empty/NaN  Replacement of empty values after conversion:
               (keep) — leave as is (default); "" empty — empty string;
               NaN — float NaN; 0 — integer 0; 0.0 — float 0.0.
  Format     Date/time columns: read format. List of presets
             (DD/MM/YYYY, YYYY-MM-DD…) or free entry in strptime format
             (e.g. %d/%m/%Y %H:%M). OK confirms, Escape cancels.

BOTTOM BUTTONS

  Save mask   Saves all settings as a reusable mask (used by Reload
              selected in Import files and by the Mask list).
  Preview     Applies types and NaN policies and refreshes the cleaned
              preview (nothing is exported).
  >> File     Opens the file export box (CSV by default, XLSX possible;
              Parquet not offered here).
  >> Table    Opens the Copy Table box with the proposed name; the full file
              is loaded on EXEC, with trimming, columns, types and shrink.
              The source file is then listed in Import files.
  >> Live     (Live mode only) Validates the structure for a CSV Live
              source. First choose the "Date/time X:" column; it must be
              ticked and at least one other numeric series must be ticked,
              otherwise a warning is shown.
  Cancel      Closes without creating anything (the window's close box does
              the same).
CHOOSING LIVE COLUMNS ("Use columns")
For a CSV Live source without a usable header, a box lists the columns:
click to select, double-click or F2 to rename (Enter confirms, Escape
cancels), list of column numbers. Use columns confirms, Cancel aborts.

GOOD TO KNOW

• Nothing is written until >> Table, >> File, >> Live or Save mask is
  used.
• If the table already exists, the Copy Table box / the import asks whether
  to overwrite or rename it.
