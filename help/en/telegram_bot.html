TELEGRAM BOT — Setup Guide

Access: Share Center ▸ Advanced ▸ Setup ▸ Telegram (? button).
Buttons: 🔗 Open @BotFather, ✓ Verify & Save, 🗑 Delete, 🔄 Refresh,
🔄 Scan new contacts, 📨 Send test, 🔍 Debug updates; Ctrl+C copies the
selected row of a list.
WysiQ uses Telegram Bots to send graph snapshots from an
open WysiQuery and Query files directly to your contacts.
You can configure several bots —
one per team, project or purpose.

STEP 1 — CREATE A BOT ON TELEGRAM

1. Open Telegram and search for @BotFather
2. Send:  /newbot
3. Give it a name, e.g.:  WysiQ RTE Graphs
4. Give it a username ending in 'bot',
   e.g.:  wysiq_rte_graphs_bot
5. BotFather gives you a token:
   123456789:AABBccDDeeFFggHH...
6. Copy the token — you will need it in Step 2.
👍 Help WysiQ grow — include 'wysiq'
   in your bot username.

STEP 2 — ADD THE BOT IN WYSIQ

In the form below the bot list:
  ID      — a unique key, e.g. bot_rte_graphs
            (no spaces, letters and _ only)
  Name    — display name shown in WysiQ
  @User   — the @username given by BotFather
  Token   — paste the token from BotFather
Click "✓ Verify & Save" — WysiQ contacts
Telegram to check that the token is valid.

STEP 3 — REGISTER SUBSCRIBERS

Each recipient must:
1. Open Telegram
2. Search for your bot username
3. Press Start or send /start
Then in WysiQ, select the bot
and click "🔄 Scan new contacts".
WysiQ reads every /start message received
and registers each Chat ID automatically.
The subscriber appears in the lower list.

SENDING

Graphs (📦 Prep in the Graph Remote, then Share Center ▸ Send):
  HTML snapshot of the current WysiQuery — sent to contacts
  whose Telegram channel is active (✈ on) in the Contacts tab.
  Uses the bot registered for that contact.
Query (📤 Share in Export query):
  Query ZIP bundle (saved WysiQuery: table + analysis +
  graph settings) — same mechanism, sent directly to
  the contact's Telegram chat.

MULTIPLE BOTS

You can add as many bots as needed:
  — one bot per project
  — one bot for graphs, one for data
  — one per team or department
Each bot has its own subscriber list.
A contact can subscribe to several bots —
scan with each bot separately.
