Expert Studio — WysiQ

Note (current version): Expert Studio is no longer opened by any menu or
button. Its main functions are taken over by the AI Command Center
(🎚 Expert Config, 🗄 AI Feed Stack, prompt and ▶ Send). This page remains the
reference for the former workshop.
The Expert Studio is the main working surface that orchestrates analytical
exchanges with the AI. It no longer performs the transport itself: it feeds
the independent Prompt window which drives the send to an AI profile, and
responses come back to the HTML Viewer and Scenario window.
Overall architecture (WysiQ after the split):
  Expert Studio      Configuration, recipes, JSON/data options, scenarios.
  AI Session         Session management (create, archive, reopen).
  AI Profile         AI profile management (create, connect, protocol).
  Prompt             Independent window — prompt editing, Send button.
  HTML Viewer        Chapter-based answers.
  Scenario           Receives scenarios corrected by the AI.

REDUCED / FULL MODE

The "Reduced" checkbox in the top-right toggles the display. The window
height auto-adjusts to fit content (no empty space that would hide the
graph below).
  Reduced (default)
    Only the action sections stay visible:
      - Data & session
      - Scenario & exchange
      - Quality bar
      - Footer (?, Settings, Close)
    Useful once the role and recipe are picked — keeps the palette
    compact above the graph.
  Full (Reduced unchecked)
    Adds the configuration sections:
      - Expert configuration (Recipe, Role, Context, Audience, Style,
        Language)
      - AI analysis options (Graph context, Tests, Signals, Correlations,
        PCA)
      - Run behavior

EXPERT CONFIGURATION

Recipe      Preconfigured analysis recipe. Changing a recipe reloads the
            other fields.
Role        Expert role the AI plays.
Context     Analysis context.
Audience    Target audience. Adjusts vocabulary.
Style       Answer format.
Language    Answer language.

AI ANALYSIS OPTIONS

Toggles that drive the analytical payload sent to the AI:
  Graph context   Current graph context.
  Tests           Statistics and tests computed in the Area palette.
  Signals         Selected series.
  Correlations    Correlation matrix.
  PCA             Principal component analysis.

RUN BEHAVIOR

Attach cropped area only    Attach only the image cropped to Area.
Hide AI console             Do not auto-open companion windows.
Open HTML viewer            Open HTML Viewer when an answer arrives.
Chapter HTML answers        Split answers into HTML chapters.

DATA & SESSION

AI Session
  Open the AI Session Center (session management: create, archive,
  reopen).
AI Profiles
  Open the AI Profile window (formerly "AI Analyst"), which manages
  AI profile connections.
Build JSON
  Rebuild the JSON payload (Analytics Feed) from the current graph
  state and toggles.
Select Data…
  Open the data selection dialog.
Prompt…
  Open the independent Prompt window (the primary editing / sending
  interface). Also opens automatically when Expert Studio opens
  (unless Hide AI console is active).
Generate Expert Report
  Assemble the full prompt (role, context, audience, style, language)
  and push it to the Prompt window for review + send.

SCENARIO & EXCHANGE

Open Scenario…
  Open the Scenario palette of the current WysiQuery.
Send to AI…
  Send the active scenario to the Prompt window (structured JSON,
  kind=wysiq_scenario_response). The user reviews then clicks Send
  in the Prompt window to actually send.
Receive from AI…
  Retrieve a scenario returned by the AI and re-inject it into the
  Scenario palette.

QUALITY / ESTIMATED PROMPT

The "Quality" bar and "Estimated prompt" text show the current prompt
quality (0-100 %) and estimated character and token counts.

FOOTER

?         Show this help.
Settings  Open WysiQ global preferences (Params).
Close     Close Expert Studio. Companion windows (Prompt, AI Profile,
          HTML Viewer) stay open independently.

WINDOW BEHAVIOUR

Expert Studio is treated like the other WysiQ floating palettes:
persistent -topmost attribute on Windows, re-raises on activation.
Clicking on the graph does not make it disappear behind.
