Import files window — Help

Access: Main window ▸ In/Out Data ▸ Import file.
The Import files window ("Imported files") lists the source files already
imported into the workspace and starts new imports. It stays open during
imports and updates each time a table is created.
Typical workflow:
  Fine load (or Bulk load) → choose the file(s) → clean / type
  (Check file) or set up the table (Copy Table) → EXEC / Table → the table
  appears in the Main list → click its name to open the graph.

LIST COLUMNS

  Full path   Full path of the source file.
  Modified    Last modification date of the source file.
  Rows        Number of rows at the last import.
  Table(s)    DuckDB table(s) created from this file. An Excel workbook with
              several sheets produces NAME__SHEET tables.
  Mask        Check file mask saved for this file (empty if none).
Click a heading: sort; click again: reverse order.

TOP BUTTONS

  Bulk load
      Multi-file picker (Excel .xlsx/.xls, CSV, Parquet). For each file,
      the Copy Table / Export Table window opens (modal) with the file name
      as table name: check the name and the options, then EXEC loads the
      table. Files are processed one after the other; an error on one file
      is reported and does not stop the following ones.
      See the "copy_table" help.
  Fine load
      Opens the Check file window for a single file: raw preview, trimming
      (Top / Bottom / Left / Right / Header), transposition, column
      selection and renaming, types, date format, NaN policy, shrink,
      reusable mask. The table is created with the name chosen in Check
      file. See the "import_check_window" help.
      If a table with the same name already exists (or NAME__… tables),
      WysiQ asks:
        Yes = overwrite (the old NAME and NAME__… tables are deleted);
        No = rename automatically (NAME_1, NAME_2…);
        Cancel = abort.
      An "Import file(s)" progress window is shown during the import.
  ?   Opens this help.

BOTTOM BUTTONS

  Reload selected
      Rereads the source files of the selected rows and reloads their
      tables (same name, same mask). Useful after the file was changed on
      disk. With no selection: message "Select one or more file rows first".
      Double-clicking a row does the same.
  Refresh
      Resynchronises the list with the registry of imported files (imports
      done elsewhere: SQL Assistant, Check file, Copy Table…).
  Close
      Closes the window (imports in progress are not cancelled).
RIGHT-CLICK MENU (on a row)
  → AI
      Sends the mask of the row (cleaning rules, without the data) to the
      AI Feed Stack. Available only if the row has a mask; otherwise the
      "→ AI (no mask)" entry is greyed out.
  Remove entry: <file>
      Removes the row from the registry of imported files. Deletes neither
      the DuckDB table nor the file on disk.

BULK LOAD OR FINE LOAD?

  Bulk load   several clean, homogeneous files, simple table settings
              (name, type, destination).
  Fine load   a file with multiple headers, stray rows or columns,
              non-standard dates, transposition, or reduction of the number
              of rows (shrink).
The saved mask (Mask column) lets you reimport the same file with exactly
the same rules through Reload selected, without going through Check file
again.

TEMPORARY / PERSISTENT

An import creates a persistent table: .parquet file + .json definition in
workspace/tables/ and an entry in the registry. Overwriting an existing
table replaces its data (no undo). Remove entry only touches the registry.
