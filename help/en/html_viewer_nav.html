WYSIQ HTML NAV — Help

Access: Main ▸ AI ▸ Answers…; AI Command Center ▸ 🌐 HTML Viewer;
Open Nav in AI Connections.
Role
The HTML Nav is used to browse quickly through the HTML answers generated by
the AI (AI Cases and former AI Sessions), as well as WysiQ HTML exports.
The detail per profile, question and run stays in the AI Case Center.
History (⏱ History tab)
The table shows one row per AI Case / session:
  Date | AI Session | WysiQuery
Double-click (or Enter) on a row: opens or reuses the tab of that Case.
The tab is named after the Case.
Navigating inside a Case
  ←  /  →   Previous / next HTML answer of the displayed Case, all profiles
            together.
  ↑         List of the documents of the upper level: ↑ Up goes further up,
            Open (or double-click, Enter) opens the chosen document, Cancel
            closes the list.
HTML bar
The HTML line shows the detail of the visible document: Case, answer
number and position in the series. It is informative (not an address
bar). An image or an embedded WysiQ graph opens in the browser with a
click.
Buttons
Open file…  Opens an HTML file of your choice in a new tab.
New tab     Creates a tab for the current profile.
Close       Closes the Nav.
?           This help.
A- / A+     Decreases / increases the font of the text rendering.
Print       Prints through the system browser.
Copy        Copies the visible text.
Reload      Reloads the current document.
Browser     Opens the current document in the system browser.
Right-click on a tab
  Rename…                    renames the tab;
  New tab for this profile   opens a tab for the same profile;
  Close tab / Close all tabs closes the tab / all tabs.
Good practice
Choose a Case in History, then sweep its answers with ← / →.
Open the AI Case Center to know the profile, the question or the exact
content of an exchange.
