AI Usage

Read-only dashboard for token consumption, response counts and timing.
Open it from the AI Command Center (Usage panel).
The numbers come from the active AI Case or legacy AI Session manifest —
nothing is estimated here.

TOOLBAR

Refresh
    Reload totals and tables from disk.
Export CSV
    Save the per-request table as a semicolon-separated CSV file.
?
    This help.
Close
    Close the window.

TOTALS BAR

Answers
    Completed AI responses in this Case / session.
Tokens in / out / Total
    Cumulative token counts across all profiles.
Cumulative time
    Sum of measured response durations.

BY PROFILE

One row per AI profile that took part. Useful for benchmark runs where the
same question was broadcast to several models.

BY REQUEST

One row per user question sent. Double-click a row to open the saved HTML
answer (when available). Click a column header to sort — sorting by Question
lines up benchmark replies side by side.
Rows without an answer yet are shown dimmed (request still pending).

STATUS LINE

Shows the number of requests and profiles, plus any unanswered count.
