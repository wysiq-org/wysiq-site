AI Knowledge Setup

This standalone window manages the protocol/knowledge JSON files sent to
the AI on connection (AI Connections). Open it from Main ▸ AI ▸
Knowledge…, AI Command Center ▸ 📖 Knowledge Setup, or Parameters ▸ AI.
It contains the "Protocol schemas" list; ? opens this help, Close
closes the window (the Send selection is saved).

PROTOCOL SCHEMAS TAB

Knowledge files are JSON files sent to the AI on every connection. They
give the AI the permanent context of your domain: business definitions,
interpretation rules, nomenclatures, conventions, industry ontologies —
in addition to the technical schemas specific to WysiQ (handshake, answer
format, metric/PCA/signal/stat request schemas).
Single folder: WysiQ/AI/protocol/
    The default WysiQ technical schemas (000_protocol_handshake_
    generic…, 001_ai_response_required_format… etc., present from
    installation) and your own business-context JSON files live side by
    side in the same folder. Every JSON file found there is listed with
    its own Send state.
Send column
    Click the symbol to toggle the state of a file:
    ✓ = sent on connection, ○ = ignored. The state of each file is
    remembered between sessions in
    WysiQ/AI/protocol_send_selection.json.
    Only ✓ files are included in the WysiQ protocol handshake sent at the
    start of each AI session.
★ CORE schemas (000, 001, 002)
    The three files marked ★ are the minimal protocol vocabulary.
    They are ✓ by default. For a simple chat outside the WysiQ protocol
    (prompts and data only), untick all three (○) before Connect.
    The "Reset (recommended)" button restores the advised values.
Other protocol files (010, 020, 040…)
    Not sent on Connect. They go automatically with the AI Feed JSON
    when the matching type is in the AI Feed Stack (e.g. Signals feed →
    signal schemas). The Send column here only concerns Connect.
JSON button
    Shows or hides the preview of the selected file (hidden by default).
Schema list (left) / JSON preview (right)
    Select a file on the left to preview its content on the right.
Right-click a file: Edit, Duplicate, Rename, Delete
    Double-click a row (outside the Send column): Edit. The JSON editor
    offers Save and Cancel.
    To import files shared by a colleague, copy them into
    WysiQ/AI/protocol/ (Open protocol folder), then reopen the window.
→ AI Feed Stack
    Drops the selected schema into the current AI Feed Stack.
Open protocol folder
    Opens WysiQ/AI/protocol/ in the system file explorer — to add,
    inspect or edit the knowledge JSON files directly with any editor.
Language of the knowledge files
    Knowledge files have no predefined language: write them in the
    working language of your domain. The default WysiQ schemas are in
    English.
WORKSPACE LAYOUT  (AI/ folder)
AI/protocol/
    Protocol + knowledge JSON files selectable with the Send column
    above. Sent on connection.
AI/protocol_send_selection.json
    Stores the Send toggles of each protocol/knowledge JSON file.
AI/Feed/<lang>/
    Question dictionary (Requests Catalog of the Command Center;
    Parameters ▸ AI).
AI/sessions/ and qai/cases/
    Archived AI exchanges (former sessions and AI Cases; see AI Case
    Center).
Metric definitions, series metadata, PCA results, correlations, tests
and signals are sent with the query analysis JSON at question time, not
from this Knowledge screen — this screen only controls the
*protocol / business context* files sent once on connection.
PCA interpretation rules, or any other rule specific to your domain, can
be added as a normal JSON file directly in AI/protocol/ — give it a
descriptive file name and tick it in the Send column above.
