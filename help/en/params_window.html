PARAMETERS — WysiQ

Access: Main ▸ Settings ▸ Parameters… (Manual… opens the Help Folder tab
directly); Params button of the Series palette; Settings… of the AI menu
(AI tab). The last tab used is reopened.
The Parameters window is organised in two levels:
  • Main tabs: Globals | Query | Statistics | Signal | AI | Help | Help Folder | Legal
  • Globals sub-tabs: Core | Display | Output | Style | List values | Screens | Help
Global settings are kept by WysiQ; to save the settings specific to a
query (axes, tables, offsets), use SaveQuery.
Text zoom (help): Ctrl + mouse wheel or A− / A+ buttons

GLOBALS TAB

The global workspace settings (Core, Display, Output, Style, Screens,
List values) are documented in Globals → Help (same languages as this
tab). This tab covers the rest of the Parameters window: the Query
parameters and the shared references (date formats, adaptive locator
logic).
  Display > Linked & transparent graphs: Link delay (ms) sets the
  synchronisation latency of LINKED graphs (0 = immediate, default 50 ms);
  Hide when transparent (Grid / Legend / Scale) chooses what a graph with a
  transparent background (▧) hides — default values, changeable per graph
  (right-click on ▧, saved in the query).

QUERY TAB

A single page groups the graph axes and the table layout.
Axes / Y axis: unit, Scale coefficient, decimals, period factor, visible
X/Y bounds, ticks and subdivisions.
X axis - bounds by table: X min/X max dates of each table instance,
Rows before resampling, Start/End positions on the composite axis.
Multi-table - table offsets: X offsets in rows, Y offset, Coeff,
Mode (Shrink/Expand), Target rows, Every N, Exec and Reset.
IMPORTANT: the X bounds of the Axes block apply to the GRAPH; those of the
X axis - bounds by table block apply to ONE table INSTANCE.
Row offsets are not real-time shifts.
For the realignment methods (including AVG, Step and Auto calendar), click
? in the Multi-table block: table_layout.txt help.
Save the query changes with SaveQuery.

STATISTICS TAB

Statistics execution parameters
  p-adjust    multiple-testing correction (BH, Holm, Bonf, none)
  Max lag     maximum lag for autocorrelation/cross-correlation tests
  Bins        number of classes (histogram) for distribution tests
  Min size    minimum sample size required to run a test
  Alpha       significance threshold
Test Notebooks (list on the left + editor on the right)
  Each notebook defines a custom statistical test (source + per-test
  parameters). Select a notebook to view/edit its parameters and its source
  code.
  The ? button opens the Test Notebooks help.

SIGNAL TAB

Controls the Signal metrics shown in the Signal palette.
  Click a row               enables/disables that metric
  Click the Signal heading  enables/disables all metrics
  HF moving average window  window size used by the HF_ENERGY metric
                            (odd values centred, even values rounded
                            down)
Changes are saved immediately — no separate Save/Cancel buttons.
AI TAB
Sub-tabs: Profile | Observatory | AI Folder | Help.
  Profile       AI profiles (provider, model, URL, key), connection test,
                🧭 Assistant… (AI Setup / Bench), provider catalogue, scan
                of local models. See the "params_ai" help.
  Observatory   Selecting the tab opens the AI Observatory settings window
                (activity server, fields sent, JSON preview); Observatory
                Settings… reopens it. See the "activity_tracking" help.
  AI Folder     Selecting the tab opens the AI folder of the workspace
                (protocol, questions, cases) in the file explorer.
  Help          Selecting the tab opens the "params_ai_knowledge" help.
The predefined questions (AI Feed Question Dictionary) are viewed in the
Requests Catalog of the AI Command Center (📋 Request): language, search
<< / >>, list and exact text sent. Files: ai/Feed/<lang>/ folder of the
program.

HELP TAB

Shows this help text directly in the window.
Use the language selector to switch between DE, EN, ES, FR and IT.
Click ↺ to reload after changing the language.
Zoom: Ctrl + mouse wheel or A− / A+ buttons.

HELP FOLDER TAB

Browse and search all the .txt help files shipped with WysiQ (all topics,
not only this window), in any of the 5 languages.
  Language selector     DE / EN / ES / FR / IT
  Search + << / >>      full-text search in the help files of the selected
                        language, navigation between results
  List (left)           all help topics for the selected language
  Text (right)          full content of the selected topic
  A− / A+               text zoom
SHARING SETTINGS (Share Center ▸ Advanced ▸ Setup)
The Contacts, Email/SMTP, Telegram, HTTP Server, 📋 Log and Help tabs are
not in Parameters: they are in Main ▸ Share ▸ Share Center, Advanced ▸
Setup tab. See the "share_params" help.

LEGAL TAB

Open-source licence information of the third-party components for the
current workspace.
  Open folder       opens the legal documents folder in the file explorer
  Drop-down list    Summary | Notices | Full licenses
The content automatically follows the current help language.
DATE FORMAT REFERENCE  (strftime codes)
All format strings use Python's strftime syntax.
Combine the codes freely, e.g. %d/%m/%Y %H:%M:%S
Year
  %Y    4-digit year                 2025
  %y    2-digit year                 25
Month
  %m    zero-padded month            01 … 12
  %b    abbreviated month name       Jan … Dec  (locale)
  %B    full month name              January … December  (locale)
Day
  %d    zero-padded day              01 … 31
  %j    day of the year              001 … 366
Weekday
  %a    abbreviated day              Mon … Sun  (locale)
  %A    full day                     Monday … Sunday  (locale)
  %u    day number (Mon=1)           1 … 7
  %w    day number (Sun=0)           0 … 6
Week
  %W    week number (Mon)            00 … 53
  %V    ISO week number              01 … 53
Hour
  %H    zero-padded 24h hour         00 … 23
  %I    zero-padded 12h hour         01 … 12
  %p    AM / PM  (locale)
Minute
  %M    zero-padded minute           00 … 59
Second
  %S    zero-padded second           00 … 59
Separator / literal
  %%    literal % sign
Time zone
  %Z    time zone abbreviation       UTC, CET …
  %z    UTC offset                   +0100

PRACTICAL EXAMPLES

  Years only (long view)               %Y
  Month + year                         %m/%Y
  Day + month                          %d/%m
  Full date                            %d/%m/%Y
  Date + time (minutes)                %d/%m %H:%M
  Date + time (seconds)                %d/%m/%Y %H:%M:%S
  Time only (hours:minutes)            %H:%M
  Time only (h:m:s)                    %H:%M:%S
  ISO 8601                             %Y-%m-%dT%H:%M:%S
  Week number                          W%W %Y
  Abbreviated month + day              %b %d

ADAPTIVE LOCATOR LOGIC

WysiQ automatically chooses the tick unit according to the visible span:
  Span > 180 d       MonthLocator   — major tick every N months
  Span 60–180 d      WeekdayLocator — major tick every N weeks
  Span 14–60 d       MonthLocator   — tick on fixed days of the month
  Span 2.5–14 d      DayLocator     — major tick every N days
  Span 0.25–2.5 d    HourLocator    — major tick every N hours
  Span 5min–6h       MinuteLocator  — major tick every N minutes
  Span < 5 min       SecondLocator  — major tick every N seconds
  Minor ticks are one unit finer than the major locator.
  The "target ticks" spinbox (Zoom 1–6, see Globals → Display → Zoom date
  thresholds) controls the density and the label format in each unit.
  Display first row: Link (ms) = Link delay, Zoom (%) = Zoom step, Pan (%) = Pan step, Arrows (ms) = Arrow repeat.
  Display > Linked & transparent graphs: Link delay (ms) controls LINKED graph synchronization latency (0 = immediate, default 50 ms);
  Zoom step (%) sets the Graph Remote keyboard zoom step (default 6%, range 1–50%), independently of Link delay;
  Arrow repeat (ms) (default 30 ms, range 15-250 ms) repeats Pan/Zoom arrows and POLAR << X / X >> immediately on press, separately from Link delay;
  Pan step (%) (default 2%, range 1–20%) sets each Pan arrow's movement distance;
