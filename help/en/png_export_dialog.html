Export (PNG/PDF/HTML) — Help

Access: Graph Remote ▸ Print.
Produces high-resolution renderings of the current graph as PNG, PDF and/or
interactive HTML, with full control over resolution, grid style, date
format, number of ticks and label placement.

OUTPUT BLOCK

Format
  PNG      Lossless raster — light, universal file.
  PDF      Vector document, infinite quality — ideal for printing/reports.
  PDF+PNG  Exports PNG and PDF at the same time.
  HTML     Interactive HTML file only (zoom/pan).
  HTML+PNG Interactive HTML file + high-resolution PNG.
HTML type
  Print quality (export res., zoom/pan)
    High-resolution PNG embedded in an HTML page with touch zoom/pan
    (Panzoom). Pixel-perfect rendering identical to the WysiQ screen.
    Recommended for mobile sharing and presentations.
  Plotly hover/zoom (~3.5 MB lib., offline)
    Standalone interactive Plotly graph — hover, zoom, pan, series toggle.
    Includes the full Plotly library (~3.5 MB). Works without internet.
  Plotly hover/zoom (~500 KB, needs internet)
    Light interactive Plotly graph — library loaded from a CDN.
    Requires an internet connection when opened.
Transparent background
  Transparent graph background (PNG and HTML+PNG only).
  Useful to place the graph on a coloured background (slide, web).
? (this button)  Opens this help window.
GRID TICKS — Style button and colour swatches
[Style] button (or click on a colour swatch)
  Opens a 2×2 window for the four grid combinations:
    X axis Major  |  X axis Minor
    Y axis Major  |  Y axis Minor
  Each panel: Colour (swatches, More... = full palette), Size,
  Alpha; changes apply immediately; Close closes.
Tick size (pt)  Size of the tick marks in the exported file.
TX  Number of major ticks on the X axis
  "auto" = matplotlib decides. Integer = forced value (e.g. 12 = monthly).
tX  X minor subdivisions
  Empty = disabled. Integer = subdivisions per major interval.
TY / tY  Same rules for the Y axis.
X AXIS
X axis (date format)
  Date/time format of the labels in the exported file (list of presets or
  typed entry, Enter to confirm).
  Independent of the format shown on screen.
  DD/MM → 31/12     DD/MM HH:MM → 31/12 23:59     YYYY-MM-DD → 2025-12-31
X labels
  Bottom     Labels below the graph (standard).
  Zero (Y=0) Extra labels on the Y=0 line.
  Top        Second row of labels above the graph.
Minor Grid lines
  X — minor vertical lines.   Y — minor horizontal lines.

RESOLUTION

Line (Cartesian)  W px / H px — size of the Cartesian graph.
Polar             W px / H px — size of the polar graph.
  Link W & H (square)  Forces width = height (square polar graph).
DPI               Dots per inch. 150 = everyday use. 300 = HQ printing.
Tight layout (prevents cropped axes)
                  Removes the white space around the graph and avoids
                  cropped axes.
Status line (coloured)
  Green < 500 MP · Orange 500–2,000 MP (slow) · Red > 2,000 MP (OOM risk).

BUTTONS

Cancel   (or Escape) Closes the dialog — values are saved for next time.
Print    Starts the export (choice of the destination file).
Each numeric setting has a slider and an entry field (Enter to confirm).
After the export, the graph display is restored.
