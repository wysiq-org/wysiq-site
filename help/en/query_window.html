QUERY SCREEN — Last PCA summary — WysiQ HELP

Access: Settings ▸ Parameters… ▸ Query tab, "Last PCA summary" block,
? button.
Role
This screen groups the active Query parameters and the latest PCA summary computed from Area.
The PCA block has four tabs: Summary / loadings, Scores / datasets,
PCA guide, Multi-table PCA; Refresh PCA reloads the latest summary. Axis parameters and table
layout are described in the "query_params" and "table_layout" helps.
A WysiQ Query is no longer only a SQL query: it is an analytical recipe. It can document the source table, selected series, derived Metrics, Area bounds, PCA results, Signals, Tests and AI Feed.
Query parameters
Y axis: unit, scale, decimals and period factor.
Axes / ticks: X/Y bounds and graduations for display and extraction.
These two blocks can be hidden to give more room to the PCA summary.
PCA summary
The Last PCA summary section shows the latest PCA computed from Area.
Stored in query.json:
- Query context,
- source table,
- used columns,
- Metric definitions present in the Query,
- X/Y bounds used for the latest PCA,
- A-enabled series used as PCA input,
- computed PCs,
- explained and cumulative variance percentages,
- main coefficients and contributions.
Not stored:
- heavy values of AXIS_PC1, AXIS_PC2, etc.,
- AXIS_RECONSTRUCTION_ERROR,
- AXIS_DIST_PCA.
These series must be recreated in Area with the PCA→Series button, or materialized into a work table if you want to keep them permanently.
Variance table
Variance %: share of information explained by each component.
Cumulative %: retained information when PC1, PC2, PC3, etc. are accumulated.
Coefficients / loadings table
To remain readable, the screen displays the main contributing series for each PC, usually the top 3 per component.
PC1, PC2, ...: loading coefficient of the series in each component.
P1%, P2%, ...: relative contribution of the series in each component.
Dom.PC: component where this series contributes most.
Σ|coef|: global importance of the series across displayed PCs.
mean / scale: centering and scaling values used by the calculation.
Series colors reuse the real colors from the Series palette.
Practical rule
To keep several historical PCA analyses, use Post-it or PPTX.
To reuse PC values later, export/materialize a work table.
