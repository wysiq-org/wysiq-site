AI COMMAND CENTER — unified AI hub

Access: AI Center button of the graph window, AI circle of the Graph Remote,
Main ▸ AI ▸ AI Command Center (Expert)… (a graph must be open).
Role
The AI Command Center is the central point to run an AI investigation on
the active WysiQuery. It gathers in a single window the prompt, the chat
thread, the connection tabs, the AI Feed Stack, the Expert configuration,
and direct access to the AI Connections panel, the AI Case Center, Usage and
the HTML viewer. The analysed graph stays the hero: the Command Center sits
on top of it and every feed sent describes that graph, never a raw data dump.
Workflow
  1. 👤 AI Connections (sidebar) — create or open an AI Case / session,
     choose a profile, then Connect. The transport window opens as a
     panel; closing it only hides it. The session stays active whether
     the Command Center is open or closed.
  2. AI Feed Stack — enable the analytical blocks to send (table, area,
     tests, signals, PCA, correlations, scenario). The order of clicks in
     the Send # column is the sending order.
  3. Expert Config — define role, style and AI level for the handshake feed.
  4. Prompt — type the question and ▶ Send, or use >>AI Next to walk
     through the Stack feed by feed, and ▶ Run Remaining to chain the
     remaining feeds.
⚡ Analyze graph — one-click analysis
The ⚡ Analyze graph button (next to Send) chains the whole workflow above
for you:
  • creates the AI Case of the query if it does not exist (no more Create
    step);
  • takes the profile already used for this query (main profile of its
    Case), otherwise the last profile used;
  • enables Feed 0 (graph context) and, if nothing else is active in the
    Stack, adds the compact summary of the Table (never the raw table);
  • connects the profile and waits until it is ready (a local model may
    take a few seconds to load the first time);
  • sends a standard analysis question in the help language — or the
    question you typed in the prompt.
If no profile is usable yet, it opens the AI Setup assistant (below); the
analysis starts as soon as the chosen models are connected. The full
workflow (Stack, Expert Config, >>AI Next) remains available for detailed
analyses.
🧭 AI Setup / Bench — find, test and compare models
Opens with the Command Center as long as no model is connected (can be
disabled in the assistant), or from the sidebar. In three screens: where
your AIs are (this PC — it can start your Ollama .bat start script —, the
other computers of the network such as a Mac, the cloud keys) → the models
found, tick one or several → a real test of each, in parallel, with
automatic corrections. ⚡ Connect & analyze graph connects every model that
answered (one tab each) and sends them the same analysis: a bench in one
click. Details: ? in the assistant.
Sidebar (◀ folds / reopens it)
  CONNECTIONS   connected profiles: click = make active; the
                "WysiQ Support" row (if available) is enabled by its On box.
  PANELS        🧭 AI Setup / Bench, 👤 AI Connections, 🗄 AI Feed Stack,
                📋 Requests Catalog, 🗂 AI Case Center, 📊 Usage,
                📖 Knowledge Setup, 🎚 Expert Config, 🌐 HTML Viewer.
  SENT PROMPTS  history of the prompts sent.
Prompt area
  📋 Request   opens the request catalog; a click loads the request into
               the prompt.
  🗄 Feed      opens the AI Feed Stack (the Stack summary above the prompt
               opens it too).
  📎 Attach    attaches files (click an attachment: enable / disable it;
               ✕ removes it).
  🎤 Mic       voice dictation.
  Clear        clears the prompt.
  Up / Down    (in the prompt) recalls previous prompts.
🔎 search bar of the thread: Enter = next occurrence, Shift+Enter =
previous, Escape = clear. Clicking the status bar opens Usage.
Connection tabs
Each connected profile has its own tab above the chat. The active tab
receives the next Send. The token counters under a tab reflect the last
exchange of that profile, to compare cost and verbosity between models.
Broadcast
Broadcast (header) adds other already connected profiles as extra targets
for the next JSON AI Feed, Data AI Feed and Send. The main profile (active
tab) is always included. The target line shows (+N) when extra profiles
are armed. Broadcast lets you ask the same question to several models and
compare their answers in a single Case.
>>AI Next (formerly Play Next)
>>AI Next walks through the Stack feed by feed for the active profile tab.
Switching tab resynchronises the cursor and proposes the next canonical
prompt that this profile has not received yet (+N = benchmark catch-up). A
freshly connected model can thus be brought to the same point as the others
without resending everything by hand.
No Fat AI Feed
Everything that leaves this window is compact structured JSON: results,
metadata and content fingerprints, never the full raw series. Raw samples
are optional and explicitly configured. Token cost stays low and the AI
reasons on computed facts.
Shortcuts
  Ctrl+Enter — send
  Ctrl+Up / Ctrl+Down — prompt history
  Ctrl+N — open AI Connections (new session)
  Ctrl+L — clear the prompt
  F1 — this help
Colours
Parameters ▸ Globals controls the Command Center palette.
Expert Config (🎚)
  Configuration window of the handshake feed: Recipe, Role, Context,
  Audience, Style, Language and AI level (drop-down lists). Save
  saves; → AI drops the configuration into the AI Feed Stack; Cancel
  closes without saving; Reset restores the default values.
Broadcast — choosing the profiles
  The "Broadcast — additional AI profiles" window recalls the main profile
  (always included) and lists the other connected profiles to tick;
  Apply arms the selection, Clear empties it. With no other connected
  profile, a message invites you to connect one first.
