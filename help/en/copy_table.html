Export Table / Copy Table — Help

The "Export Table" window creates a WysiQ table (DuckDB + .parquet file in
the workspace) from a source, and can also push the rows to a remote
database. It is opened by:
  • Main ▸ In/Out Data ▸ Export (selected table);
  • Import files ▸ Bulk load (one window per file);
  • Check file ▸ >> Table;
  • the Table window, the SQL Assistant and result exports.
Typical workflow:
  check Input / source → type Target table → choose Target connection
  → (remote database: Remote target table + Remote push) → SQL (check)
  → EXEC.

STEP 1 — FILE OR TABLE?

From some windows, a first box asks for the destination:
  File  (export to exchange)            write a file (see below);
  Table  (DuckDB workspace + remote)    open the Export Table window.
Continue confirms; Cancel aborts. File imports go directly to Table.

EXPORT TABLE WINDOW — FIELDS

  Input / source        Origin of the data (file, table, SQL query);
                        read-only.
  Target table          Name of the WysiQ table to create (required).
  Owner                 Owner stored with the table.
  Created               Creation date (read-only).
  Target connection     Local (DuckDB): the table stays in the workspace.
                        A connected remote profile: the table is created in
                        the workspace AND the rows are pushed to that server.
                        Only active profiles are offered.
  Remote target table   (remote connection) Name of the table on the server;
                        follows Target table until changed by hand.
                        Use schema.table only if the database requires it.
  DuckDB ▸ Add row#     Adds a row-number column.
  Remote push           (remote connection) Remote write mode:
    Create / recreate table and load rows   (re)creates the table then
                                            inserts all rows (GRANT rights
                                            of the old table are lost);
    Append rows to existing table           adds the rows to an existing
                                            compatible table;
    Delete all rows, then insert            empties the table then inserts
                                            (structure kept).
WysiQ always creates a TABLE (no more VIEW): a table can contain metrics
computed in Python and multi-table data that a DuckDB view cannot
represent.

BUTTONS

  ?       Opens this help.
  Help    Descriptive sheet of the table to be created (columns, types,
          source), in a viewer with A− / A+, Copy and Close.
  SQL     Shows the CREATE TABLE script (dialect of the target connection);
          Copy copies it to the clipboard (for a DBA). This button does not
          run the script on the server.
  Cancel  Closes without creating anything.
  EXEC    Runs:
            1. name check ("Name is required");
            2. if the table already exists: "Table '…' already exists.
               Overwrite it?" — Yes replaces the data, No aborts;
            3. full load of the source (file reread in full, mask and
               shrink applied) and CREATE TABLE in DuckDB;
            4. writing of the .parquet and of the .json definition in
               workspace/tables/, update of the registry and of the Main
               list;
            5. if remote connection: writing according to Remote push.
          A final window summarises the result (OK / Enter / Escape).
EXPORT TO FILE ("File export")
  Name                  File name (without extension).
  Folder                Folder (… to browse); default
                        workspace/exchange.
  Parquet / XLSX / CSV  Formats to write (several possible).
  CSV delimiter         Semicolon ; | Comma , | Tab \t | Pipe |.
  Add Row# column       Adds a row number.
  Export                Writes the file(s); Cancel aborts.
A file export creates no table and does not change the workspace.
QUICK IMPORT ("Create")
For a single file, a simplified box shows File and Table name:
Create (or Enter) loads the file into a new table; ? opens this help;
Cancel aborts.
EXPORTING GRAPH DATA (overlay / results)
A small "Export…" box offers Format: Parquet or XLSX, Max rows
(ALL or N), Sheet name (XLSX), and shows the number of rows and columns.

PRECAUTIONS

• Overwrite permanently replaces the data of the local table.
• Create / recreate and Delete all rows change the remote database: check
  the connection and the target table name before EXEC.
