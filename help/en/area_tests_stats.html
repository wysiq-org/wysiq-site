STATISTICAL TESTS — Reference guide

This file covers the detailed documentation of each statistical
test. The tests are run in the Statistical Tests window (opened
from the toolbar); the panel formerly embedded in the Area palette
has been removed. For the interface controls (Scope, pAdj, Mode,
ReCalc…) see the stats_tests_window help.

SCOPE & ALIGNMENT

Scope Area / All
  Tests can run on the selection (Area) or on the whole
  series (All).
  • Area : only the points inside the rectangle (Xmin..Xmax).
  • All  : the whole series, regardless of the rectangle.
  Tip: compare Area vs All to know whether an effect is local
  or global.
  If a result surprises you, switch Area/All to understand the
  impact of the selection.
Tol (alignment on X)
  Tol defines the X alignment tolerance used by pairwise tests
  (S1 vs S2).
  formula: bucket(x) = round(x/tol)*tol  (approx.)
  • tol = 0 : strict alignment (often by index if exact X values
              are rare).
  • tol > 0 : aligns nearby X points — useful when series have
              slightly shifted timestamps.
  Always check n (paired points) in the Tests table.
  Increase Tol if your series have the same shape but not
  exactly the same timestamps.

PAIRWISE TESTS

Pearson  (linear correlation)
  Measures the linear relationship between two paired series.
  r ∈ [-1, +1]
  r close to +1 → strong positive linear correlation.
  r close to  0 → no linear relationship.
  r close to -1 → strong negative linear correlation.
  Relevant if the relationship is roughly linear and outliers are
  limited.
Spearman  (rank correlation)
  Measures the monotonic (not necessarily linear) relationship via
  ranks.
  ρ ∈ [-1, +1]
  More robust to outliers and to non-linear monotonic
  relationships.
  Prefer it if the relationship is monotonic but not linear, or
  when outliers are present.
t-test  (paired)
  Parametric test on the mean of the differences d = S1 − S2.
  H0: mean(d) = 0
  small p → significant mean difference between the two paired
  series.
  Valid if the deltas are roughly normal (or n is large).
Wilcoxon  (paired)
  Non-parametric alternative to the paired t-test (on the ranks of
  the differences).
  H0: median(d) = 0
  More robust if the differences are not normal or with strong
  outliers.
  Prefer it if the distribution of deltas is skewed or has
  outliers.
MAE / RMSE
  Error metrics between S1 and S2 on the paired points.
  MAE  = mean(|d|)
  RMSE = sqrt(mean(d²))
  RMSE penalises large errors more (sensitive to outliers).
  Use them to measure forecast vs actual performance.
Cohen d  (paired effect size)
  Effect size on the deltas, expressed in standard deviations.
  d = mean(deltas) / std(deltas)
  ≈ 0.2 small  |  0.5 medium  |  0.8 large  (rule of thumb)
  Avoids the trap: "very small p but practically no effect".
GROUP TESTS  (≥ 3 series)
ANOVA  (one-way)
  Global parametric test (k series) of equal means.
  H0: mean(S1) = mean(S2) = … = mean(Sk)
  small p → at least one series differs from the others.
  Complete with Tukey HSD to identify the pairs.
  Use it if the residuals are roughly normal and the variances are
  comparable between groups.
Kruskal-Wallis
  Global non-parametric test (k series) of equal distributions
  (rank based).
  H0: identical distributions
  small p → at least one series differs from the others.
  Complete with Dunn to identify the pairs.
  Use it if the distributions are skewed/with outliers or if
  normality is doubtful.

POST-HOC TESTS

Tukey HSD  (post-hoc after ANOVA)
  Pairwise comparisons after ANOVA; controls the type I error
  over all pairs (family-wise).
  Based on the studentised range distribution (q).
  Procedure:
    1. Run the ANOVA first.
    2. If the ANOVA is significant, read the Tukey rows.
    3. p_adj < alpha → significant difference for that pair.
  Prefer Kruskal+Dunn if variances differ strongly or with
  large outliers.
Dunn  (post-hoc after Kruskal)
  Pairwise comparisons on ranks, after Kruskal-Wallis.
  z statistic on rank differences.
  p_adj < alpha → significant difference (non-parametric).
  Use it when Kruskal is significant and/or the data are not
  normal.

MULTIPLE-TESTING CORRECTION

p_adj  (multiple-testing correction)
  Corrects p-values when several comparisons are made, to
  control the false-positive rate.
  • Bonf (Bonferroni): very conservative — multiplies each p
    by the number of tests. Use it if a single false positive
    is critical.
  • Holm: step-down, less severe than Bonferroni.
  • BH (Benjamini-Hochberg): controls the FDR — recommended by
    default for exploratory analysis.
  Always look at p_adj (not only p) when many pairs are
  tested.

EFFECT SIZES

eta²  (ANOVA effect size)
  Share of the total variance explained by the factor (which
  series).
  eta² = SS_between / SS_total
  Useful to quantify the magnitude, not only the significance
  (p).
  Use it if p is very small but the practical effect could
  remain weak.

GLOSSARY

paired      Test on the same X points; compares d = S1 − S2.
one-way     One-factor ANOVA (k groups = k series).
post-hoc    Tests after a global test (ANOVA/Kruskal) to
            identify which pairs differ.
HSD         Honestly Significant Difference (Tukey). p-values
            already adjusted (family-wise control).
FDR         False Discovery Rate — proportion of false positives
            among the significant results.
eta²        ANOVA effect size (share of explained variance).
n           Number of paired points used in the test.
stat        Value of the test statistic (r, t, W, F, H, z
            depending on the test).
p           Raw (unadjusted) p-value.
p_adj       Adjusted p-value after multiple-testing correction.
note        Additional tag: "paired", "non-param",
            "post-hoc", etc.
