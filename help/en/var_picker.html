Variable picker — Help

Compact list opened from the numeric fields of metrics (right-click on k,
+/-, Min, Max, Δ, Fill, Lag, WHERE value…), or through
Rules & params ▸ Rules & Vars… in the graph window.
Buttons: Stay open, Vars series, PLOT, New…, Catalog (opens the Variables
Catalog), ?, Save, Close. Double-click or Enter on a row = insert the
reference.

OPENING / INSERTION

Right-click a linked field → opens this picker.
Click a row → inserts &ref into the active field.
"Stay open" keeps the window open while editing the metric field.
Theme / Variable filters narrow the list (remembered for the session).

CREATING A VARIABLE

New… creates a variable without going through the Variables Catalog: theme,
name, value, unit, description. A theme name that does not exist creates
the theme. If a field is targeted (metric, WHERE value…), the ref of the new
variable is inserted there. Opened from Rules & params ▸ Rules & Vars…
(no targeted field), the variable is only created and selected.
Right-click a row: Insert ref / Create… / Duplicate… / Rename / edit… /
Delete.

IN QUERY / SHOW / VARS SERIES

IN
  ✓ = variable used by at least one metric of the open query
      (combo k/+/−/Min/Max/Δ/Fill, WHERE, table WHERE…).
Show  (IN variables only)
  Enables/disables the variable in the preview.
  Click the Show heading → all ON / all OFF.
  The G/T/A boxes of the Series palette remain; the preview only filters.
Vars series
  • List limited to IN variables.
  • The Description column is replaced by sliders (bounds between the JSON
    value and the current simulated value).
  • The other metrics are hidden in the preview while Vars series is
    ticked.
  • Hover / right-click on the Variable name: unchanged list of metrics.
  • The window shrinks to its sliders; it gets its size back when Vars
    series is unticked.
PLOT
  Refreshes the graph (like PLOT of the Series palette) after a value
  change.

METRICS USING THIS VARIABLE

Hover over the Variable column (normal mode) or the Variable name (Vars
series): "Uses: …" tooltip (direct refs) and "Depends: …" (combo/alias
chain).
Right-click the Variable name:
  list of metrics (read-only), then Insert ref / Duplicate / Rename / Delete.
VALUE — SIMULATE vs SAVE
Click the Value cell (or the label in Vars series mode) → direct editing.
Simulated value
  Applied immediately to the metrics and the preview (Min/Max follow the
  simulation). Shown with a trailing * (not saved).
Save
  Writes all simulated values into the theme JSON on disk.
  Enabled only if there is at least one * value.
  Confirmation dialog before writing.
Close without Save
  Cancels all simulated values (*) and returns to the JSON values.
  Clears the variables preview on the graph.

WINDOW

Wider default size to keep PLOT and ? visible.
Position and size remembered per query (like the Series / Table palettes).
Resize or move the window — the geometry is restored when this query is
reopened.
METRIC FIELDS (&x.y)
In the Composition, a variable is shown in its compact form &x.y
(x = theme no., y = variable no.), e.g. &1.4.
Hovering over the field → tooltip: theme, name, value, unit and
description, e.g. "&1.4 = energie.min_nucl = 35000 MW".
Right-click the field → opens this picker.
The &x.y numbers are specific to the workspace: the query stores the
by-name form (&theme.variable), portable from one workspace to another.

SORTING

Click a heading (IN, Ref, Theme, Variable, Value, Description): ascending
sort; click again: descending sort. No marker in the heading.
?
  This help (language set in the application Params).

DISPLAY ON THE GRAPH / STYLE

Show keeps its behaviour (selection in the query preview).
Display is distinct: when ticked, the variable is drawn directly on the
graph as a graphic marker, WITHOUT text (no name, value or unit). A numeric
value produces a horizontal reference line; a formula using series
produces a curve if its dependency series are available.
Display is OFF by default and changes neither series, metrics nor
WHERE. In Vars series mode, each row has three clickable swatches:
Legend (legend text), Display (graphic marker) and Style.
Style opens the style popup WITHOUT Position: colour (More...), depth
(↓ ↑), Type, Marker, Size, Alpha and Blink. Normal / Below / Above states:
Below and Above take the Normal values as long as they are not changed.
Close closes the popup. Styles and Display are saved in the theme JSON. See
also the "variables_catalog" help (Line, Fill, Bar, Point, Both types).
