Sort X — Help

Sort X sets the ORDER of the points (the rows of the query) along X, with up to
three priority keys. Opened from the Sort X button of the Series palette
(Table + X Axis row). The sort is saved with the query.
EACH ROW (Sort 1, Sort 2, Sort 3)
  Column   What to sort on: "<X> — X-axis value" (the plotted X, including a
           composed X metric) or one of the inputs of the active X metric.
           Empty = row not used. Sort 1 is applied first, then Sort 2 for ties,
           then Sort 3.
  Mode     How the value is read:
             Value               the value itself (date or number)
             Weekday             day of the week; order starts on
                                 Settings ▸ Globals ▸ Core ▸ Week 1st day
             Day of month (1–31) groups every 1st of the month, every 2nd, …
             Week-in-month       index of the week inside its month (1–5)
             Month               month of the year (Jan … Dec)
             Year                calendar year
           The modes offered are set in Settings ▸ Globals ▸ List values ▸
           Sort X (comma-separated keys raw, dow, dom, wom, month, year;
           separate lists for datetime and numeric X; old polar step tokens
           there are ignored).
  ASC/DESC Ascending or descending order.
           "<X> — X-axis value" in DESC with mode Value mirrors the X axis
           (large values on the left; the ticks stay linear).
HOW IT IS DRAWN
  Calendar modes (Weekday, Month, …) keep the Sort X order of the rows. For
  series rendered as Line or Both, the points are then drawn as markers only
  (no connecting line), otherwise the chart would fill with segments crossing
  back and forth in time. Series rendered as Point and polar charts are
  unchanged.
BUTTONS
  ?        This help.
  Clear    Removes the sort (back to the natural X order) and replots.
  Cancel   Closes without applying.
  Apply    Applies and replots; the window stays open to compare settings.
