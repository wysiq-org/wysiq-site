AI Setup / Bench — Help

The assistant finds the usable AI models — on this PC, on the other
computers of the network and in the cloud —, tests them with a real
question and creates the profiles. Choose one model, or several to compare
them side by side (bench).
It opens with the AI Command Center (untick "Open this assistant when
the AI Command Center opens" to avoid it), from the sidebar
(🧭 AI Setup / Bench), from Parameters ▸ AI (🧭 Assistant…) and from
⚡ Analyze graph when no profile is usable yet.
1 · WHERE ARE YOUR AIs?
  This PC
    Discover Ollama / LM Studio on this computer
                 Looks for Ollama (port 11434) and LM Studio (port 1234) on
                 this computer. The Ollama models folder ("Ollama data")
                 is recalled below.
    Start Ollama automatically if it is installed but not running
                 If nothing answers on port 11434, the assistant runs an
                 *ollama*.bat start script it finds (workspace, WysiQ
                 folder, home folder, Desktop, Documents) or
                 "ollama serve", then waits up to 30 s.
  Local network
    Other computers (e.g. a Mac running Ollama or LM Studio)
                 The other computers; type their IPs or names in
                 Hosts / IPs (e.g. MacBook-Pro.local), separated by
                 commas. They are remembered.
    Scan the whole subnet (≈ 10 s)
                 Queries every address of the subnet.
  Cloud APIs
    Providers with an API key
                 The providers whose key is already saved (or in an
                 environment variable), listed below.
    Add a key:   choose the provider (or let it be recognised from the
                 prefix: sk-ant- → Anthropic, sk-or- → OpenRouter, AIza →
                 Gemini, xai- → Grok), paste the key, then Add.
  Open this assistant when the AI Command Center opens
                 Opens the assistant every time the Command Center opens
                 as long as no model is connected.
  ?              This help.   Close   Closes the assistant.
  Search →       Starts the search and goes to screen 2.
  ↻ Last selection (n) — test →
                 Skips the search and retests the models of the last bench.
2 · CHOOSING THE MODELS
  Models are grouped by location (This PC, LAN <host>, Cloud —
  provider). Clicking a row (or Space) ticks it. Several ticked
  models = a bench. Columns Model, Size, Profile (the existing profile
  reused, or "new profile"). The last selection is ticked again
  automatically. None unticks everything; "n selected" counts the
  selection; ← Back returns to screen 1; Test selected → runs the tests.
3 · TEST & CONNECTION
  Each model receives a small real question, in parallel. ✔ = it
  answered (time shown), ✖ = failure, with a hint. Double-click a row
  for the full error.
  Fixed automatically (🔧): missing /v1 (Anthropic, OpenAI, Ollama…),
  OpenRouter's /api/v1, Gemini's /v1beta/openai, a URL ending in
  /chat/completions, "Bearer" or quotes pasted with the key.
  Connect       Saves and enables the profiles that answered, connects
                them (one tab each) and makes the first one the default
                profile.
  ⚡ Connect & analyze graph
                Same, then sends the Analyze graph question to each
                connected model: each answer arrives in its own tab.
                Later Sends go to the active tab only.
  Retry failed  Retests the failed models (a local model loading for the
                first time can be slow).
FREQUENT FAILURES
  Nothing answers on this PC   Ollama / LM Studio is not started.
  LAN computer unreachable     On that computer, Ollama must listen on the
                               network: OLLAMA_HOST=0.0.0.0 (Mac:
                               launchctl setenv OLLAMA_HOST 0.0.0.0, then
                               restart Ollama), and the firewall must
                               accept incoming connections.
  API key refused (401/403)    Copy the whole key again; check the
                               provider.
  Quota / credit (429)         Check the billing at the provider.
  Model not found (404)        This model name no longer exists for your
                               account — choose another one.
