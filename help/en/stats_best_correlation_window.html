Find Best Correlation — Help

This window searches, for two series, the lag that maximises the absolute
Pearson correlation. It also computes the associated linear regression
and can turn it into an editable residual Metric in WysiQ.

1) INTERFACE

Access: Best corr button of the Statistical Tests window, after ticking a
series A and a series B (otherwise: "Select Serie A and Serie B").
  Target        (read-only) Target y = series A; series B is source x.
  Scope         (read-only) Selection of the Statistical Tests window:
                Area restricts the computation to the area; All uses every point.
  Lag           Maximum shift (numeric field). The scan runs from -Lag to +Lag.
  Run           Starts the search.
  See residual  Loads the residual into __COMBO__ and opens the Metric Editor.
  Create Serie  Creates a named Metric in the Series palette and opens
                the Metric Editor so it can be checked or edited.
  Clear         Clears the results.
  Export        Saves the grid as .xlsx or .txt ("No result to
                export" if the grid is empty). Ctrl+C copies the selected
                rows to the clipboard.
  → AI          Sends the selected rows, or the whole grid when no row
                is selected, to AI Feed.
Summary (above the grid): Best lag, Pearson, Counter, Slope,
Intercept, Relation of the best result. Click a grid heading:
sort.
The row chosen in the grid supplies the lag, slope and intercept used by
See residual and Create Serie. With no selection, WysiQ uses the best
result.

2) READING THE RESULTS

  lag           Shift in number of points.
  corr          Pearson correlation r at this lag.
  counter_corr  Correlation obtained at the opposite lag.
  p             Pearson p-value (blank if SciPy is unavailable).
  spearman      Spearman rank correlation.
  kendall       Kendall's tau.
  slope         Slope of the regression target ~ shifted source.
  intercept     Constant of that regression.
  n             Number of valid pairs after alignment.
  relation      direct if r > 0, inverse if r < 0.
  lag = 0: series aligned with no shift.
  lag > 0: the source is shifted by lag points and precedes the target.
  lag < 0: shift in the opposite direction.
A lag is computed only if at least three finite pairs remain.

3) RESIDUAL METRIC CREATED

The fitted model is:
  estimated target = slope × shifted source + intercept
The created Metric represents what this model does not explain:
  residual = target - (slope × shifted source + intercept)
In the Metric Editor, WysiQ builds exactly two components:
  target: coeff = 1,        dx = 0,   offset = 0
  source: coeff = -slope,   dx = lag, offset = -intercept
The proposed name has the form:
  residual_target_vs_source_lag+N
It is made unique automatically if that name already exists.

4) SEE RESIDUAL OR CREATE SERIE?

See residual opens the special Metric __COMBO__ in the Metric Editor.
It is used to preview and adjust the computation before keeping it.
It may replace the previous content of __COMBO__.
Create Serie immediately adds a new Metric to the Series palette of the
current graph, then opens the Metric Editor. The Metric remains fully
editable: name, coefficients, dx, offsets, component activation, style
and the other parameters available in the editor.
It is part of the query configuration and can be reused like any other
Metric once the query is saved and reloaded.
Note: the button still carries the historical label "Create Serie",
but the object created is indeed a Metric (virtual combined series).

5) INTERPRETATION AND LIMITS

The residual Metric is used to study what is specific to the target:
anomaly, remaining trend, break, seasonality or event not explained by the
source. It can then be analysed in the graph, Area, Signals, the
statistical tests, PCA, or sent to the AI.
• Correlation does not mean causation.
• The lag is expressed in points, not automatically in seconds or days.
• A large lag reduces n and can give a fragile result.
• Check the sign of the lag, the slope, the graph and the business context.
• Scope=Area lets you study a particular regime or period.
• The coefficients are computed on the chosen range; changing them in
  the Metric Editor changes the Metric without rerunning the search.
