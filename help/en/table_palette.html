Table palette — Help

Access: Table button of the graph window or Ta circle of the Graph Remote.
The Table palette shows the query data in tabular form: an aggregates area
per series (nb, sum, avg, min, max, Δ) and a scrolling detail table. It
shows the series ticked T in the Series palette; with several tables, names
are prefixed by their table (Table.series).
Typical workflow:
  tick T in Series → set rows / Dec / UF → filter (WHERE of a series,
  Search of a column) → sort (Sort) → Export.

1) TOOLBAR

rows / total
  Number of rows shown in the detail table (Enter to apply). The total,
  after filters, is shown after "/".
Dec
  Number of decimals shown (Enter or leaving the field).
UF  (unit factor)
  Multiplies values before display (e.g. 0.001 to go from Wh to kWh).
Adj
  Ticked: UF is also applied to the aggregates of the top area.
Sort
  Sort popup with at most 3 levels (one row per level):
  - box right of the column: enables / disables the level without losing
    the chosen column (immediate effect);
  - ASC / DESC: clickable text, toggles the order;
  - Apply applies and leaves the popup open; Clear removes all sorts;
    Cancel closes.
SQL
  Shows the generated queries (DATA SELECT and AGGREGATES SELECT), with A− /
  A+ (or Ctrl+wheel), Copy, Close and the option "Include aggregates rows in
  exported file".
Export
  Opens the export window of the work table (CSV / XLSX / Parquet file, or
  new WysiQ table). See the "copy_table" help.
WHERE  (box)
  Enables / disables the global filter combining the WHERE of the series
  (see 3).
Row#  (box)
  Shows / hides the row-number column.
?
  This help.
Refresh
  Rereads only the Table data (e.g. new Live rows), without PLOT or change
  of the graph zoom.
2) AGGREGATES AREA (top)
One row per visible series: name | nb | sum | avg | min | max | Δ (max − min),
computed on the retained rows (zoom, WHERE, ⚠• alerts).
• Click a series name: WHERE editor of that series.
• Click a heading: sort on that column.

3) GLOBAL WHERE

When the WHERE box is ticked, the active WHERE conditions of the series are
combined and applied as a row filter to the detail table.
The WHERE of a series remains a restriction on the whole data set of that
series (graph included).
4) DETAIL TABLE (bottom)
• Frozen columns: Seq, Row and the active X column stay visible on the left
  while scrolling horizontally.
• Click a heading: ascending sort; click again: descending.
• Drag the heading separators to resize the columns (including in the
  frozen area).
• Right-click a column title or a cell: Search popup on that column (same
  editor as WHERE, but it only selects rows of this table). Several Search
  popups can be open at the same time, even on the same column (title
  "Search: column #2"…). A new right-click first reopens an existing search
  of the column, otherwise creates one.
  Apply only saves the search of its own popup and leaves it open; each
  applied search is added to the previous ones according to its "With other
  cols" (AND / OR). Clear only removes the search of its own popup.
• Ctrl+C copies the selected rows (tab separator).
• Wheel: vertical scrolling; Shift+wheel: horizontal.
• The separator between aggregates and detail is saved with the query.
5) WHERE / SEARCH EDITOR (popup)
  Where ON / Search ON   enables the condition.
  With other cols        NONE, AND or OR (combination with the others).
  c1, join, c2           conditions; + shows a 3rd condition (c3).
  Operators              =  !=  <  <=  >  >=  ~ (contains)  ^ (starts with)
                         $ (ends with)  in
  Value                  threshold, pattern or variable reference (&1.4); for
                         a date, a click opens the picker (OK / Cancel).
  Apply / Clear / Cancel apply, clear, close.
The filter applies to the raw values of the column, before the UF factor.
A metric is filtered here like a normal series; the WHERE of the Metric
Editor apply to the components of the metric.
Missing values: type NaN with = (missing values NaN / NULL / NaT) or
!= (present values, zero included). NaN is not equal to 0; no missing row
is invented.

⚠• ALERTS MODE

When the alert button of the Series palette is on ⚠•, the Table keeps only
the alert instants: the rows where a series of the same table is in alert
(all columns remain). Header statistics and Export apply to these rows.
Switching back to △ or ⚠ restores all rows.
TIPS
• Dec = 0 for integer data.
• UF = 0.001 to show kWh when the data are in Wh.
• Sort + Export quickly export a sorted subset.
• The Table does not refresh by itself on Live packets: use Refresh.
