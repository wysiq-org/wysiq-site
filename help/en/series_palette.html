SERIES PALETTE — Help

The Series palette drives the graph: tables and X axis, axis ranges,
visibility of each series (graph, table, Area), point styles, metrics
(computed series) and threshold alerts.
Search keywords: sort → Sort X · yr, right axis, twin → Yr · alert,
threshold, blink → ALERTS · style, marker, below, above → SERIES STYLE ·
multi-table, tab, propagate → TABLE TABS.

TOP BAR

  Scroll the series list with the mouse wheel or two-finger touchpad gesture
  over series rows and checkboxes.
SaveQuery  Save the query (series, Normal / Below / Above styles, metrics,
           tabs, palette settings).
Params     Open global settings (Globals ▸ Core).
≡ / ─      Full list (≡) or Mini (─): the compact list hides series whose
           In, G, T and A are all off (metrics stay visible).
Auto / Man Auto: the graph replots as soon as a row changes (In, G, T, A,
           *X, Yr). Man: those changes wait for PLOT (the Table still
           updates). X / Y Min-Max, ticks, X axis, styles and metrics always
           replot. Saved with the query.
△ ⚠ ⚠•     Threshold alerts of THIS graph (all its tables), click = next
           mode: △ off · ⚠ alert points shown · ⚠• alert points only, the
           others dimmed, and Area computes on the alerts. Display only (no
           replot, axes do not move). See ALERTS.
PLOT       Recompute and redraw the graph.

TABLE AND X AXIS

Table      Combo of the workspace tables. Choosing a table adds it as a tab
           (multi-table query); choosing it again while it is already a tab
           creates a 2nd instance (RTE2023_2, renamable), a view on the same
           table without copying data, with its own series, coeff and
           offsets. Remove a table: right-click its tab ▸ Remove table.
           Right-click (or Shift+click) « Table » or the combo: table menu
           (✓ = in the query; a click adds or removes).
rows: N    Row count of the active table.
X Axis     Horizontal axis: date / numeric column, or metric (virtual
           series). Right-click the combo: X metrics catalog. A tab can have
           its own date metric (e.g. JourHeure + 1096 days → 2026 dates):
           its rows are placed on those dates.
Sort X     Multi-key ordering of the points along X (X metric inputs +
           composed X value). Modes: Settings ▸ Globals ▸ List values ▸
           Sort X; week start: Globals ▸ Core.
?          Open this help.

VIEW CONTROLS

Empty fields = automatic scale. Enter or leaving the field = replot.
Click a Min / Max label: calendar (for X when the axis is a date; for
Y / Yr when the field holds a date).
X Min / Max      Visible X range.
Y Min / Max      Left Y axis range.
Yr Min / Max     Right Y axis range (series with Yr on).
Tick X / Tick Y  Ticks: « auto » or a number.
Tx / Ty          Minor X / Y grid: checkbox + number of subdivisions.
X0: ↔            Overlay: all tables start at the same X0 (calendar
                 overlay).
X0: ↔↔↔          Sequential: tables follow each other in tab order. The
                 active mode is green; offsets are recomputed on every tab
                 add, removal or move.
 TABLE TABS (multi-table query)
One tab per table; the main table is the 1st tab. The grid shows the
series of the active tab.
Green / grey dot  Table drawn or not in the current graph. Click the dot:
                  toggle without changing tab. Remembered per graph
                  (Graph 1, Graph 2…) and in the query. Table and Area are
                  not affected.
◀ ▶ / wheel       Scroll the tabs when wider than the palette.
Right-click (or Ctrl+click) a tab:
  Set as main           Make it the main table.
  Propagate UI          (main tab) copies In/G/T/A, Yr, coeff and style of
                        its series to the same-name series of the other
                        tables; metric copies follow too.
  Propagate metrics     copies its metrics into every other table
                        (« RTE2023.<metric> », ingredients repointed; a table
                        missing a used column is skipped).
  Propagate thresholds  copies its alert rules and Below / Above styles.
  Propagate All         all three at once.
  Shown in this graph   same as the green / grey dot.
  << Move left / >> Move right, Rename…, Remove table.

SERIES ROWS

Name         Color = series color (grey when G is off). Hover: full name.
             Click: Style window. Right-click: menu.
@            (metrics) @ live · ❄ frozen · ⚠ stale cache. Click:
             composition editor; right-click: freeze / unfreeze this
             metric; hover: ingredients.
In           Source for a new metric (does not plot by itself).
G            Draw in the graph (remembered per graph).
T            Show in the Table window.
A            Show in the Area palette.
*X           Coefficient (e.g. -1 to invert, 1.2 for +20 %).
Yr           Use the right Y axis.
Right-click menu on the name
  Set alert thresholds…  Variables catalog in threshold mode for this
                         series: select a variable, then Set Low, then
                         Set High.
  Duplicate              Virtual copy of the series (name asked).
  Rename…                Metric: rename; multi-table series: short alias
                         (legend, tooltip).
  Composition…           (metric) ingredients, WHERE, windowing.
  Delete                 (virtual series only).
 SERIES STYLE (click the name)
Several Style windows can be open (one per series); the new one opens on
top, slightly offset, and each moves independently. Changes apply live.
Point state  Normal  the series style;
             Below   points under the low threshold;
             Above   points over the high threshold (and inside mode).
Color        Palette or More… .
Depth (z)    Drawing depth (front / back).
Position     Normal: order of the series in the list. Below / Above:
             front / back offset of the alert points.
Type         Inherit, Line, Point, Both, Fill, Bar.
             Bar: vertical bars in line mode, filled sectors in polar.
             Move a window by dragging any free area or static label.
Marker       Inherit, Circle, Square, Tri ▲, Tri ▼, Diamond, X, Plus.
Size         Normal: line width or marker area. Below / Above: multiplier
             of the series size (1 = same).
Alpha        Opacity 0.05 – 1.
Blink        (Below / Above) only the alert points flash.
Below / Above defaults: Inherit, size 1, Blink on, orange (Below), red
(Above). The 3 states are saved with the query.

METRICS

A metric is a series computed from several columns, with optional WHERE and
X windowing; saved as JSON, reusable between queries, usable in Y or as the
X axis.
• Metrics and committed scenarios at the top of the list, columns below.
• Global filtering: Table palette (WHERE), like a real series.
• Freeze (❄): cache not recomputed; editing a source turns dependent frozen
  metrics ⚠ (Apply in the editor to refreeze).
 ALERTS (thresholds)
Workspace-global rules (workspace_alerts.json), identified by Table +
Series; Low / High = number, variable (&1.4) or formula variable using
[Series]. No data, SQL or metric is changed: only a graph overlay is added.
Set a threshold: right-click the name ▸ Set alert thresholds…, pick a
variable, Set Low then Set High (one threshold is enough); the graph
switches to ⚠. Manage all rules: Variables ▸ Thresholds.
Multi-table: the △ ⚠ ⚠• button acts on the whole graph, whatever the active
tab. A series without its own rule uses the rule of the same-name series of
another table (active tab, then main table), with its Below / Above style if
it has none. A table's own rule (Propagate thresholds, Thresholds window)
wins.
Evaluation: real values (coefficient included); markers drawn on the
displayed curve (Cum / Norm, Yr axis). Exact series identity (« Solaire » ≠
« SolaireThermique »). [Consommation] is the series of the SAME table as
the tested series, even when not plotted; [RTE2023.Consommation] is always
that table. Missing reference value = no alert at that X. Only plotted
series (G) are evaluated. Graph status bar: « Alerts …: N points
(series: n…) ».
Table in ⚠•: the Table keeps only the alert instants (rows where a series
of the same table is in alert, all columns); header stats and Export use
those rows. Changing the mode refreshes the Table.
Area in ⚠•: series in alert join the Area (even with A off) and count their
alert points only; the other A series are computed at the alert instants of
their table. Changing the mode refreshes Area. The Area rectangle may start
/ end on the axis scales: it is snapped to the edge (X0, Y0…).

MULTIPLE GRAPHS

G and Yr checks, Y Min / Max, Yr Min / Max and tab dots are remembered per
graph (Graph combo of the graph window): switching graph restores them,
editing them only affects the selected graph.
