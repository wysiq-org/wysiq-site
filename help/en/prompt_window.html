Prompt — WysiQ

Note (current version): the Prompt window was only opened from Expert
Studio, which is no longer accessible. The prompt is now typed directly in
the AI Command Center (prompt area, ▶ Send, Ctrl+Enter).
The Prompt window is the independent interface where you edit the question
sent to the AI. Expert Studio feeds it (Send to AI…, Generate Expert
Report), and the Send button delegates transport to the existing plumbing
(session, feed grounding, answer routing to HTML Viewer and Scenario
window).
USAGE
1. Open: from Expert Studio ("Prompt…" button) or automatically when
   Expert Studio opens.
2. Edit: type or modify the prompt text. Expert Studio can pre-fill
   the area via Send to AI… (scenario) or Generate Expert Report
   (full report).
3. Send: "▶ Send" button. The AI Profile window is opened / raised
   automatically to host the connection, the question is sent with
   the current feed (JSON AI Feed, Data AI Feed, or Area feed), and
   the answer comes back to the HTML Viewer.

BUTTONS

Clear     Empty the prompt area.
AI Request…  Opens the AI Request catalogue (saved AI requests).
AI Feed…  Opens the AI Feed Stack.
Attach…   Attaches files to the prompt; 📌 attaches them for the whole
          session. Attachment list: left-click toggles on / off, right-click
          removes.
🎤 Mic    Opens the voice recorder.
▶ Play    Sends the next group of the plan prepared in the AI Feed Stack (one
          Send # group per click); greyed out without a plan.
Refresh   Updates the "AI Feed: N feeds" summary.
▶ Send    Send the prompt to the AI via the AI Profile / Session
          plumbing. All checks (profile selected, session active, feed
          grounding) apply as they did in the former AI Analyst.
?         Show this help.

ANSWER ROUTING

Answers do NOT appear in this window:
  - HTML Viewer: contains the formatted answers (chapters if the
    "Chapter HTML answers" toggle is active in Expert Studio).
  - Scenario window: if the answer is a structured scenario
    (kind=wysiq_scenario_response), points are injected there.

AI CONNECTION

This window does not manage AI profiles — use the "AI Profiles" button
in Expert Studio to create, connect or switch profiles. It also does
not manage sessions — use the "AI Session" button.

WINDOW BEHAVIOUR

Treated like the other WysiQ floating palettes (Expert Studio, Series,
Table): stays above the graph permanently (persistent -topmost attribute
on Windows) and re-raises on activation or focus.
