AI SETTINGS — Requests · Knowledge · Sessions · Profile

Access: Parameters ▸ AI ▸ Help (this help opens when the tab is chosen),
Main ▸ AI ▸ Help.
LAYOUT OF THE AI TAB (Parameters)
  Profile       AI profiles (see the "params_ai" help).
  Observatory   selecting this tab directly opens the AI Observatory
                settings window ("activity_tracking" help).
  AI Folder     selecting this tab opens the AI folder of the workspace in
                the file explorer.
  Help          opens this help.
REQUESTS (PREDEFINED QUESTIONS)
Library of reusable questions to insert into the AI prompt. It opens from
the AI Command Center (📋 Request or PANELS ▸ 📋 Requests Catalog):
"AI Requests" window.
The files are stored in: WysiQ/AI/Feed/<language>/<question_name>/question.txt
Inserting a question into the prompt
    Double-click, Enter or Ctrl+D on a question → inserts the full text
    into the Command Center prompt.
    Ctrl+C on the text on the right → inserts the selected text (or the
    whole body if nothing is selected).
Creating a question
    Add a folder WysiQ/AI/Feed/<language>/<question_id>/ containing a
    question.txt file (the folder id is used as the label, spaces =
    underscores), or duplicate an existing question (right-click ▸
    Duplicate) then edit it.
Language
    Selects the language of the question folder to show.
    Questions from a second folder (English) are added as a complement if
    the chosen language does not cover every folder.
Searching Questions
    The Search field filters the question list on the left AND highlights
    the occurrences in the text on the right.
    The << and >> buttons move between occurrences in the text.
    The current occurrence is highlighted in orange, the others in yellow.
Right-click a question
    Edit — opens the full editor (id renaming + text editing).
    Duplicate — copies the question into a new folder.
    Rename — renames the folder without opening the text editor.
    Delete — permanently deletes the question folder.
KNOWLEDGE
Knowledge files are JSON files sent to the AI at each connection (Connect
button of AI Connections). Window: Main ▸ AI ▸ Knowledge… or
Command Center ▸ 📖 Knowledge Setup. They give the AI the permanent context
of your domain: business definitions, interpretation rules, nomenclatures,
conventions, industry ontologies.
A single folder: WysiQ/AI/protocol/
    The WysiQ technical schemas (Protocol v0.2) and your Knowledge files
    live in the same folder. Every JSON file of the folder is listed in the
    Knowledge screen with its own Send state.
    The default WysiQ files (000_protocol_handshake…, 001_ai_response…
    etc.) are present from installation. You can freely add your own
    business-context JSON files.
Send column  ☑ / ☐
    Clicking the box toggles the state of the file: ☑ = sent on connection,
    ☐ = ignored. The state of each file is remembered between sessions in
    WysiQ/AI/protocol_send_selection.json.
    Only ticked files are included in the WysiQ Protocol v0.2 handshake
    sent at the start of each AI session.
What the AI does with Knowledge
    On Connect, WysiQ sends all ☑ files as system context.
    The AI then recognises your product codes, units, business thresholds,
    series names or any interpretation rule specific to your domain,
    without you having to repeat it with every question.
Language of Knowledge files
    Knowledge files have no predefined language: write them in the working
    language of your domain. The default WysiQ schemas are in English.
Creating a Knowledge file
    Add a JSON file to WysiQ/AI/protocol/ (Open protocol folder button of
    the AI Knowledge window), or duplicate an existing file (right-click ▸
    Duplicate) then edit it. The JSON is checked on save — an invalid JSON
    is rejected.
Preview
    The JSON box of the AI Knowledge window shows the preview of the
    selected file.
Right-click a file
    Edit — opens the built-in JSON editor with checking on save.
    Duplicate — copies the file under a new name.
    Rename — renames the file (the Send state follows the renaming).
    Delete — permanently deletes the file.
SESSIONS AND AI CASES
AI exchanges are archived per WysiQ query. Current exchanges are AI Cases
(qai/cases): questions asked, answers received, tokens consumed and HTML
reports. They are viewed in the AI Case Center (Main ▸ AI ▸ AI Cases…)
and the HTML Nav (Main ▸ AI ▸ Answers…).
Historical sessions (previous versions) remain stored in
WysiQ/AI/sessions/<query_name>/; the former Sessions screen is no longer
opened by any menu ("ai_session_window" help).
PROFILE
A Profile is a configured instance of an AI provider: model, URL, API key,
temperature and timeout. Several profiles can coexist; the Default
connection box marks the profile preselected by the AI Setup / Bench
assistant.
For the detailed help on the profile fields, open the Profile tab then
click the ? button of that tab.
