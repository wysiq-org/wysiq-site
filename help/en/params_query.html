QUERY - GRAPH AXES AND TABLE LAYOUT

Settings > Query shows the current graph's axes and table layout together
on ONE page. Without an active graph, the axes fields use WysiQ defaults.
AXES / Y AXIS
  Unit text      Y axis unit label (MW, EUR, etc.).
  Scale (x)      Y unit conversion multiplier; 1 = unchanged.
  Decimal        Display decimal places.
  Period factor  Factor used by period-dependent calculations.
  X min / X max    Visible X axis bounds, not a per-table selection.
                 Empty = automatic.
  Y min / Y max    Visible Y axis bounds. Empty = automatic.
  X/Y ticks      Major tick count; auto lets WysiQ choose.
  x/y minor      Minor grid subdivisions (0 = none).
Click X min or X max labels to open the date picker. Press Enter or
leave an axes field to commit a change.
X AXIS - BOUNDS BY TABLE
  X min / X max  Date/time selection per TABLE INSTANCE of the query.
  Rows           Selected source count before resampling.
  Start / End    First and last composite X positions after processing.
  The same source can be added twice (such as spot2225_2); changing
  either instance's date bounds does NOT modify the physical source.
MULTI-TABLE - TABLE OFFSETS
  X offset       Offset measured in ROWS; 0 = overlay with the main table.
                 Auto (calendar) suggests an offset from reference dates.
  Y offset       Additive Y adjustment.
  Coeff          Y multiplier.
  Mode           As is, Shrink, Shrink AVG/SUM/MIN/MAX or Expand.
  Target rows    Requested final row count.
  Every N        Keep every Nth row; takes priority over Mode.
  Exec           Apply and replot.
  Reset          Sequential / Overlay or selective reset.
Click the ? beside table offsets to open the detailed table_layout help
for presets, modes, an RTE/SPOT example, and the limitations of row offsets.
Use SaveQuery to retain query-specific settings.
FIX27 - VISIBILITY AND ROW COUNTS
  Settings reopens on the last used tab (during this session).
  Hiding a graph table does not remove it from Query settings: its
  date bounds, offsets and sampling parameters remain editable.
  Rows = selected source rows / original rows BEFORE time Adjust.
  Start and End are inclusive ZERO-BASED indices: 0..70127 means
  70128 composite positions, not 70127 rows.
  Nb in Table/Metric counts non-NaN values available after alignment.
  Every = 2 keeps every second row; Every = 30mn performs time Adjust
  with the selected Shrink and Expand methods.
  Two instances of one source need not show the same prices at a given
  graph X if one is As is (row alignment) and the other is Adjust 30mn.
