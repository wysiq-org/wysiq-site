SHARE & PUBLISH CENTER

TERMINOLOGY
WysiQuery   The live whole: source table + analysis (series, metrics,
            filters) + graph window.
Query       Saved WysiQuery snapshot (query.json in queries/).
Queries     Plural — several Query files.
WysiQ prepares share packages from an open WysiQuery (graph HTML
snapshot) or from an exported Query (ZIP bundle) — interactive HTML
(matplotlib PNG with zoom/pan in the browser; Plotly in local WiFi
preview), optional voice brief, short analysis text — then publishes
automatically where possible and prepares drafts for social networks.
Query ZIP exports follow the same pipeline
(gallery, feeds, LinkedIn draft, Telegram channel).
📦 Prep button in the graph remote palette:
  Left-click    = Prep popup (recorder + outbox)
  Right-click   = quickly toggle contacts On/Off
Main window → Share → Share Center, Send tab:
  list the prepared files, choose the recipients, Send.
  Automatic channels (Publish tab) run on Send, not on Prep.

SEND TAB (OUTBOX)

Files prepared in:
  workspace/share/outbox/graphs/    HTML, PNG, PDF, voice WAV
  workspace/share/outbox/queries/   Query ZIP bundles
Sources: Remote 📦 Prep, Print export, Query → Share…
Manual WhatsApp: attach the files from share/outbox/graphs/ or …/queries/

PUBLISH TAB

AUTOMATIC CHANNELS

  Telegram      broadcast to a channel + direct send to contacts
  Discord       post via webhook — file + link + caption if enabled
  Site gallery  copies HTML/ZIP to the local/public gallery folder
  RSS           updates wysiq_feed.xml
  JSON feed     updates wysiq_feed.json for a site / API
  Tick the channels you want, then click
  "Save publish options".
  TG channel ID   identifier of the broadcast channel or group
  TG bot id       optional — replaces the bot from bots.json
  Discord webhook   webhook URL (Discord server settings)
                    sends HTML/ZIP attachment + caption + link

SEMI-AUTOMATIC SOCIAL NETWORKS

  LinkedIn      copies the post text + opens LinkedIn in the browser
  Reddit        prepares title / body; the user submits manually
  X / Twitter   opens the tweet intent with text and link
  These channels open a browser tab with the pre-filled draft.
  You complete and publish it yourself.

DEFAULT MESSAGE IDENTITY

  Site base URL    base address linked in all posts
                   e.g. https://wysiq.org
  Default tags     hashtags added to social drafts
                   e.g. #WysiQ #DataVisualization #Analytics
  Signature        footer in generated posts
                   e.g. Made with WysiQ

GALLERY / FEEDS TAB

SITE GALLERY

  Local folder     destination folder for HTML / ZIP files
                   empty → workspace/share/outbox/graphs
                   Query → gallery/queries/ subfolder
  Public base URL  public address where the files are reachable
                   e.g. https://wysiq.org/visualizations

RSS / JSON FEEDS

  RSS title        channel title in the feed XML
  RSS description  short description of the channel
  JSON filename    name of the output JSON file
                   default: wysiq_feed.json

GENERATED FILES

  Text area listing all the files present in the publish folder.
  Click "Refresh list" to update it.
Buttons:
  Save gallery/feed options   saves the settings
  Refresh list                re-reads the publish folder
  Open publish folder         opens the folder in the file explorer

SOCIAL DRAFTS TAB

Test the draft templates before publishing.
  Title     title of the graph or analysis
  URL       public link to the graph's HTML file
  Insight   optional short observation about the data

PREVIEW / OPEN

  Preview LinkedIn / Preview Reddit / Preview X
               choose an entry — the draft is displayed
  Open LinkedIn / Open Reddit / Open X
               choose an entry — opens the network with the preview text
  Copy text          copies the preview to the clipboard
  Create draft files saves one .txt file per network
                     in workspace/share/drafts/

DISCORD — SET UP AND TEST

Discord is fully automatic (like the Telegram channel broadcast):
each Send (Share Center) or 📤 Share… posts directly to your Discord
channel via a webhook. No browser tab to complete — the message appears
at once.
Unlike LinkedIn, Discord receives the .html or .zip file as an
attachment. You do NOT need a public website or hosting for members to
open the graph — they download it from Discord.
WHAT WysiQ SENDS TO DISCORD
  • Caption text     short message from the generic publish template
                     (title, URL, default tags)
  • Attachment       graph .html or Query .zip
  • Voice memo       WysiQ_{title}_voice.wav if recorded in 📦 Prep
  • Embed            card with the graph title + clickable link (if a URL
                     is defined)
Configuration stored in:  workspace/share/publish.json

STEP 1 — CREATE A WEBHOOK IN DISCORD

  1. Open Discord (app or browser) → your server
     (create a free server if needed: "+" → Create My Own).
  2. Create or choose a text channel, e.g.  #wysiq-graphs
  3. Channel settings (⚙ next to the channel name)
     → Integrations → Webhooks → New Webhook
  4. Name it "WysiQ" (or anything), confirm the target channel.
  5. Click "Copy Webhook URL"
     Format: https://discord.com/api/webhooks/123456789/AbCdEf…
  Keep this URL secret — anyone who has it can post to your channel.
STEP 2 — CONFIGURE WysiQ
  1. Open Share Center… (Share menu).
  2. Publish tab → Automatic channels → tick Discord.
  3. Paste the URL in "Discord webhook".
  4. Click "Save publish options".
  Discord is disabled by default (unlike LinkedIn). Tick it once.
STEP 3 — TEST WITH A GRAPH (same path as Telegram)
  1. Open a graph with data.
  2. Graph Remote ▸ 📦 Prep, then Share Center ▸ Send tab.
  3. Optionally record a voice comment → Send.
  After the Email/Telegram send to contacts, the publish pipeline also
  posts to Discord if enabled. Check your Discord channel:
  you should see the caption, the attached .html file,
  WysiQ_{title}_voice.wav (if recorded) and an embed.
  For a Query: Query > Export query → 📤 Share… → Send.
  Discord receives the .zip bundle in the same way.
TELEGRAM CHANNEL vs DISCORD WEBHOOK
  Telegram channel    BotFather bot + TG channel ID + bot token
  Discord webhook     only the webhook URL — no bot per recipient
  Both attach the file directly. Both send the voice memo on Send.
  Both work without wysiq.org hosting.

WITHOUT ACTIVE HOSTING (DOMAIN ONLY)

  Discord works immediately: the interactive .html is uploaded to
  Discord as a file. Members click the attachment → it opens in the
  browser.
  The link in the embed may point to a local or WiFi URL if no public
  URL is configured — the attachment stays usable; only the embed link
  is less convenient until Gallery or HTTP Server is configured.

TROUBLESHOOTING

  Nothing in Discord     → Discord unticked, empty webhook URL, or
                           "Save publish options" not clicked.
  Invalid webhook        → recreate the webhook in Discord and paste
                           the new URL (must start with https://).
  Deleted webhook        → Discord returns an error; WysiQ ignores it
                           silently — check the channel and update
                           publish.json.
  File too large         → Discord limit ~25 MB; WysiQ graph HTML ~150 KB.
  No voice on Discord    → record before Send in the 📦 Prep window; same
                           as Telegram.

LINKEDIN — HOW TO TEST (WITH OR WITHOUT AN ACTIVE SITE)

LinkedIn is semi-automatic: WysiQ prepares the post text and opens
LinkedIn in your browser. You paste the text and publish it yourself.
PREREQUISITES (2 minutes)
  1. Open Share Center… (Share menu).
  2. Publish tab → tick LinkedIn (Semi-automatic social networks).
  3. Click "Save publish options".
  LinkedIn is enabled by default. Telegram and LinkedIn can both stay
  ticked.
TEST 1 — WITHOUT SENDING A GRAPH (fastest)
  Social drafts tab of the Share Center:
    1. Edit Title and URL if needed (put a real https://… URL when you
       have one).
    2. Preview LinkedIn combo → the draft text is shown at the bottom.
    3. Copy text → paste elsewhere (Ctrl+V) to check the clipboard.
    4. Open LinkedIn combo → the browser opens the LinkedIn share dialog.
  This validates template + clipboard + browser opening — without
  sending a graph.
TEST 2 — SAME AS TELEGRAM (via 📦 Prep on a graph)
  1. Open a graph with data.
  2. Graph Remote ▸ 📦 Prep, then Share Center ▸ Send tab.
  3. Optionally record a voice comment → Send.
  What happens automatically:
    • The LinkedIn post text is copied to the clipboard.
    • LinkedIn opens in the browser (share-offsite with the URL).
    • A .txt draft file is also saved in
      workspace/share/drafts/  (…_linkedin_….txt).
  In LinkedIn: paste the text (Ctrl+V), check the link, then publish
  yourself.

IMPORTANT — THE URL IN THE POST

  LinkedIn can only preview links reachable from the public Internet
  (the LinkedIn servers fetch the page).
    URL source                           LinkedIn link preview
    http://192.168.x.x:47430 (WiFi)      ✗  local only — no preview
    Local path (C:\… or workspace/…)     ✗  not a web link
    Public base URL (Gallery tab)        ✓  if the files are on a web server
    HTTP Server upload (Setup tab)       ✓  if the upload succeeds
    Site base URL (Publish tab)          ✓  only if this address really
                                            serves the files

NO ACTIVE HOSTING (DOMAIN ONLY)

  You may own wysiq.org, wysiq.fr, wysiq.eu, etc. without a website
  online yet. That is normal during setup.
  What works without hosting:
    • Telegram (.html file direct to contacts or channel)
    • Email with a .html attachment
    • Manual WhatsApp via workspace/share/outbox/graphs/ or …/queries/
    • LinkedIn text copied + browser opened (Social drafts or Send)
    • .txt draft files in workspace/share/drafts/
  What does not work until the files are served on the web:
    • Clickable public link in a LinkedIn post (preview card)
    • RSS/JSON feeds pointing to real public pages
    • Gallery Public base URL (e.g. https://wysiq.org/visualizations)
  When you add hosting later:
    • Gallery / Feeds → Local folder + Public base URL on your server
    • or Setup → HTTP Server → Public URL + Upload path
    • wysiq.org cloud hosting — coming soon
  Meanwhile: use Telegram or Email for the interactive .html;
  use LinkedIn for the prepared text — paste it manually, or mention
  the file shared through another channel.

TROUBLESHOOTING

  Nothing opens         → LinkedIn unticked or "Save publish options" not
                          clicked.
  Empty clipboard       → try again; Windows may block the clipboard from
                          a thread.
  LinkedIn opens but    → configure a public URL (Gallery or HTTP Server)
  the link is useless     when hosting is available; the local WiFi URL is
                          not enough.

SETUP TAB — CONTACTS

Stored in:  workspace/share/contacts.json
Add contacts manually (Add / Edit frame: Add adds, Update modifies the
selected contact, Delete removes it) or import them from a spreadsheet
(📂 Import xlsx/csv). "Click On/✉/✈ to toggle" reminds you that the
columns toggle on click. Each contact has:
  Name    — display name
  Email   — for Email/SMTP sending
  Phone   — reference for Telegram

LIST COLUMNS

  On    = contact globally enabled
          Click to enable/disable.
  ✉ on  = email channel enabled
          Click to enable/disable.
  ✈ on  = Telegram channel enabled
          Click to enable/disable.
  📱 on  = phone reference (manual WhatsApp sharing)
          WysiQ copies the files into workspace/exchange/
          — no automatic WhatsApp sending (paid API).
  TG    = ✓ if the Telegram Chat ID is registered
          (see Telegram section — Step 3)

IMPORT FROM A SPREADSHEET

  Click "📂 Import xlsx/csv" to load an Excel or CSV file.
  A window ("Map columns to contact fields:") lets you map your
  columns, then Import:
    Name column   → contact display name (required)
    Email column  → used for SMTP sending
    Phone column  → phone reference
  Existing contacts are not overwritten.
  New names are added to contacts.json.

SETUP TAB — EMAIL / SMTP

Stored in:  workspace/share/sender.json
WysiQ sends the graph as a .html attachment over SMTP.
If a voice comment was recorded, it is attached
as WysiQ_{graph title}_voice.wav in the same email.

FIELDS

  Sender name     shown in the From field of the email
  SMTP server     e.g. smtp.gmail.com
  Port            587 for STARTTLS  /  465 for SSL
  Username        your email address
  Password        see the Gmail note below
  STARTTLS (port 587)  recommended for port 587
  Test & Save     saves the settings, then tests the SMTP connection and
                  authentication ("Connection successful!").
  Reminder shown: "Gmail: enable App password in your Google account".
GMAIL
  Gmail requires an App Password —
  not your usual Google password.
  Go to:  myaccount.google.com
          → Security
          → 2-Step Verification
          → App passwords
          → Create "WysiQ"
  Use the 16-character code (no spaces).
HTML MODE ("HTML mode:")
  Standalone (~3.5MB, offline)
                ~3.5 MB   works offline
                          Plotly.js embedded (WiFi / legacy paths)
  Lightweight (~500KB, needs internet)
                ~500 KB   requires an internet connection
                          Plotly.js loaded from a CDN
  Note: graph sending by Email and Telegram currently uses a
  standalone matplotlib PNG HTML (~150 KB) with touch zoom/pan —
  independent of the Plotly mode above.

SETUP TAB — TELEGRAM

WysiQ sends the graph's .html file directly
via a free Telegram Bot. Zero cost. No third-party
service.
If a voice comment was recorded, it is sent
as a separate audio message after the graph.

STEP 1 — CREATE YOUR BOT

  Open Telegram → search for @BotFather → send /newbot
  Give it a name, e.g.:  WysiQ Analytics
  Give it a username ending with 'bot',
    e.g.:  wysiq_mycompany_bot
  👍 Help WysiQ grow — include 'wysiq' in the name.
  BotFather gives you a token:  123456:ABCdef...

STEP 2 — PASTE THE TOKEN AND VERIFY

  Paste the token → click Verify & Save.
  WysiQ calls getMe to confirm that it is valid.
  The token is saved in workspace/share/sender.json.

STEP 3 — REGISTER THE RECIPIENTS

  Each recipient must open your bot in Telegram
  and send /start (once only).
  Then click "Scan new contacts" in WysiQ.
  WysiQ reads the incoming messages and registers each
  Chat ID automatically in contacts.json.

STEP 4 — TEST MESSAGE

  Sends a confirmation message to all registered Telegram
  contacts to check that everything works.
ON SEND (Send)
  WysiQ calls sendDocument to deliver the .html file
  directly in the recipient's Telegram chat.
  The recipient taps the file → it opens in
  their mobile browser → zoom and pan available.

SETUP TAB — HTTP SERVER

For teams that have an internal web server
or a NAS.
WysiQ uploads the graph HTML to your server
and generates a short clickable link sent to the recipients.

FIELDS

  Public URL     URL visible to the recipients
                 e.g. https://wysiq.mycompany.com
  Upload path    destination folder on the server side
                 e.g. /var/www/wysiq/graphs
                 or the remote SFTP path
  Username       server login (if required)
  Password       server password (if required)
METHODS ("Method:")
  SFTP          SSH transfer — most secure
  FTP           classic FTP
  HTTP PUT      REST upload endpoint
  Local folder  shared network drive
Buttons: Save saves the "Server configuration"; Test URL checks that
the public URL responds.
wysiq.org cloud hosting — coming soon ("wysiq.org cloud sharing
(coming soon)").
When Public URL and Upload path are configured here, each Send (Share
Center) or 📤 Share… also uploads the graph HTML or the Query ZIP to
your server (local folder, HTTP PUT, FTP, or SFTP if paramiko is
installed). The public link is used in feeds, Discord, Telegram channel
and social drafts when the upload succeeds.
 SENDING A GRAPH (📦 Prep then Send)
There is no longer a 📱 button in the remote palette: sharing a graph
takes two steps.
  1. Graph Remote ▸ 📦 (left-click): optional voice recorder
     (● Rec, ■ Stop, ▶ Play, Erase), then 📦 Prep stores the HTML (+ WAV)
     in share/outbox/graphs/. Cancel closes without writing anything.
  2. Share Center ▸ Send tab: choose the file, the channel (Email, TG,
     Both), the recipients, then Send:
       Email contacts    → graph .html + voice .wav as attachments
       Telegram contacts → graph .html via bot, voice .wav as audio message
  Right-click on 📦: "📱 Contacts On/Off" window (columns On, Name,
  ✉on, 📱on, ✈on) to quickly enable / disable contacts and channels.

WHATSAPP SHARING (MANUAL)

  Graphs (.html) are copied to   workspace/share/outbox/graphs/
  Queries (.zip) are copied to   workspace/exchange/queries/
  Share these files yourself from WhatsApp on your phone
  or computer — no automatic WhatsApp sending.
On each Send from the Share Center or 📤 Share…, WysiQ also runs the
Publish pipeline if enabled: exchange copy, HTTP server upload (if
configured), gallery, JSON/RSS feeds, Telegram channel broadcast,
Discord webhook, LinkedIn draft (text copied + browser opened).
 QUERY SHARING (📤 after Export query)
After Query > Export query, the result popup offers 📤 Share…
  Channel     Email / Telegram / Both (default from Setup)
  Bot         optional Telegram bot selector (bots.json)
  Recipients  checkbox list — only the ticked contacts receive
              the Query ZIP bundle
On send, the same publish effects as for graphs:
  exchange/queries/   manual WhatsApp / file sharing
  gallery/queries/    if Site gallery is enabled
  JSON / RSS feeds    if enabled in the Publish tab
  Discord webhook     if Discord is enabled + webhook URL filled in
  LinkedIn            draft text copied + share dialog
  Telegram channel    if TG channel ID is configured
Import on the recipient's side: Query > Import query.
Note: a Query ZIP contains the saved WysiQuery definition
(table, analysis, graph settings, optional PNG/PPTX, voice memo) —
not only an HTML snapshot of the graph.
The ZIP is sent as is (Email, Telegram, Discord webhook, gallery)
so that technical profiles can import it via Query > Import query,
change the WHEREs, filters and metrics, and rebuild or adapt the graph.
Optional voice memo in the bundle:
  WysiQ_{query name}_voice.wav
  (older bundles may still contain voice_note.wav)

SETUP TAB — SEND LOG

Stored in:  workspace/share/send_log.json
Each Email or Telegram send (graph or Query) is logged.
  Refresh     re-read the log from disk
  Purge       delete all entries (confirmation asked)
  Export CSV  save the log as a spreadsheet file
Columns: date/time, graph or Query title, channel, contact,
address, status (OK / ERR), error message if any.

SEND RESULT

After Send, a small result window shows an icon (success or error)
and the message (number of successful sends, errors per contact and
channel, e.g. "no chat_id", "SMTP error"); OK closes it. The detail of
each send is kept in the 📋 Log tab.
