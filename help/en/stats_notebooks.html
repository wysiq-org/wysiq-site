Test Notebooks — Help

Notebooks are standalone statistical tests, written in plain Python
in the program's stats/notebooks/ folder. Every file is readable and auditable:
formula, dependencies, minimum conditions and result notes are
directly in the code — no black box.
Access: Params button of the Statistical Tests window, or Settings ▸
Parameters… ▸ Statistics tab.
The Statistics tab offers: the "Statistics execution parameters" frame
(default p-adjust: BH, Holm, Bonf, none), the list of notebooks, the
"Per-test parameters" frame (parameters of the selected notebook, drop-down
lists) and the ? button (this help).

1) CONCEPT

  A notebook is a Python module with two elements:
    META  dict describing the test (key, title, description).
    run(context)  function receiving data and returning
                  {test, stat, p, effect, note}.
  Notebooks are integrated into the test engine: they
  appear in the result grid exactly like built-in tests,
  with the same columns.
  context received by run():
    "A"      list of values (selected series A)
    "B"      list of values (selected series B)
    "params" dict of parameters configured in Params

2) AVAILABLE NOTEBOOKS

── Pearson
  Linear correlation between two aligned series.
  File   : notebooks/pearson.py
  Input  : A and B (at least 3 common finite points).
  Output : r (stat), p-value (SciPy or blank), r (effect).
  Needs  : NumPy. SciPy for the p-value.
── ADF (Augmented Dickey-Fuller)
  Stationarity / unit-root test on series A.
  File   : notebooks/adf.py
  Input  : A (at least 8 finite points).
  Output : t-stat, p-value, note "lag=X method=...".
  Needs  : statsmodels (main method).
           NumPy fallback if statsmodels is absent
           (manual regression on first differences).
  Params : Autolag (AIC/BIC/t-stat/none),
           Regression (c/ct/ctt/n),
           Max lag.
  Read   : low p → reject unit root → series likely
           stationary.
── Granger causality
  Tests whether past values of B improve prediction
  of A (Granger sense of causality).
  File   : notebooks/granger.py
  Input  : A and B (at least 12 common finite points).
  Output : F-stat, p-value, note "best lag=X method=...".
  Needs  : statsmodels (required — no full fallback).
  Params : Max lag (default 5, max 8).
  Note   : "Granger causality" is predictive, not causal
           in the strict sense. Result is sensitive to
           the chosen lag.
── Change point
  Detects a mean-shift in series A by scanning all
  possible split positions.
  File   : notebooks/change_point.py
  Input  : A (at least 18 finite points).
  Output : t-stat at best split, Cohen d (effect),
           note "idx=X mean_before=... after=...".
  Needs  : NumPy only.
  Params : Min size (minimum segment length, default 8).
  No p-value is computed.
── Mutual information
  Non-linear dependence measure between A and B.
  File   : notebooks/mutual_info.py
  Input  : A and B (at least 8 common finite points).
  Output : raw MI (stat), normalised MI (effect),
           note "normalized=X method=...".
  Needs  : scikit-learn for the main method.
           2D histogram fallback if sklearn is absent.
  Params : Bins (default auto = sqrt(n), max 24).
  0 = total independence. No p-value.
3) FINE-TUNING PARAMETERS (Params)
  The Statistics tab of Parameters (Params button of
  Statistical Tests) lets you configure each test's parameters:
  ADF          Autolag, Regression, Max lag
  KPSS         Regression, N lags
  Granger      Max lag
  Change point Min size
  Mutual info  Bins
  ACF          Max lag
  Rolling corr Rolling window
  Chi2         Bins
  Shapiro      Warn above N (sampling threshold)
  Mann-Kendall Alpha
  Parameters are persisted in the workspace and apply
  to all subsequent runs.

4) TRANSPARENCY AND AUDIT

  Each notebook file is self-contained and short
  (under 60 lines as a rule). It is designed to be read
  and verified without any special tooling.
  To audit a test:
  1. Open stats/notebooks/<name>.py (program folder)
  2. Read the run(context) function line by line
  3. Check META for the test metadata
  4. Compare with the reference documentation
     (SciPy, statsmodels, sklearn as applicable)
  When a dependency is absent:
  - Granger and ADF (statsmodels): result absent or
    NumPy fallback with note "method=fallback".
  - Mutual info (sklearn): 2D histogram fallback
    with note "method=hist2d".
  - In all cases, the note field identifies the method
    actually used.

5) REQUIRED DEPENDENCIES

  NumPy        Required for all notebooks.
  SciPy        Pearson p-values, some fallbacks.
  statsmodels  ADF (main method), Granger (required).
  scikit-learn Mutual info (main method).
  Without statsmodels: Granger produces no result.
  Without scikit-learn: Mutual info falls back to hist2d.
