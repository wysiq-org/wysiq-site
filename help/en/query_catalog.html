Query Catalog

Access: Main ▸ Query ▸ Catalog.
The Query Catalog lists every Query saved in the current workspace. It
lets you browse, filter, open, rename and delete Queries without going
through the tree of the main window.
Text zoom: Ctrl + mouse wheel.

TOOLBAR

Refresh
  Reloads the list from disk. Use it if Queries were saved or deleted
  while the catalog was open.
Open
  Opens the selected Query in a Graph window. Same as double-clicking the
  row (outside the Sel column) or pressing Enter.
→ AI
  Sends the definition of the selected Query (JSON structure, without
  data) to the AI Feed Stack.
Rename
  Opens a dialog to rename the Query (shortcut F2). The JSON file is
  renamed and its internal query_name field updated.
Delete
  Permanently deletes the selected Query (shortcut Del key).
  A confirmation dialog is shown before any action.
JSON
  Opens the raw JSON of the selected Query in a read-only text viewer.
  Useful to inspect the full definition without opening a Graph window.
  Supports Ctrl + wheel (zoom) and horizontal scrolling.
  Search (bottom left): type a word, << / >> (or Enter / Shift+Enter)
  for the previous / next occurrence, n/N counter. Ctrl+F: search
  field, Escape: clear.
?
  Opens this help window.

LEFT PANEL: FILTERS AND QUERY LIST

Catalog filters
  Query like
    Filters the list on a substring of the Query name.
  Table like
    Filters the list to queries referencing a table whose name contains
    the typed text.
  Both filters can be combined.
Queries list
  Sel column
    ✓       = the Query is visible in the tree of the main window.
    (empty) = the Query is hidden from the main window.
    Click a row of the Sel column to toggle visibility.
    Click the Sel heading to enable all / hide all at once
    (enable all if at least one query is hidden, otherwise hide all).
    The setting is saved to params.json immediately. The tree of the
    main window is refreshed automatically after each toggle.
  Sorting
    Click the heading label "Queries [A-Z ▲]" to cycle through four
    sort modes: A-Z, Z-A, Date ascending, Date descending.
Table list (right of Queries)
  Lists the distinct tables referenced by the loaded queries.
  Click a table name to filter the Queries list on that table.
  Click "(all)" to remove the table filter.
  Click the "Table ▲" heading to sort the table list.
CONTEXT MENU ON A QUERY (right-click)
Right-clicking a query row opens a context menu:
  Open
    Opens the query in a Graph window.
  → AI
    Sends the query definition to the AI Feed Stack.
  Rename…
    Renames the query.
  Save metrics to catalog
    Scans the query JSON for virtual series (metrics / combo). Every
    metric found that does not yet exist in the metrics catalog is
    created (workspace/metrics/).
    Metrics already present are skipped so that nothing is overwritten.
    A summary dialog shows how many metrics were created or skipped.
    Use it when a query contains metrics that were never explicitly saved
    to the catalog.
  Delete
    Permanently deletes the query.

RIGHT PANEL: QUERY DETAIL

Query header
  Query     Name of the selected Query.
  Owner     Owner stored in the JSON (if present).
  Table     Reference table of the Query.
  Modified  Last-modification timestamp stored in the JSON.
Series list
  Shows the series (columns) defined in the selected Query.
  For a multi-table Query, series are prefixed by their table
  (Table.series).
  Columns:
    @      Metric marker. Shown only for virtual series (non-empty
           expr_type): @ for a standard metric, ❄ for a frozen metric.
    Serie  Column or metric name.
    Axe    Axis: X for the X axis, Yl or Yr for the left/right Y axis.
           Yl/Yr is shown only for series with G (Graph) enabled.
    G      ✓ if the series is plotted in the graph view.
    T      ✓ if the series appears in the table view.
    A      ✓ if the series is active in the area view.
    Coeff  Scale coefficient applied to the series.
  Only series with at least one active flag (G, T or A) are shown,
  plus every metric whatever its state.
  Click the "Serie ▲" heading to sort the series. The X row always
  stays at the top of the list.
  Double-clicking a metric series (marker @ or ❄) opens the Combo Editor
  directly for that metric, without opening the query in a Graph window.
  Pressing Enter on a focused metric row has the same effect.
JSON viewer
  Shows the raw JSON of the selected Query. Read-only; use Open to edit
  the query through the Graph window.
  Ctrl + wheel to zoom the text.
AI Answers
  The AI exchanges of the selected query, newest first.
  They come from the query's AI Cases (AI Command Center), plus the
  older HTML answers if any remain.
  Columns:
    Date         Local date and time.
    AI profile   Profile that answered.
    Answer       Start of the answer, ⚠ + message for an error, or
                 📄 for an HTML report.
  An answer and its HTML report share one row (📄 = report available).
  Double-click (or Enter): 📄 rows open in the browser; the others open
  the AI Case Center on their Case.
  Open in browser  Same as double-click.
  Open AI Case     Opens the AI Case Center on the Case of the chosen row.
  The 🤖 icon in the query list marks queries that have an AI Case.
KEYBOARD SHORTCUTS (Queries list)
  Enter = Open · F2 = Rename · Del = Delete · double-click = Open.

VISIBILITY IN THE MAIN WINDOW

The Sel flag of the Query Catalog controls which queries appear in the
tree of the main window.
Queries with Sel = (empty) are hidden from the main window, even after a
Refresh. Only queries with Sel = ✓ are listed.
This keeps the main window readable while keeping every query in the
catalog for occasional access.
The setting is stored in params.json under the "hidden_queries" key.
