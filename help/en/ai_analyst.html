AI Connections — WysiQ

Access: AI Command Center ▸ PANELS ▸ 👤 AI Connections (Ctrl+N in the
Command Center).
The AI Connections window opens the AI Case of the query, chooses an AI
profile and connects it. Sending (JSON feeds, data, questions) is then done
in the AI Command Center: prompt, ▶ Send, >>AI Next, ⚡ Analyze graph. Each
exchange is archived automatically in the active AI Case (see AI Case Center).
Typical workflow:
  AI Case: (proposed name = query name) → Create → AI profile: → Connect
  → back to the Command Center (one tab per connected profile) → send.

CONTROLS

  AI Case:      Name of the AI Case (editable field). Clicking the displayed
                name lets you rename it.
  Create        Creates the AI Case (shared by all profiles) or reopens it if
                it already exists. An AI profile must be selected.
  Close         Closes the panel (the connection and the Case stay active;
                the Command Center can be closed or opened without cutting
                the session).
  ?             This help.
  Last req:     Tokens of the last exchange (all profiles).
  Session:      Cumulative token total of the active AI Case.
  AI profile:   AI profile to use (list of the profiles of Parameters ▸ AI).
  Connect       (enabled only when an AI Case has been created or opened)
                Connects the current profile: sends the selected protocol
                schemas and the query/Case context as a handshake. Does not
                send the analytical payload. Once connected, the button
                becomes Disconnect (the profile disconnects, the Case stays
                open, the other profiles stay active).
  AI Params     Opens Parameters ▸ AI (profiles, keys, models).
  Open Nav      Opens the HTML answer viewer.
  Connection log  Connection log (handshake, errors, tokens).

SINGLE MULTI-PROFILE AI CASE

A single AI Case groups all active AI profiles: same folder, same
history, same displayed name.
  Main profile
    The first connected profile becomes the main profile. Its questions
    (JSON AI Feed, Data AI Feed, Send) are the reference events of the
    Case, replayable on the other profiles.
  Secondary profiles
    Any profile added afterwards is secondary. When it connects, it
    automatically receives as a replay the questions already asked to the
    main profile, to produce its own answer on the same analytical feed.
    Each profile has its own tab in the Command Center.
  Switching tab (profile)
    Selecting the tab of a profile in the Command Center switches to that
    profile, its replay queue and its history; the Case does not change.

PROTOCOL

- The schemas sent by Connect are selected in AI Knowledge Setup (Send
  column). Reset (recommended) restores the 3 ★ CORE schemas (000, 001,
  002) if everything was unticked by mistake.
- The other schemas (PCA, signals, stats…) go automatically with the
  matching JSON feed of the AI Feed Stack.
PAYLOAD AND SENDING (in the Command Center)
- The feeds of the AI Feed Stack decide what the analysis JSON contains
  (graph, Area, tests, signals, correlations, PCA, scenario).
- Data samples are sent only on request; only their recipe is archived,
  never the row values — a replay regenerates a fresh sample from the
  active data.
- ▶ Send sends the prompt question to the active profile (and to the
  Broadcast targets).
  DATA INTEGRITY
  The protocol schemas require the AI to use only the data received in the
  WysiQ payloads. It must never invent, extrapolate or imagine values,
  names, amounts or identifiers absent from the payload. If a piece of data
  is missing, the AI must say so explicitly.

REPLAY

- >>AI Next (Command Center) walks through the queued steps for the active
  profile. The queue can be prepared in the AI Case Center.
- When a secondary profile is connected, the replay of the main profile's
  questions is triggered automatically.
- Only the main profile's questions are duplicated on the secondary
  profiles; those asked directly to a secondary profile remain its own.

TOKEN COUNTERS

- "Last req": tokens of the last exchange, all profiles together.
- "Session": cumulative total of the active AI Case; reset at each Create
  and Close of the Case.
- The counter under a profile's tab (Command Center) shows the tokens of
  its last request.
