AI FEED STACK — preparing the analytical blocks of the next prompt

The AI Feed Stack is the dedicated window where you assemble the analytical
blocks that go with your next AI prompt. Open it from the AI Command
Center (AI Feed Stack panel). Each feed is a compact JSON description of a
part of the active graph — never a raw data dump.

TOOLBAR

+ Add feed ▾
    Menu: Table Feed, Area (stats JSON), Area graph (PNG crop), PCA report,
    Signals, Stats / tests, Correlations, Current scenario; then Rebuild
    handshake (Feed 0) — recreates the protocol feed (useful if the Expert
    AI level changed while the Stack was closed). Select Data… only appears while Expert Studio is open (window
    no longer accessible in this version).
    The handshake (Feed 0) is created and refreshed automatically.
Empty
    Removes every feed from the Stack, except the Feed 0 handshake.
Refresh
    Reloads the list from the current basket.
Preview
    Shows or hides the preview of the selected feed (JSON, or an image for
    an Area graph feed; click the image to enlarge it). Hidden by default to
    keep the window compact. Used to check exactly what will be sent
    before spending tokens.
?
    This help.
Close
    Closes the window (the Stack is kept).
STACK LIST
    Columns: Send #, When, Kind, Name, Size. Hover: feed detail.
    Multiple selection + Del key: delete the selected feeds.
    Numbered feeds are walked through by >>AI Next in the Command Center.

SEND # COLUMN

    Left-click a cell: assigns the next number; clicking again removes the
    number.
    Right-click on Send #: "Send with step #n" joins an already assigned
    number (same group = grouped send — useful for memoryless profiles
    that must compare several Areas in a single message);
    "New step (send alone)" creates a separate step; Disable removes the
    number.
    Click the Send # heading: tick all / untick all.
    Right-click elsewhere on the row: Delete (or "Delete n feeds" with a
    multiple selection).
PROTOCOL vs STACK
    Only the three CORE schemas (000-002) go on Connect (Knowledge Setup).
    The other protocol files (PCA, signals, stats...) are sent
    automatically with the AI Feed JSON when the matching type is present
    here — for example, a Signals feed also sends the signal schemas.
    You never manage protocol files by hand; the Stack does it for you.
ORIGINAL vs CURRENT DATA
    A feed replayed from an AI Case can be sent on the data originally
    sent, or rebuilt on the current data with the same recipe (same bounds
    and shrink). Right-click the Send # column of a feed coming from an AI
    Case to switch Original data / Current data; a tooltip shows the
    current mode. Right-click the Feed column for Delete or Duplicate.
    Duplicate adds a 2nd entry in the OPPOSITE mode, to send the original
    and the current version side by side (for example to compare two
    years). Feeds added through the AI button of a window are always on
    current data and do not have this choice.
→ AI BUTTON OF THE WINDOWS (Area, Table, Signals…)
    Left-click: sends the item to the Stack according to the chosen mode.
    Right-click: "Left-click sends:" menu with the modes Area data (JSON),
    Area graph capture (PNG), Both (data + graph) (✓ = active mode), then
    "Send now (current mode)" to send immediately.
