THRESHOLDS / ALERTS

Access: Rules & params ▸ Thresholds… (graph window) or Variables Catalog
▸ Thresholds.
WINDOW BAR
  Refresh          Reloads the rules.
  Catalog          Opens the variables catalogue.
  Alerts enabled   Globally enables / disables the workspace alerts
                   (saved immediately).
  ?  / Close       This help / close.
  Create, Edit, Duplicate, Delete   Rule management (double-click a
                   rule = Edit). A rule box offers Table, Series,
                   Low, High, Mode; OK (Enter) / Cancel (Escape).
Thresholds are workspace-global rules applied to graph series.
CREATE A RULE
• Table: choose a table from the query.
• Series: choose a series from that table.
• Low: optional lower threshold.
• High: optional upper threshold.
• Mode: outside, above, below, or inside.
Low and High may contain:
• a numeric value;
• a variable reference such as &1.4;
• a calculated variable based on a formula.
VARIABLES AND SERIES
A variable formula may use a series.
[Consumption] means the Consumption series from the current table.
[RTE2023.Consumption] always means the Consumption series from table RTE2023.
If the reference series has no value for an X position, no threshold is applied to that point.
DISPLAY
Alert point styling is defined in the series Style window:
• Normal
• Below
• Above
Each state can have its own color, type, marker, size, alpha, depth, position, and Blink setting.
The alert button in the Series palette cycles through:
△  alerts off
⚠  alerts displayed
⚠• alert points only; other points remain faded for context.
In ⚠• mode, Area uses only alert instants: the series' own alert points, otherwise the alert X of a series of the same table.
CATALOG
The Catalog button opens the full workspace Variables Catalog to create or edit variables used by thresholds.
RIGHT-CLICK ON A SERIES (Series palette)
Set alert thresholds… opens the catalog in threshold mode: select one variable, then Set Low / Set High.
In a multi-table query, turning alerts on (△ ⚠ ⚠•) from one table turns them on for every table of the graph: a series without its own rule uses the rule of the same-name series of another table (active tab, then main table).
Main tab ▸ Propagate thresholds copies all rules and Below / Above styles of the main table.
Type / Marker « Inherit » in Below / Above use the series' own; size is a multiplier of the series' size (default: Inherit, size 1, Blink, orange / red).
