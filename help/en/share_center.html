SHARE & PUBLISH CENTER

Access: Main ▸ Share ▸ Share Center, Main ▸ Query ▸ Share…, Open Share
button after a 📦 Prep. At the top: Catalog opens the Share Catalog (sharing
history, Main ▸ Share ▸ History); Close closes the window.
AUTOMATED INTERFACE
The center is organised in 4 tabs: Send, Channels, Advanced and Help.
Channels detects and reuses existing settings automatically.
  • Auto configure: automatically picks a valid Telegram bot if possible,
    checks the bot and tries to detect a recent channel/group.
  • Check channels: checks Telegram, the Discord webhook and the Gallery
    folder.
  • LinkedIn, Reddit and X are marked Assisted: WysiQ prepares the text
    and opens the browser; final validation stays manual.
The Publish, Gallery/Feeds, Social drafts and Setup settings are in the
sub-tabs of Advanced. They are only needed for detailed settings.

FULL WORKFLOW — FROM DATA TO SHARING

STEP 1 — BUILD THE GRAPH
  1. Main window: select a table in the workspace tree.
  2. Click its name (or double-click the row).
     A Graph window opens with the data.
  3. Graph toolbar → Series: add series, choose the X axis, style.
  4. Graph toolbar → PLOT: run the analysis and draw the graph.
  5. Adjust zoom, pan, polar mode, legend if needed.
     The navigation controls are in the Graph remote palette
     (Toolbar → Graph button, or the floating WysiQ remote).
STEP 2 — PREPARE THE SHARE
  In the Graph remote palette, click the 📦 button (left click):
    • A popup opens with the graph title.
    • Optional: ● Rec to record a voice comment,
                ■ Stop to finish,  ▶ Play to listen,  Erase to cancel.
    • Click 📦 Prep to stage the graph.
  What Prep does:
    → Renders the graph as interactive HTML (Plotly for Cartesian,
      PNG + Panzoom for polar).
    → Saves the HTML to workspace/share/outbox/graphs/
    → If a voice comment was recorded, saves the WAV next to it.
    → Shows the "Staged in share/outbox/graphs/" confirmation:
      Open Share opens the Share Center (Send tab), OK closes.
  Right-click 📦 → quick On/Off toggle of contacts and channels
  without opening the preparation popup.
STEP 3 — SEND FROM THE OUTBOX
  In the Send tab (Outbox list):
    1. The staged file appears in the list (☐ = not selected).
       Click the row to select it (☑).
    2. Choose the Channel: Email | Telegram | Both.
    3. Recipients: all active contacts are preselected.
       Click a name to restrict to that contact only.
    4. Click Send.
  On sending:
    → Email contacts receive the HTML as an attachment
      (+ voice WAV in the same email if recorded).
    → Telegram contacts receive the HTML file through the bot
      (+ voice WAV as a separate audio message).
    → The automatic channels (Advanced ▸ Publish) run as well.
STEP 4 — THE RECIPIENT OPENS THE GRAPH
  The recipient gets an .html file.
  Opening it in any browser:
    • Cartesian graph: Plotly — hover, zoom, pan, legend, PNG export.
    • Polar graph: high-resolution PNG with touch zoom/pan (Panzoom).
  No installation required. Works on mobile and desktop.
SEND TAB (OUTBOX)
  Lists every staged file:
    share/outbox/graphs/   → graph HTML + voice WAV
    share/outbox/queries/  → Query ZIP bundles
  Click a row to select / deselect (☑ / ☐).
  Channel       Email | Telegram | Both
  Recipients    all active contacts by default;
                click a name to restrict.
  Send          sends the selected files.
  Refresh       rereads the outbox folders.
  📂 Outbox     opens the folder in the file explorer.
ADVANCED ▸ PUBLISH — AUTOMATIC CHANNELS
  These channels run automatically on every Send (not on Prep).
  Enable each channel and click Save.
  Telegram broadcast
    TG channel ID = @channel_name or numeric chat ID
    TG bot ID     = optional, replaces the default bot
    → HTML/ZIP posted to the channel (separate from sending to contacts).
  Discord webhook
    URL = https://discord.com/api/webhooks/…
    → HTML/ZIP posted as an attachment in the Discord channel.
  Gallery
    Local folder  = destination of the HTML/ZIP copies
    Public URL    = e.g. https://wysiq.org/visualizations
  RSS / JSON feeds   updated automatically on every Send.
  Social networks (semi-automatic):
    LinkedIn   → text copied to the clipboard + LinkedIn opened.
    Reddit     → title/body prepared; you submit manually.
    X/Twitter  → tweet intent opened with text and link.
  Message identity:
    Site URL      = base address in all posts
    Signature     = message footer
    Default tags  = hashtags
ADVANCED ▸ GALLERY / FEEDS
  Local folder        HTML/ZIP destination (empty = outbox/graphs)
  Public base URL     e.g. https://wysiq.org/visualizations
  RSS title / description   XML channel metadata
  JSON file name      default: wysiq_feed.json
  Generated files     outbox, feeds, drafts list. Click Refresh.
ADVANCED ▸ SOCIAL DRAFTS
  Test the templates before publishing.
  Title / URL / Insight → select the channel in Preview
  → the draft text appears; adjust before publishing.
  Copy          copies the draft to the clipboard.
  Save drafts   writes .txt files to workspace/share/drafts/.
  Open combo    opens the selected network with the text.
SHARING QUERIES (ZIP bundles)
  Main window → Query → Export query…
    → a ZIP bundle is created (table + analysis + graph settings
      + optional PNG/PPTX + voice note).
  In the export result window, click 📤 Share… to send by
  Email/Telegram.
  Or: the ZIP is copied to share/outbox/queries/ and appears
  in the Send tab for later sending.
  Recipients import it with: Query → Import query….
FOR CONTACTS, EMAIL, TELEGRAM, HTTP SERVER
AND THE SENDING LOG — see Advanced ▸ Setup ("share_params" help).
CHANNELS AND ADVANCED TABS — CONTROLS
  Channels: one row per channel with the Use box (enable / disable the
  channel); Auto configure, Check channels, Advanced… (opens the Advanced
  tab).
  Advanced ▸ Publish: automatic publication options, choice of the
  Telegram bot (↺ reloads the list), Save, Open feeds folder.
  Advanced ▸ Gallery/Feeds: gallery folder (…), Save, Refresh,
  📂 Feeds, 📂 Outbox.
  Advanced ▸ Social drafts: preview and opening of drafts, Copy,
  Save drafts.
  Frames of these tabs: Publish = "Automatic channels", "Social networks
  (semi-auto)", "Message identity"; Gallery/Feeds = "Site gallery", "RSS /
  JSON feeds", "Generated files"; Social drafts = "Draft generator",
  "Preview". Field details: "share_params" help.
  Advanced ▸ Setup: contacts, email, Telegram, HTTP server, log
  ("share_params" help).
  Help: this help (Language, A− / A+).
