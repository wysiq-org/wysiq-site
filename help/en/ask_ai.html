WysiQ — Ask AI | Help

PURPOSE
Ask AI lets you work with YOUR OWN AI assistant (ChatGPT, Claude, Gemini, Microsoft Copilot, Le Chat, DeepSeek, Perplexity, Grok, Qwen Chat or any other web assistant). No AI API key and no subscription managed by WysiQ: the assistant opens in your usual browser, where you are already logged in.
WysiQ prepares the request and the files, you send them, then you paste the answer back into WysiQ. WysiQ never drives the assistant's page: it only uses the clipboard and your browser.
Open it from Main ▸ AI ▸ Ask AI…, or the Ask AI button of a graph (Analyze Query task preselected). The API profiles stay available in AI ▸ AI Command Center (Expert).
YOUR ASSISTANTS
The first time, tick the assistants you use. Assistants… changes the list or adds another one (name and https:// address; Add another… to add several, OK to confirm). The drop-down list at the top chooses the assistant; the second one chooses the task; ? opens this help. Only the public chat address is saved, never a login, a cookie or a key.
THE FIVE TASKS
Ask AI: free exchange; you can add files.
Find Data: public sources, datasets and series by theme, country and period. The assistant lists its sources in a JSON block; Check links requests every proposed data address and shows "data" only when dated numeric values were decoded. Create connector from selected continues with the WWW connector task.
Create / Complete WWW Connector: give a link (Inspect shows what WysiQ receives: format, fields, dates) or choose one of your sites to complete. The assistant receives the WysiQ connector schema and a working example, may ask you questions, then returns the connector JSON.
Analyze Query: the series, statistics and graph of the active WysiQuery.
Full AI Feed Report: complete report from the material you select (query, statistics, tests, signals, correlations, areas, AI Feed Stack items, sources and licences, graph picture).
STEP BY STEP
1 Prepare: WysiQ builds the prompt and writes the ticked files in the AI Case. Nothing is sent.
2 Copy & open: the prompt is in the clipboard, the assistant opens in the browser and the files folder opens. Paste (Ctrl+V), attach the files, send.
3 Import answer: Paste copies the answer from the clipboard; Import answer saves it in the AI Case as an HTML report (View report) and reads its JSON block.
Continue: write your next message and Prepare again; the conversation goes on in the same AI Case. New conversation starts a new one.
WHAT IS SENT
"Sent to the assistant" lists every item; click ✓ to include or exclude it. Add file… adds a file of your choice; Refresh from WysiQ rebuilds the items from the current state. Files opens the files folder; Prompt shows the prepared prompt. Double-click a history row: open its report. Small JSON items are also copied into the prompt for assistants without file upload; larger ones must be attached. Keys, passwords and tokens are always removed. Raw data (data_sample.csv) is never ticked by default. manifest.json describes each file.
CONNECTOR PROPOSED BY THE ASSISTANT
WysiQ validates the JSON (https addresses, known formats, declared parameters) and shows the problems. Open WWW Connection opens the connectors window; JSON shows the draft. Save draft connector saves it as your own site: a catalogue site is never replaced. Test draft makes a short request; Prepare again sends the errors or the test result to the assistant with the current draft.
A proposal is never Ready: only a successful Test in WWW Connection, with dated numeric observations, makes a connection Ready.
WHERE IT IS KEPT
Every Ask AI conversation is an AI Case (qai/cases): requests, files, prompts, answers and HTML reports. Find them in AI ▸ AI Cases.
Respect the terms of use of your assistant and of the data providers.
