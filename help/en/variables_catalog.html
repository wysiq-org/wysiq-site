Variables Catalog

The Variables catalog lists the workspace constant packs, grouped
by theme (energy, finance, custom…). Use them in the numeric fields
of metrics with the compact syntax &theme_id.var_id (e.g. &1.4).
Same layout as the Tables catalog: themes on the left, variables on the right.
Opening: Metric menu → Variables…

TOOLBAR

Create / Duplicate / Delete
  Below the theme and variable lists.
Thresholds
  Opens the Thresholds window (workspace alert rules, see the
  "thresholds" help).
Set Low / Set High
  (threshold mode, opened by Set alert thresholds… in the Series palette; the
  bar shows "Alert: Table.Series — select one variable, then Set Low /
  Set High"): select a variable then Set Low; the same button
  becomes Set High for the upper threshold.
Import / Export
  Imports or exports a theme as a portable JSON file (theme and variable
  names, without workspace IDs). On import, new IDs are assigned;
  names stay stable for metrics (&energie.seuil_kwh).
Refresh
  Reloads from disk, assigns missing IDs, clears the cache.
JSON
  Shows the raw JSON of the workspace theme (with IDs).
Search theme / Search variable
  Filters the theme list and the variable grid.
Close / ?
  Close or this help.

LEFT PANEL: THEMES

Sel
  Enables the theme for &… resolution.
ID
  Numeric identifier of the theme (workspace). Used in &1.4.
Theme
  Technical name of the pack (file name, e.g. energie).
Description
  Free text.

RIGHT PANEL: DEFINITION + VARIABLES

Definition
  Theme (name), theme ID, Ref prefix (&1.), description, modification date.
Variables grid:
  Sel, Display, Style, ID, Variable (technical name), Value, Unit, Description, Ref (&1.4)
  Double-click a row to edit; F2 = rename; Del = delete.
Right-click a theme: Create variable, Rename…, Duplicate, Export theme…,
Import theme…, Delete (F2 = rename the theme).
Right-click a variable: Edit…, Style…, Toggle Display/Show, Duplicate,
Rename…, Delete.
Edit / Create box of a variable: Theme, name, Value (formula allowed;
Insert adds a series reference [Table.Series] or a variable reference), Unit,
Description; OK (Enter) confirms, Cancel (Escape) cancels.
COMPACT PICKER (while editing a metric / WHERE)
This catalog does NOT show "used in the query" — that is the role of the
compact Variables picker, opened by right-clicking a linked numeric field
(k, +/-, Min, Max, Δ, Fill, Lag, WHERE value…).
The picker shows:
  ● black if the variable is used in the open query (read-only)
  Legend for the legend text (● variables)
  Vars series with sliders
  Inline simulation (* until Save)
See the picker help (?) for details.
NUMERIC IDS (UI) vs NAMES (PERSISTENCE)
Each theme and each variable has an incremental numeric label
(unique across the whole workspace). In the UI (catalog, picker, metric fields):
  &1.4     theme id=1, variable id=4
  &1.&4    accepted form (equivalent)
  &4       variable id=4 alone, if unique in the workspace
In the metric / query JSON saved on disk, references are converted
to stable names:
  &energie.seuil_kwh
Both forms are resolved at run time. Theme import/export only
carries the names (not the IDs).

USE IN THE METRIC EDITOR

Fields k, +/- (offset), Min, Max, Δ and Fill of each component:
  • Type &1.4 directly or choose via right-click → compact picker
  • "Keep open" keeps the window open while editing
  • Simulated values (*) applied immediately; Save writes the theme JSON
On Apply/Save, the metric stores &energie.seuil_kwh (stable name).
The editor shows &1.4 again on reopening if the theme still exists.
Same principle for Lag, Size, Step (Group by X) and Free (X0).
Reference not found (theme or variable deleted) → default value of the field:
  k / transform_k = 1.0 · offset / fill = 0 · lag / size / step / free = 0.
The ref stays in the metric JSON (to be corrected or validated later).

USE IN WHERE CLAUSES

Variables can also be used in the Value fields of WHERE clauses (Table/Area
palette, series WHERE, metric composition WHERE).
Value field
  • Simple ref (&1.4) or arithmetic expression:
    &a.x + &b.y · &energie.seuil * 1.1 · (&a.min + &a.max) / 2
  • Right-click → compact picker to insert a ref.
Operators: = != < <= > >= ~ ^ $ in
Several rows: AND / OR between c1, c2, c3.
Persisted as stable names in the query JSON; the UI shows &1.4 again if the
theme exists. Changing a value here updates metrics and WHERE after refresh.

DISPLAY ON THE GRAPH / STYLE

Legend = text of the variables used in the query, in the Legend panel.
Display = only a graphic marker. Never a name, value or unit
written on the graph. The variable does not become a Series or a Metric.
Display is still possible for a constant not used in the query.
For a numeric constant, a single marker covers the whole width:
  Line : horizontal line at Y = value.
  Fill : thin horizontal band around the threshold + level line.
  Bar  : horizontal band over the WHOLE width, from Y = 0 to the threshold,
         with an outline. Size sets the outline thickness,
         Alpha the band transparency.
  Point : a single marker at the threshold level.
  Both : full line + a single marker.
An expression varying with X can draw a curve; in Bar, a single continuous
area joins the curve to zero instead of one bar per sample.
In polar mode, Line produces a circle; Bar fills the disc up to the
threshold radius over 360 degrees, without pie slices.
If the threshold is outside the visible Y range, it stays at its real value
(and becomes visible again after zooming). No label or artificial edge
line replaces it. Axes and data are unchanged.
Thresholds are rebuilt in PNG/PDF exports, without graphic text.
Style: same controls as Series, except Position: colour, Depth (z),
Type, Marker, Size, Alpha and Blink. Initial values: Z = 0,
Type = Inherit, Marker = Inherit. Normal / Below / Above are independent.
Legend, Display and styles are saved in the theme JSON.
