SCAN LOCAL LLMs (Parameters ▸ AI ▸ Profile ▸ Scan LLM…)

Find Ollama, LM Studio and other OpenAI-compatible servers on this PC or
your LAN, then create one AI profile per discovered model in one click.

WHEN TO USE THIS

  • Ollama runs on another PC (e.g. 192.168.8.101) with large models.
  • You installed several local models and want profiles without typing URLs.
  • LM Studio or a custom local OpenAI server is running on a non-default port.
Use Catalog… for a fixed offline list of known model names.
Use Discover… for cloud providers (requires API keys).
Use Scan LLM… for live detection on local/LAN machines.
SERVER TYPES (port per type)
Ollama          Default port 11434. Native /api/tags + OpenAI /v1/models.
LM Studio       Default port 1234. OpenAI-compatible local server.
Other (OpenAI-compatible)
                Default port 8000. Any OpenAI-compatible endpoint.
Tick only what you need — fewer types = faster scan.
HOSTS
List of machines to probe (this PC and LAN — same list, same ports).
  127.0.0.1 / localhost        This PC (loopback)
  192.168.x.x (This PC — LAN)  This PC's network address (added automatically)
  192.168.x.x (LAN)            Another machine on your network
Add / Rename… / Remove / Purge…
Remove     hide IP from scan, keep profiles (e.g. away from office).
Rename…    server moved (.101 → .100) — migrates profiles + host list.
Purge…     zombie IP — permanently delete all profiles for this address.
Parameters ▸ AI ▸ Profile ▸ Purge IP… does the same for a typed IP address.
Cloud URLs (api.anthropic.com, openai.com…) are rejected — they would
slow the scan and never host a local Ollama server.
On open, invalid hosts from old configs are cleaned automatically.
SCAN LAN SUBNET (slow) — "Scan LAN subnet (slow — skips 127.x)" checkbox
Optional sweep of 192.168.x.1–254 on each enabled port.
Leave unchecked when you already know the IP (much faster).
The subnet field is pre-filled from a LAN host in the list when possible.

SCAN BUTTON & PROGRESS

Click Scan. The button is disabled during the run.
A progress bar and status line show the current step, e.g.:
  Ollama @ 192.168.8.101:11434
  Subnet 192.168.8.x:11434 (48/254)
Typical scan of one LAN IP with Ollama only: a few seconds.

RESULTS TABLE

Location    This PC or LAN (+ IP)
Server      Ollama | LM Studio | Other
Model       Model id (e.g. qwen3-coder:30b)
Status      reachable / error
Click a row to check/uncheck. New models are checked by default if no
profile exists yet.

APPLY SELECTION

Creates one enabled profile per checked model.
  • Local PC  → combo label [Local Ollama] model name
  • LAN host  → combo label [LAN 192.168.8.101] model name
                profile id suffix __192_168_8_101 (one profile per model per IP)
  • Base URL and model field filled automatically.
Profiles created here have source "user" — they are never deleted by
Catalog Apply.
TIPS
  • Ensure Ollama is running on the target machine (ollama serve).
  • On Windows, allow port 11434 through the firewall for LAN access.
  • Timeout per host is ~3 s — unreachable hosts fail fast.
  • After Apply, profiles appear in Parameters ▸ AI ▸ Profile and AI Connections combo.
