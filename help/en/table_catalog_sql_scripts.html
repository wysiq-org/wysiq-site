WysiQ - Catalog: SQL scripts (technical)

The catalog separates the remote listing, the columns and the statistics.
The paths below are relative to the program folder.
1. List of remote tables:
   connexions/bundled/<connector>/list_tables.sql
2. Columns and statistics (created/modified/row_count):
   connexions/bundled/dialect_lexicon.json
   section catalog_sql (dialects of each DBMS).
3. Execution and assembly:
   connexions/catalog_sql_runner.py
   connexions/table_column_rows.py
Business definitions and Sel/Recipe belong to the JSON files of
workspace/tables/, not to the SQL scripts. WWW connectors are not
an SQL connection: their resources and parameters are in
workspace/WWW/connectors/ and their provenance in source/www_source.
L sources are managed in workspace/live/live_tables.json.
See also the Table Catalog help (?) for the codes LO, RS,
RL, WS, WL and L. There is no Static / Live switch in the catalog
(it is done by right-clicking the table in the Main window).
Legacy V objects remain readable when they exist; they are not
a data acquisition family.
