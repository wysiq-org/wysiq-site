GLOBALS — WysiQ settings

Sub-tabs: Core | Display | Output | Style | List values | Screens | Help
These settings apply to the whole workspace (params.json).
Scr2 only moves the graph — palettes and tables stay on the main screen.
Close with [X] — automatic save.
CORE
Workspace
  Root directory (WysiQuery)   WysiQ root folder (always named WysiQ).
  Browse… / New…   Open or create a workspace (New… warns if a
                   workspace already exists in the chosen folder).
  Switch           Workspace switch box:
                     Permanent — remember this workspace on next startup
                     Temporary — after quit, restore the previous workspace
                     Keep loaded tables (T MEM stays available)
                     Clear all tables — fresh DuckDB for the new workspace
  Personal settings: <user>_params.json · factory: params_ORI.json
                   Personal settings file and factory file.
  Restore defaults (ORI)…   Replaces your personal settings with those of
                   params_ORI.json ("Personal settings were restored"
                   confirmation).
  Query import: add its metrics & scenarios to workspace catalogs
                   (ticked by default) When a query is imported, its
                   metrics and scenarios are added to the workspace
                   catalogs; an identical definition is skipped.
Dates & numbers
  Date format (Min Max)    X Min / X Max fields of the Series, Area, Signal
                           palettes and windows that take a date bound.
  Date format (cursor)     Cursor bubble on the graph: date/time shown with
                           the series values.
  Date format (X axis)     X-axis ticks of the graphs. The date zoom
                           thresholds can pick a finer format depending on
                           the visible range.
  Date format (tables)     Date cells of the Table windows, Main window
                           (LAST MODIFIED, tables and queries loaded or not),
                           Area, Signal, catalogs and table previews/exports.
  Week 1st day             Mon=0 … Sun=6.
    start X axis           Weekly X-axis ticks start on that day.
    auto                   Automatic choice of weekly ticks.
  Day abbr. (Mo→Su)        Abbreviations of the 7 days (3 characters max,
                           tooltip = day name) used by the ticks and
                           Sort X ▸ Weekday.
  Unit text / Scale (x) / Decimal / Period factor
                           Default axis values of a new query (see the
                           Query tab).
  Nb digits for Exp notation  Number of digits from which values switch to
                           exponential notation.
  Decimals (default)       Table / Area decimals.
Table
  Table display rows       Maximum rows in the Table palette (number or ALL).
Help language
  Language                 Help language: EN / FR / DE / ES / IT.
  Text size                Font of the help windows (A− / A+).

DISPLAY

Plot defaults — type, render, line width, marker, alpha for new graphs.
  In polar mode, bar forms filled angular sectors of radius Y, without
  turning the data into percentages.
  Render values: line, point, both, fill, bar. "bar" draws a bar from Y=0
  up to each value, with a thickness set by Line width. "fill" fills from 0
  up to each value while keeping the thickness and colour of the line as
  outline (the per-series render stays editable in the series style popup).
Linked, transparent & large graphs — settings of overlaid graphs.
  Link delay (ms)  synchronisation delay of LINKED graphs after pan, zoom or
                   polar rotation, also used for the hold-to-repeat of
                   "<< X" / "X >>". 0 = immediate; default = 50 ms.
  Hide when transparent  what a graph hides when its background is
                   transparent (▧ button of the graph window):
                   Grid (grid, ticked by default), Legend (legend, title,
                   comment), Scale (axis values, dates, polar frame /
                   circle). Default values for all graphs; each graph can
                   have its own setting (right-click on ▧), saved in the
                   query. A change applies immediately to transparent
                   graphs.
  Keep on top (even without focus)
                   a transparent graph stays above the other windows, even
                   without focus (ticked by default). Its transparent areas
                   let you see and click what is below.
  Large graphs     Fast drawing (only the points visible on screen)
                   (ticked by default): a cloud of several thousand points
                   draws only the points visible in the view, one per screen
                   cell of the marker size. Pan, zoom and resize become
                   faster; the picture stays the same. Data, cursor, Table,
                   Area and statistics always use all the points. Untick to
                   draw every point.
Graph margins — matplotlib margins (left/right/bottom/top).
Zoom date thresholds
  Six zones according to the visible range (days): threshold, Auto switch,
  format, X ticks, X minor, else format.
  Full guide: ? button on this panel (params_zoom_display topic).
SCREENS (Scr2)
Secondary sub-tab of Globals, right of List values and just before Help.
Image capture is done with PrtScr in the graph; only window placement is
configured here.
Moves only the active graph window to a 2nd screen (HDMI, Miracast,
extended desktop). Palettes, tables, Parameters and other windows stay on
the main screen.
  Mode
    auto     First secondary monitor detected by Windows.
    monitor  Choose from the list (Refresh displays).
    custom   WxH+X+Y geometry (typed directly or with the buttons below).
  Monitor → geom — takes the size and position of the chosen monitor.
  Graph → geom   — takes the size and position of the active graph;
                   produces no image. First place the graph where wanted.
                   In Custom mode, untick "Maximise on target" to keep
                   exactly its size.
  Maximise graph on target screen
    Maximises the graph on the target.
  Refresh displays
    Rescans the screens. Windows must be in Extend mode (Win+P), not
    Duplicate only.
  Test Scr2 — tests on the active graph.
  Graph header: Screen2 button = same toggle.

OUTPUT

Export graph (format, size, Transparent bg = transparent background),
Snapshot (Footer: capture footer text), Overlay size, PPT record
(PowerPoint slides after SHOT; "Create PPT on first SHOT" creates the
presentation on the first SHOT).
PrtScr — Choose the application that automatically opens the PNG captures.
Windows default keeps the current Windows association. The list detects the
software declared PNG-compatible; Refresh updates the list, Browse… lets you
pick an .exe. The choice is saved in the settings, without changing the
Windows association or the snapshots/ folder. Right-click PrtScr always
captures the whole desktop.
STYLE
Color panel — 4×8 colour grid; More… opens the full picker,
  Reset colors restores the original palette.
Axes — Font, Style (Bold / Italic), X/Y colours and visibility;
  Reset restores the default colour of a row.
Grid line colors — major/minor X/Y grids.
UI — background, buttons, ttk theme, modern/classic style.

LIST VALUES

Polar step menus (CSV) — polar X / X360 steps (1y, 7d, 1h …).
Sort X — CSV modes for X sorting (raw, dow, dom, month, year …).
Saved globally in params.json.
  Display first row: Link (ms) = Link delay, Zoom (%) = Zoom step, Pan (%) = Pan step, Arrows (ms) = Arrow repeat.
  Display > Linked & transparent graphs: Link delay (ms) controls LINKED graph synchronization latency (0 = immediate, default 50 ms);
  Zoom step (%) sets the Graph Remote keyboard zoom step (default 6%, range 1–50%), independently of Link delay;
  Arrow repeat (ms) (default 30 ms, range 15-250 ms) repeats Pan/Zoom arrows and POLAR << X / X >> immediately on press, separately from Link delay;
  Pan step (%) (default 2%, range 1–20%) sets each Pan arrow's movement distance;
