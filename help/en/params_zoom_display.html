ZOOM DATE THRESHOLDS (Globals → Display)

Controls how the datetime X axis labels and tick density change when you
zoom or pan. Units for thresholds and Auto switch are always in DAYS.
HOW ZONES WORK
Six rows (Zoom 1 … Zoom 6). The visible span picks the first zone where:
  span ≥ that row's threshold
  (and below the next higher zone's threshold)
Example defaults:
  Zoom 1  ≥ 365 d     ~ year view
  Zoom 2  ≥ 30 d      ~ month view
  Zoom 3  ≥ 1 d       ~ day view
  Zoom 4  ≥ 1/24      ~ 1 hour   (0.041667 d)
  Zoom 5  ≥ 1/1440    ~ 1 minute (0.000694 d)
  Zoom 6  ≥ 1/86400   ~ 1 second (≈ 0.000012 d)
  else    < Zoom 6    sub-second

COLUMNS

threshold
  Breakpoint in days. Enter fractions for sub-day (1 h ≈ 0.041667).
Auto switch
  Still in days. Inside the CURRENT zone only: if the visible span is
  SMALLER than this value, densify locators (hours / minutes) — format,
  X ticks and X minor stay those of THIS row (not Zoom 4/5/6).
  0 = off.
  Examples with defaults:
    Zoom 3 Auto switch = 3.0 → view < 3 days → hourly-style ticks
    Zoom 4 Auto switch = 0.5 → view < 12 h  → finer ticks
format
  strftime for X labels in that zone (always the zone selected by span).
  auto = use Core → Date format (X axis).
  For hours while still in Zoom 3, set an explicit format (e.g. %d/%m %H)
  — do not leave "auto" if Core has no hour component.
  Possible patterns are the same date formats offered on the Core tab
  (and free adaptations of those codes). See Globals / Settings help
  for the full strftime reference.
  Typical: %d/%m %H:%M (hours), %H:%M (minutes), %H:%M:%S (seconds).
X ticks
  Target number of MAJOR ticks for that zone.
  0 = use Series palette "Tick X".
  Prefer ~10–12 so labels stay readable and land on round clock values
  (00:00, whole hours). Do not leave 0 if Tick X is high (e.g. 24):
  zoom would inherit that density and crowd the axis.
X minor
  Subdivisions BETWEEN major ticks (minor grid).
  0 = use Series palette "Tx".
  7 = week mode on wide views (Monday majors + daily minor grid).
  When zoomed to ≤ ~4 weeks (or denser than 7 days/tick), labels switch
  automatically to every weekday (Mon–Sun) even if X minor = 7 — available
  space wins.
  Ex. Zoom 3 → 12 ; Zoom 4 → 12 ; Zoom 5 → 6 ; Zoom 6 → 4
else format
  Format when span is below Zoom 6 (e.g. %H:%M:%S.%f).
CLOCK ALIGNMENT
Majors are placed on calendar / clock boundaries (midnight, whole hours,
round minutes), not on arbitrary linspace offsets like :16 or 04:51.
SERIES PALETTE vs THESE PARAMS
On zoom, Zoom X ticks / X minor override Series Tick X / Tx when > 0.
Home (non-zoomed) year views may still follow Series + week settings.
TIPS
  • Your active settings live in {user}_params.json (workspace root).
  • To share the same zoom thresholds with other users of this
    workspace, copy your zoom values into params_ORI.json — they
    become the Restore defaults (ORI) baseline for everyone.
