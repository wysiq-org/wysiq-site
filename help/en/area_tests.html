AREA — STATISTICAL TESTS (panel moved)

Important
The tests panel formerly embedded in the Area palette has been removed. The
statistical tests (Pearson, Spearman, t-test, Wilcoxon, ANOVA, Kruskal,
Tukey, Dunn…) are now run in the dedicated Statistical Tests window,
opened from the toolbar. See the stats_tests_window help for the full
documentation.
The same statistics also reach the AI Analyst JSON automatically: the
test engine (stats/tests_engine.py) is reused directly, without an
embedded interface.
What remains in the Area palette
The Area palette keeps the computation of selection statistics on the
rectangle (nb, sum, avg, min, max, Range, and the extended columns σ, NA,
IQR, MAD, skew, kurt through the Stats toggle, plus percentiles through Pct).
See the area_palette help.
Data scope
The tests apply to the series whose A toggle = ON in the Series palette.
In the Statistical Tests window, the scope (Area rectangle or full
series) and the matching of X values according to the tolerance are
managed from that window.
Reminder of the available tests (Statistical Tests window)
Pairwise:
  Pearson r     Linear correlation + two-tailed p-value.
  Spearman r    Rank correlation + p-value.
  t-test        Paired t-test on aligned X (SciPy required).
  Wilcoxon      Wilcoxon signed-rank (paired, non-parametric).
  MAE / RMSE    Deviation errors (no p-value).
  Cohen d       Effect size of the paired difference (no p-value).
Group (≥ 3 A series):
  Levene / Bartlett   Equality of variances.
  ANOVA (one-way)     Parametric test of equal means.
  Kruskal             Non-parametric alternative to ANOVA.
  Tukey HSD           Pairwise post-hoc (statsmodels required).
  Dunn                Non-parametric post-hoc (scikit-posthocs required).
Multiple-testing correction: BH (Benjamini–Hochberg, FDR, default),
Holm (Holm–Bonferroni), Bonf (Bonferroni, the most conservative).
Dependencies
• Basic tests (Pearson, MAE, RMSE, Cohen d): NumPy only.
• Parametric tests (t-test, Wilcoxon, ANOVA…): SciPy required.
• Tukey HSD: statsmodels required.
• Dunn: scikit-posthocs required.
A missing package produces an explanatory information row.
