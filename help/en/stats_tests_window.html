STATISTICAL TESTS — Help (Statistical Tests window)

Access: Tests button in the Graph window header (between Area and
Signals), or the Te dot in the Graph Remote. Both open the same Statistical
Tests window for the current graph, separate from the Area palette.

1. PURPOSE

Statistical workbench for the numeric series of the current graph:
- pair tests (series A and B),
- multi-series tests (G selection, Group box),
- time-series diagnostics (each ticked series).
Typical process:
  Selection (Area or All) → tick A / B / G in the series list →
  choose the tests (Quick tests, themes, boxes) → Run (or Auto insight)
  → read / sort the results → Export or → AI.
1.1 Data frame
- Selection: Area (points of the Area rectangle) or All (all the data).
- Refresh: re-reads the list of the graph's series.
- Clear: unticks all the series.
- Series / A / B / G list: click on a box to tick it; click on the A, B or
  G header to tick / untick the whole column; click on the Series header to
  sort.
1.2 Test selection frame
- p-adjust: BH, Holm or Bonf (see §4).
- Quick tests: ticks the quick tests (slow tests are excluded, §9);
  unticked = untick everything.
- Group: enables the multi-series tests (restores the default quick group
  tests); unticked = group tests disabled.
- Theme on / Theme off: ticks or unticks all the tests of the theme chosen
  in "Themes / subgroups".
- All on / Clear: all tests ticked / none.
- The detail area describes the selected theme or test; one box per test.
1.3 Results bar
- Run: runs the ticked tests (waiting window during the computation).
- Auto insight: runs the same tests and adds an interpreted summary.
- Best corr: opens the Find Best Correlation window (help
  "stats_best_correlation_window").
- Clear: empties the results.
- Export: saves the results as .xlsx or .txt.
- → AI: sends the results (without raw data) to the AI Feed Stack.
- Params: opens Parameters ▸ Statistics (test notebooks, help
  "stats_notebooks").
- ?: this help.
- Table: click on a header to sort; Ctrl+C copies the selected rows.
- The settings (selection, tests, p-adjust, decimals) are saved with the
  query.

2. DATA SELECTION

2.1 Scope = Area
- uses only points remaining inside the stored area / rectangle filter.
- if the area is empty, no usable series is returned.
2.2 Scope = All
- uses the full available data range;
- series eligibility still depends on the series list exposed by the
  graph context.
2.3 Cleaning and alignment
- values are converted to float;
- NaN / +inf / -inf are removed;
- paired tests align A and B to the same usable length;
- the displayed n is the effective usable sample size after filtering
  and alignment.

3. UI DEFAULTS

Default values on open:
- Scope: Area
- p-adjust: BH
- Decimals: 3
- max lag sent to the engine: 30
Quick tests:
- intended for rapid exploration;
- slow tests are intentionally excluded from the quick preset.

4. P-VALUE ADJUSTMENT

Applied to all numeric p-values returned by the run.
Available methods:
- BH   = Benjamini-Hochberg FDR control
- Holm = step-down family-wise adjustment
- Bonf = Bonferroni correction
If a test does not produce a p-value, p_adj stays blank.

5. ANNOTATIONS USED IN THE NOTE FIELD

5.1 p_note(p, n)
- p <= 0.05 -> Significant
- p > 0.05  -> Not significant
- if n >= 1000, suffix: "large sample"
5.2 effect_strength(d)
- |d| >= 0.8 -> Large
- |d| >= 0.5 -> Medium
- |d| >= 0.2 -> Small
- otherwise   -> Negligible
5.3 eta_strength(eta²)
- >= 0.14 -> Large
- >= 0.06 -> Medium
- >= 0.01 -> Small
- otherwise -> Negligible
5.4 dw_note(dw)
- dw < 1.0  -> Strong positive autocorr
- dw < 1.5  -> Positive autocorr
- 1.5..2.5  -> No autocorr (OK)
- 2.5..3.0  -> Negative autocorr
- > 3.0     -> Strong negative autocorr

6. PAIR TESTS (A/B)

6.1 Pearson
- linear correlation coefficient r in [-1, 1]
- SciPy pearsonr when available, otherwise NumPy corrcoef fallback
6.2 Spearman
- rank-based monotonic correlation
- robust to monotonic non-linearity and outliers
6.3 Kendall
- concordance measure on ranks
- often useful on short samples or many ties
6.4 Linear regression
- model: y ~= intercept + slope * x
- displayed stat = r
- effect = r²
- note also contains slope, intercept, stderr when available, and
  adjusted R²
6.5 t-test paired
- paired mean comparison on aligned A/B values
6.6 t-test independent
- classical independent-sample t-test
6.7 Welch t-test
- independent-sample t-test without equal-variance assumption
6.8 Wilcoxon
- non-parametric paired comparison
6.9 Mann-Whitney
- non-parametric independent comparison
6.10 Cohen d
- pooled effect size for independent groups
- formula:
  d = (mean(A) - mean(B)) / pooled_sd
6.11 Cohen d paired
- paired effect size on differences
- formula:
  d = mean(A - B) / sd(A - B)
6.12 Best lag
- scans integer lags in [-max_lag, +max_lag]
- returns the lag with the strongest absolute Pearson relation
- note includes best lag and number of scanned lags
6.13 Variation corr
- correlation on first differences: diff(A), diff(B)
- useful when raw levels drift but local co-movements matter
- WysiQ computes both:
  - Variation Pearson
  - Variation Spearman
6.14 Partial corr
- correlation between A and B while controlling a 3rd selected series
- requires at least 3 selected series
- formula:
  r_xy.z = (r_xy - r_xz*r_yz) / sqrt((1-r_xz²)(1-r_yz²))
6.15 Chi2 contingency
- A and B are automatically binned into a contingency table
- chi-square independence test is then applied
- note contains number of bins and degrees of freedom
6.16 Distance corr (dCor)
- detects linear and non-linear dependence
- exact implementation is O(n²)
- stat = distance correlation
- note reminds the qualitative meaning
6.17 Mutual information
- histogram-based dependency measure
- captures non-linear relations even when Pearson is near zero
- stat = MI in nats
- effect = normalized MI (when entropies are positive)
- note contains bin count and normalized MI
6.18 Rolling corr
- rolling-window Pearson correlation between A and B
- stat   = mean rolling correlation across windows
- effect = strongest absolute rolling correlation observed
- n      = number of windows used
- note contains window size, number of windows, best absolute rolling
  corr, last rolling corr
6.19 Granger causality
- lagged predictability screening, reported in both directions:
  - A -> B
  - B -> A
- stat   = best F statistic found across scanned lags
- p      = corresponding F-test p-value when SciPy is available
- effect = relative SSE improvement of unrestricted vs restricted model
- note   = best lag
- interpretation: this is predictive lead/lag evidence, not proof of
  real-world causality
6.20 Durbin-Watson
- applied on residuals of the A/B linear regression
- formula:
  DW = sum((e_t - e_{t-1})²) / sum(e_t²)
- target value around 2

7. GROUP / MULTI-SERIES TESTS (G)

7.1 Shapiro
- normality test per selected series
- if a series has more than 5000 points, WysiQ samples 5000 values
  with fixed RNG seed 42
- note states the sampling when this happens
7.2 Anderson-Darling
- normality test with critical values
- note contains the reference significance level and critical value used
7.3 Jarque-Bera
- normality from skewness and kurtosis
- formula:
  JB = n/6 * (S² + (K-3)²/4)
- note contains skewness and excess kurtosis
7.4 Levene
- variance homogeneity test, relatively robust to non-normality
7.5 Bartlett
- variance homogeneity test under stronger normality assumptions
7.6 ANOVA
- one-way parametric multi-group test
- effect = eta² computed from between-group vs total sum of squares
7.7 Kruskal-Wallis
- non-parametric alternative to ANOVA
7.8 Friedman
- repeated-measures non-parametric comparison
- WysiQ truncates all groups to the shortest usable length
- note explicitly states the truncation
7.9 KS 2-sample
- distribution equality test between A and B style samples
- for group runs, this is still driven by the selected series values
  used by the engine
- note: H0 = same distribution

8. TIME-SERIES TESTS ON INDIVIDUAL SERIES

8.1 ACF
- autocorrelation function for lags 1..min(20, max_lag)
- stat = strongest absolute autocorrelation found
- p    = approximate normal p-value when available
- effect = best lag
- n    = number of lags evaluated
- note contains IC95 and significant lags
8.2 Mann-Kendall
- monotonic trend test
- stat = z-score
- note contains S and the trend direction
8.3 ADF stationarity
- minimal Augmented Dickey-Fuller style regression
- H0: unit root / non-stationary
- stat = t statistic of the lagged level term
- p    = two-sided t approximation when SciPy is available
- note contains the lag used
8.4 KPSS stationarity
- KPSS level-stationarity test
- H0: stationary
- stat = KPSS statistic
- p    = approximate p-value from common KPSS critical values
- note contains the Newey-West lag used
- practical use: complementary to ADF
8.5 Change point
- scans one split point across the series
- stat   = strongest standardized mean shift
- p      = Welch-like split p-value when available
- effect = split index
- note   = left and right segment means
- this is a screening indicator for a single dominant break, not a full
  segmentation framework

9. SLOW TESTS

WysiQ flags these tests as slow and excludes them from Quick tests:
- Best lag
- Partial corr
- Chi2 contingency
- Distance corr
- Rolling corr
- Mutual information
- Granger causality
- Change point
Main reason:
- repeated lag scans;
- O(n²) distance-style computations;
- repeated regressions;
- many split candidates.

10. LIMITS AND AUDIT NOTES

- correlation is not causation;
- Granger is predictive, not structural causality;
- ADF and KPSS are simplified in-software implementations, not a full
  econometric package replacement;
- mutual information depends on automatic binning;
- change-point screening assumes one dominant split;
- group tests can compare series of different meanings if the user
  selects heterogeneous signals;
- all results depend on the currently filtered and cleaned data only.

11. REPRODUCIBILITY

Results are deterministic for the same:
- input data,
- scope,
- selected series,
- selected tests,
- p-adjust setting,
- max lag.
The only explicit sampling rule is Shapiro > 5000, which still stays
  reproducible because WysiQ uses a fixed RNG seed.
Open tests from the Tests button in Graph or the Te dot in Graph Remote.
