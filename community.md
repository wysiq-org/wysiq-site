# Open Collaboration

WysiQ embraces the open-source ecosystem rather than rebuilding it.

Instead of asking users to create yet another account, WysiQ uses GitHub as its primary collaboration platform.

GitHub provides Releases, download statistics, version history, issue tracking, discussions, documentation, examples and community contributions.

The official website, **wysiq.org**, complements GitHub with White Papers, short training videos, product news, Enterprise information and showcase demonstrations.

**GitHub is the home of the WysiQ community.**

**wysiq.org is the showcase of the WysiQ vision.**
