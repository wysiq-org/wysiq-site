WysiQuery

A WysiQuery (.wysiq) is not simply a project file.

It is a portable JSON description of an analytical workspace.

It may store selected datasets, graph configuration, metrics, areas, signals, scenarios, tests, display settings and analytical context.

The format is lightweight, human-readable, version-friendly and Git-friendly.
