# Metric Composer

Metric Composer is a central part of WysiQ.

Metrics are reusable analytical objects that enrich the Graph Workspace.

Metrics can be aggregations, moving averages, ratios, differences, shifted series, grouped computations, cross-table metrics, PCA-derived metrics or scenario metrics.

A metric can become a new series in the graph and a new component of the internal analytical table.

Metrics are stored in WysiQueries and can be exchanged between queries and workspaces through the Metric Catalog.
