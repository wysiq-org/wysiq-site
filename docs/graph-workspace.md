# Graph Workspace

The Graph Workspace is the Data Oscilloscope.

It is not a dashboard and not a static report.

It is an interactive analytical construction workspace.

The graph is where the analyst observes, zooms, pans, compares, overlays, aligns, shifts, measures, selects, derives and validates.

## Graph-generated analytical knowledge

The Graph Workspace can create:

- metrics
- areas
- signals
- scenarios
- PCA series
- tests
- statistical outputs
- overlays
- snapshots
- presentations

## Internal analytical table

When a graph is built, WysiQ constructs an internal table representing the graph workspace.

This table can combine series from multiple sources, align them on a common X axis, apply offsets, shrink volumes, add derived metrics, include PCA series and keep analytical selections.

In Community Edition, this internal analytical table supports visual exploration, AI Sessions, WysiQueries and sharing.

In Enterprise Edition, it can also be published as an analytical dataset back into enterprise databases, Business Intelligence platforms and enterprise information systems.
