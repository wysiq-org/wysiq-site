# Data Studio

Data Studio prepares heterogeneous multi-source data before it enters the Graph Workspace.

It replaces the older idea of a simple SQL Assistant.

SQL is one of the tools, but the purpose is broader: create prepared analytical tables and views from files, local data and, in Enterprise Edition, enterprise data sources.

## Sources

Community Edition:

- CSV
- Excel
- local files
- local DuckDB data

Enterprise Edition adds:

- enterprise databases
- enterprise applications
- ODBC-compatible sources
- business data platforms

## Operations

Data Studio can be used to:

- create local analytical tables
- create views
- build joins
- build unions
- transform column formats
- normalize dates
- create calculated columns
- reduce data volumes with Shrink
- save preparation recipes
