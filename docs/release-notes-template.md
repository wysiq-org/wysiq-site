# WysiQ Enterprise v1.1.138-beta

First public beta release of WysiQ Enterprise.

## Download

- Single self-contained Windows executable
- No installation required
- Beta expires: **2026-09-01**

## Included

- WysiQ Desktop
- Embedded multilingual help
- Default configuration files
- Default AI profiles
- Workspace templates

## Requirements

- Windows 10 or Windows 11
- 64-bit

An Internet connection is only required when using AI providers.

## Documentation

User help is embedded in WysiQ and copied into each workspace at first launch.

For product information, White Paper and training videos, visit https://wysiq.org
